01研究愿景 / VISION

今天的智能，常常困在此刻。
我们想给它一条连续的时间线。

真正的学习不只发生在训练结束之前。它也应该发生在每一次观察、每一个选择、每一个结果之后，让新的经验成为下一步决策的一部分。

态极探索如何让内部状态跨越交互延续，如何从行动后果中学习，并在保留已有能力的同时获得新技能。这不是一次无依据的能力承诺，而是一条正在被实现与验证的研究路线。

02 · COGNITIVE ARCHITECTURE

一个闭环，
而非一串孤立模块。

认知不是单向流水线。观察改变状态，记忆提供上下文，推理形成选择，行动带来新反馈——循环由此继续。点击左侧，查看每个环节。

PERCEPTION & STATE

把新的观察，放进正在延续的内部状态。

感知并不只是提取一次性特征。新的输入会与已有状态相遇，修订对当前情境与世界的认识，让下一次理解拥有历史，而非从零开始。

INPUT环境观察
→
ENCODE感知表征
→
UPDATE内部状态
目标：在多次交互之间延续知识与内部状态。
MEMORY SYSTEM

记住经历，也提取经历背后的知识。

不同记忆承担不同职责：工作记忆维持当前任务，情景记忆保存经历，语义记忆提炼共同知识，程序记忆积累技能。它们协作，而非堆叠成同一个信息仓库。

STORE保存经历
→
RETRIEVE按线索取回
→
CONSOLIDATE巩固与提取
目标：让经验在需要时可用，而不只是被存储。
REASONING & PLANNING

按任务、不确定性与资源，选择计算路径。

具有不同表征和学习规则的组件共同处理问题。推理不止给出一个答案，还要结合目标、状态和可用资源形成行动路径，并在新信息出现时修订计划。

CONTEXT状态与记忆
→
PLAN候选路径
→
SELECT行动选择
目标：专门化协作，让计算投入与任务需要匹配。
ACTION & LEARNING

让行动的后果，真正回到学习之中。

语言、工具和环境交互连接到可观察的结果。反馈不止用于评价一次输出，也用于影响后续状态与决策，使系统在真实后果中积累能力。

ACT工具与环境
→
FEEDBACK观察结果
→
LEARN更新后续决策
目标：通过学习、重放、巩固与结构适应实现长期发展。

03 · MEMORY, IN FOUR VOICES

记忆不是一种能力，
而是四种不同的分工。

从眼前任务到长期技能，每种记忆都有自己的时间尺度与用途。它们共同支撑一个更连续、更能从经验中受益的系统。

01 / NOW

工作记忆

维持当前任务与正在使用的信息，让思考拥有清晰的此刻。

Working memory
02 / EXPERIENCE

情景记忆

保存经历过的事件与上下文，使过去可以被重新取回。

Episodic memory
03 / KNOWLEDGE

语义记忆

从多次经历中提取共同知识，形成可迁移的理解。

Semantic memory
04 / SKILL

程序记忆

把反复实践沉淀为技能，让学会的行为能够持续保留。

Procedural memory

05 · HONEST BY DESIGN

研究原型，
而非完成时。

清晰的边界不是退让，而是可靠研究的起点。Seed 将架构目标、当前实现与实验结论分开描述。

  1. 01
    当前是可运行的研究基础

    实现包含实验内核和限定范围的原型，不等同于完整通用认知系统。

  2. 02
    长期发展仍是研究目标

    保留旧能力并获得新技能的方向，需要持续的实验实现与验证。

  3. 03
    能力表述以证据为准

    小型学习示例展示具体接口，不能据此推断通用语言理解能力。

06 · BEGIN WITH SEED

从一次学习开始，
观察智能如何延续。

通过一个最小 Python 示例，体验字节学习与 checkpoint 恢复。每一个宏大的认知目标，都从可运行、可检查的一步开始。

quick_start.py
from seed import Seed

model = Seed()
model.learn_bytes(b"abcdabcdabcdabcd", epochs=200)
checkpoint = model.checkpoint()
restored = Seed.from_checkpoint(checkpoint)
print(restored.generate(b"a", length=8))

需要 Python 3.12+。这是字节学习接口的研究示例，不代表通用语言理解能力。
