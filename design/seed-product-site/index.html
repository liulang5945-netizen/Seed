STEP 01 / PURE UTF-8 BYTE & MACRO VOCAB

纯 UTF-8 字节基元，以及可中性生长的宏词表

全面移除 BPE 与固定词表限制：0–255 直入原始 UTF-8 字节，256–258 为流边界与填充符；3 层严格因果卷积（dilation=1,2,4）构成本地字节特征，并支持通过 DynamicByteVocab 无损中性挂接新宏词元。

# BYTE_VOCAB = 259 (0..255 raw bytes, EOS/BOS/PAD)
# 3-layer causal Conv1d (k=3, d=1/2/4) -> 8-byte patch
a_byte, e_patch = self.encoder(byte_ids)
# Lossless dynamic macro birth (0.0 perturbation):
model.grow_macro_symbol_neutral_(b'\xe5\x8e\x9f\xe7\x94\x9f')

原生推理
TaijiNativeRuntime.observe_and_respond → BytePatchEncoder → StatefulNeuralGroup (bmm) → utf8_mask

跨窗传递持久化主体内态 (H, z, a, F)；携带外部记录时启用 U2 §7 位置敏感复制头并支持单条撤销。

影子生长
NativeGrowthController → mark_all_mature_ → grow_stateful_units_svd_neutral_ → OutcomeRouter

先冻结成熟老单元再在隔离沙盒出生新单元，经保持率与净增益双门验证后原子提交并迁移 AdamW 动量。

外部台账
ActionLifecycleLedger (9 states) → ConditionalValueHead → OutcomeRouter (5 planes)

隔离内部想象、自生成信号与外部真实收据；支持 4 边界断电恢复，禁止对已发生世界事实做伪回滚。

02研究愿景 / VISION

今天的智能，常常困在此刻。
我们想给它一条连续的时间线。

真正的学习不只发生在训练结束之前。它也应该发生在每一次观察、每一个选择、每一个结果之后，让新的经验成为下一步决策的一部分。

态极探索如何让内部状态跨越交互延续，如何从行动后果中学习，并在保留已有能力的同时获得新技能。这不是一次无依据的能力承诺，而是一条正在被实现与验证的研究路线。

Semantic memory

06 · HONEST BY DESIGN

研究原型，
而非完成时。

清晰的边界不是退让，而是可靠研究的起点。Seed 将架构目标、当前实现与实验结论分开描述。

  1. 01
    有界闭环已验证，不外推为通用智能

    N31–N37 仅在封闭词表、两族合成物理与百会话耐久范围内完成 0 check / 0 final 签署；N38 开放中文纯字节预训练仍在进行中。

  2. 02
    工程原型调度 ≠ 主体内学得自主

    启发式触发器均显式标注 engineering_prototype；主体内自发学得策略（VX5）需要后续真实表征与结果反馈联合训练验证。

  3. 03
    严格保持 CR-1 与世界事实不可逆

    台账禁止假回滚已执行的外部世界动作，结果路由器阻断虚构/自生成反馈，所有能力表述以实际源码与可复现读数为准。

07 · BEGIN WITH SEED

从原生纯字节开始，
观察智能如何延续。

通过 TaijiNativeRuntime 体验纯 UTF-8 字节响应、SVD 中性生长与跨重启持久恢复（早期 seed.Seed TSK-v8 字节示例见仓库 README）。

native_quick_start.py
from taiji.native_cognitive_backbone import NATIVE_PRESETS
from taiji.native_runtime import TaijiNativeRuntime

rt = TaijiNativeRuntime.from_preset(NATIVE_PRESETS["native_byte_tiny"])
out = rt.observe_and_respond("今天我们一起", max_new_bytes=24)
rt.backbone.grow_stateful_units_svd_neutral_(group_idx=0, budget=8)
rt.save("native_runtime.pt")
restored = TaijiNativeRuntime.load("native_runtime.pt")

需要 Python 3.12+ 与 PyTorch。上述示例展示原生接口与中性生长能力，不构成开放对话能力签署。
