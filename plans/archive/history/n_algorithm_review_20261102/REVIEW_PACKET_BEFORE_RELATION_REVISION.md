## 1. 三条路线

### 路线甲：在现底座上换读的结构（把"选择"当成可学生成的对象）

- **前提**：读通路选不出记录，是因为选择没有被建成一个可学习的对象（key 匹配／打分头都在同一张 tanh-MLP 里被平均掉）。
- **支持它的证据**：D1 仍在场（换描述词确实移动查询与注意力：槽 0.001072、注意力 L1 0.021845）；10.21a-2 rev2 的方差分解显示，同样两个描述词在**单行**词表下能分到 **51.40%** 方差，在**五行**表下只剩 **0.40%** ⇒ 衰减发生在"多行竞争"这一环，不是查询编码坏掉。
- **反对它的证据**：D3 的 0.1362 与 10.21.4 的 0.1125。若值侧本身就带不出映射，换选择机制也无处安放选对的结果。
- **第一包草案**（四件套）：范围＝只测"给定正确选择，下游能否把答案算对"（oracle-conditioned 上界），**不含任何梯度**；数据＝10.21 夹具 dev 面（`fixture_digest cee43f9c…`），confirm 面继续封存；预算＝≤60 CPU 秒（按 0.034 秒／次读、约 800 次读的上界计，含 30 秒 reserve）；出口＝`oracle_reachable`／`oracle_unreachable`／`budget_stop`／`engineering_failure`。**这一包先于任何再训练**，因为它能把"值侧不可达"这条结论本身否证掉。

### 路线乙：另立基础机制研究合同（跨会话经验、反馈更新、无提示选择）

- **前提**：这三项是目标里的独立能力，不必等组合泛化先成立（03 §规划修正已开放此路径）。
- **支持**：仪器面已齐——身份／谱系绑定（11.1a）、快照往返与硬退续跑逐位一致（11.2b／11.4c）、约束式反馈更新的工程门（R022–R027）、活动与生长的六出口闭环（09.8）。**缺的从来不是能不能存，而是"经验有没有改变后续行为"没有正读数**。
- **反对／空白**：11.3a 固定答案套件地板 **0/5**、11.3c 信度不可分（top 概率区间重叠、熵 5.496 对均匀 5.549 ⇒ 无阈值可分）。任何"求助／弃答"判据在这把尺上今天都读不出差别。
- **第一包草案**：主问题只留一个——同一身份、同一连续状态下，**一次可核验的纠错经验能否降低同类任务的后续错误率**；数据＝合成任务＋已有语料权利内，不读 sealed；预算＝先做 pilot 定价（≤30 CPU 秒），总包 ≤600 CPU 秒（对照 08.3 已测单价 9.148 CPU 秒／更新，包内更新次数上限由 pilot 实测决定，不预设）；出口＝`experience_transfers`／`no_transfer`／`ruler_not_resolved`（信度尺不可分就记第三条，不许换次要指标）。

### 路线丙：收束为工程结论，不再追加能力声称

- **前提**：在 3.3M 参数、冻结编码、合成夹具与这个数据量下，"输入条件化的组合读出"与"自身机制承担决策"不可达；继续花配额是重复已被排除的变量。
- **代价**：目标里的决策／表达／经验三项将长期停在 ✗，仓库交付物变成"仪器＋负结论＋可追溯成本"。
- **第一包草案**：不包（只补 05 台账与 13.7 总账的引用完整性）。
