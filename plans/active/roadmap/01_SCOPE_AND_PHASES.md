## 1. 三层路线与编号

| 层 | 回答的问题 | 编号与维护 |

| 能力轴 | 哪项能力在什么范围得到认可？ | 持续学习、知识内化、协作、身体、产品等；每轴独立证据/批准 |

## 2. M0～M8 总阶段账本

| 阶段 | 职责与继承状态 | 剩余必达项 / 退出条件 | 进入下阶段的关系 |
|---|---|---|---|
| M0 基础真实性 | 历史基础测量与 checkpoint 基线已完成限定范围 | 继承报告；能力或 owner 改变时做相关回归，不重跑全部历史 | 作为所有后续阶段底座 |
| M1 基础训练 | 历史 foundation/局部学习基线可继承，不代表通用语言 | 数据、模型、恢复与能力边界有明确摘要；新增规模属于新验收 | 已支持 M2，不因后续负结果整体撤销 |
| M2 可信训练与测量 | 当前范围已有 owner/data/read-only score/fresh restore 证据 | 新训练仍需隔离、无泄漏、可继续恢复和目标一致；不授予开放域能力 | 支撑 M3～M5，按变更检查 |
| M3 Workbench 因果边界 | R0～R5 与真实合同已有窄证据，后续 P5.2a 接预测执行 | 新范围内预测来源、权限、真实 outcome、恢复、保持全闭合；未经批准不扩大真实写入 | 合同资产供 M5 使用；泛化失败归回相应能力，不撤销合同资产 |
| M4 / M4.V2 持续发展与结构成长 | v1 路线已归档；继承/保持机制有证据，K 轴限定晋级已获批准 | **结构成长未完成**：若声称成长，需真实压力、同最终容量对照、出生/贡献 lesion、保持、资源及恢复；开放域长期发展仍待验 | 当前 M5 工作已经发生，不恢复过时的全面冻结；允许限定范围前进，不等于 M4 整体退出 |
| M5 知识与身体 | 当前主研究阶段；K 轴限定晋级，知识 trial、执行及协作各有部分证据 | 知识、协作/选择、在线更新、身体执行四轴逐项结项；见 §3。全部必达项通过或经独立范围决策明确排除后，才可评审 M5 限定阶段退出 | 退出清单驱动 M6；不以单个 K 或 H2 Gate 代替 |

| M7 CI 与发布 | 每步持续检查，正式发布尚不能由局部测试推断 | 实际发布 workflow 通过；代码/数据/model/package manifest 对齐；安装启动、回滚、安全和发行包验收 | 满足并批准后才能声明发布就绪，不以“零新增”代替绿 CI |

## 4. 长期目标不可从地图消失

| 核心需求 | 主责位置 | 不可偷换的完成含义 |
|---|---|---|
| CR-1 唯一主体 | M0/M2 + 全阶段 | 外部 provider/仪器不成为隐藏认知 owner |
| CR-2/3 异质协作与激活 | M5 协作轴，M4 长期发展 | 选择与真实协作收益有因果证据，不只模块存在 |
| CR-4 开放式成长 | M4.V2 | 未触发不等于通过，不因 K 晋级取消 |
| CR-5 身体闭环 | M3/M5/M6 | 真实执行、反馈、权限和恢复，不只动作预测 |
| CR-6/7 生命调节、睡眠/梦境/玩耍 | M4 持续发展，M5 在线学习 | 既有模块/窄 Gate 单列证据，长期机制收益仍须对应验收 |
| CR-8 多系统记忆与连续性 | M2/M4/M5 | 保存、保持、遗忘和恢复后的连续性 |
| CR-9 自主学习与递归改进 | M4/M5 | 真实经历改善后续能力且守住旧能力 |
| CR-10 跨域与多模态 | M5 能力扩面、M8 执行支撑 | 当前单结构/模板稳健不能称跨域泛化 |

这些是长期目标映射，不是追加到当前 B0 的训练清单。每次阶段评审必须披露尚未覆盖项，禁止让它们因首页精简而失踪。

## 5. 防止局部研究无限延长

- 每个新探针必须绑定某个阶段出口或当前决策；没有绑定则进探索登记，不自动阻塞主线。
- 同质复现只计稳健性，不重复计晋级进度。**B0 的 WP-1.5 原为可选；2026-09-15 起改为冻结前必过门**，按下一条要求说明理由：D1 已确认取最强参照（`required 1.65`），而实测增益 `+2.000` 正好等于 `ceiling_gain 2.0` ⇒ **零余量**；原协议规模（每格 2 context / 3 种子）**无法区分"真稳健"与"样本恰好贴边"**，这是原协议识别不了的风险，故不是悄悄移动终点，而是判据变严后补足采样。扩面本身只读、不改任何判据与阈值。
- 冻结后新增门必须说明原协议无法识别的风险，独立版本化审阅；不悄悄移动终点。
- 一个工作包达到出口即结项，未解问题回到轴级账本分类；不在其尾部无限追加字母/撇号分支。
- 通过轴评审后复用已获认可资产，只有新范围或回归证据才重开；避免反复证明同一件事。
