### 1.2 N 系列在 VISION 能力路线中的位置（出口后去向）

N 系列是 VISION 完整能力路线的**第一段（修复＋加速）**，不是全部。定位与衔接：

- **整体计算链定位（§2）**：观察编码 → 持续状态/工作空间 ↔ 记忆 → 候选生成 → 后果预测/选择 → 表达或行动 → 真实反馈。N1 修的是**"记忆 ↔ 持续状态"这一环**（读取形态）；N5 通电的是**"后果预测/选择"这一环**（世界学习）；N2 通电的是"训练/治理"层的巩固门。全链贯通后，一个输入到输出必须能追踪到实际加载的模块（§2"清点实际加载 bundle"要求）。
- **五级演进映射（§17.3）**：①条件内容能力（N1 出口+S7 读数改善）→②稳定上下文与组合（N4 出口：纠错/干扰/改述/未见组合与旧能力保持）→③同一可用 bundle（§19.8 可加载候选）→④联合认知闭环（§19.5：记忆→信念→后果预测→选择→执行→反馈同任务闭环）→⑤持续适应与更高上限（N2/N5 加速点兑现）。N 系列收官＝①②⑤的机器加速版就绪；③④是出口后的下一段主线。
- **出口接回实施包地图（§19.10）**：N 系列出口后按 §19.10 的六包地图选择下一有界包——R2 语言覆盖与组合（§19.4 课程五层：精确内容→绑定关系→跨轮时间→真实语言覆盖→组合深度）→ 同 bundle 集成 → 联合行为（§19.5 接口表，参照 §8.10 U0–U5 串行出口备选）→ 持续适应/知识巩固（§19.6）→ 成长/自主/产品规模化。每包"实现触点、继承/重训/废止、实际课程与划分、目标及参数、最少判别对照、资源和保存恢复、主要行为门、停止/返回、产物路径"九项填实。
- **远期边界**：§20 多模态（首个能力包＝图像＋文本对象属性/空间关系问答，§20.5）与 §21 信息治理（四类独立判定＋分层准入）不在本主线，但 §21 的准入/抗污染在 N5 真实采料开跑时即时生效（不可信输入不进巩固）。
- **N 系列收官不等于 VISION 完成**：语言覆盖、联合行为、用户交付（L2/L3）、多模态按 §17.3 依赖逐级开放，均需各自预注册与 owner 批准。

## 2. 阶段结构（P 痛点 → S 正解 → N 阶段；每项含推进步骤与实施设计）

### N1 P1 接口修复（最优先；一切机制失败的总根源）

- **目标**：情景召回**驱动 fabric 沿存储轨迹重放**（走现成 `episodic_feedback` 通道进皮层，[fabric.py](../../../taiji/fabric.py) 已实现该通路——管线大半现成、错在接线），生成从被再激活的状态继续。"说完"成为重放走完的副产品，不需要终点检测器。这同时是 P2 的正解（读取与计算同基底；脑的回忆是**再激活**——皮层重新进入当年表征状态——不是贴摘要进读出头）。
- **痛点证据**（§19.13 P1）：复制电路把锁定事件经位置注意力**池化成 257 维分布**加进 logits（[copy_circuit.py](../../../taiji/copy_circuit.py) `evidence()`→`_pool_into`），无终点信号、无顺序保证。实证链：α=0 与不挂回路**逐位恒等**；never-LF 群边界概率卡 0.006（需 ≥0.048）；五种切开方式（剂量 α／余弦上下限／时序窗／竞争式／资格门控）同向失败（X=0/9/27 对线 58，Y 全 0）。
- **推进步骤**：
  1. **S5 便宜证伪**（最先；零训练、判据先冻、可与 N2/N3 并行）：内容末字节 ⇒ 证据让位＋轨迹演到终点（终点检测器）。两个结果都是真知识——never-LF 显著缓解 ⇒ P1 诊断坐实；不缓解 ⇒ 病在更深（基底），转入基底归因（§4 分流表）。
  2. S5 判读入库后，落 S1 的实施规格与判据（预注册，走 PLAN-N1-01 编号）。
  3. S1 实施与验收。
  4. **全器官同读验收**：复述、世界转移、身份同构——"从经验序列读出这条经历"是同一种读法，一次修复应全器官受益（§19.13 S1）。
- **实施设计**（VISION 内容转化为执行组件）：
  - **计算链定位（§7.1）**：回答计算链＝问题编码→**当前会话和可见记忆**→内容选择/必要检索或计算→表达解码→回答与来源记录。S1 修复的是第二环——记忆进入生成的方式从"贴摘要"改为"沿轨迹重放走完"；生成头通过 Taiji-owned 内容/状态接收条件，格式检查可拒绝错误输出、不能把参考答案重写成"模型答案"。
  - **否决门（§7.5，验收时逐条核）**：固定字符串也能达到同分／改问法即失效／上下文被忽略／缺权重仍有相同回答——任一出现即判 S1 未成立，不得以总分通过，不得仅靠 UI 效果结项。
  - **错误分账（§7.2）**：知识未知、理解失败、检索错误、推理错误、表达错误**五类分开统计**；原型优先短回答的相关性、正确性、上下文和不知道时拒答，而非长篇流畅度。
  - **训练配方（§19.3）**：L_answer 完整答案因果序列损失为主（短任务完整展开）；绑定类辅助目标只在 train 且披露"监督增加"解释；不用 dev/final 答案更新模型；copy 持续性按完整值测量（重复首字符、多处同字、同前缀不同后缀、跨 UTF-8 字节、提前停止都入诊断）。
  - **判别材料（§19.4 精确内容层＋§17.5）**：判别簇须含未见新值完整输出、同前缀不同后缀、多处重复词、关键事实交换应换答、无关重排应保答、从未提供的属性应承认未知——每个变化单独标记，不合成含糊总分。
- **判据方向**：S5＝never-LF 群缓解幅度（分母与读数单位预注册时冻）；S1＝复述严格命中对第 0 点 7/24 的增量、三器官读数＋否决门全过。判据模板按 §16.1 共同标尺八项填写；S1 信用设计受 §8.6 第 1 条约束（末端错误必须能改变早期编码与状态保留——判据须含"梯度确实到达轨迹起点"的读数）。
- **出口交付**：S5 判读报告入库；S1 后的再激活读取通路＋三器官读数（附北极星第 0 点对照）；实施规格按 §18.4 登记"生产者→实际消费者→更新来源→恢复归属"映射（声明字段存在不算接入）。出口后接 §1.2 五级演进的第①级验收与"双通道 A+B"架构评审输入。
- **对北极星的意义**：复述严格命中、never-LF 率直接读出"经验→能力"通道是否接通——本项是速率成立的前提。

### N2 P5 离线重放→巩固通电（能力与窗口解耦；机器加速点①）

- **目标**：情景不进窗口，睡眠蒸馏成慢结构——**目标的准确表述是"能力与窗口解耦"，不是"无上下文限制"**（脑的工作记忆严格有界约 4±1 组块；脑做到的是行为能力与窗口大小解耦：极小活动集＋关联式记忆按需供给）。taiji 管线已有七成。
- **痛点证据**（§19.13 P5）：[sleep_pass.py](../../../seed_platform/sleep_pass.py)（708 行）**在产品活着**——analyze→project→corpus 落盘、C6 能力快照随行、consolidation 路由与 life 引擎 `sleep_taiji` 已暴露；**缺的不是机制**：基质级器官睡眠（`organs=True`）与改权重（`learn=True`）默认关且从未在真实长跑启用，材料环稀薄。
- **推进步骤**：
  1. **C6 六决策点 owner 批**（见下方内嵌块）。
  2. 按批准的材料方案扩容（决策点③若裁"等面扩容"，本步骤与后续解耦）。
  3. 真实长跑启用 `sleep_pass` 的 organs/learn 路径（通电即得加速点①）。
  4. 离线重放→巩固循环取读数（新旧任务矩阵、巩固前后）。
- **实施设计**（VISION 内容转化为执行组件）：
  - **写入合同（§5.3）**：真实 outcome 可写情景存储 E；关联记忆 A 写入需来源/预算与置信检查；过期、错误、重复经历有撤销/去重规则；**E 删除与 θ 中已巩固知识删除不是同一操作**。
  - **巩固行为（§10 睡眠巩固行）**：输入依据＝有来源经历、干扰与保持评估；实际更新＝E/A/φ 中稳定内容进入候选 θ——不是全部重放内容都进巩固。
  - **巩固目标（§19.3 L_keep 行）**：新旧切片都记录；**不蒸馏已知错误答案来"保持"**；保持集与调参集分离。
  - **惊讶度处理（§8.3）**：惊讶度高可能是噪声、不可学环境或攻击，**不等于应强化记忆**；巩固权重结合来源、可预测性、重放收益、旧能力风险；固定强度与调制方案作同预算对照。
  - **巩固经历分类（§17.2 第 5 类）**：发展训练、运行记忆和快参数之间的合并有来源、版本及旧任务矩阵；重放/巩固不是天然无遗忘。
