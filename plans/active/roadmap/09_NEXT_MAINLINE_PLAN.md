## 0. 北极星与第 0 点

**北极星＝经验→能力的转化速率**（单位经验 × 单位算力 → 能力增量），以 S7 的 A 线基线为第 0 点：装机自做 **13/72**（X24 面）、停摆面主列 **41→59**、资格门控 X=**0/9/27**、复述严格命中 **7/24**。方向裁定（owner 2026-10-05）：**模仿脑架构，以学习与进化的速度超越之**——上下文按脑的方式处理（极小活动集＋关联式按需供给＋离线巩固）；三个机器加速点＝重放不受睡眠窗口限制／经验流并行／批量无损巩固。总根源判读：**管线大半现成、错在接线**（P1 记忆接口缺陷是全部机制失败的总根源）。

**测量框架**（速率怎么读）：
- 一切能力主张对北极星**附第 0 点对照**（S7 四组基线数字），只给数不给名＝未取到。
- **速率竞赛在机制验证之后开跑**（§19.13 前置裁定）：N1 修复读取接口之前，加速只是更快地原地踏步；N1 出口后，N2/N3/N5 的加速点读数（巩固后能力增量、容量解除、生长复合）才是速率本体的读数。
- 速率的具体测量协议（经验单位、算力单位、能力增量读数面）在 N2/N3 各自预注册中冻结，本文不预定数值。

## 1. 主线叙事：修复期 → 加速期 → 补全期

N 系列不是六个并列任务，而是一条因果链：

1. **修复期（N1，唯一前提）**：把记忆读取从"贴摘要"改成"再激活重放"，让"经验变能力"的通道真正接通。机制不复合，一切加速无意义。
2. **加速期（N2 ∥ N3 → N5，速率本体）**：三个机器加速点通电——①重放不受睡眠窗口限制（N2）、②经验流并行（材料环扩容后）、③巩固批量且无损（N5）。N3 回答"容量是不是封顶"这个战略问题。
3. **补全期（N4，质量上限）**：读取形态补全（轨迹态＋模式分离），依赖 N1 打通的正确读取通路。
4. **N6 贯穿**：工程债随实施项清，不单独立项。

## 2. 阶段结构（P 痛点 → S 正解 → N 阶段；每项含推进步骤与出口）

### N1 P1 接口修复（最优先；一切机制失败的总根源）

- **目标**：情景召回**驱动 fabric 沿存储轨迹重放**（走现成 `episodic_feedback` 通道进皮层，[fabric.py](../../../taiji/fabric.py) 已实现该通路——管线大半现成、错在接线），生成从被再激活的状态继续。"说完"成为重放走完的副产品，不需要终点检测器。这同时是 P2 的正解（读取与计算同基底；脑的回忆是**再激活**——皮层重新进入当年表征状态——不是贴摘要进读出头）。
- **痛点证据**（§19.13 P1）：复制电路把锁定事件经位置注意力**池化成 257 维分布**加进 logits（[copy_circuit.py](../../../taiji/copy_circuit.py) `evidence()`→`_pool_into`），无终点信号、无顺序保证。实证链：α=0 与不挂回路**逐位恒等**；never-LF 群边界概率卡 0.006（需 ≥0.048）；五种切开方式（剂量 α／余弦上下限／时序窗／竞争式／资格门控）同向失败（X=0/9/27 对线 58，Y 全 0）。
- **推进步骤**：
  1. **S5 便宜证伪**（最先；零训练、判据先冻、可与 N2/N3 并行）：内容末字节 ⇒ 证据让位＋轨迹演到终点（终点检测器）。两个结果都是真知识——never-LF 显著缓解 ⇒ P1 诊断坐实；不缓解 ⇒ 病在更深（基底），转入基底归因。
  2. S5 判读入库后，落 S1 的实施规格与判据（预注册，走 PLAN-N1-01 编号）。
  3. S1 实施与验收。
  4. **全器官同读验收**：复述、世界转移、身份同构——"从经验序列读出这条经历"是同一种读法，一次修复应全器官受益（§19.13 S1；对应 §19.2 字面层 R"退出时点"的学习版表述，从候选升格为实证必做）。
- **判据方向**：S5＝never-LF 群缓解幅度（分母与读数单位预注册时冻）；S1＝复述严格命中对第 0 点 7/24 的增量、三器官读数。
- **出口交付**：S5 判读报告入库；S1 后的再激活读取通路＋复述/世界转移/身份同构三器官读数（附北极星第 0 点对照）。
- **对北极星的意义**：复述严格命中、never-LF 率直接读出"经验→能力"通道是否接通——本项是速率成立的前提。

### N2 P5 离线重放→巩固通电（能力与窗口解耦；机器加速点①）

- **目标**：情景不进窗口，睡眠蒸馏成慢结构——**目标的准确表述是"能力与窗口解耦"，不是"无上下文限制"**（脑的工作记忆严格有界约 4±1 组块；脑做到的是行为能力与窗口大小解耦：极小活动集＋关联式记忆按需供给）。taiji 管线已有七成。
- **痛点证据**（§19.13 P5）：[sleep_pass.py](../../../seed_platform/sleep_pass.py)（708 行）**在产品活着**——analyze→project→corpus 落盘、C6 能力快照随行、consolidation 路由与 life 引擎 `sleep_taiji` 已暴露；**缺的不是机制**：基质级器官睡眠（`organs=True`）与改权重（`learn=True`）默认关且从未在真实长跑启用，材料环稀薄。
- **推进步骤**：
  1. **C6 六决策点 owner 批**（见下方内嵌块）。

- **出口交付**：一次真实长跑＋离线巩固的完整读数；巩固后能力增量/单位经验（速率本体读数，附第 0 点对照）。

### N3 P3 容量决定（战略级，二选一或并行）

- **目标**：解除容量封顶——回答"约束在容量不在符号数"之后的第一刀。
- **痛点证据**（§19.13 P3）：两条独立 2M run 中段平台——语料档 online_accuracy 0.495→0.533 后平、holdout 全程 2.6 不动（`a31_chunked_self/progress.jsonl`）；自答档 0.5934→0.5941 全程平（`a31_onpolicy_20261003`）。2M 符号≈单遍语料 2%，但模型先饱和 ⇒ 约束在容量；参数×数据的 scaling 轴**零测试**。
- **两条路**（owner 二选一或并行，各解释如下）：
  - **甲 scaling 探针**：参数 ×10 单点，region/容量/数据同步扩。上限高——直接回答"容量是否封顶"这一战略问题，确认即打开整个 scaling 轴（后续容量路线的地基）；代价＝算力消耗大、单点周期长。
  - **乙 R4 通电**：训练器接 bridge+trigger（[train_seed_corpus.py](../../../scripts/training/train_seed_corpus.py)）。便宜——生长协议完整且测试过，且同时是 N5 的实施面（一体两裁）；风险＝压强阈必须**先在线面冻结**（accuracy 0.59 ⇒ 残差阈值 ≥0.4，生长节奏以面为准，不冻结即疯长）。
  - **并行**：上限最高（战略问题＋生长节律同时回答），但双份算力。
- **前置**：owner 批准路线与算力。
- **判据方向**：平台读数是否解除（两组 2M 基线为对照锚）。
- **出口交付**：容量决定＋对应读数；若选乙/并行，R4 首轮真实生长读数。

### N4 P2 读取形态补全（S3 轨迹预测图＋S4 模式分离；依赖 N1 的 S1）

- **S3 轨迹态**：召回互携带"第 k 段/共 n 段/终点在 n"的**轨迹态**（脑参照＝海马 successor representation，"接下来会到哪"的位置编码，让回忆自带进行位置感），替代静态混合——`_successor_bonus` 是对的直觉、错的粒度（进度链在事件末字节处设计性消失：`range(1,n)` 无末字节后继）。
- **S4 模式分离**：存储前**稀疏编码**（脑参照＝齿状回，海马入库前的"打散"工序，让相似经历存成互不干扰的码），降低寻址干扰——对应仓内 34.6% 空库/寻址失败读数。
- **依赖**：N1 的 S1 落地后才有正确的读取通路可补全；判据方向（寻址失败率、轨迹完整性读数）随预注册冻结。
