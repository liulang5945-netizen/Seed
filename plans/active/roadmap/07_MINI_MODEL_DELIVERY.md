# Taiji Mini：用户可体验的模型交付里程碑

> 2026-09-15；用户要求不仅看 Gate，还要拿到实际有能力的迷你模型验证成果。
> 本文定义交付，不声明模型已经交付。执行顺序由 [03](03_CURRENT_EXECUTION.md) 维护，不启动 vision 新核心、不扩大默认产品权限。

## 1. 什么时候得到模型

| 交付点 | 阶段位置 | 用户得到什么 |
|---|---|---|
| Mini-Preview | B1 完成后，B2 正式评审前 | 实际训练 checkpoint、模型身份、交互输入与原始预测/组合选择；诚实展示失败或常量输出，不要求 B1 必须正结果才可查看 |
| Mini-v0 能力包 | B2 验收后、P5.2d 在线扩展之前 | 在声明任务范围可实际完成任务的模型包、独立运行入口、隔离工作目录、可查看的执行结果、保存恢复 |
| Mini-v0.1 适应包 | P5.2d 对应验收后 | 同一模型学习前后对照、跨会话恢复及旧任务保持；不把单次记忆写入说成终身学习 |
| 后续原生语言包 | 语言生成专项范围和验收冻结后 | 原生内容/表达输出；未通过前不承诺开放聊天，不等待它才交 Mini-v0 |

**不等整个 M5 完成，更不等 M6/M7 产品发布或 vision 新架构完成。** 若 B2 未通过，仍交 Preview 与失败样例，但不能给失败包贴“有能力 v0”的标签；阶段评审必须明确缺项，不无限追加探针而不让用户见模型。

## 2. 第一版到底能做什么

首版定位为有限任务的行动/选择迷你模型，不是 ChatGPT 式通用语言模型。候选能力：读取显式目标与当前可见状态，预测组合/动作，按允许范围执行文件与语言状态相关任务，显示真实结果与失败原因。哪些能力最终列入包，以 B1/B2 实测为准，不能预填成功。

受控表单/结构化目标是有效输入入口，但必须明确它限制了自然语言理解范围。用户应能改文件名、内容、合法目标组合并重新运行；不允许只能点击固定答案样例。

目前 B1 训练对象是组合选择器，不等于一个能自由写文章的生成模型。GUI、格式化日志、renderer 说明、外部 provider 文字都不能冒充它的原生生成。

## 3. 每次输出必须展示的来源

| 内容 | 来源标识 | 验证方法 |
|---|---|---|
| checkpoint 名、摘要、参数量、训练数据范围 | 模型元数据 | 实际加载文件校验，缺 checkpoint 直接拒绝，不静默随机初始化 |
| 候选分数、所选组合/动作、模型生成参数 | model-output | 展示原始结构和时序，不从参考轨迹回填 |
| 参数绑定、状态摘要、可读说明 | deterministic-binding / renderer | 标明规则来源，不计作生成能力 |
| 权限拦截、执行副作用、终态验证 | host / environment | 沙箱文件差异、真实 outcome；与模型预测分栏 |
| 外部编码器/provider（如有） | external-instrument / external-generation | 明示依赖与缓存；禁用外部生成后重测原生成绩，不谎称全链纯原生 |

用户看到的是可核验行动/预测记录，不伪造模型内部思考过程。

## 4. 能力包必须随附的资产

- 一份明确版本的 checkpoint 或互相依赖的 checkpoint bundle，注明不是所有成果已经合成一个单体模型。
- manifest：代码提交、schema、文件摘要、所需仪器、依赖版本、能力范围、外部依赖、许可与恢复方法。
- 一个真实可执行的本地入口及逐条运行说明；发布前验证命令，不在计划中杜撰已存在的 CLI。
- 首次运行自检：依赖、模型加载、目录权限、恢复、无网络生成回退；未知输入有明确拒绝。
- 固定回归样例与用户自由改动入口；成功和失败样例都附原始输出，不能只挑最好结果。
- 学习关闭模式为默认；后续提供显式学习开关，独立显示前/后 checkpoint，保留 parent。

优先复用现有终端/Workbench 可用部分；需要新增体验入口时只做轻量界面，不重做桌面产品。

## 5. Mini-v0 能力验收

1. 全新进程加载，不重新 fit 即可预测；重复恢复行为在定义容差内一致。
2. 在冻结独立任务上完成声明能力；相对无学习/固定策略及相关对照有实测依据，具体阈值在实现前冻结。
3. 至少提供未参与拟合的参数/任务组合体验；记录用户现场输入表现，不将现场尝试回填正式测试成绩。
4. 模型输出确实驱动执行；错误预测仍显示失败，不被脚本修正为成功。
5. 安全、拒绝、保持、恢复和预算门通过；外部写入局限于批准沙箱。
6. 交付说明能让用户独立操作，附一次端到端运行记录；接口存在或 pytest 通过不足以结项。

生成能力单列：若输出只是组合 ID，就叫组合选择；若输出受控动作序列，就叫行动序列生成；自由文字必须是实际解码器输出，经未见提示、约束正确率和非背诵检查，不用模板包装升级名称。

## 6. 与总阶段的关系

Mini-Preview 是可见性出口，Mini-v0 是 M5 内的有限能力交付，不等于 M5 全阶段退出。M6 再负责正式桌面体验与默认采用，M7 负责发布；vision 原型另行评审。首版不要求实现结构成长、全模态或开放聊天，未覆盖项明确列出。
