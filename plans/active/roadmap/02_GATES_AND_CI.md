# Seed / Taiji 晋级、阶段退出与发布门禁

> 更新：2026-09-16。配合 [总阶段地图](01_SCOPE_AND_PHASES.md)；执行顺序只由 [03](03_CURRENT_EXECUTION.md) 决定。本文不修改历史冻结实验阈值。

## 1. 四种完成不得混写

| 完成层级 | 满足条件 | 可以宣布什么 |
|---|---|---|
| 实验完成 | 按冻结设计执行并记录成功/失败/阻塞 | 完成一次测量；负结果也可以结项 |
| 能力轴晋级 | 该轴范围/必达门冻结、证据齐备、保持/恢复/预算/安全通过，独立批准 | 只在批准范围内晋级 |
| 大阶段退出 | 01 中该阶段必达轴逐项结项，共同门通过；排除项获显式范围批准 | 该交付范围可以进入下一阶段，不等于长期愿景完成 |
| 产品采用/发布 | 实际依赖 artifact 准入、行为批准、端到端/正式 CI、恢复与发布 manifest | 指定行为采用或指定版本发布 |

`can_promote` 必须写明所属报告/轴，不设一个无范围的全项目布尔值。K 轴已晋级，其他报告 false 不撤销它；它的 true 不替其他轴授权。

## 2. 每次晋级评审的固定清单

1. **范围**：父阶段、能力轴、任务/数据/环境、允许的主张与明确排除项。
2. **冻结判据**：每门公式、参照、样本单位、预算、阈值来源；机器门与文字一致。
3. **能力证据**：独立测试、公平可部署对照、必要 lesion/归因，拒绝把 oracle 或模板先验当模型能力。
4. **保持与连续性**：旧任务、跨轮累积、正确 parent/lineage、无泄漏与可恢复继续。
5. **训练保存**：正式训练前零步完整保存、独立恢复、原子写入、容量/磁盘预检；失败则不启动。
6. **安全与运行**：权限、失败语义、拒绝、环境撤销与模型 rollback 分开验；相关工程检查实际通过。
7. **资源**：calls/updates/参数/wall/存储按冻结口径，预算超限不可隐藏。
8. **依赖**：逐项继承已批准资产，不以存在 checkpoint 代替准入。
9. **独立批准**：项目所有者审阅范围、机器门、未完成项与风险；批准或拒绝均落盘。
10. **同步结项**：报告/scorecard、01 轴状态、03 执行出口、plans 首页同一提交更新。

评审表字段：门 ID｜父阶段/轴｜判据版本｜证据路径/摘要｜pass/fail/blocked/not-applicable｜剩余动作｜批准记录。not-applicable 必须解释其范围依据，不等于通过；缺证据保持待核验。
