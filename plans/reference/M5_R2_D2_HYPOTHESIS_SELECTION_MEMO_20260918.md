## §1 决策点

R2-D1 已交付**结构上可辨识**的固定 dev：最佳可接受固定策略 M1=0.1735、M3=0.0581、M4=0.0，读背景参照键 M1/M3/M4/M5=1.0，金形状标签诊断臂 M4 仅 5/11（6 个 fact_flip 全错）。现在要选择**第一个在该 dev 上接受检验的学习假设**，冻结其隔离验证合同。

## §2 证据盘点：哪些候选族已否决、边界是什么

| 候选族 | 结果 | 精确边界（可继承什么） |
|---|---|---|
| H3.7/H3.7B 哈希 sketch + 固定 phase 工作空间 | 无内容方向，boundary/因果消融门失败 | 证明「response 自身 sketch 监督」不含 prefix 依赖；不证明任何工作空间架构无效 |
| H-GEN 生成态训练（scheduled sampling，φ≤0.5） | 两臂 dev exact 均 0/16，生成同一边际众数 | exposure bias 在该预算下非充分根因；teacher forcing 不因此被判为错误方法 |
| H-OBJ 上下文对比损失（λ=1，3 seed 有效预算） | treatment 0.0417 vs control 0.0208，无门可过 | 改动确实生效（margin gap 变动）但无收益；只冻结 λ=1/margin=1，不判对比族死刑 |
| H-FBW 首字节 5× 加权 | treatment 三 seed 全 0，control 0.1042 | 「首字节全错」不是重视程度问题，是从 prefix 状态读不出内容 |
| wide 2× 几何容量判别 | 0.0625 vs 0.1042，无提升 | 容量不是当前瓶颈；只试了单一 2× 几何 |
| H3.8 v1/v2 可训练 prefix 编码器→末状态工作空间→循环 renderer | train 可学习性双绿；matched dev `workspace_unused`（v2 均值差 +0.022，2/3 lesion 正信号但未过门） | 联合反传/单通道图可优化、可拟合；未证明稳定的可迁移内容贡献 |

**两条对账结论：**

1. **旧负结果不能在 D1 上复用为机制判决。** H3.8 v1/v2 及全部损失族都在旧 dev（16 题、按色重复、无反事实对）上评定；那个 dev 无法区分边际命中与内容改善——这正是 R2-D1 存在的理由。任何臂都必须在 D1 上重新跑。
2. **已否决路线的收敛点一致指向信息路径本身。** 「加损失」三形式与「加宽」全灭后，容量判别结项原话是：问题不在「参数多少」也不在「损失怎么加」，而在「**内容如何从 prefix 状态进入生成路径**的机制」。H3.8 v2 是该机制的一种形式（末状态一次派生），尚未在可辨识 dev 上检验；VISION 方案 A 是它的直接对照形式。

## §3 VISION 五方案对当前证据的匹配

| 方案 | 针对的失效形态（§16.2） | 当前是否有对应证据 | 本包判断 |
|---|---|---|---|
| **A 逐位置证据记忆** | 关键材料无法从末状态恢复；逐位置保留信息 | H3.8 全部槽由同一末状态 h0 派生（[sequence_workspace.py:304-305](../../taiji/sequence_workspace.py#L304-L305)），生成期只读不写；F5 观察到输出塌缩为边际众数 | **选为最小判别**：与现原型同族、增量最小，且其失败形态可直接路由到 B/C |

| C 递归潜空间推理 | 单步读取稳定，组合随深度退化 | **尚无**；D1 的 11 个翻转对（含 5 个双事实 combo）将首次给出该切片信号 | 后置；需先证明读取正确（A 成功而 combo 失败才指向 C） |
| D 行动条件世界模型 | 策略不随真实后果调整 | 不在 R2 语言主线；03 §3 明确 D 不是前置 | 本包不选 |
| E 元训练快慢学习 | 给反馈仍不适应新规则 | 基础内容读取尚未形成，VISION §15.7 自述「基础读取都没学会时不以扩大更新自由度解决一切」 | 后置 |

**不选纯数据扩大（候选③）的理由：** 新假设包的第一职责是在干净仪器上分离机制；D1 train 已含 174 个去重 episode（旧有效预算档为 25），数据暴露同时扩大。若机制臂在 4× 数据上仍无收益，数据假设仍可作为后继独立对照（课程/规模另立合同），但不应在首包里与机制变化混为一谈。

## §4 唯一推荐假设：H-A1（方案 A 最小切片）

> **在相同数据、解码器与因果序列 CE 下，把证据条目的写入从「prefix 末状态一次性派生固定槽」改为「prefix 扫描期间逐位置写入、生成期由渲染状态重新查询」，将使内容依赖自由回答（M3）与平衡翻转对（M4）超过等机制的末状态对照；该收益必须在反事实对上表现为答案随单一事实正确翻转，而不能由固定「未知」命中、参数容量或位置/绑定捷径解释。**

与 H3.8 的**实质区别**（VISION §15.3「真正区别」）：

| 维度 | H3.8 v2（对照） | H-A1（A 臂） |
|---|---|---|
| 证据条目来源 | 4 个槽全部是同一 h0 的线性投影 | L 个条目来自扫描中 L 个不同位置状态 h_i（train 174 题 L≤84 byte，dev/final L≤99） |
| 写入时机 | 回答开始前一次 | 经历 prefix 的过程中逐位置写入 |
| 生成期访问 | 对 4 槽内容寻址（已有） | 对 L 条目同族内容寻址；精确信息不必压进末状态 |
| 其余一切 | prefix 因果扫描、start_vector、循环 renderer、真实下一 byte CE | **完全不变**；不开 copy、不加辅助损失、不快参数、不跨 episode 记忆 |

**上限更高而非更保守的理由**：逐位置证据是持续上下文、精确引用与未来对象级表示（B）的共同地基；末状态派生槽在原理上无法随材料增长保留多事实。先在最小同族对照中证明「信息保存位置」这一变量，后续压缩记忆、copy 门、对象绑定都有可挂载的正向资产，而不是在未证明读取有效的结构上直接重写核心。

**与 M4 attention 外挂闸门的边界（硬约束核对）：** A 臂的读出沿用 v2 已批准的 `_content_read` softmax 内容寻址（[sequence_workspace.py:345-358](../../taiji/sequence_workspace.py#L345-L358)），只是把 4 个末状态槽换成 L 个逐位置条目。它是 episode 内、隔离 R2 原型族内的信息访问路径变化，**不是**跨学习周期的长程协作算子（无 SSM/Mamba/Transformer 骨干堆叠、无跨 episode 注意力、无时间信用外挂），不触发 M4 闸门；合同中必须按此口径命名，不称「引入 attention 方案」。

## §5 最小判别设计（合同冻结前的规格草案；数值在合同中冻结）

**臂（同 D1 fixture、同 seeds 20260917/8/9、同训练预算、从零构建）：**

1. **A 臂**：graph v3，逐位置 K_i/V_i（共享投影 rw→sw），生成期同族寻址读取。
2. **C0 锚点**：H3.8 v2 图原样（4 槽，h0 派生），血缘锚点。
3. **C1 等机制对照（主对照）**：与 A **同参数、同前向代码形状**，但每个位置的条目都由末状态 h0 广播生成——即「等机制但无逐位置信息」。若 C1≈A，逐位置信息不增加任何东西，假设直接被否；这比加宽槽数更干净（v2 的 4 槽加宽到 L 会使 workspace_key/value 参数膨胀约 20 倍，混淆参数与信息源）。
4. **表面策略天花板**：b0/b1/b2 已冻结（M1 0.1735 / M3 0.0581 / M4 0.0），模型臂必须超过它而不只是互相对比；b3 仅诊断。

**无上下文模型基线（D1 合同 §4.2 的执行方式）：** 对训练后同一 checkpoint 不重训，仅在评测时删除材料从句（保留问题干）生成并评分；完整题与删除题的**逐题差**为上下文边际。三臂同做，证明收益确实来自读到材料。

**A 臂 lesion（仅诊断，命名分账）：** ① 键/值错行打乱（破坏内容绑定，保留全部信息量）——M4 应崩塌；② 读取脱挂/置零——应回落到无上下文基线水平。D1 语料内置的 fact_flip/combo_flip 是输入级反事实替换，invariance 对是抗干扰检验，不另造。

**指标：** M1/M2/M3/M4/M5 全用 D1 冻结定义，逐题记录、按 source_group 分组、3 seed 报均值/最差 seed。建议门（**提案值，合同冻结，看 dev 前固定**）：

- 训练可学习性门：A 与 C1 均能拟合 train（沿用 H3.8 probe 纪律，loss 收敛与 train M1 双绿）；
- G-内容：A 臂 M3 均值超过表面天花板 0.0581 且对 C1 的优势 δ_M3 ≥ 0.20；
- G-翻转：A 臂 M4 ≥ 0.50 且对 C1 δ_M4 ≥ 0.25；其中 fact_flip 子集必须非零（b3 证明金形状标签在该子集为 0/6）；
- G-因果：键值错行 lesion 使 M4 下降 ≥0.50 个完整对比例；无上下文评测使 M3 大幅回落（上下文边际为正且显著）；
- G-保持：boundary_stop 不退化、三 seed 方向一致（至少 2/3 且最差 seed 不为负）、checkpoint 零步保存/新进程恢复/续训一致；
- 任一门不过即按预承诺停止，不扩 epoch、不调 λ、不换 dev。

**失败路由（每种结局指向不同下一步，不重复试同质方案）：**

| 观察 | 归因与去向 |
|---|---|
| train 不可拟合 | 回计算图/实现门，不扩大数据 |
| A≈C1（逐位置无增量） | 末状态压缩在该规模非瓶颈 → 转 B（绑定/对象结构）假设选择 |
| A 读取被依赖（lesion 崩塌）但 fact 对过、combo 对不过 | 信息访问成立、关系计算不成立 → 转 C 假设 |
| 只 M1 升（「未知」命中）、M3/M4 不动 | 假设否决；D1 仪器直接识破，不允许晋级表述 |
| A 全面过门 | 进入能力覆盖扩大（03 §5.3 第 3 段），copy/压缩记忆作为独立变量另包，不自动读 final |
