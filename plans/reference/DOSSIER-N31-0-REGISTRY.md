# N31.0 组件登记表（标准组件与工程组件）

> 登记表 — 2026-11-24（D-20261124-466）。依据 [机制通过标准与训练放行条件](../active/MECHANISM_ACCEPTANCE.md) §9 与 §5（终态）。**只登记，不开线；终态变更须记 D 号。** 零训练。

## 1. 登记规则

- **标准组件**：成熟方法承担同一角色，直接采用；不需要级3 对标，但须在 N32 配置中写明版本。
- **工程组件**：基础设施（胶囊、生命周期 API、逐样本状态、评估框架），只需级1（不变量）。
- **必需能力**（§5.1）不在此登记为可替换项：单位身份与生命周期、持续活动状态、可学习连接、持续可塑性、按需规模生长。
