## 1. 设计（owner 第 3 步：MetaOptNet/R2-D2 式）

同一翻转训练后的主体，**可微 ridge 元学习巩固** 800 步：每 batch 96 样本分 support/query，support 上闭式 ridge（λ=1e-2）解出读出 $W=(X_s^TX_s+\lambda I)^{-1}X_s^TY_s$，query 上交叉熵，梯度反传到单元＋适配器；无任何 MLP 头参与训练。

## 4. 判读

1. **方向正确**：未见颜色对线性泛化 **0.557 → 0.707（+0.15）**，证明「support/query 元学习」确实在推动**可迁移的线性读出**，而不是按颜色对记忆。
2. **因果保持**：休眠 0.106、唤醒逐值、适配器 drop 0.471（用不同读出验证）⇒ 功能仍在新生单元＋新连接上。
3. **代价**：已见对线性 0.937→0.866、mlp16 0.734→0.374——元学习把状态推成「ridge 线性可读但 MLP 难迁移」的几何，说明**读出几何被重塑**；mlp16 不再是合适主判据（owner 已提醒它混入优化速度）。
4. 未见对 logreg 0.553 仍低：logreg 读出（不同目标）对未见对的泛化差，提示泛化仍有限，需要更强条件化（更多样本/更大支持集/正则/混合目标）。
