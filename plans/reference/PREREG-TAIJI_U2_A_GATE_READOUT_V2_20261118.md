# 预注册：A 门读出（预算修正版 v2-fixture）

> 冻结于 2026-11-18，**在开跑之前**。判据不放宽（fit ≥0.80），只把预算调到与实测可学性匹配。
> 依据：探索臂达成 fit 0.906（29/32）用了约 16k 例曝光，而原门 256 更新 × batch 2 = 512 例，低约 30 倍（`cb972560a`）。

## 1 范围

- **主张**：在 3 体世界中，主体能从观测里读出"被问对象的位置"，并以字节形式发出对应的中文词（左/中/右/未知）。
- **不主张**：跨物体数泛化（fixture 固定 3 体）、记忆使用、纠正与保持、生长收益。
- **数据边界**：训练用世界的真值位置**仅**用于生成标签与评测，**不进模型输入**；模型只拿到观测、坐标、请求字节。

## 2 协议（冻结）

| 项 | 值 |
|---|---|
| fixture | `first_a_support_22_5_v2.py`（全分片 3 体） |
| 训练 | 768 世界，batch 8，lr 1e-2，Adam(0.9,0.999) |
| 更新数 | **4,000**（32k 例曝光），每种子 |
| 损失 | 首字节用**未掩码**分布（压 EOS）+ 首字节权重 2.0 |
| 读出 | `readout=pixel-salience`（余弦匹配 + 温度 clamp 0..log16）+ `delta_head`(8→32→257，末层零初始化) |
| 种子 | 20261110 / 20261111 / 20261112 |
| 评估 | fit = 32 个 fit 世界，逐字节贪心解码（首字节掩 EOS、UTF-8 约束），准确 = 输出串完全等于目标 |

## 3 判据与出口（冻结）

- **fit 通过**：3 种子 **中位 fit ≥ 0.80**（即 ≥26/32）。逐种子也报，任一 <0.70 记 `unstable_seed` 但不上报为通过。
- **fit 未过**：结案为 `readout_below_gate`，**不读 check**，写收束卡。
- **fit 过**：**读 check 一次**（32 个 check 世界，1/2 曝光 → 消耗 1 次），check ≥0.70 记 `readout_passes`，否则 `fit_only`。
- **任何情况下**不解锁 22.5.1／22.6／22.7，不签 A 父，不签能力。

## 4 与旧门的差异（必须记账）

| 项 | 旧门 | 本预注册 |
|---|---|---|
| batch | 2 | **8** |
| 学习率 | 1e-3 | **1e-2** |
| 更新数 | 256 | **4,000** |
| 首字节损失 | 掩 EOS | **不掩** |
| fixture | v1（1–2 体训练 / 3 体评测） | **v2（全 3 体）** |
| 读出 | patch | **pixel-salience + delta_head** |

这些差异都是**实测倒逼的口径修正**，逐条有据；判据（fit ≥0.80、check ≥0.70、曝光 1/2）**未动**。

## 5 已知风险

- 探索臂 0.906 是单次运行，种子方差未知；三种子可能拉开；
- `delta_head` 增加 2,313→更大参数量，需在收束卡登记参数量变化；
- 训练 4,000 更新 × 3 种子 ≈ 70 分钟墙钟（8 worker 并行，0.35 s/更新）。
