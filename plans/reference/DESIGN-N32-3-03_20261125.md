# 预注册卡：N32.3.03 Q2 可学性 v3（输入标准化＋换名增广＋MLP 工程门；探索）

> [预注册·探索] — 2026-11-25（D-20261125-521，owner 授权，≤442 CPU，即 N32.3.02 未用的额度）。依据 N32.3.02 复核 D-520、numpy 诊断 D-518 / D-520。脚本 [n32_3_03_learnability_v3.py](../../scripts/training/n32_3_03_learnability_v3.py)；运行 [run_n32_3_03.ps1](../../scripts/training/run_n32_3_03.ps1)。**读前冻结。** 只做 Q2，不比较 S vs RT，不改成绩单；探索 seed 20261120–22；确认 seed 与 v2 confirm 集都不读。

## 1. 问题

把 N32.3.02 中可以解释的差距（没有输入标准化、单层 tanh、没有增广、呈现量不足）全部消除后，GRU＋read_gate 能不能在 Q2（一跳方向关系）上达到 0.85？MLP 参照先证明这条 torch 管线能学会。

## 2. 数据（冻结）

| 项 | 值 |
|---|---|
| 来源 | 数据合同 v2（`taiji-23-composition-v2`），只取 Q2 |
| 训练 | train 世界（k < 6,000）× 4 个方向 = 24,000 行；**换名增广**：每个世界另做 3 次随机换名（6 个名称的排列，生成器 seed 20261125，与模型 seed 无关），共 96,000 行 |
| 验证 | val 世界（6,000–6,999）× 4 = 4,000 行，不增广、不参与训练 |
| 编码 | `taiji-23-composition-ticks-v1`；Q2 恒为 13 个 tick（3 个场景＋10 个问句字），截去填充 |
| 标准化 | 按训练张量统计：GRU 按 48 个特征维，MLP 按展平后的 624 维；方差为 0 的维度置 0 |
| 数据顺序 | 每个（seed, 臂）用 sha256 导出的生成器，同 seed 可逐位复现 |

## 3. 臂（冻结）

| 臂 | 结构 | 训练 |
|---|---|---|
| **E0 MLP 参照（工程门）** | 624→256→256→10，ReLU，He 初始化 | Adam 1e-3，weight decay 1e-4，常数学习率，batch 256，8,000 步（约 205 万次呈现），seed 20261120 |
| **SF GRU**（场景在前，原编码） | GRU(48→96)＋末步输入 read_gate（bias 1.0）＋96→64→10 | Adam 3e-3，余弦衰减到 10%，梯度裁剪 1.0，batch 256，6,000 步（约 154 万次呈现），seed 20261120 |
| **QF GRU**（问句在前；单变量） | 同 SF，只把 10 个问句 tick 移到 3 个场景 tick 之前 | 同 SF |

每 2,000 步在验证集上评测一次，记录学习曲线；另报训练集抽样准确率、预测「未知」的比例、各类准确率。

## 4. 流程与出口（读前写定；脚本自动判定）

1. **冒烟**：每臂 40 步，按实测外推。冒烟 CPU 加上全量外推 ≤442 才运行全部三臂；去掉 QF 能放进 442 就只跑 E0＋SF；否则停止。
2. **E0**：val < 0.90 ⇒ **`engineering_failure`**：管线仍未验证，GRU 不运行、不判读。
3. **筛选**：SF、QF 在 seed 20261120 上运行；取 val 更高者（相同取 SF）。
4. 最好的 GRU 臂 < 0.85 ⇒ **`gru_not_learnable`**。
5. 否则在 seed 20261121、20261122 上重跑这一臂：3 个 seed 都 ≥0.85 ⇒ **`learnable`**；否则 ⇒ **`learnable_unstable`**。
6. 超出 CPU 上限或出现 NaN ⇒ `engineering_failure`。

## 5. 后续（读前写定）

| 出口 | 后续 |
|---|---|
| `learnable` | N32.3 结线：「Q2 在 GRU＋read_gate（选中的编码顺序、u96、约 154 万次呈现）下可学」。这只是 R1 的**前置**；R1 比较要先对 Q3 做同样的可学性检查，再另写预注册并单独授权 |
| `gru_not_learnable` | **N32.3 结线：「R1 未检验：GRU＋read_gate 骨干在 Q2 上未学会（当前配置），而 MLP 能学会，瓶颈在循环骨干或读出方式」**；不追加 |
| `learnable_unstable` | N32.3 结线：「Q2 在 GRU 上可学但不稳定（seed 方差）」；R1 未检验；不追加 |
| `engineering_failure` | N32.3 结线：「R1 未检验（管线未验证）」；不追加 |
