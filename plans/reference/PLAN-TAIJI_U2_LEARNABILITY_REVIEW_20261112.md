# Native训练内可学习性与任务可识别性重审

> 22.5.P3.5，2026-11-12。承接P3.4完整负结果及资源失配，P3.5.1任务及P3.5.2–3学习链/计算核验已交付，P3.5.4已准入，当前队首P3.5.5按共同600实际训练CPU终点执行。

## 1. 设计约束与唯一推进方向

P3.4已检验直接证据读取，Native-query/capacity均恒左边，训练内和候选重评分亦无条件收益。Transformer能拟合抽查训练例，未见三对象仍弱。当前应先使同一Native机制在一个可识别、可核验的小任务内完成学习闭环，再讨论扩大未见轴与后继能力。

优先路线为“任务可识别性审计→训练内可拟合性与表达/条件读取分解→原生图计算摊销→有界学习复核”。保持原始U2与研究候选的身份/谱系。每项干预只改变一个具名因素，数据、反馈、资源及出口在读新行为前冻结。该卡不预设换核心单元或新增器官能解决问题。

## 2. P3.5.1任务与范围冻结

生成器在冻结时列出六实体×四答案的完整支持矩阵、实体/答案/对象数计数、问题文本先验及公开图像oracle可解性。选择最小完整因子范围，至少使每个被比较实体出现全部被评分答案；具体规模须先按fixture价确定。原train64/fit32保留历史身份，原fit中的5个额外未见组合不再混同为单纯对象数未见。

设置同场景不同实体请求的可核验对，确保目标随公开内容与请求共同变化。配对用于明确任务依赖，答案标签留在监督侧，原生forward继续接收公开证据。完整分母及问题/图像单侧基线共同冻结。配对导致标签比例变化时，主门须对照新先验在读新结果前确定。

P3.5.1已按[配对小世界合同](SPEC-TAIJI_U2_PAIRED_WORLD_20261112.md)修正并落地。原固定缺席循环规则在完整非RGB问题历史上有2/3上界，已以反例登记。当前train/dev各18世界、180个episode、360应答轮；每个可见实体与全部五个缺席实体、两种请求顺序配对。六种颜色共享非RGB母体，所有部分输入及完整非RGB问题历史的上界均为0.50。

每个实体问题具有未知30次和左/中/右各10次监督，24个组合全覆盖。train/dev world及family seed分别隔离。完整图公开oracle均360/360；9个新回归及既有相关回归共29项通过，双精度4例独立接续与804条梯度比较最大差0。CPU19.265625，0训练更新。

同一世界两个请求沿实际输出状态接续，评测完整360分母含错误首答的后续影响。第一轮未结束则第二轮阻塞并计错，训练teacher prefix与自由评测分开。训练内≥0.90、同范围dev≥0.80、相对部分输入控制增益≥0.15保留为P3.5.2–4准入前学习门草案。正式多实体A仍按0.80/3seed/独立check承接。

按三个范围分别报告，不能以一个指标替代另一个。

## 3. P3.5.2学习链分解

先在同一父及同一参数范围，比较完整自由表达与原输出头的完整答案似然，记录每个负责模块的实际更新和输入必要性。P3.4重评分未能救回Native，因此当前不能只归因为greedy滚动。

若训练内完整任务仍不拟合，再设计明确标注的机制上界/干预，分别限制感知、请求条件读取及表达学习的混杂。任何标签辅助或oracle状态只进入具名诊断臂，其结果不签模型能力。必须有去除辅助后的同主体验证入口。具体干预和数值门由本卡下一版合同定稿，不将猜测写为已证瓶颈。

若Native能训练拟合而新世界失败，再进入组合泛化设计；若连固定小集都失败，先定位最早失效环节，后继B/C/D/J继续等待。若源/仪器失败则先工程结案，能力负结果按原证据保留。

## 4. P3.5.3计算摊销与资源协议

源码中同一request/goal编码、公开证据重编码和K/V投影可能在多个字节步骤重复。先按正常入口测出各环节CPU、Python/张量成本、内存及更新曝光数，才能选定优化。每个可复用量必须明确依赖参数revision、原始包摘要、请求版本及阶段边界。

候选摊销须复用同一可微图，验证原/优化输出、逐参数梯度及必要元导数；禁止以detach缓存换取价格后仍声称信用闭环。参数迁移、请求切换、撤销、恢复和并发主体均使对应派生缓存重新校验或重建。该项是可学习机制的执行组织审查，任务收益仍由后继实际实验签署。

价格校准覆盖真实Adam的首步及非零moment稳态开销，可在临时参数/状态上执行等价函数式运算并明确更新计数。新实验考虑预注册“最后一个不超过共同实际训练CPU额度的accepted checkpoint”作为资源终点，限定单步越界成本，数据曝光和更新数同时报告。它只能用于新合同，本轮固定步数的资源失配保持原出口。
