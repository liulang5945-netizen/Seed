## §3 Step 0：可分离性的"逐级剖面"（零训练）

### §3.1 沿链路要测的五级

`Taiji.observe` 里从输入到读出分布的实际链路（读码所得，`taiji/model.py:2027-2081`）：

1. **区域迹** `state.regions`（各区的激活）
2. **皮层投影** `fabric.predictive_context(regions)`
3. **上下文器官输出** `predictive_context.encode(...)` ⇒ `base_context`（96 维）
4. **最终 cue** `state.motor_context`（= 第 4 级；若 `_gated_temporal_candidate is None` 且无 residual bridge，
   则与第 3 级**逐位相同**——这一点 Step 0 里顺手核实，能省一级）
5. **读出分布** `step.probabilities`（P3 已测过这一级）

对每一级用**同一个** `consistency = cos(换A方向|B=b₀, 换A方向|B=b₁)` 统计量，得到一条
**可分离性剖面**。零假设对照（同题面 ×2 必须精确为零）与实测随机基线（族间方向互配）**逐级都跑**。

### §9.0 又一处必须更正：`receptors` **不是学习映射**，它压根不训练

写 §7 时我把它叫"学习映射"。实现前读码后确认：`SparseReceptorBank` 的 `channel` / `polarity` 在
**构造时由 generator 抽定，之后没有任何路径改它**；`BytePredictiveContext.learn()` 只更新

### §9.4 跑完之后按什么判（**判据在训练前就已冻结，见 §4.2，不再改**）

* **主判据（机制）**：`struct-on` 的**可分离性 `consistency` 中位**显著高于 `struct-off`
  （逐族配对、精确符号检验 **p < 0.05**），仪器用 Step 0 那一版**分块口径**。
  **不达标 ⇒ 不进入下一步、不申请更大预算。**
* **副读数（只报不判）**：成句率（题面总体 P）、CAP D+E 机器计分、P3 的 KL。
  副读数**不得**用来推翻主判据的否定结论。
* 边界照旧：**成句率不是会回答**；不得据此解除 R2 的 M5 排除；不得改 CAP 冻结线。

## §10 更快的验证方式：**初始化筛选器**——它在花掉预算之前就把方案否掉了（2026-09-23）

### §10.1 为什么可以"不训练就验"

`receptors` **是固定的随机稀疏压缩、不训练**（§9.0），而 `recurrent` 在本基座里为 0
⇒ `context = bound_norm(receptors(cat(activity, trace)))` 里**唯一由这次改动决定的那一步，
在训练开始前就已经是最终形态**。于是可以拿两套配置（同架构、同 seed，只差开关）
在**初始化**状态下跑同一批冻结刺激，直接量最终 cue 的可分离性。**分钟级、零训练。**

**边界（不许省）**：这一读**能否证、不能确认**——上游区域动力学也在训，理论上存在"训练后上游
反过来适配分块"的可能。它给的是**先验**，不是证据。

### §10.2 读数一：实现的那一档在初始化上就是**负的**

`reports/taiji_r2_factorization_at_init_20260923.json`：

| 级 | 关 | 开（48/48） | Δ |
|---|---|---|---|
| 1 activity 块 | +0.6303 | +0.6303 | 0 |
| 2 trace 块 | +0.7256 | +0.7256 | 0 |
| **3 `context`（要改的那处）** | **+0.6417** | **+0.6236** | **−0.0180** |
| 5 读出分布 | +0.6198 | +0.6324 | +0.0126 |

⇒ 分块把目标量做**差**了。而它不训练 ⇒ 长跑改不动它。

### §10.3 读数二：把筛选器当扫描器用，**正在训练的那一档是所有档里最差的**

`reports/taiji_r2_factorization_split_screen_20260923.json`（预注册档位 `k ∈ {0,24,32,40,48,56,64,72,96}`，
`k`＝activity 半拿到的通道数；k=0/96 表达不了、如实跳过）：

| k_act / k_trace | **3 `context`** | 5 读出分布 |
|---|---|---|
| 24 / 72 | 0.6889 | 0.6729 |
| 32 / 64 | 0.6745 | 0.6823 |
| 40 / 56 | 0.6856 | 0.6827 |
| **48 / 48（我实现并已开训的那一档）** | **0.6236** | 0.6324 |
| 56 / 40 | **0.7188** | 0.7098 |
| 64 / 32 | 0.6662 | 0.6605 |
| 72 / 24 | 0.6821 | 0.6840 |
| *（不改造）* | *0.6417* | *0.6198* |
| *（trace 块本身，即上游天花板）* | *0.7256* | — |

**三条结论**：

1. **48/48 是所有档里最差的一个，还低于"什么都不改"** ⇒ 那轮 22–38 h 的长跑连
   "机制比基线好"这个前提都不成立。**已于 14m21s 停掉**（尚未产生 checkpoint，无可回收）。
2. **最好的档（56/40，0.7188）也只是把 context 拉回接近 trace 块本身的 0.7256**——
   ⇒ **分块最多"少损失一点"，从不"创造可分离性"，而且没有任何档达到可分离区（≥0.9）。**
3. 相邻档之间摆动 0.095（48→56）而刺激集只有 6 个族 ⇒ **排序本身很不稳**，
   挑"最好的 k"就是**在小集合上挑**。所以连 56/40 也不该直接送进长跑。

### §10.4 方案更正：**投影不是杠杆，靶点要上移到区域侧**

把 §10.3 与 Step 0 的剖面合起来读：**全链路没有任何一级达到可分离，最好的量是 trace 块本身的 0.7256。**
分块做的只是"让 context 少丢一点"，天花板就是 0.7256 ——**所以缺口在更上游**：区域动力学本身
就没有把"哪个词扮演哪个角色"分开。⇒ **靶点应定在区域侧**，而不是 `receptors`。

**同时改变工作方式（这是本节的真正产出）**：
**任何结构改动先在初始化上筛（分钟级），只有初始化就明显改善的，才进长跑。**
`scripts/training/probe_taiji_r2_factorization_at_init.py` 与
`scripts/training/screen_taiji_r2_factorization_splits.py` 就是这台筛选器，可复用到别的结构改动上。

### §10.5 本节的边界

筛选器**只否证不确认**；它的排序在 6 族上有噪声；它量的是**初始化**状态。
因此"停掉那轮长跑"的依据是**两条**：机制在初始化上就是负的（§10.2）＋正在训练的档是最差的（§10.3）。
这两条足以说"这 38 h 不值得花"，**不足以**说"分块这个方向被彻底证否"。

## §11 真正的诊断：**结构在初始化时就有，是训练把它花掉的**（2026-09-23，零训练、分钟级）

### §11.0 为什么敢接下去 —— 先堵掉"这就是种子噪声"这个洞

`§10.4` 说"靶点上移到区域侧"。但在下结论前必须承认一个洞：**Step 0 的剖面是在训练过的
`seed_beta.pt` 上量的，而"初始化"那一端是新构造的另一份模型**——训练器当初是否**恰好**从这份配置
起步、有没有另设 seed，我**没有核实**。只要 seed 不同，那个差就有一部分是种子差异。

⇒ 所以先做两件零训练的自我证伪，都用**同一把尺子**（Step 0 的分块口径）与**同一条构造路径**
（`Seed(SeedConfig(...))`）与**同一批冻结刺激**：

1. **`probe_taiji_r2_separability_before_training.py`** —— tick 0 与 16M 对齐：

| 级 | tick 0 | 16M | Δ |
|---|---|---|---|
| 1 activity 块 | +0.6303 | +0.4586 | **−0.1717** |
| 2 trace 块 | +0.7256 | +0.5766 | **−0.1490** |
| 3 `context` | +0.6417 | +0.4197 | **−0.2220** |
| 4 context_trace | +0.6767 | +0.5199 | **−0.1568** |
| 5 读出分布 | +0.6198 | +0.4587 | **−0.1611** |

2. **`probe_taiji_r2_init_seed_spread.py`** —— 初始化本身的跨种子分布（预注册 8 个 seed），
   判读线先写死（训练值落在 init 的 min/max 之外才叫"超出初始化波动"）：

| 级 | init min | median | max | **16M** | z | 判定 |
|---|---|---|---|---|---|---|
| 1 activity 块 | +0.5388 | +0.6053 | +0.6303 | **+0.4586** | −5.17 | **beyond_init_range** |
| 2 trace 块 | +0.6150 | +0.6539 | +0.7256 | **+0.5766** | −2.05 | **beyond_init_range** |
| 3 `context` | +0.5790 | +0.6418 | +0.6724 | **+0.4197** | −5.72 | **beyond_init_range** |

**三级全部低于初始化的最小值** ⇒ 这个差**不是种子噪声**。

### §11.1 结论（**这推翻了本提案原来的病因**）

> **槽结构在初始化时就已经存在**（跨 seed 0.58–0.73），**是 16M 的下一字节训练把它花掉的**：
> 每一级都掉到初始分布之外，区域迹本身也掉（−0.149 ~ −0.172）。

于是前面所有现象一次讲通：

* `receptors` **不训练** ⇒ 换它的形状不可能救回来（§10 的扫描已实测）；
* 读出头**训得动**，所以它买到了"流畅"，但它拿到的输入**早就没有角色结构**，因此买不到"答对"；
* Step 0 看到的"全链路没有一级可分离"，**不是某个零件坏了，而是整体被训练抹平了**。

**⇒ 本提案原来的"改某个零件的形状"是错的杠杆。真正的杠杆是训练侧：目标函数 / 正则 / 任何能
让"按角色分解"不被花掉的压力。**（`§4.2` 的主判据与配对臂设计仍然可用，只是被改的那一处要换成训练侧。）

### §11.2 下一步的形态（**停在决策点**）

训练侧的东西**没法在初始化上筛**（初始化两边一模一样）。所以最快的可信路径是**分段短跑**：
用同一台分块仪器在 **250k / 500k / 1M** 处各量一次，看"掉下来"的斜率在两种设置下有没有区别——
比 16M 短一个数量级，而且**沿路就有读数**。要不要走这条、以及动哪一处训练侧设置，**需要所有者定**。

### §11.3 本节的边界

* 8 个 seed 样本小、用 min/max 作界很脆 ⇒ z 分数只作旁注；**"低于最小值"这一条是硬的，"差多少"不作精确主张**。
* 仍未核实训练器当初是否**恰好**从这份第 0 tick 配置起步 ⇒ 若另设过 seed，差值会被高估；
  但**三级同时低于分布下界**这一点，用单纯的种子差异解释不了。
* 刺激集仍是那 6 个冻结族。

## §5 什么会否掉本提案的前提（**先说清楚**）

1. **Step 0 出现"全程可分离、只有读出分布不可分离"** ⇒ 前面三条线索的归因要重写（§3.3 第 3 行），
   本提案**作废**，改从读出侧重新立题。
2. **Step 0 的可分离性剖面在同一级上跨刺激集不稳定**（换一组族数字大幅移动）⇒ 说明当前统计量的
   族间方差过大，**先修仪器再谈结构**，本提案暂停。
3. **`struct-off` 与现行基座在副读数上不可比** ⇒ 说明重训路径本身引入漂移，先查实现差异，不进入主判据。
