# 24-S.0 预注册：跨会话经验学习与可支付维护（五会话窄卡；≤1200 CPU；零 check）

> [预注册] — 2026-11-22（D-20261122-282）。合同：[MAINLINE §3A.2 `24-S`](../MAINLINE.md)：净益 `>=0.05` 且持续 `>=2` 会话；四类纠错 `2` 交互内恢复。上游 23-S `verified`（D-281，pending ratification）。**本文零训练、零 check；执行需单卡授权。**

## 1. 主体与范围（沿用 S1-RT 机制）
- 72 单元 `SelectivePersistentGraph`；三任务路由 24/24/24；参数级保护（wd=0）；`capsule_v2` 携带 routes，**每会话结束保存/恢复一次**；
- 会话数：**5**（窄卡；正式 24-S 为 10 会话×32 轮另行定价）；每会话训练 200 步；
- 任务：CN（8 类）＋P-B 四类纠错＋P-D 遮挡物理；会话内按 2:1:1 交错。

## 2. 会话流（预注册，固定）
| 会话 | 新增/修订 | 内容 |
|---|---|---|
| S1 | 建立 | CN(seen)＋P-B 基准流＋P-D 基准流 |
| S2 | 新组合 | CN **新颜色对子集**＋P-B 新实体映射＋P-D 新遮挡位置 |
| S3 | 修订①：过时标签 | P-B 旧标签翻转（source=trusted） |
| S4 | 修订②：误导来源＋矛盾 | P-B 加入 misleading source；CN 出现两来源矛盾 |
| S5 | 延迟保持 | 仅评测，不新增数据 |

修订③「来源撤销」（S4 内）与④「责任模块反馈」（S3/S4 对 P-B 头反馈）在同一流内各触发一次。

## 3. 判据（读前冻结）
| 门 | 判据 |
|---|---|
| G1 保持 | S5 相对 S1 峰值：CN ≥0.95−0.02、P-B ≥0.85−0.02、P-D ≥0.80−0.02 |
| G2 纠错恢复 | 四类纠错各自「2 交互内」恢复至 ≥0.85 |
| G3 净益 | S2–S4 各会话相对 S1 的会话末综合分增益 ≥0.05，且**持续 ≥2 会话** |
| G4 恢复一致 | 每会话 capsule 前向差 ≤1e-6；恢复后三任务差 ≤1e-6 |
| G5 预算 | 3 seeds、≤1,200 CPU、零 check/final |
| G6 纪律 | `criteria_sha256` 读前冻结；不调阈 |

出口：全过⇒`24s0_verified`；G1/G2/G3 任一不过⇒`24s0_partial`；超帽⇒`budget_stop`；工程失败⇒`engineering_failure`。

## 4. 披露
- 合成受控面，四类纠错为**程序化事件**，不等于真实对话/开放中文；
- 「交互」定义为一次数据批次更新（2 交互=2 批）；
- 固定分区/保护为实验层机制；heads 单独序列化；零 check/final；不签 24-S 正式包/29/C/D/J。
