⇒ 所以"读取＝贴摘要"不是修辞：**答题时进皮层的是一枚池化且按场龄衰减的向量**，
`recall()` 的逐步证据（`MemoryRecall` 的 `time_code`／`episode_code` 等）没有沿存储轨迹被重放进生成。
H-S1b 要动的就是这一格：**生成开始时，对被检索到的事件做一段逐步再激活，读出头条件于再激活之后的状态。**

## §1 要动的最小格（开关化，默认关）

1. 新增配置开关 `answer_reactivation_replay`（默认 `False`）。关闭时**不得进入任何新分支** ⇒ 默认路径逐位不变，
   这条中性由 G-N1d-1 机检，不靠"看起来没改"。
2. 开关开时，在一次答复的**首个生成步之前**：从检索结果取该事件的存储轨迹步序列，
   以 `learn=False` 连续调 `fabric.step(..., episodic_feedback=<第 k 步的重放投影>)` 走 `N` 步，
   把所得区域状态作为该答复后续步骤的条件基底；`N` 与取哪条轨迹都由旗标显式给，不留隐式默认。
3. **不改** `recall()` 的池化摘要语义、**不改** `memory_confidence_decay`、**不改** `consolidate()` 那三处注入 ⇒
   本件只加生成期一条通路；夜间重放与它互不冒充（若要合并是另案）。
4. 逐步状态的来源只允许**读**现有存储（`MemoryRecall` 字段／情节场在册轨迹），
   **不许**把 `DevelopmentalReplayEvent` 那束拿来当持久来源（§0 末两行给了它会被清空与有上限的出处）；
   若发现现存载体不足以支撑"沿轨迹逐步重放"，结论要写成**阻塞项回报 owner**，不许现场改成"池化多步近似"再声称测的是 H-S1b。

## §2 判据（先冻四条，每条写"什么情况下为假"）

* **J-N1d-1 生成条件真改变（动态范围）**：同一题、同一权重，开关关与开关开两次答复的首步候选分布必须**不全等**
  （逐字节比较，不写"看起来不同"）。为假的情形＝再激活算完没接到读出头（那本件测的是仪器不是产品）。
* **J-N1d-2 梯度到轨迹起点（§8.6 第 1 条的硬读数，缺此项不结项）**：训练一趟里对 `L_answer` 求导，
  取再激活段**第一步**的区域状态与末步的梯度范数各一枚出版，要求首步范数 `> 0` 且同趟内非零；
  负对照＝把再激活段截断成只走首步，读数必须落到 0 或该臂被拒收 ⇒ 这把尺能为 false 才算存在。
* **J-N1d-3 三器官同读**：复述／世界转移／身份同构三器官在同一次修复下各出一枚读数，
  每器官同时给"装机第 0 点"对照（现读参照值取自 09 §2 与 A 支线收官件：装机 13/72、主列 41→59、

* **J-N1d-4 否决门四条逐条过（§7.5）**：固定字符串同分／改问法即失效／上下文被忽略／缺权重仍有相同回答，
