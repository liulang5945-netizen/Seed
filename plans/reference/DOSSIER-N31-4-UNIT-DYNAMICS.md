## 1. 级0：机制算法（设计）

| 字段 | 内容 |
|---|---|
| owner | Taiji 核心单位（`taiji/u2_selective_units.py`：`SelectiveNeuralUnits`） |
| input | 每 tick 的外部写入输入（任务 token 投影）＋跨单位信号（`w` 连接）＋持续状态 |
| state | 每单位：持续活动向量 `state`、慢变量 `a`（多时间尺度）、可塑参数（r/p/c/eta/b/w/write_in/write_state、write_bias） |
| update | 每 tick：写入门控（`write_in(state)` 与 `extra` 偏置之和经 sigmoid）→ 候选写入 → 按门混合进状态；状态经 `w` 与自身循环项更新；慢变量 `a` 以较慢时间常数跟踪活动 |
| output | 状态向量（末步读出，read_gate 见登记表）；单位级活动可供下游读出头/路由 |
| downstream | 读出头、路由（N31.1）、生长队列（N31.3）、胶囊（工程） |
| resource | 参数量与 FLOPs 可对齐（本卡与 GRU＋read_gate 等 FLOPs，差 ≤0.5%）；N31.4.01 中 selective 参数量 +21% |
| lesion | 单位休眠/退役（生命周期 API）；read_gate 去除（D-329 证据：下降 0.47–0.48） |
| checkpoint | 胶囊 v2 逐位恢复（ENGINEERING） |
| evidence | D-329、D-330、N31.4.01（本卷宗） |

**可证伪主张（一条）**：在需要跨多槽保留与覆写的长时程任务上，写门＋慢变量 a 的 Selective 单位（等 FLOPs）优于 GRU＋同位置 read_gate；若在确认 seed 上配对差 ≤0.02（平）或更差，则主张被否证，按标准替代处理。

**标准替代集**：GRU＋read_gate、LSTM＋read_gate（等 FLOPs；同 lr 网格）。
**预期失败方式**：① 长时程覆写时慢变量拖累 → H3 上低于 GRU＋read_gate；② 写门饱和/退化为常数门 → 与无门等价；③ 参数更多但表达不增益 → 平（应判 REPLACE-STANDARD）。
**资源估算**：每单位 O(d_state²) 的状态更新＋O(d_state) 门控；随单位数线性增长，生长时由适配器承载新队列（N31.3）。
**场景声明**：合成任务、**非任务无关**（H 档任务族内），未引入任务名/脚本常数路由 → 属机制组件（可作为认知机制候选），不依赖外控。
