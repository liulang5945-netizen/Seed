# A.3 接口复核：前缀 0 在噪声底，后前缀是教师强制泄漏；C 不成立，建议改走体内列读通路（2026-11-16）

[复核报告](../../reports/taiji_u2_a3_interface_20261116.json)、[守卫回执](../../reports/taiji_u2_a3_interface_guard_20261116.json)、[契约](../manifests/taiji_u2_a3_interface_20261116.json)。前置：[A.2 结果卡](RESULT-TAIJI_U2_A2_BYTE_20261115.md)。

## 1 裁定

机器判定为 **`interface_partially_decodable`**（前缀 0 线性探针 fit 0.4375 ≥ 0.40），但**这不是 C 可行的证据**：同一测量点上，标签打乱零假设 0.34375、列 token 参考 0.375、RBF 探针 0.34375，14/32 的读数落在噪声内；更直接的是，前缀 0 的 x 对**被涂列颜色**的探针只有 **0.0154**（背景 0.963）。**结论：当前主体的 x 在答题前不携带场景读；C（读作教师蒸馏）不成立。**

后前缀（1–6）的可解码性升到 0.81–1.0，是**教师强制泄漏**：缓存按目标字节推进状态，x 里已经含了答案前缀，不是从场景读出来的。不得引用为“x 携带答案”。

## 3 判据缺陷登记

原判据只看 `max(linear, rbf) ≥ 0.40`，没有要求**相对零假设/参考的最小效应量**。这次 0.4375 因此触发了 partial 分支，但零假设 0.34375、参考 0.375、被涂列颜色 0.015 同时指向“无信号”。下一张复核卡必须把判据改为：

- 主测量与打乱零假设之差 ≥ 0.20，且
- 被涂列颜色探针（前缀 0）≥ 0.50，且
- 只允许前缀 0；前缀 ≥1 一律标为泄漏，不进入判定。

## 4 三条接口的裁决

| 选项 | 机制 | 上限 | 裁决 |
|---|---|---|---|
| A 固定投影 | 校正后的逐列 logits 经固定投影进 `joint_readout` | 管线能答，主体不读 | 可作回退；不签 A 父 |
| B 可训适配器 | 同上，但投影可训（管线参数） | 略高于 A | 可作回退；不签 A 父 |
| C 读作教师 | 主体自己的 x 必须携带读类别，再训字节头 | 最高（主体自己读） | **当前 x 不支持**（见 §1–2） |
| **D 体内列读通路** | 把 16 个列 token 以“请求为 query 的逐列注意力”接进主体读出头，答题前即可用 | 最高，且是唯一让主体自己读的路径 | **建议作为下一卡** |

D 的要点：前缀 0 的读必须来自列 token，而不是已经生成的前缀；参数量要小（设计帽 ≤ 8k 标量），主体其余部分冻结或小范围解冻；先做零训练设计对账与定价，再请求训练授权。

## 5 能主张与不能主张

**能**：当前主体在答题前的 x 不暴露被请求颜色（被涂列颜色 0.015、类别 0.44 对零假设 0.34）；后前缀的可解码性来自教师强制前缀；A/B 只能作为管线，不能让主体自己读。

**不能**：不能写“C 已证否到信息不存在”（闭式探针复现不了非线性读，列 token 参考也只有 0.375）；不能写“x 携带答案”；不能写 A 父或能力；不能把 0.4375 写成部分可解码的正面证据。

## 6 唯一的下一步

**`22.5.A.4` 体内列读通路设计卡（零训练设计 + 定价，不训练）**：把“请求作 query、16 个列 token 作 key/value 的逐列读”接进 `joint_readout` 的位置，写清参数量、初始化、旧能力保持、前缀 0 读门（fit ≥0.80）、字节门与预算，再请求训练授权。A/B 保留为回退，C 在当前 x 上关闭。
