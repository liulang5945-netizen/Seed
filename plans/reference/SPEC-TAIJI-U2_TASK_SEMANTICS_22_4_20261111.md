# U2 22.4.0任务语义与信息权利

> 文档状态：[合同] — 2026-11-11。父身份取22.3接受清单。首版实现环境/评分侧的绑定和权利检查，完整二维世界及模型可学习元数据入口由后继子卡交付。

## 1. 输入和职责

持续goal与当前answer_request分别保存原文及版本。request_id绑定goal_version、world_version、实体、时间意图current/previous/unknown、合法证据ID和目标。实体/时间结构字段属于环境oracle，模型接收原始请求及已授权可见输入。文本解析失败进入全分母错误。

环境事实登记entity、value、version、source、evidence_id及可见原文。首版位置问答current取声明world_version内最高版本，previous取该实体倒数第二个版本，缺少事实时输出“未知”。同实体同版本冲突返回fixture_invalid，后续冲突任务另冻结允许求证集合。

## 2. 权利与信息

模型可见输入由调用方显式提供的原始观测/请求/历史序列构成，oracle结构化事实只供生成与评分。相同全部合法可见输入需要不同目标时，成对可辨性检查拒绝该夹具。该检查需要调用方真实声明完整可见输入，世界生成器继续负责覆盖证明。

反馈分别登记observation、train_label、online_correction、help_reply、score_only及释放轮次。train_label仅在train/fit的发展期使用，在线纠正和求助回复在预测提交后按释放时间消费。score_only留给评分器。验证器拒绝提前、越分区或错通道使用。

## 3. 标签与评分

微型夹具的中文请求由环境侧request_text模板生成，校验文本和环境标签对应。该模板用于合同测试，模型仍由自身可学习机制读取原始请求。开放措辞与完整物理世界在后继生成器中独立验证。

任务校验核对request/goal/world身份、实体、版本、来源、合法证据及标签。评分按冻结请求列表逐轮进行，缺失、解析失败、无EOS、非法UTF-8或内容不符均计错。多余响应列为协议错误并加入分母。响应按原始完整内容匹配，数据源和位置联合成立才得分。

22.4.0用微型合成合同夹具验证六类错配与合法信息成对检查。它不承担世界物理模拟、任务oracle≥0.95、记忆空白≤0.60或能力验收。22.4.1先适配模型可见记录元数据和结构，22.4.2–4再冻结完整世界/分区/实价。当前0optimizer、0check/final读取。
