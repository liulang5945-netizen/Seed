## 1. 总结先行

**项目已经形成可执行的研究模型、局部学习机制、训练与恢复工具，以及限定任务范围内的正向成果；但尚未形成通过基本对话、问答和上下文验收的统一原生模型。**

这不是“没有模型存在”，也不是“模型已经能用，只差界面”。真正的差距在于：部分机制成立、部分预测指标改善，尚未稳定转化为同一模型入口下的内容正确性与可用能力。

目前可以分成四类结果：

| 类别 | 已有结果 | 当前可作出的结论 |
|---|---|---|
| 已认可的限定成果 | K轴继承式持续学习、显式runtime附着 | 在五类合成载体和opt-in范围内成立，不等于通用持续学习 |
| 工程与局部机制成果 | 保存恢复、来源绑定、B2-v4协作实验、R2一致性修复 | 形成可复用资产；其通过范围不能扩大成整模型能力 |
| 已完成的负结果 | H3.7、H3.7B目标几何比较、H3.8 v1/v2 | 相应候选未过冻结门，按规则停止；不是整个Taiji或所有类似架构的否定证明 |
| 尚不可判的结果 | 原P3b的数据分布效应、P3b-v2中断pilot | 证据不足或合同/身份未闭合，不能补写成功或机制失败 |

阶段仍为M5。M4结构成长未完成，M6默认采用、M7发布、M8设备优化也没有由本轮结果获得晋级。

## 2. 已经得到哪些正向成果

### 2.1 K轴：有明确范围的持续学习机制成立

[K轴晋级宣布](M5_K_PROMOTION_DECLARATION_20260912.md)记录：五类合成课程上的继承、累积学习与保持证据，以及checkpoint、中断恢复、真实runtime附着、rollback和非干扰合同已形成闭环；项目所有者已批准限定晋级。runtime附着的4/4 cell在其消费合同下复现。

可保留的结论：**Taiji并非完全不能学习或保持，某些明确任务上的机制已被验证。**

不能外推：开放域终身学习、自然语言问答、结构自我成长或默认产品采用。`growth_admitted=false`；附着为显式opt-in、进程内状态，不是默认聊天入口已使用全部研究成果。

### 2.2 B2-v4：冻结任务族内的协作判断得到支持

[原始报告](../../reports/taiji_b0_b2v4_collaboration_20260916.json)的九项门为true，`outcome=collaboration_supported`、`experiment_passed=true`；同时`can_promote=false`、`growth_admitted=false`。

可保留的结论：冻结机制、选择程序与任务族内，协作收益和相关对照有证据。不能将实验gate成立写成产品核心已集成、跨任务族协作普遍成立或M5协作轴整体晋级。

### 2.3 R2：训练、恢复与信用一致性已有真实工程成果

H3.7B保留下列修复：

1. 计划目标更新后刷新首字节预测缓存，避免使用旧概率计算新状态的误差。
2. 槽位混合前向使用0.75/0.25时，反传按同一混合关系分配；四phase局部映射通过数值差分检查。
3. byte-aligned目标有独立格式；旧格式不自动迁移，错误格式拒绝加载。
4. 两臂工程验证均完成零步/child保存恢复、新进程加载和一步续训一致性检查。

原始材料：[修复合同](M5_R2_H3_7B_CONSISTENCY_REPAIR_20260917.md)、[旧目标臂](../../reports/r2_h3_7b_validation/legacy_target/report.json)、[byte对齐臂](../../reports/r2_h3_7b_validation/byte_aligned/report.json)。每臂工程验证为12episodes、537byte更新、277,970有效参数。

这些成果证明“训练链条更一致、结果更可追溯”，不证明“修复后能回答问题”。局部梯度映射正确也不是整个系统已经实现完整跨时间信用分配。

## 3. 模型是否存在，实际输出是什么

存在实际权重、checkpoint、加载器和生成报告。必须区分不同入口，不能把它们混成一个统一能力分数。

### 3.1 默认入口的实测：模板回应，不构成问答能力

[2026-09-17 CAP-0报告](../../reports/taiji_cap0_baseline_v1_20260917.json)绑定代码`2a922986…`及checkpoint/评价集摘要；链路为`relax_legacy_guard=false`、`constrained_decode=false`。它不是当前HEAD全部模型的统测，也不是H3.8候选的能力报告。

C01提供“南山图书馆每周二闭馆”后提问“南山图书馆周几闭馆？”，记录的回应是：

> 我已收到你的问题：“南山图书馆周几闭馆？”。当前原生语言表层正在形成稳定表达。

这不是回答“周二”。它是默认受保护入口的实测表现，不能据此声称原生解码器生成了这段流畅模板文字。

| 维度 | 机器计分结果 | 仍待人工检查 |
|---|---:|---:|
| C 基本问答 | 0/14 | 6题 |
| D 上下文与工作记忆 | 0/16 | 4题 |
| E 指令与简单推理 | 0/20 | 0题 |
| B 基本对话 | 无机器归一分 | 20题 |
| G 不确定性与安全 | 无机器归一分 | 20题 |
| A/F/H 真实性、代表能力、性能 | 未执行 | 不计通过 |

因此C/D/E存在明确缺口；B/G不能写成0分或通过，A/F/H不能拿其他局部测试代填。

### 3.2 原生研究路径的实测：确实生成，但内容错误

[H3.7 treatment seed20260917报告](../../reports/taiji_r2_h3_7_treatment_dev_20260917_seed20260917.json)的`dev-answer-green`原始生成是：

> 不能捍斍不桮嚥定柴柚柀

该样例`exact_response=false`，必需词覆盖为0。这说明存在真实生成路径，同时说明“输出合法中文字符”与“形成正确回答”相差很大。它是旧H3.7样例，不代表所有后续checkpoint。

## 4. 语言路线的主要实验结果

### 4.1 H3.7：分解式工作空间没有获得已注册的内容收益

[三seed汇总](../../reports/taiji_r2_h3_7_matched_dev_result_20260917.json)：

| 指标 | control | treatment |
|---|---|---|
| dev sequence criterion | 0.25 / 0.25 / 0.25 | 0.25 / 0.25 / 0.25 |
| dev完整回答精确匹配 | 三seed均0 | 三seed均0 |
| 必需词覆盖 | 三seed均0 | 三seed均0 |
| UTF-8合法率 | 三seed均1 | 三seed均1 |
| 结束边界率 | 1 / 1 / 0.875 | 1 / 0.875 / 0.875 |

汇总为`stopped_before_final`；内容方向、边界不退化、消融撤销真实收益等门未同时成立。sequence criterion的0.25不是问答正确率25%。

后续一致性审计发现训练/目标混杂，因此最稳妥结论是：**这份实现及实验设置没有形成所要求的收益**。不能据此断言工作空间方向理论上无效，也不能因为消融改变了输出就宣布找到了有效内容机制。

### 4.2 H3.7B：修复有工程价值，但byte对齐目标没有dev优势

[可学习性报告](../../reports/r2_h3_7b_validation/learnability_analysis.json)给出两臂各12/12训练样例的平均surprise改善：

| 目标 | 训练前surprise | 一轮训练后surprise | 训练集完整回答匹配 |
|---|---:|---:|---:|
| 旧字符安全分段 | 5.6192 | 4.1376 | 0 |
| byte对齐分段 | 5.6192 | 4.2762 | 0 |

之后独立的两轮dev验证中，[旧目标臂](../../reports/r2_h3_7b_validation/dev_legacy_target/report.json)的surprise变化为−1.434426、字节预测准确率变化为+0.206858；[byte对齐臂](../../reports/r2_h3_7b_validation/dev_byte_aligned/report.json)分别为−1.434191、+0.176785。

结论：训练信号并非完全无效，未见数据上的字节预测也有改善；但是**目标几何替换没有体现预期优势**。两轮dev与一轮工程探针是不同预算，不能把它们拼成同一个run。保留一致性修复，停止围绕这次几何更换追加预算。

### 4.3 H3.8：联合序列训练可拟合，但工作空间收益不稳定

两版均使用三seed；下面的accuracy是**给定正确历史时的下一字节预测准确率**，不是自由回答正确率。

| 已核实字段 | [v1原始报告](../../reports/r2_h3_8_matched_dev_20260917.json) | [v2原始报告](../../reports/r2_h3_8_matched_dev_v2_20260917.json) |
|---|---:|---:|
| 工作空间臂dev平均accuracy | 0.600629 | 0.622642 |
| 基线臂dev平均accuracy | 0.616352 | 0.600629 |
| 平均差值 | −0.015723 | +0.022013 |
| 逐seed工作空间优势 | 1/3 | 2/3 |
| 逐seed正向lesion落差 | 1/3 | 2/3 |
| 所有seed训练拟合门 | 通过 | 通过 |
| 边界不退化门 | 通过 | 通过 |
| 冻结综合结果 | `workspace_unused` | `workspace_unused` |

v2限制了prefix绕过工作空间的通道，部分指标方向变好，但仍未满足逐seed稳定性和均值差门。报告标签`workspace_unused`应理解为该协议的停止类别，**不是“每个seed中工作空间都毫无作用”**；v2已有2/3正向lesion信号，但不足以晋级。

两版final均未读，`can_promote=false`；按预承诺停止该候选族的追加投入。不能把两次负结果升级成“成熟训练无效”或“所有可学习工作空间无效”。

### 4.4 原P3b与P3b-v2：不是同一条结果

原P3b：按[后续R0审计](M5_R0_EVIDENCE_GATE_AUDIT_20260916.md)，两臂均已停止；唯一共同检查点17M上，C/D差值为0、E差值+0.05（一题）。共同点数量不足，数据分布主效应不可判。[早期阶段稿](M5_P3B_RESULT_20260916.md)仍含pending，不能以它覆盖后续审计。

P3b-v2：新合成语料80行，train/dev/final为40/20/20；pilot被用户收束中断。旧磁盘checkpoint虽记录24episodes/1080byte更新，却早于被停止的进程，且目标格式与文字合同有偏差，缺完整报告。**不能写成“训练失败证明目标对齐无效”，也不能写成“已完成待发布”。**详情与hash见[收束记录](PROJECT_CONSOLIDATION_20260917.md)。

## 5. 目前最可靠的结论

1. **工程可执行性与模型能力是两条账。** 保存恢复、误差更新、梯度测试通过，说明实验可以更可信地运行；回答是否正确仍需单独证明。
2. **字节预测改善不足以代表可用语言。** H3.7B有明确surprise改善而train exact仍为0；H3.8的teacher-forced准确率不能换算为对话成绩。
3. **机制接入不等于机制承担有效功能。** 权重改变、概率面改变或某次lesion有影响，都需要相对于公平基线的稳定收益支撑。
4. **输入被编码不等于输入内容被正确使用。** 不能只用输入敏感性来判断理解、上下文记忆或推理成立。
5. **局部机制成果不应被语言负结果抹掉。** K轴、恢复资产和限定协作证据仍有价值；但也不能反过来用它们替代R2语言验收。
6. **现有材料尚未确定一个唯一、充分的失败根因。** 目标、表示、信用、生成状态、数据规模和评估入口都有待区分；失败配置与理论不可能性不是同一件事。

## 6. 需要收紧的旧结论与口径

| 旧表述或易产生的误读 | 本总览采用的表述 |
|---|---|
| H3.8 v1逐seed优势门0/3 | 原始报告为1/3；综合仍失败，不影响停止决定 |
| 无prefix训练 ⇒ prompt→response依赖在监督中结构性缺席 ⇒ 失败必然 | 这是过强推断。冻结prefix编码仍可能给读出提供可学习条件；已有条件化response损失不能被称为完全没有回答监督。未证明充分根因 |
| `workspace_unused` ⇒ 工作空间完全不起作用 | 未达到预注册的稳定贡献门，保留不同seed的实际正负信号 |
| 旧target的train-bound拟合 ⇒ 已学会语义坐标 | 正scalar经逐槽L2归一化抵消；血缘绑定不等于学得语义几何 |
| P3b没测出数据效应 ⇒ 数据分布不重要 | 检查点/分辨率不足，原实验不可判 |
| 没给用户展示过模型 ⇒ 没有模型存在 | 有checkpoint与真实研究输出，但默认入口、实验生成与统一可用模型尚未对齐 |
| 局部测试通过 ⇒ 当前仓库CI全绿 | 测试绑定各自提交和范围；当前HEAD全量CI未确认 |

这些是对结论强度的整理，不重写原始报告，也不补发任何晋级。过去路线选择可作为历史保留，但重新决策应使用上述收紧后的口径。
