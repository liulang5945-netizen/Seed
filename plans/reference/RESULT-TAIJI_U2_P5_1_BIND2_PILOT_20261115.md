## 3 归因：锚与第二步各自留下了痕迹

- **身份锚有效**：去掉锚的 C 臂，槽内容余弦 **0.7067**；A 臂只有 **0.1991**。锚让三个槽从“几乎同一个平均内容”拉开。
- **绑定内第二步有效**：B 臂（只保留第一步）损失只降到 1.2549、fit pair 0.0897；A 臂降到 1.1594、fit pair 0.1667。第二步在同样的 461 步里带来了更低的损失和更高的 pair。
- **C 臂“零重复”不是优点**：它同时把槽数一致压到 10/32、pair 压到 0.1154，说明它是靠“少报对象”避免重复，不是靠正确分化。**不能**把 C 的零重复读成“无锚更好”。
- **set 仍为 0**：461 步只够让机制活起来，不够形成完整对象集合。A 的 pair 0.1667 也低于 P4.3 在 1844 步的 0.359；试点没有、也不应该证明全剂量能过 set ≥0.80。
