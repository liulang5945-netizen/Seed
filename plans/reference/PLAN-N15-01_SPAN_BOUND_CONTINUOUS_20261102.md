## 2. 根假说复核：哪里是架构，哪里是数据/训练

**不是数据污染或宿主捷径。** 置换世界（next dev world）的期望答案随记录映射改变，模型在 permuted 条件仍有 0.6063；无来源/错误记录降到 0.00。若只是记住 goal→action，置换条件应接近 0；若只是复制最近来源，错误记录条件不会同时降 0.75。内容通路门通过，说明记录确实进入了读取与表达。

**不是“再多训几步就好”。** 训练批次 NLL 已到 1e-4，开发教师强制 NLL 0.849，自由生成 0.584；继续对教师强制目标加步数只会更贴合给定前缀，不会自动修好未见实体和自由前缀误差。14.6 已明确不追加剂量/seed/步数。

**最弱的是绑定，不是“读不读”。** 未见实体 0.2125 与真实/置换两侧 0.4438 指向同一个缺口：模型能把**见过的描述**对应的实体读出来，但不能稳定把**新描述**绑定到记录中的实体，也不能在同一 goal 下同时按两个世界的映射作答。source top-1 仅 0.3125，说明第一步选中的对象记录常常不是正确记录；精确率 0.584 主要靠混合读取和生成弥补。

**结构层级是正号但不稳健。** A−C（记录级寻址 vs 扁平位置）点估计 +0.106/+0.131，但 8 world 配对 bootstrap 只有 1/4 格下界为正；A−B（双向上下文 vs 局部编码）点估计 +0.081/+0.013，B_local 接近 A。不能把 14.6 的失败整体归给“层级架构完全无效”，也不能签“记录级寻址是必要增量”。下一包要检验的是**绑定机制**，不是再加一层同样的头。

**rescue 是接口脆弱性的证据。** 强制正确对象记录、实体起点、gamma=1 后，准确率从 0.75 降到 0.00。说明当前“读取→H→表达”的接口对一次正确内容注入不稳定；新的读取路径必须把 rescue 作为**门**，不能只作报告。14.6 的 rescue 不设门，是这一条的遗留缺口。

**根假说的边界。** 14.6 支持“内容通路可以学、且是必要的”，部分支持“主体能在声明的合成任务上形成记录条件行为”；不支持任务可靠性、层级必要性、保持、连续状态、跨 session、反馈纠错、主动选择和生长。它不证伪整个 N 根假说，但也没有为根假说签字。继续沿 N 主线不等于继续同一接口加剂量。

## 3. N15.1 唯一机制候选

**名称**：span-bound compositional reader + self-prefix training（描述跨度绑定读取 + 自由前缀训练）。

**不换主体、不叠头**：保留 09.8 父主体的 H/F、继承字节编码器、generate/mix 头与恢复协议。新的 `span_binding` 读取**替换** 14.4 的“整记录池化摘要选记录 + 记录内位置 softmax”路径，而不是在旧读取之上再加一个头。旧的记录级 `K_record`/`Q_value` 池化选择在新候选里停用并单列；新参数只承担目标描述跨度↔记录描述跨度的对齐和实体跨度选择。14.4/14.5/14.6 的模块与卡片不改，作为历史接口保留。

### 3.1 描述跨度绑定

记录仍是完整观察的原始字节（`描述是实体。`），宿主不在 `是` 处切分、不提供描述/实体 span、不渲染动作 ID。模型在共享字节单元上学习：

1. **目标描述→记录描述的对齐**：用目标单元与记录单元做可学双线性对齐，得到每个记录的对齐分数；记录选择由该分数（而不是池化摘要）决定。目标里哪几个字节是对象/地点描述，由模型从训练信号中学，不由宿主标注。
2. **描述末尾→实体起点的相对位置**：对齐到记录描述后，用可学相对位置分布选择实体跨度；不在宿主代码里写死“跳过描述+是”的偏移。记录内位置分数与 coverage 仍按原协议工作。
3. **同一内容分布**：选中的记录/实体跨度产生一个内容分布，继续同时进入递归 H 更新和原始字节输出；不新增第二个输出头，不改变 EOS/复制的边界。
4. **ID/标签隔离**：来源 ID、版本、实体 span 只用于评分/oracle；前向不接评分上下文，错误输出不被宿主修正。14.4 §3.1 的硬编码边界继续有效。

这套绑定直接针对 14.6 的三个弱轴：未见实体（共享字节单元 + 描述↔记录对齐，而不是记录池化摘要）、真实/置换两侧（同一 goal 下按记录映射选择实体）、source top-1（记录选择由描述对齐而非池化摘要）。

### 3.2 自由前缀训练

任务门用自由生成，14.6 的训练却只用教师强制前缀。N15.1 在同一原始字节 NLL 上加入**声明的自前缀课程**：

- 更新 1–100：100% 教师强制（先建立基础复制/生成分工）。
- 更新 101–200：50% 教师强制 / 50% 自前缀；自前缀由模型生成，**停止梯度**，只对完整目标的字节 NLL 反传。
- 更新 201–300：25% 教师强制 / 75% 自前缀；自前缀停止梯度。
- 开发/确认仍用自由生成；训练读数不替代自由生成。
- 自前缀的采样长度、批次混合和停止梯度在 N15.1.0 定价件中冻结；不做网格，不在 14.6 之外追加剂量搜索。

这是一项训练/目标改动，不是新头：它让负责参数见到自己的前缀误差，目标仍是同一条 27 字节动作＋EOS。

### 3.3 三臂

- **A_span_full**：完整 span-bound 读取 + 双向记录上下文 + 自前缀课程。
- **B_span_local**：同容器/初始化，停用双向记录上下文残差（`u=a`），其余相同；披露停用参数。
- **C_span_flat**：同整记录编码与表达，停用 span 级记录选择，位置分数在所有合法位置上统一 softmax；用可学 null 位置，取 pi 后相同方式输出；保留但停用的记录级参数单列。

三臂共享同一 09.8 父、同一 v2 数据、同一优化器配方与输出端点。A 对 B/C 的总体增益、逐 seed 8 world 配对 bootstrap 2000（seed 若沿用 57031 或新声明）继续按 14.6 的口径。
