## §2 新门定义（M1-P，钉住题面总体）

> **M1-P**：在**题面总体 P** 上，A 臂的成句率 ≥ `max(B, C)` 的成句率 **+ 15 pp**，
> **且** A 与该最好者的逐题配对**精确双侧**符号检验 **p < 0.05**。

**题面总体 P 的定义（本件钉死，此后引用 M1 必须带它）**：

- 源：`data/p3b_all_fresh.jsonl`；**可用区间**＝行内累计字节偏移（`Σ(len(text.encode())+1)`，与血缘
  清单 `emitted_symbols` 口径一致）**≥ 16,000,000** 的行 ⇒ 下标 **4026..29875**，共 **25,850** 行。
  （该区间在三臂训练窗口 `[11,199,800, 27,199,800)` **之外**。）
- **抽样规则**：`stride = 25,850 // 160 = 161`；相位 φ 的集合取第 `4026 + φ + 161k` 行（k=0..159）。
  **φ = 0 ⇒ 主集（已公布）**；**φ = 80 ⇒ 复制集（本件新封）**。
- **题面**＝该行 `text` 的**前 32 个字符**。每条独立会话、`greedy` 解码。
- 构建器 `scripts/training/build_r2_readout_m1_v3_prompts.py`（同一段代码产两个相位；已存在即拒跑）。

**成句判据**：**直接 import** 已 FROZEN 的 P1/P2 仪器（`diag_taiji_r2_surface_decode.py`）——
语料 n 元每字符平均对数似然 ≥ **−7.8**、长度 ≥ 8 字符、单字占比 ≤ 0.35；反向对照门
（真中文通过率 ≥0.5、打乱拒绝率 ≥0.9）不过则整件拒跑。**一个字不重写。**
