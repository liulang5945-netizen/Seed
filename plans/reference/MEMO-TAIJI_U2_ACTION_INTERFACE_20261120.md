# 备忘：动作接口可行性（物理后果轴）——接口可用、单步位移量随体参数变化

> 文档状态：[可行性] — 2026-11-20。回执：[r1](../../reports/taiji_u2_action_interface_20261120.json)／[r2](../../reports/taiji_u2_action_interface_r2_20261120.json)。**零训练、零 check。**

## 1. 接口事实（读代码＋实测）

- `PhysicalWorld.step(action_id, action)`：15 维动作；`command[0:9]` 为 act/inspect/ask one-hot（act=index 0）；`command[9:11]`＝作用点目标，`command[11:13]`＝力方向，`command[13]`＝强度，`command[14]`＝脉冲时长（≤0.05）。
- 单步 act 实测：被作用体产生**方向可控**位移（+x 推→dx≈+0.17；−x 推→≈−0.18；+y 推→dy≈+0.11），其余体位移 <0.01；同 seed `elapse` 基线位移约 0.006–0.01。
- **位移量随体参数/初始状态变化**：4 个 seed 中单步目标位移范围 `0.042–0.183`；靠近边界会被夹住（r1 的 0.042 案例即边界钳制）。

## 2. 判读

1. **动作接口真实可用**，满足「行动＋真实结果反馈」的第一条件；且动作效果是**物理推进**（由 `advance` 的力/质量/阻力计算），不是标签回填。
2. 单步位移（0.04–0.18）小于位置三分桶宽度（≈0.33），多数样本**不动桶**；若直接做「单步后果分类」，头空间被边界样本主导且样本效率低。
3. 因此物理后果任务应改为**多步重复动作**（如 3 次同向推），把位移累积到 0.15–0.5，使「动作→后果桶」的变化成为主要信号；边界钳制改为任务内显式分支（推到边界后停在桶边缘），而不是剔除。
