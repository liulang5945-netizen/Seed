# 设计草案：可学两步任务（同向/反向判断，22.X，零训练设计稿）

> 状态：[设计草案/待实现] — 2026-11-20。依据 D-20261119-110：工作记忆写回卡因任务本身不可学（oracle 0.50–0.625）而按出口判 `task_not_learnable`；本设计先让**任务可学**，再验证写回机制。

## 1. 任务定义（二分类，本质需要记忆）

- 动作对：r1、r2 各含方向 `direction ∈ {+1,−1}`；
- 标签：`same = 1 if direction1 == direction2 else 0`（**同向 vs 反向**）；
- **单 tick 只看 r2 不可能判断**（不知道 direction1）；必须依赖对 tick1 信息的保留/写回；
- 数据扩充：合并多个 `build_partition` seed 的行（目标 ≥800 对训练对），fit 保留 64 对；方向分布与标签平衡须记录。

## 2. 写回与四臂

- tick1 看 r1 → 预测其方向（2 类），**把预测方向写回** tick2 输入（one-hot 写特征维 39–40）；
- tick2 看 r2＋写回方向 → 预测 `same`；
- 四臂：自写回、零写回、shuffled 写回（随机方向）、oracle 写回（真实 direction1）。

## 3. 门（预注册）

1. **可学性（先决）**：oracle 写回 `same` 准确率 ≥0.85；
2. **组合增益**：自写回 ≥0.65 且比零写回高 ≥0.15；
3. **写回必要性**：评估清零写回使准确率下降 ≥0.15；
4. **控制**：shuffled 写回 ≤0.55（不可显著优于其先验）。
全过 ⇒ `working_memory_writeback_ready`（有界：单主体、二分类两步任务、显式写回通道）；门 1 不过 ⇒ `task_not_learnable` 再次停止；其余按 partial/negative 记录。

## 4. 预算与出口

- 复用 `UnitScan`；训练 1,500 步、3 seed、零 check、**价 ≤250 CPU**；阈值不调；
- 数据对覆盖检查：每臂各 ≥300 评估对，标签平衡偏差 ≤0.10；
- 出口：全过记有界 verified；门 1 过而写回门不过记 `working_memory_writeback_partial`；否则 negative 并停止同范围。

## 5. 判读边界

即使通过也只是「**二分类两步记忆任务上的显式写回**」有界成立，不等于一般顺序推理/递归发展；不改任务轴 `fit_face_only` 与 check② 状态。
