## 1. 核查发现（已逐行复核代码）

1. **`collect_activity` 收集的是历史快照，不是末态**：
   - `run_s2_wm_gap2_20261120.py:100-113`：`state_carry` 传入 `use=list(range(gap))`，函数把**每个 tick 的单位活动**追加到外部 Python 列表并 `torch.stack` 成 `[B,T,30]`；
   - `run_s2_wm_gap3_20261120.py:110-119` 复用同一函数；
   - `run_s2_working_memory_20261120.py:107-119`、`run_s2_cn_continuous_20261120.py:176-183`、`run_s2_cn_continuous2_20261120.py:185-194` 同样如此。
   - 目标恒在 `t=0`（`run_s2_wm_gap2_20261120.py:58-60`），读出带**可学习位置嵌入** `self.pos[0]`，因此注意力可直接从外部历史数组下标 0 取 t=0 快照。
   - **机制上等价于外置 KV-cache / replay，不是单位状态 z/a/H 的保持。**
2. **特征下标碰撞**（`run_s2_wm_gap2_20261120.py:63-64`）：`body*8 + 2 + colour`（colour 0–5 → 2–7）与 `body*8 + 6 + position`（position 0–2 → 6–8）重叠；跨 body 亦有越界（body2 position 写 24 进入 tick 位）。该 fixture 的特征是**有损/歧义**的。

## 5. 规则增补

1. **禁止把「历史快照拼接」当状态保持**：任何 `state_carry` 臂必须显式声明读取的是末态还是外置历史，并另设 **history 对照臂**；
2. **fixture 特征槽必须做**下标重叠检查（colour/position/tick 位），并在卡内记录偏移表；
3. **目标位置不恒为 t0**：至少加入随机目标位置/多目标变化，防止位置嵌入直接索引；
4. 任何「状态保持」结论必须由 **state_final（只读末态）** 臂支撑，history 臂只能作为上限/对照。
