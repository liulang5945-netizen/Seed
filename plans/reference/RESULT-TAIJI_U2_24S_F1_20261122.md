## 3. 判读

1. **纠正可从反馈学到**：臂 A 单调上升 0.078→0.969（8 交互），C 冻结 0.027、D 反馈置换 0.0 ⇒ 增益来自**正确标签反馈**（G2 因果成立）；无标签暴露不产生学习。
2. **但 4 次交互预算不够**：0.590（差 0.160）；5 次 0.758。8 次预算下可达 0.969 ⇒ 「新来源优先」规则可学，但慢于原设想。
3. **保持崩溃是主问题**：A 臂 8 交互后基准流 0.992→0.574（regime 下降 0.766）；头级臂 B 亦从 0.965（4 交互）跌到 0.328 ⇒ 快纠正与旧能力保持直接冲突（与 22.8 J3、D-72/73 同型）。按 objective「保持已核验旧能力」**本卡不能签 verified**。
4. **G3 预注册 lesion 测量无效**：代码审查（`SelectiveNeuralUnits.forward`）显示 gates 只影响 recurrence/activity，**不清零写入**；mask 置零因此不是有效消融。按纪律 G3 照预注册判「不过」、不改判；另立**事后**消融诊断（D-299，[`diag_24s_f1_ablation`](../../reports/diag_24s_f1_ablation_20261122.json)）只作披露：臂 A 正常 0.965；**恢复 base 单元参数（保留纠正头）=0.473**（单元参数贡献 0.492）；**恢复 base 头（保留纠正单元）=0.664**（头贡献 0.301）；**置零 p24 读出状态=0.223**（读出通路必要）；全恢复=0.027（=base，sanity）。⇒ 纠正在**单元参数与头之间分布**，单元表示是因果必要的部分（非唯一）。
5. **复现性披露**：`Subject72` 构造依赖全局 RNG 状态；F1 与 F1b 的 base 读数一致（0.992/0.027/0.852），早期诊断 base 为 0.832 系构造 RNG 顺序差异，不影响方向结论；后续卡在构造前固定 `torch.manual_seed(seed)` 以保证可复现。
