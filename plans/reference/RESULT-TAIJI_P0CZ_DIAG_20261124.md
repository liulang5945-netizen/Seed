## 3. 判读（关键：跨会话生长扰动）

1. **跨会话生长会破坏「上一会话训练出的旧能力」**：R0 在会话 2 生长 B 后从 1.000 掉到 **0.519/0.660**（与 P0-CS「先学后长」现象一致）；R1/R2 各自学习后都 1.000。
2. **胶囊本身是精确的**：恢复后 R2=1.000、状态差 0.0 ⇒ 破坏来自**生长本身**（新增队列经跨组连接反馈改变旧队列状态、旧读出失配），不是保存/恢复机制。
3. **会话 3 又生长 C 后 R1 仍 1.000**：因为 R1 的读出头与 B 队列是在会话 2 内一起训练的，而会话 3 的生长对 B 的影响较小（或 R1 鲁棒）——但 R0 两次都没恢复。
4. 结论：**跨会话「先学后长」需要重校准旧读出**（或在会话开始就要规划好全部队列）；胶囊不能替代重校准。
