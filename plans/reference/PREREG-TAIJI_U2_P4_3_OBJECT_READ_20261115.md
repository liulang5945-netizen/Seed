## 1 一句话

P4.2 证明字节头不是瓶颈、主体的对象读在四向答案信号下贴随机。本卡把 P4.1 成功的那条规则（**身份式稠密标签**，不是几何式距离）在原处再上一用：给**每个可见对象**加"颜色（6 色＋无）＋位置（左/中/右）"两路训练期标签，迫使主体的绑定／对象读把答案暴露出来；**服务输出仍是主体自己的字节头**。

## 2 为什么是这一张

| 证据 | 结论 |
|---|---|
| P4.1 | 编码器在逐列 7 类颜色 CE 下把四向任务做到 fit 0.906；只解冻不加监督只有 0.531 |
| P3.29 | 稀疏四向监督不产生颜色路由；给出中间颜色标签后 31/32 |
| P4.2 | 读脚手架 fit 0.3125→0.34375（贴 4 类随机 0.25），字节头 fit 0.25；**缺口在绑定／对象读** |

所以本卡的唯一变量是**读层的监督密度与形式**；编码器冻结、观测布局、数据、字节头构造都不动。

## 3 构造

**阶段 0（复用，不重建）**：从 P4.2 的 run 根加载 P4.1 B 臂 bundle（`reconstruct-B-007376.pt`，sha256 `f6705088…`），只校验摘要；不再重跑 7,376 步重建。

**读标签（公开、图像内、确定性）**：对每张 16×16 图，用 P4.1 的逐列主导色得到每种色板色占据的列，列均值 x 归入左/中/右；每个可见对象给一对 `(颜色, 位置)`。每例 0–3 对；fit 32 例共 **78 对**（平均 2.44）。**已声明的限制**：被遮挡或太小而检测不到的对象不进入标签，读不被要求恢复不可见对象；这也意味着标签数是可见集，不是世界里的 3 个 body。

**脚手架（训练期、评估时不存在）**：读主体自己的对象表示 `object_z`（`[branches, 3, 8]`，branch 平均），共享一个 8→16→7 的颜色头和一个 8→16→3 的位置头，实测 **458 参数**（预注册手算 490，运行报告以实测为准，已同步更正）；3 个槽与 0–3 个标签做 **6 种排列的精确最小匹配**（颜色 CE＋位置 CE），空槽学"无"。

**可训集**：编码器冻结在 P4.1 B；其余 22,350 参数＋脚手架。阶段 2 与 P4.2 完全相同：全部冻结，只训 `joint_readout`／`byte_head`／`copy_gate`（8 张量／3,919 标量），缓存主体自己传给 `emission` 的实参，训练前 3 个位置做回放一致性检查（1e-6）。

## 4 判据（冻结原文）

| 项 | 定义 | 门 |
|---|---|---|
| 读 pair 准确率 | 可见 `(颜色,位置)` 对，匹配后颜色与位置都对；fit 78 对 | **≥0.95** |
| 读 set 准确率 | 整个可见集合完全一致（不多不少）；fit 32 例 | **≥0.80** |
| 读基线（必须同表公布） | 常量最常见 pair **0.0897**、常量最常见集合 **0.0625**、零训练脚手架 **0.0385／0.0** | — |
| 字节路径全应答轮 | fit 32 轮全部计入；精确字节＋EOS＋合法 UTF-8 | **≥0.80** |
| 纠正率 | 首轮错误 ≥4 时，每个错误 8 次 Adam（lr 0.001），即时重问；分母＝首轮错误 | **≥0.80** |
| 稳定性损失 | 首轮正确的题在纠正后仍正确；上界＝max(1, 10%×首轮正确数) | **≤上界** |
| 反馈增益 | 学到副本第二遍 − 同主体冻结更新对照第二遍（0 更新、状态摘要不变） | **≥0.05** |
| 恢复 | 保存 final，独立进程重载，32 条输出逐字节相同 | 逐字节相同 |
| A 保持／3seed／check② | 无 A 父／单 seed／不读 | `not_applicable`／`not_in_scope`／`not_read` |
| accepted parent | 不签 | `false` |

**联合规则（本卡起生效）**：反馈类通过必须同时满足纠正率、稳定性上界与增益——P4.2 的 0.0625 增益是用 8 个对的换 10 个错的，单看增益会被骗。
