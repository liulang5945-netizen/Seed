# N1-173：自由滚动训练探针（scheduled sampling）

日期：2026-10-25，Asia/Shanghai。状态：**实施前冻结**。承接[N1-172 结案](PLAN-N1-172_execution_closeout_20261025.md)§7。N1-172 已排除「更新预算不足」，并把瓶颈定位到「教师强制拟合 ≠ 自由滚动」。本包只改训练时喂入 decoder 的上一字节来源，不改模型、数据、选择、折与主判据。

## 1. VISION 条款对账

- VISION §89：loss/TF 不等于自由生成；本包把**训练题自由滚动**设为可判性前置，绑定仍只看留出题自由生成与错配对照。
- VISION §81：生成必须由模型读取被选证据产生；本包检验同一 `next_logits` 在自喂入路径上是否仍能落在目标回答上。
- VISION §93：保持面独立；不改默认模型，不写 L2。采样决定不回传、不新增可学习参数。

## 2. 证据与单一变量

- N1-172：两折训练 TF 中位数 .9531/.9414（96 步早停），但同批训练题自由匹配仅 0–4.7%，留出 0/8。说明模型能在教师强制下预测正确字节，却无法在自己的前缀上维持目标回答。
- 本包只改一处：训练时每个目标位置以课程概率 `p = min(0.5, 更新序号/256)` 用模型自己的贪心 UTF-8 合法字节作为下一步输入，否则用目标字节；损失仍只对目标字节计算。模型结构、参数、数据、seed、学习率、折分配、评估函数全部不变。

## 3. 设计与预算

- 同一 16 题、折 0/1、每折 12 训 4 留出（selection digest 必须等于 `5db33945…`）。
- 两折各固定 **120 次整批更新**（不做早停，避免「用留出题决定步数」的任何可能）；每折 147,456 target byte 曝光。
- 0 步读数共享一次；120 步测该折 16 题的 TF/自由 128 byte，留出题加对照 A/B 与错配 TF。
- 目标：训练题自由匹配中位数 ≥0.50（滚动可判前置 R）；留出 8 题中 ≥4 题自由匹配 ≥0.20 且比 A/B 各高 ≥0.15（绑定主判据 G）。

## 4. 预注册判据与出口

- **R（滚动前置）**：两折训练题自由匹配中位数均 ≥0.50。未达 → `INCONCLUSIVE_ROLLOUT`（仍发布全部读数，不判绑定）。
- **G（绑定主判据）**：R 达成且 8 个留出题中 ≥4 题 own ≥0.20 且 ≥A+0.15、≥B+0.15 → `PASS_BINDING`。
- R 达成但 G 不满足 → `FAIL_NO_GENERALIZATION`。
- 次判读 S：逐折训练/留出自由匹配分布、own/错配 TF、A/B 均值、不同自由输出数、TF 中位数与损失曲线（只报告）。
- 若 R 未达但训练自由匹配较 N1-172 明显上升（中位数 ≥0.10），记录「SS 有效但剂量不足」，不自动加步数。

## 5. 费用与停止线
