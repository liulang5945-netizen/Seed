# 预注册卡：NCH.3.02 开放自然中文连续任务探索（跨句式、字符互斥 OOV 与真语料干扰）

> [预注册·探索] — 2026-11-26（依据 [DESIGN-NCH-3-01](DESIGN-NCH-3-01_20261126.md) `open_env_ready` 与 owner 指令：先完成「开放自然中文连续任务」探索验证再进 `N35`）。本卡为探索卡：**零确认 seed、零 `check/final`、不得使用 `verified`**；不修改 `MAINLINE.md` 队首。

## 1. 主体与四臂因果对照

- **探索 seed**：`7101, 7102, 7103`（`SPOT_CHECK_SEED = 7101`）；
- **评测划分**（互不重叠，各 60 局 × 6 回合 = 360 回合 / 120 查询回合）：
  1. `train_seen`（`8100–8159`）：已见实体/地点组合与训练句式；
  2. `heldout_paraphrase`（`8200–8259`）：未见自然中文同义句式与未见干扰句；
  3. `heldout_oov_entities`（`8300–8359`）：**100% 汉字互斥**的 OOV 物件（`OOV_ENTITIES`）与 OOV 地点（`OOV_PLACES`）＋未见同义句式（验证真正的开放词表指代与指针复制泛化）；
  4. `real_corpus_distractor`（`8400–8459`，若 `data/simple_zh/dialogue_extended_clean.jsonl` 存在）：在 OOV 物件/地点与未见句式之上，嵌入真实中文对话语料抽取的日常干扰句。
- **对比臂（同编码器架构、同批大小 16、同步数 `STEPS`、同优化器与 LR 调度）**：
  1. `open_chinese_memory_pg`（主臂：`use_history=True, use_copy=True`）：全 UTF-8 字节多尺度卷积＋双向编码记忆＋字节级位置/内容混合指针生成器＋product `utf8_state` 约束解码；
  2. `stateless_single_turn_pg`（无历史控制臂：`use_history=False, use_copy=True`）：仅看当前回合 UTF-8 字节，隔离验证跨回合记忆必要性；
  3. `no_copy_vocab_only`（无指针控制臂：`use_history=True, use_copy=False`）：保留全部跨回合记忆但禁用指针复制，隔离验证 OOV 开放词表是否真靠指针复制而非死记训练地点字；
  4. `history_shuffle_ablation`（主臂零训练因果干预）：在评测时用确定性种子打乱前序回合字节顺序，验证主臂决策因果依赖真实历史篇章而非表层启发。

## 2. 预注册探索门（3/3 seed 全过才算 `signal_positive`，CAP ≤ 600.0 CPU）

- **C0（设施校准）**：`train_seen / heldout_paraphrase / heldout_oov_entities` oracle 均为 `1.0`，随机查询 ≤ `0.05`，零答案泄露；
- **G1_train_seen**：主臂 `query_turn_success >= 0.85` ∧ `query_answer_em >= 0.85` ∧ `all_turn_success >= 0.85` ∧ `utf8_valid_rate == 1.0`；
- **G2_heldout_paraphrase**：主臂 `query_turn_success >= 0.75` ∧ `coref_success >= 0.70` ∧ `corr_neg_success >= 0.70`；
- **G3_heldout_oov**：主臂在 `heldout_oov_entities` 上 `query_turn_success >= 0.75` ∧ `query_answer_em >= 0.75` ∧ `unknown_abstain_success >= 0.75`（且若 `real_corpus_distractor` 存在，额外记录读数）；
- **G4_causal_and_open_controls**：
  - 在 `heldout_oov_entities` 上：主臂 `query_turn_success - stateless_single_turn_pg >= +0.50`，且 `stateless.known_answer_em <= 0.15`；
  - 在 `heldout_oov_entities` 上：主臂 `known_answer_em - no_copy_vocab_only >= +0.40`，且 `no_copy.known_answer_em <= 0.15`；
  - `history_shuffle_ablation` 使主臂在 `heldout_oov_entities` 的 `query_turn_success` 至少下降 `0.35`；
- **G5_repro_and_persistence**：`7101` 重跑 `weights_exact == True` ∧ `SessionStore` 磁盘胶囊重载后在 `heldout_oov_entities` 输出逐条精确一致。
