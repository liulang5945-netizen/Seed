# 架构问题与改造建议核实

日期：2026-10-26。范围：核实用户提出的七类问题及改造方案，不以技术名词替代项目证据。当前判断不改动已冻结训练/评价规则，不凭一份理论建议整体重写在用架构。

## 主要裁决

最重要的真实欠账是：同一任务中的表示、记忆、世界预测、选择、语言和反馈尚无已验证的共同能力及学习信用链。[核心需求](../active/TAIJI_CORE_REQUIREMENTS.md)已明确承认这一点。V4只让既有GRU神经证据chunk进入decoder；有非零梯度与扰动响应，仍不能声称对象级世界模型、情景记忆选择或规划已共同驱动语言。

项目并非因此已经被证明必须把学习算法、时序、稳定性、计算图与硬件五层同时推倒。现有证据支持修复确定的接口/计算图矛盾，以及对表示、学习与计算扩展提出有限候选；不能把不同实现的结果混在一起作全面必败证明。

## 问题是否准确

| 原主张 | 核实结论 | 证据与范围 |
| --- | --- | --- |
| 当前语言失败源于纯Hebbian/eligibility无法分配长程信用 | 当前因果归因不成立 | 旧TSK有局部更新；N169起的独立语言候选用GRU、attention、autograd/交叉熵及AdamW。长期/跨模块信用仍未证明，但不是当前候选只有局部关联学习 |
| byte序列放大中文时间步与计算负担 | 风险成立，固定比例与根因断言未证 | 常见汉字通常占3个UTF8字节，但相对哪个分词/组块基线、有效时界缩短多少、容量是否主要耗于拼字均需测量。不能由此证明byte方案不可用 |
| 宏观认知概念与语言候选“两张皮” | 有实质依据 | 当前语言切片未证明由对象世界、情景选择和规划后果驱动。状态ref、相同宽度和workspace名称都不证明共享语义 |
| TF高而自由滚动低说明数学意义的混沌 | 现象成立，动力学诊断未证 | 正确前缀与自生成前缀会改变轨迹；N174训练自由中位数实际为.937/.305/.294，并非全部0。指标差距不能单独证明混沌、唯一吸引子或唯一误差来源 |
| 留出0/48证明语义正确率为0、完全忽略问题 | 推论过强 | N174的0/48是逐字前缀门，不是人工语义正确率；错配target又改变答案难度。已知prompt交换改变分布，但这也不等于正确使用语义 |
| workspace未进入next_logits | 对V3成立，对当前V4需更新 | [V3审计](../../reports/taiji_n1_plan176_learning_paths_20261026.json)显示workspace梯度为空、扰动差0；[V4迁移审计](../../reports/taiji_n1_plan176_v4_parent_migration_20261026.json)显示读取/信用接通。后者只修工程可达性，行为收益另判 |
| 500题需百万CPU秒，成本呈指数爆炸 | 数量不符、扩展结论未建立 | [N174家族](PLAN-N1-174C_execution_closeout_20261025.md)含partial和续训合计57,047.937 CPU秒；N175三run合计167,862.797 CPU秒。更早原生训练账不可并入这一500题GRU实验；输入attention含输入×输出长度成本，不是已证明指数算法 |

## “原生”与训练算法口径

[架构§6.1](../active/TAIJI_NATIVE_ARCHITECTURE_V1.md)明确分开发展训练与终身学习，并允许递归、attention、autograd/optimizer；历史上确曾有禁backward阶段，其后已撤销。准确表述应披露实际算法、监督源及依赖，不能把全模型永远“纯local”作为当前事实。

GRU/autograd本身符合现行方法约束；真正的原生验收是Taiji是否拥有并因果使用共同表示、状态、记忆、目标、决策与反馈。代码位于taiji目录、参数归本项目，均不足以证明这一点。[N169设计](PLAN-N1-169_shared_language_chain_design_20261025.md)明示这是自有byte生成的独立语言切片，未加载外部LLM权重，也明示世界/目标/价值尚未消费该新state。

## 解决思路是否准确

| 建议 | 可采纳部分 | 必须修正的承诺及验证 |
| --- | --- | --- |
| 分层预测编码取代全部本地规则 | 值得作为跨层信用候选 | PC与BP/BPTT等价依赖具体算法、初始化、推断/更新规则和时间展开处理；任意稳态PC并不自动等价，也不自动更快或更具生物真实性。[PC分析](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0266102)、[2025勘误](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0320944)、[Z-IL](https://arxiv.org/html/2103.04689) |
| 向量调质器/Critic | 可研究多任务责任与价值分解 | 一个向量或Critic并不自动知道失败应由谁负责；需明确任务反馈、分量监督来源、模块更新责任与置换/冻结对照，不用激素类比替代学习信用证据 |
| 局部byte Worker＋慢速全局Core | 有价值的高上限表示/计算候选 | MEGABYTE使用固定patch；全局推进次数减少不等于同等端到端提速，更不保证语义抽象。[MEGABYTE](https://arxiv.org/abs/2305.07185) |
| 熵跃迁产生概念边界 | 可用作计算分配候选 | 熵是预测不确定性，不是词/概念边界真值；BLT是具体熵模型及阈值设计，还需计入边界估计成本、上下文漂移和任务收益。[BLT](https://arxiv.org/html/2412.09871v1) |
| 全局强收缩消除自由滚动崩溃 | 稳定性与扰动恢复值得测 | 收缩会同时压低有用历史差异，且相同后续输入的收缩界不能保证不同生成字节后的语义自愈。优先区分持久记忆与快速执行子空间，并同时测恢复、可区分性和保持。[Stable Recurrent Models](https://arxiv.org/html/1805.10369) |
| DAgger/轨迹扰动替代全部TF | 访问自身轨迹、学习恢复是合理候选 | DAgger要求学习者状态上的专家反馈及额外条件；噪声和原目标后缀不一定构成有效恢复监督。TF仍可作形成阶段，不能因固定SS探针失败就否定全部闭环训练。[DAgger](https://proceedings.mlr.press/v15/ross11a.html) |
| 反事实/InfoNCE强迫理解问题 | 相关事实交换和错误条件对照应采纳 | 同一输入随意配反义金标会制造冲突监督；应改变可核验事实/问题条件并同步目标。互信息或对比损失能利用捷径，仍需未见组合、无关干扰与真实任务正确性 |
| 感知与执行解耦、全局记忆锚定 | 方向合理，部分结构已存在 | V2/V3已把只读byte_memory/输入hidden与decoder_hidden分开，每步重新寻址输入证据；不应将其说成只有一个同质循环缓冲区。尚未证明的是这些读取与独立世界/记忆/规划的语义责任一致 |
| 对所有模块强制任意非零梯度/敏感度CI | 对声明必要的可微路径建立工程回归 | 不适用于所有状态、合法关闭分支、冻结模块或离散/local更新；极小人为旁路也能造出非零。必须附相关/无关干预、切断/救援及行为收益，工程门和能力门分别裁决 |
| Block-sparse带来100%利用率和100–1000倍提速 | 可在实测热点上比较块稀疏与稠密算子 | 性能取决于形状、密度、块大小、精度、对齐、算子/显存开销；官方资料不保证任意模型的该幅提速。[NVIDIA Block-SpMM](https://developer.nvidia.com/blog/accelerating-matrix-multiplication-with-block-sparse-format-and-nvidia-tensor-cores/) |
| 用scan无损并行任意当前循环 | SSM可作新主干候选 | Mamba的高效scan依赖对状态的结构化仿射递推；普通GRU的hidden依赖门控不能直接套用。O(log L)并行跨度、总运算量、单步相对上下文的代价必须分别报告。[Mamba](https://arxiv.org/abs/2312.00752)、[S4](https://arxiv.org/abs/2111.00396) |

对本项目还需注意：decoder的argmax字节选择会反馈到下一步输入，仅约束固定输入下的hidden收缩不能直接证明整个离散反馈闭环收缩，这是从当前计算链得到的适用边界。反事实也不要求每个输出字节都改变；相同前缀/UTF8规则完全可能合法共用，应验任务相关内容及整体答案。V4的极小非零残差同样不能靠“梯度非零”自动获得正确内容使用证书。

## 推进裁决与重构触发条件

1. **确定缺口直接修。** 必要信息存在但未被真实消费者读取，落实生产者→状态→消费者→任务误差的工程链；如V3的workspace问题，不以更多同质训练替代接线修复。
2. **信息在接口前已不可区分，或状态无法保留任务必需差异时，重构表示/主计算链。** 不能强迫只改读出，也不能仅凭一个更宽向量排除结构问题。
3. **路径接通仍无任务收益，继续做同资源、同数据的表示/更新/读出因果对照。** 先区分已见拟合、未见组合、自由轨迹与旧保持；不把梯度、参数变化或一个toy通过当作统一认知通过。
4. **多尺度与硬件候选按实测热点进入。** 比较信息损失、长程任务、真实吞吐、峰值内存、恢复及旧保持；不在缺少测量时许诺1–2周、70–80%语义压缩或百倍加速。
5. **PC/向量调质等更新机制单独验证。** 使用相同任务、反馈与资源比较学到的新能力及旧保持，而不是因为算法名称像生物就替换所有更新器。

当前已将推荐落实为[N177实施合同](PLAN-N1-177_joint_cognition_slice_20261026.md)：已训N176按原合同有限结案，与共同对象/事件状态、必要记忆/世界预测/规划、语言及反馈接口的静态工程并行。N176正收益或独立语言成熟不构成共同链修复前置；其实际结案及费用在后继新训练前纳入。更广多尺度表示、并行主干与更新规则研究归VISION候选，均保留高上限方向，但不作为无证据全面推翻的执行令。本次核实已接入03/09/10/07的真实依赖；本轮只重编计划，不启动新的训练或sealed消费。
