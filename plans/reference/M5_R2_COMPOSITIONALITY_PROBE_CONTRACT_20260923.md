## §2 设计：2×2 因子，判"同槽效应是否跨另一个槽保持一致"

对每个**族**（一个含两个槽的骨架）取 2×2 四格：`(a₀,b₀) (a₁,b₀) (a₀,b₁) (a₁,b₁)`。
记四格的 **cue** 为 `c₀₀ c₁₀ c₀₁ c₁₁`、**读出分布**为 `P₀₀ P₁₀ P₀₁ P₁₁`。

**核心量（可分离性）**：换 A 的效果**在 B 的两个水平上是否同一个方向**——

- `u_B0 = c₁₀ − c₀₀`（B=b₀ 时换 A 的方向）
- `u_B1 = c₁₁ − c₀₁`（B=b₁ 时换 A 的方向）
- `consistency_A = cos(u_B0, u_B1)`；对称地 `consistency_B = cos(c₀₁−c₀₀, c₁₁−c₁₀)`

**为什么这个量有判别力（关键，不能省）**：在 96 维的 cue 空间里，**两条互不相干的随机方向余弦接近 0**
（标准差 ≈ 1/√96 ≈ 0.10）。所以"consistency 接近 1"是一个**远离随机基线**的强预测，
而"两个方向正交"在 96 维里是**废判据**（随机就正交）——这一点在设计时就被排除掉。

**基线（实测，不用拍的数）**：把**不同族**的方向互配（族 i 的 `u_B0` 对族 j 的 `u_B0`，i≠j），
得到"不相干方向"的经验分布，作为对照。

## §3 判据（执行前冻结，不得事后调）

| 读数 | 判定 |
|---|---|
| `median(consistency_A, consistency_B) ≥ **0.9**` | **可分离**（表征支持按槽组合） |
| `0.5 ≤ median < 0.9` | **部分纠缠**（如实记 partial，不四舍五入成结论） |
| `median < 0.5` | **整体纠缠**（表征是"一整团"，换一个槽会重排全部） |

- 阈值 0.9 / 0.5 的正当性：随机基线中位 ≈ 0（**同时报实测基线**），0.9 约在随机基线之上 9 个标准差；
  0.5 是明确的"半程"分界。
- **同时报（不参与判定）**：KL 交互比 `kl_AB / (kl_A + kl_B)`（可加性读数）。
- **零假设对照**：同一条题面在**两个全新 episode** 各跑一遍 ⇒ cue 必须**逐位相同**、KL 必须**恰好 0**。
  不满足 ⇒ 仪器有噪声底，**整件拒跑**（与 P3 同一条硬前置）。
- 若一致性中位**没有明显高于实测基线**（差 < 0.1）⇒ 记 **inconclusive**，不硬套可分离/纠缠。

### §6.1 怎么读（**不许把它读成"纠缠得很厉害"**）

1. **判定落在线上，只差 0.021**（0.479 < 0.5）。阶梯是**先注册**的，**不改**；但也**不许**把它说成
   "表征严重纠缠"——实质读法是：**同槽方向确实存在**（比随机基线高 0.50），
   **但它随另一槽的水平而变**，达不到"按槽分解"。
2. **实测基线 −0.023 印证了设计时的推理**：96 维 cue 里随机方向余弦 ≈ 0。没有这条，
   "consistency ≈ 0.48"是没有分母的数字。
3. **两个 checkpoint 的 12 个值逐位相同** ⇒ 这是**上游**（`predictive_context` / `fabric`）的性质，
   **训读出头改不了它**。这条与 P3（cue 两臂逐位相同）互相印证，也是一次独立的写入面复核。
4. KL 交互比从 0.668 升到 **0.930**（训练后的读出在**分布**层面更接近可加），
   但逐族噪声大（0.32–1.08），**只作旁注，不参与判定**。

### §6.3 边界

- 本件只说"在这份基座/这条链路/这套刺激上，同槽效应跨另一槽不一致"，
  **不**说明内容对错、**不**构成语言能力主张、**不**解除 R2 的 M5 排除。
- **刺激集由我撰写**（已披露）；逐族异质 ⇒ 中位数是**族间中位**，换一族集合数字会动。这一条写进边界，
  不许当成"表征纠缠程度 = 0.479"这种精确主张。

## §5 允许与禁止的主张

- 允许：说"在这份基座/这份 checkpoint、这条链路上，换一个槽的效应跨另一个槽**一致/不一致**"。
- 禁止：① 任何语言/回答能力主张；② 解除 R2 的 M5 排除状态；③ 改 CAP 冻结线；
  ④ 把"可分离"读成"会推理"——它只说明**表征对槽位有可分解的响应**，不说明内容正确。
