## 2. 数据与词表（读前冻结）

- 颜色 8（红蓝绿黄紫橙黑白）；**所有留出模板用字必须出现在训练模板中**（A3 首版失败教训）；

  3. `{c1}与{c2}中，后提到的那个`
  4. `我要{c1}和{c2}里后说的`
  5. `从{c1}、{c2}里挑后说的那个`

  1. `请给我{c1}和{c2}中后说的那个`
  2. `先说{c1}后说{c2}，要后者`
  3. `{c1}与{c2}中后说的那个`
  4. `挑{c1}与{c2}里后说的`
  5. `从{c1}、{c2}里，我要后说的那个`
- 词表由 5 个训练模板全部字集合确定（估计 ≈30 字）；留出模板不得引入新字；

## 3. 臂与判据

| 臂 | 说明 |
|---|---|
| **pos_attn（主）** | 位置嵌入＋两步注意力读出（A1 默认口径，经冻结 23.0b 父） |
| mean_pool | 平均池化读出（对照） |
| replay | 同一位置注意力直接读原始字符特征（可学性先验，须 ≥0.80） |

**门（读前冻结，不得调）**：
- G1 replay ≥ **0.80**（否则判 `presentation_failure`，不出能力结论）；
- G2 pos_attn ≥ **0.60**；
- G3 pos_attn ≥ mean_pool + **0.10**；
- G4 旧三技能损伤 ≤0.02、恢复 diff ≤1e-10。

**出口**：全过 ⇒ `a3c_verified`（有界：自然措辞语序）；G2 或 G3 不过 ⇒ `a3c_partial`；G1 不过 ⇒ `presentation_failure`（记录用字/长度问题，不重试同卡）；超帽 ⇒ `budget_stop`；工程失败 ⇒ `engineering_failure`。
