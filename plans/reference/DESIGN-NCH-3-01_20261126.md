# 预注册卡：NCH.3.01 开放自然中文连续任务设施校准（零训练）

> [预注册·零训练] — 2026-11-26（依据 [COVERAGE-MATRIX](COVERAGE-MATRIX_20261126.md) 缺口 D 与 owner 指令：在进入 `N35` 前先补齐「开放自然中文连续任务」探索验证）。本卡为零训练设施校准，不读任何确认 seed，**零 `check/final`**，不改动 `MAINLINE.md` 队首。

## 1. 设施与去泄露设计（`taiji/open_chinese_task_env.py` + `taiji/open_chinese_subject.py`）

- **全开放 UTF-8 观测接口**：环境每回合仅输出 `{"text", "utf8_bytes", "step", "turns"}`，无任何封闭词表 ID、无 `task_id`、无静默 OOV。
- **100% 字符互斥 OOV 划分**：
  - `TRAIN_ENTITIES`（120 组合）与 `OOV_ENTITIES`（12 种自然中文物件）汉字集合**零交集**；
  - `TRAIN_PLACES`（100 组合）与 `OOV_PLACES`（12 处自然中文地点）汉字集合**零交集**；
  - `TRAIN_PATTERNS` 与 `HELDOUT_PARAPHRASE_PATTERNS`、`TRAIN_DISTRACTORS` 与 `HELDOUT_DISTRACTORS` 严格互斥；可选加载 `data/simple_zh/dialogue_extended_clean.jsonl` 真实语料干扰句。
- **6 回合连续篇章推理**：每局含两次位置建立、移动（含指名与跨轮指代 `move_coref`）、口误更正（`correction`）、撤销否定（`negation`）、日常干扰句与 2 轮提问（指名查询、跨轮指代 `coref_recent / coref_first`、与表面同构的**未出场物件拒答** `clarify_unknown -> "未知"`）。

## 2. 零训练校准门（读前写定，CAP ≤ 10.0 CPU）

| 门 | 要求 |
|---|---|
| `disjoint_oov_and_patterns` | 实体/地点字符集零交集、句式与干扰集零重叠 |
| `zero_query_answer_leak` | 三大划分（各 40 局）全部查询回合文本不包含目标答案串 |
| `obs_isolation_and_determinism` | 观测键仅 4 项、同 seed 逐字段确定性一致 |
| `oracle_all_splits_exact` | `train_seen / heldout_paraphrase / heldout_oov_entities` oracle 全步与整局均 `== 1.0` |
| `random_low` | 随机基线在三划分上 `query_turn_success <= 0.05` |
| `utf8_subject_and_store_ready` | 未训练 `OpenChineseCognitiveSubject` 约束解码 100% UTF-8 合法，且 `SessionStore` 往返逐位一致 |

## 3. 出口

- `open_env_ready` / `open_env_failure` / `engineering_failure`。零确认 seed、零 `check/final`。
