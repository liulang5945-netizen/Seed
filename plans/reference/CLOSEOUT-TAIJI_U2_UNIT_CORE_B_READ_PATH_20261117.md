## 3 五项残留（收束必须随身携带）

1. **聚焦 2/3**：seed01 0.730227、seed03 0.514639 过门；seed02 **0.389147** 未过（差 0.110853）；有效列数 3/3 过门（4.31／4.83／4.59）。
2. **值侧是更深的墙（已实测）**：oracle 强制聚焦下，与 `position_head` 同类、拟合到收敛的线性无 bias 头 fit **0.78125／0.71875／0.625（0/3 达 0.80）**、train **0.921875／0.84375／0.859375（1/3 达 0.90）**；同一探针在 r1 权重上是 **0.90625／0.71875／0.90625**，r2 的任务训练让 seed01／seed03 **退化**（−0.125／−0.28125）。
3. **三变量不可归因**：r2 同时动温度标量、`W_q` 2× lr、注意力监督，帽内没有消融臂；事后定位是诊断，不是消融。
4. **外推口径被证伪**：定价探针的 3 步线性外推（`log_tau` 13.06／15.06／13.09）被实测 4.58／4.67／4.06 证伪；以后不得用线性外推作准入依据。
5. **verify 仪器缺陷**：`temperature_starts_at_zero` 是出生期不变量，却被 `verify()` 用在训练后胶囊上（结构必假）；实质复算 15/15 与 run 逐值一致；冻结 runner／契约／判据未改。

## 4 可复用教训（写给下一轴）

1. **尺度不是默认杠杆**。在花一次训练之前，先用**冻结权重的温度扫描**回答"把尺度加到目标，读动不动"；U.1r2 的事后扫描给出 fit 三 seed 零增益，成本只有 7.28 CPU，却直接改变了结论。
2. **值侧必须有独立门**。一个只由任务交叉熵训练 384 步的读出头痛过"值侧可解码"；oracle 聚焦下收敛头仍 0/3 达门，且 r2 让 r1 已有的值侧可解码性退化。下一轴应把"值侧在冻结注意力下的可解码性"作为**独立预注册门**，先于端到端读门。
3. **方向监督要看未见场景**。训练标签注意力监督把训练集聚焦 loss 从 2.77 压到 0.067（seed01），但未见 fit 场景只到 0.73／0.39／0.51；"训练集上拟合了目标"不等于"查询方向泛化"。
4. **同出生配对与零训练定位要成为标准件**。r2 与 r1 出生权重逐位相同，配对才敢说 +0.1875／+0.09375／+0.0625；事后定位把"剂量不足"改写成"方向＋值侧双缺口"。
5. **仪器正对照要模型无关**。把"oracle 头达门"当仪器检查会假红；几何 `[x, x², present, 1]` 正对照（1.0／1.0）才是"尺子有量程"的证据。

## 5 能签与不能签

**能签**：`unit-core-b-v1` 的单位直读路径在已声明范围（first_a 单查询颜色、384 更新、冻结编码合同）内**不可达读前提**；三张卡均有定位；值侧在 oracle 聚焦下仍 0/3 达 fit 门且相对 r1 退化；尺度加到设计目标无读增益；工程纪律（恢复逐位、仪器正对照、零封存读取）成立。
