## 1. 主计算图及职责

```text
原始输入＋来源 → 可学习上下文/事件编码 → 版本化持久内容状态
query/Goal＋时间意图 → 内容读取 → 随生成前缀逐步消费内容的语言/行动头
合法任务误差 → 本候选声明的编码、写入、读取、表达参数/状态
```

| 部分 | 设计要求 | 必须保留的边界 |
|---|---|---|
| 输入与编码 | 内容可进入候选记忆；span/act/对象解析作辅助视图 | 未核实与可信事实分账，来源/权限不可绕过；任务域清单不作封闭语义准入表 |
| 内容状态 | 同一内容身份关联latent、原始引用、来源、当前/历史、时间与版本 | owner/scope/session、encoder revision；参数变化后旧latent需重编码/失效/迁移 |
| 查询读取 | query/目标及时间条件参与读取，区分同实体各版本 | 合法候选mask；宿主不能按gold替模型选择 |
| 表达/行动 | 每步根据生成前缀与内容读取/融合 | 原始复制受模型选址控制；真实动作有授权、回执及未知结果结算 |
| 信用 | 任务目标与辅助目标分账，指定负责模块实际可被塑形 | 不强迫所有离散接口autograd；冻结/断路/禁写组如实声明 |

TSK、identity、现有编码器/GRU、精确复制和状态容器作为可比较或继承的组件，不因名字原生而必留，也不一次全部推倒。原WorldObject等视图支持审计，不替代实际可学习内容。
