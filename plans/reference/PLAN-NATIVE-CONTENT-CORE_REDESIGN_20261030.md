# 原生共同内容核心重构推进方案

日期：2026-10-30。状态：**方向已由本轮用户指示采纳为计划主线；实现、实验与采用尚未批准或执行。** 依据[核心设计重审](TAIJI_CORE_DESIGN_REVIEW_20261030.md)，执行事实仍由[03](../active/roadmap/03_CURRENT_EXECUTION.md)维护。本件替代旧硬解析/局部头连续补洞作为唯一主路线，不撤销历史协议、结果或费用。

## 1. 新主计算图及职责

```text
原始输入＋来源 → 可学习上下文/事件编码 → 版本化持久内容状态
query/Goal＋时间意图 → 内容读取 → 随生成前缀逐步读取的语言/行动头
合法任务误差 → 指定编码、写入、读取、表达参数/状态
```

| 部分 | 现行设计要求 | 保留的硬边界 |
|---|---|---|
| 输入与编码 | 连续内容可进入候选记忆；span/act/对象解析作为辅助视图，不是唯一准入门 | 未核实内容与可信事实分账；来源/权限不能被软学习绕过 |
| 内容状态 | 同一内容身份对应latent、精确引用、来源、当前/历史、有效/获知时间、版本和置信 | owner/scope/session及编码器revision；更新后旧latent需失效/重编码/迁移 |
| 查询读取 | query/目标与时间条件进入读取；同实体不同版本可区分 | 合法候选mask；宿主不能先用gold答案替模型选择 |
| 表达/行动 | 每步根据生成前缀与所选内容读取/融合，不把学习永久限为同一字节bias | 同一bundle；真实动作仍须授权、回执及未知结果结算 |
| 信用 | 完整任务目标与辅助目标分账，允许必要模块被任务塑形 | 离散分支可用合适信用机制，不要求所有接口autograd；禁写组单列 |

TSK、identity、现有编码器/GRU、精确复制与状态容器是可比较/可继承组件，不因名字原生而必留，也不在一次重构中全部推倒。原WorldObject等视图继续支持审计，不代替实际可学习内容。

## 2. 单一推进链与工作包

以下“重构-1…6”只是本方案的工作包标签，不新增N机制轴或改原实验编号。实际实现由用户推进；助手当前只维护方案。

| 工作包 | 输入与交付 | 验收/停止 | 后继 |
|---|---|---|---|
| 重构-1 统一语义合同 | 新任务范围、byte时间对齐、当前/旧值选择、可见信息、固定评分分母、来源身份 | 所有目标/状态/生成/评分在公开案例中一致；发现矛盾先结束该设计，禁止开训 | 当前唯一方案队首 |
| 重构-2 比较与最小核心设计 | 新主图、修正语义的旧图基线、同资源普通学习基线；模块/状态/参数责任清单 | 任务能区分内容使用、旧值、来源与旁路；架构包比较与credit单因素问题分开 | 签最小候选合同 |
| 重构-3 隔离实现与零步工程 | 编码/版本记忆/query读取/动态生成、真实信用路径、禁写组 | 固定公开fixture的相关/无关、切断/合法救援、前向等价及完整恢复；不称已学会 | 通过后定价 |
| 重构-4 标定与冻结 | train-only单位成本、父能力保持集、新独立分区、数值门、来源/代码SHA | 标定本身先限额；checkpoint/optimizer/RNG/cursor可恢复；总预算/失败出口/跨包停止线冻结 | 单次验证准入 |
| 重构-5 一次有界比较 | 同数据/权限/资源的候选与基线；新图内信用on/stop | 独立未见完整任务、机制净效应、保持/恢复与总成本合取裁决；无有效证据不自动加轮 | 正负均有限结案 |
| 重构-6 能力接力 | 符合范围的父候选与前后版本 | 任务所需T2/T3→自然连续任务→跨会话适应→条件扩域，按07分主张验收 | 不由局部过门自动升级 |

每包保存输入/输出契约、变化与继承、原生推理入口、参数责任、最小反例、成本与退出。未交付项明确待办，不能用测试数量、模块数或train loss代结案。

## 3. 重构-1需要用户实施的语义合同

- 首个范围仍可有限，但必须有“同query/同当前值、不同历史值”的合法历史对、相关更正、竞争候选、无关干扰与未知。实体/值/措辞/时间不能固定共现；旧已消费面只能作开发诊断。
- 逐byte约定明确第t步计算时已见哪些输入、对应哪一目标；不能先取当前logits却监督下一位。训练/生成/评分采用同一协议。
- 旧值查询必须指定可消费的版本/时间语义；检验整个hidden/workspace/source-cache，而不是只过滤显式引用就宣称隔离。
- 所有应答轮按独立任务类别计入固定分母；解析失败、拒答与错误不得靠模型act筛出分母。分别报告query与非query、state与answer、正确性与敏感性。
- 切断必须损害正确性、救援必须恢复正确性；重复同输入输出相同只算复现。工程oracle解析/状态上界与生产路径隔离。

首版五项边界已拍板，具体语义以[R1合同§3/§7/§8](SPEC-NATIVE-CONTENT-CORE_R1_SEMANTIC_CONTRACT_20261030.md)为准：12实体×3属性×每属性4值、每槽最多3合法版本；时间意图current/previous/unknown；固定全部应答轮分母；未解析内容可带来源/状态入store而不自动成为可信事实；三类架构组同资源比较，读取与内容条件表达须都有实际任务信用。该确认不等于数据/预算冻结、语义审计通过或训练准入。

## 4. 比较设计与保留范围

| 对象 | 用途 | 不能得出的结论 |
|---|---|---|
| 原N177/F/N178证据 | 旧正负结果、实现/测量混杂、局部解析改善及费用 | 不改标签洗成成功，不当干净的架构否证 |
| 修正语义的旧主图 | 公平评价硬门/当前值/固定bias路线的实际代价 | 不能只修新图而让旧基线背负已知错目标 |
| 简单普通学习基线 | 同任务/权限/资源下，区分机制是否值得其复杂度 | 不借不同语料、参数预算或外部认知偷换研究对象 |
| 新共同内容核心 | 主架构包的行为/保持/资源比较 | 多部分一起变化时只称架构包收益 |
| 新图内credit on/stop | 同初态前向值/结构、仅切指定信用的机制比较 | 梯度非零不能替代任务净收益 |

原四实体与未覆盖实体的缺口、N178八实体train与face2的不同口径必须保留。新包重新声明覆盖/分区，不将face2反复加压后的成绩称独立确认，不沿旧词表或题量自动扩面。

## 5. 验收、预算与退出

新架构没有已证明的优势，也未设定虚构机时。实施前需用户确认具体候选、比较问题与成本；训练前必须验证完整checkpoint保存、独立恢复及继续行为。

采用/扩面要求未见任务净收益、所声称状态/信用的正确性因果效应、旧保持、来源/隔离/恢复和预算同时满足。负结果回唯一主要缺口；不可判回判别设计；工程/预算停止不算科学反证，不自动重跑。旧F跨包重审计数和费用不因更名或发现目标错误清零；新包须在投入前明确本次范围的累计停止线与复审决定。

原有有效授权N178b只按其原终点/预算有限结案，本方案不停止/恢复/追加该运行；后续再开剂量、seed或F变体需新的准入决定，不作为默认队列。

## 6. 大阶段与交付映射

N1–N6保留为机制责任轴，当前主图设计牵动N1内容/信用、N2保持、N3覆盖/成本、N4记忆、N5任务所需世界/选择与N6可信工程。宏观阶段是共同内容机制→受限联合任务→自然中文连续任务/L2–L3→跨会话适应/L4→条件自主扩域/L5，不是先把独立语言训好再拼器官。

T2/T3只在选定任务需要时接入；原生状态与中文表达从最小核心共同发展。达到07原L3条件即可最小用户验收，不额外等待全T3、L4或全部长期CR。冻结原门与历史M批准继续有效，本方案不补发任何能力通过。
