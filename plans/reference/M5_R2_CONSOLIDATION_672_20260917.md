## §2 三条必须同时声明的结论

1. **"672 档 exact 非零"确认**：6/6 seeds 训练正常（train 0.77–0.87），4/6 seeds 的
   dev `exact` ≥ 0.19 —— **数据多样性对该档位的正效应成立**（此前只有 3 seeds）；
2. **但方差很大且呈双峰**：2 个 seeds 近 0 ⇒ **"0.2540"不能作为点估计引用**，
   引用口径必须是 **"0.22 ± 0.16（双峰，6 seeds）"**；
3. **⚠️ 评测集已变**：本档的 dev 是 **672 条**（scaled 语料的 dev 拆分），
   与标准 57 条语料的 dev=16 条**不可直接比较** ——
   "0.2242 vs 0.1042"是**不同评测集上的读数**，不是同一标尺上的提升。
