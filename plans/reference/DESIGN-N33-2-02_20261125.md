> [预注册·探索] — 2026-11-25（D-20261125-580；N33.2 线内，≤80 CPU）。依据 owner 全批（`D-20261125-579`）：声明新确认 seed 组 `20261601–03`（备用 `20261611–13`）、从 `N33` 现有 `1,200 CPU` 预算划出 `N33.2 <= 300 CPU`、批准加固 `taiji/session_store.py` 并执行 `N33.2.02`；持续可塑＋按需生长入训留待独立后续卡与本卡解耦以免混淆归因。**本卡全程探索 seed（2001/2002/2003），严守零 check / final / confirm。**

## 1. 研究问题与环境（`taiji-cross-session-v1`）

前置 [N33.2.01](RESULT-N33-2-01_20261125.md)（`harness_ready`）仅验证了 `SessionStore` 的持久化一致性，尚未证明策略能实际**利用**跨会话状态改善行为。本卡检验同一主体从会话 1 保存并通过磁盘 `SessionStore` 恢复的 `capsule + pending + experience`（9 维），能否被学得策略用于驱动会话 2 决策（继续哪槽任务 / 是否先 verify / 何时休息 / 无未结事项则 `finish_idle`）。

- **环境**：[cross_session_env.py](../../taiji/cross_session_env.py)（`STATE_DIM = 15`，含 6 维会话 2 局部观测＋9 维会话 1 恢复记录编码；`ACTIONS = ("work_0", "work_1", "work_2", "verify_pending", "rest", "finish_idle")`；`HORIZON = 8`）；
- **实验臂（同构对照）**：
  - `persistent`：PPO（`15→64→Tanh→6/1`，4,000 episodes），真实观测全部 15 维；
  - `stateless`（同构对照）：完全同构网络、超参、seed 与采样生成器，仅在训练与评测时将跨会话 9 维置零（只能靠当前会话内局部观测摸索）；
  - 参考上界：`scripted_persistent_policy`（仅用于 `C0` 门校准与评测对照，绝不参与训练）。
- **确定性**：延续 `N33.1.08` 规范，显式局部采样生成器 `seed_from("N33.2.02", arm, train_seed, "sample")`，并对 `persistent` 首 seed `2001` 独立跑两遍检查权重 `torch.equal` 逐位一致。

## 2. 预登记门与出口（读前写定）

评测固定走真实磁盘 `SessionStore` 流程（`EVAL_SEEDS = 6000..6099`，n=100）：会话 1 写入 `.session` → 从磁盘 load 并核对 `digest` 与张量逐位一致 → 执行会话 2 → 已解决的 `pending` 写回并 reload 校验清空。

- **C0（零训练环境/尺子校准，须先全过）**：
  - `scripted_persistent`：`mean_return >= 4.0`、`resolve_rate >= 0.90`、且 `zero_cross` / `swap_cross` 反事实收益降均 `>= 4.0`；
  - 真随机（持久生成器）与全部 6 个单动作常量策略均 `mean_return < 0.0`。
- **G1（跨会话收益，3/3 seed）**：每颗 `persistent` seed 的 `mean_return >= stateless + 3.0`，且 `mean_return >= 0.85 * scripted`、`resolve_rate >= 0.80`；
- **G2（反事实因果利用，3/3 seed）**：`persistent` 策略在真实磁盘 `SessionStore` 上满足：
  - 置零反事实降 `normal - zero_cross >= 3.0`；
  - 置换反事实降 `normal - swap_cross >= 3.0`（排除只学会「盲目干活/不看具体内容」）；
- **G3（确定性＋存储闭环）**：`repro_exact == True`（`2001` 两遍权重 `torch.equal`），且全评测 `store_roundtrip_exact == True` 与 `post_s2_persist_exact == True`。

| 出口 | 条件 | 后续 |
|---|---|---|
| `cross_session_positive` | `C0` ∧ `G3` ∧ `3/3` seed 通过 `G1 ∧ G2` | 可申请 `N33.2.90` 确认（用新组 `20261601–03`）或接生长入训卡 |
| `cross_session_partial` | `C0` ∧ `G3` ∧（部分 seed 过或仅过部分反事实/G1） | 定位原因后按单变量推进 |
| `cross_session_negative` | `C0` ∧ `G3`，未达 `partial` | 记录跨会话收益未成立，待 owner 裁定 |
| `engineering_failure` | `C0` 未过 / `repro_exact` 失败 / 存储校验失败 / 超预算 / 非有限 loss | 停下排查工程故障 |
