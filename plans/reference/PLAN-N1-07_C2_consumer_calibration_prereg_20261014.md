# PLAN-N1-07 · C2 生成消费有界校准预注册（2026-10-14 r1）

本件承接 [PLAN-N1-06](PLAN-N1-06_carrier_consumer_alignment_20261014.md) §4，冻结一次**零训练、非能力结项**的消费者可行性校准。C1 批⑵完整结果已通过（见 [PLAN-N-01](PLAN-N-01_development_revision_20261014.md) §7 和 08 ㊵-875）。本件只授权范围定义与预算决策准备；**不授权消费者产品代码、正式跑面或训练**。C1 的 75 分钟预算只用于 C1，不能挪作 C2。

## 1. 本校准回答的问题

在固定模型权重和同一用户会话候选池中，问题状态能否从两个已保存的逐步经历里选中正确 episode；沿该轨迹再激活能否改变后续生成；这些变化是否依赖正确内容与顺序。已知正确 episode 的 oracle 臂只验证消费通路上界，不能作为检索能力或记忆能力证据。

本轮只覆盖精确事实提取这一器官，不能宣布 C2、S1 或 N1 通过。C2 完整出口仍须在同一候选和同一实现下分别验证**复述、世界转移、身份同构**，并覆盖事实翻转、改问法、未知拒答、完整输出/停止、错误分类、跨会话隔离与来源；任何一器官缺失都不由另两器官代答。未知问题与跨会话全局检索不进入这 16 项校准。

## 3. 选择器与消费行为

1. query key＝将本轮问题按产品 `SeedRuntime.chat()` 序列化并喂入后、首个答复字节发射之前的 `cortical_cue()`；查询状态在选择和回放前固定。
2. episode key＝该 episode 全部已保存向量的逐维算术均值，经 L2 归一化；该均值**只用于候选排序**，不用于再激活。
3. 候选分数＝query key 与 episode key 的 cosine similarity，按最高分取 top-1。完全并列时用向量内容 SHA-256 字典序打破并列，不读取序号、位置、source 或任何标签。没有可用向量则响亮拒绝，不能静默回退到摘要或现场重算。
4. 重置与再激活：每个 query 先从同一母档恢复、`learn=False`，重置动态状态，喂完问题后选取 episode；在答复首步前将其**完整有序原轨迹**逐步送入 `fabric.step(..., episodic_feedback=...)`，再从该状态生成。最长轨迹不超过 256；对一题的配对控制，回放调用数 `N=max(L1,L2)`，较短轨迹尾部补零。补零不计为轨迹向量；逐步轨迹不得用池化向量替代。
5. 生成设置固定为贪心、`max_length=256`、UTF-8 严格解码、产品重复惩罚 2.0/window 8；保持输入身份、prompt 序列化、输出器官及所有其他配置不变。记录/选择/回放臂的前后权重摘要必须相同。

## 4. 配对臂与计量

每个固定题面跑以下 7 臂，顺序由题目 ID 的 SHA-256 固定打乱；每臂从同一母档恢复、每题重置状态：

| 臂 | 行为 | 判别目的 |
| --- | --- | --- |
| no-replay | 不提供 episode、不执行预回放 | 有无记忆供给的行为基线；成本不等量，单列披露 |
| zero-replay | 执行相同 `N` 次状态步，反馈向量全零 | 区分轨迹内容与额外状态推进 |
| oracle-correct | 由保密计分标签指定正确 episode，按原序回放 | 消费通路上界诊断；不得计作选择能力 |
| model-top1 | 按 §3 的 query cosine selector 自行选择并回放 | 唯一可计模型可见检索的臂 |
| wrong-episode | 回放同题另一条候选轨迹 | 内容依赖；与正确轨迹步数匹配 |
| shuffle-correct | 正确轨迹按 item ID 派生的固定非恒等排列重排 | 顺序依赖；若长度不足 2，标记该题不具此对照资格，不补造差异 |
| pooled-correct | 正确轨迹均值重复 `L` 次并补零至 `N` | 同剂量池化负对照；不能据此称逐步轨迹成立 |

逐题出版 selector top-1 命中、top-1/runner-up 分数与间隔、完整输出、严格答案命中、错误值/额外事实、输出字节数、自然停机/吃满预算、实际回放步数、恢复状态与权重摘要。计分按每项恰好一次的 16 个配对题，另按 8 种 `kind` 和两种答案位置分层；不合并器官，不以包含答案子串代替完整输出。校准集过小，所有行为读数只作描述，不作显著性或能力结论；不设“pilot 通过线”。

## 5. 保存恢复、守卫与停止线

- 支持阶段只写入 32 条真实生成 episode（16 题×2 轮），记录关闭后原子保存独立 checkpoint；在新 Python 进程用 weights-only 路径恢复并核对 episode ID、来源、shape/dtype/finite、逐步内容摘要。题目第三轮的 query episode 不得存在于支持档。
- 消费阶段在另一个新进程加载支持档；记录开关保持关闭。缺失/错 ID 必须返回空或响亮拒绝；禁止回退 last-event、对话 history、剪贴板或查询现场重算。
- no-replay 默认臂须与原生成路径逐位一致；消费者所有臂 `learn=False`；开关恢复默认关闭；输入母档 SHA 不变；报告拒覆写并自述完整命令、题面/母档 SHA、每臂计数与 `kind=tail` 收尾覆盖。
- 任一支持 episode 缺失/多出、query 泄漏、存取摘要不等、候选器读取标签/位置、权重变化或默认行为改变 ⇒ 整个校准拒判。仪器机械缺陷只允许修复一次；不能缩样本或删对照凑预算。
- 16 项/7 臂加 32 条支持生成和独立保存恢复，**最多 10 分钟本机 CPU**；此数字只覆盖这次 C2 校准，不包括 C1，也不是后续 104 项/三器官面预算。达到 8 分钟仍未完成时只观察并预计是否能在 10 分钟内结束；预计越线则正常完成已启动的单臂后停止，不启动下一臂、不减样本。实际总 CPU 时间必须写入报告。

## 6. 判读出口与下一步

- 若 selector 选错：结论限于当前无训练 top-1 表示未能在该样本选对；oracle 臂只能定位消费上界。先检查 query/episode 表示与来源/会话池契约，不扩大载体容量，也不把 oracle 结果包装成能力。
- 若 selector 选对、oracle 及 model-top1 仍无行为贡献：将断点归到再激活/生成消费或表达/推导层；逐项读分布与输出，不训练、不改默认。
- 若轨迹内容与顺序呈可区分的行为贡献：只完成本次单器官的机制定位；下一件仍须先补齐世界转移和身份同构任务合同，再冻结 C2 全面统计门与各自的运行预算。
- C3 训练、跨会话全局检索、长期保留/逐出策略、默认产品挂载均不在本件。

**当前唯一决策：是否批准 C2 有界校准最多 10 分钟本机 CPU。** 该预算独立于刚完成的 C1 批⑵；同意后才实施消费者开关/测试并运行本件，未同意则计划停在这份可复核规格，不缩小题面或对照。
