# 首问交互信用的实际更新合同

> P3.7.2，2026-11-13。真实研究父更新0，固定24次隔离Adam影子步。工程帽240 CPU／480 wall，预留后项目未分配5490 CPU。

## 1. 信息、父及梯度定义

沿[P3.7计划](PLAN-TAIJI_U2_FIRST_BINDING_20261113.md)绑定P3.6预算内D与TF-actual。只使用既有train的三个位置、颜色配对(0,1)/(2,3)。两个父各做float32/64，float64从同一float32文件显式转换，并在新optimizer中按目标精度导入原moment，步龄保留。

同一四格的四个episode均来自原任务。完整45个四格重组恰好覆盖原180个episode一次，既有题目权重由完整日程保持。工程测量固定原六格子集，后续学习数据权利另按原分区签署。

每episode的CE仍为0.5×(首问teacher CE＋实际首答状态下的次问CE＋blocked outcome)。首问监督分支与实际生成分支分开，gold首答状态保留在评分侧。四格CE取四episode均值，Δ沿原完整序列优势定义，辅助目标为softplus(−Δ)。CE为每问7符号均值，Δ为完整7符号序列对数优势的混合差分。

固定测量J_ce、J_mix和J_ce＋J_mix，系数均为1，各自取六个四格均值。本卡检验这一固定尺度的更新效果。逐目标逐参数记录梯度及None模式，组合梯度仅在两个目标均未使用某参数时保留None。

## 2. 24次影子步与moment控制

每个精度／父分别有三目标×两moment配置，各做一步，共24步。所有参数和Adam状态来自独立克隆，检查存储无别名。inherited完整继承moment及步龄；zero_first_moment只清exp_avg，保留exp_avg_sq和step，隔离一阶动量分子。该控制的数值尺度仍由原二阶moment和步龄决定。

步长0.001及β/eps沿原真实Adam，不扫描系数或学习率。未使用参数保持grad=None，参数与moment时钟均应维持原值。更新后将影子参数复制到独立完整主体，重新走正常输入及原字节评分入口，报告六格逐值、CE、交互、参数位移与实际首答变化。若离散首答变化，CE的局部线性预测和重新生成后的目标分别记账。

梯度内积给出首阶分数变化预测g_ΔᵀΔθ，并与真实前向差分对照。原CE与交互梯度的夹角、范数及每参数更新记录用于定位任务冲突、信号尺度和moment作用。研究父参数及Adam摘要在每次影子步前后核验，真实learner更新0。

## 3. 预定判据及出口

主测配方为继承完整Adam的J_ce＋J_mix。两种精度都须满足平均Δ增加超过相应数值容差、至少四个四格分别改善超过容差，且平均CE增加不超过0.005。Δ绝对容差float32为8e-6，float64为1e-10，超出前轮float32约1e-6的差分舍入量级。该判据只签固定步长和固定尺度下的局部有效更新。

符合为fixed_joint_objective_effective_local_update，随后进入正常入口、恢复和实价。其余完整测量为fixed_joint_objective_not_supported，按实际结果修订负责接口／信用机制。非有限数、所有权或继承失配为engineering_failure，超帽为budget_stop。六组控制结果按原身份保留，不在本卡内筛选新系数并追加试验。

任何局部更新结果均继续接受完整自由两问及输入切断的后继裁决。P3.7.3后才冻结真实学习剂量。原研究父、旧任务和封存分区权利分别保留。

## 4. 实现及检查

`first_binding_objective_22_5.quad_terms`在同一首问状态复用两个候选答案评分，gold CE用于原实际历史目标。监督答案仅由数据标签提供，实际首答由正常greedy字节输出生成。原生成的64字节／EOS和blocked分母沿用。

核验脚本记录全部逐参数梯度／位移、原状态摘要及实际影子调用数。回归覆盖原CE及全部参数梯度等值、空首答实际历史、None所有权、未用参数的Adam步龄和四格完整日程。核验源、父文件、数据和报告SHA在机器合同中冻结后执行。
