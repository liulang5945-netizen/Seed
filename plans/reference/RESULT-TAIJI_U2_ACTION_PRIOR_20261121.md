# 结果卡：A2 动作接地可学性先验（`action_prior_not_learnable`；replay 0.784<0.80，闭环保持关闭）

> 文档状态：[结果卡] — 2026-11-21（D-20261121-215）。上游 [A2 裁定](MEMO-TAIJI_OWNER_DECISIONS_20261120.md)、[D-20261119-210](RESULT-TAIJI_U2_CN_LOOP_20261120.md)。**零 check/final、只读 fit。**

## 1. 协议

- 修掉 colour/position 下标重叠：每物体 10 槽（colour 0–5、position 6–9），3 物体 = 30 维；
- 指令字符袋投影 16 维；flat 特征 46 维；**强 MLP（3×256）** 直接预测动作（槽位×方向，12 类）；
- 训练 3 个措辞模板、fit **留出第 4 模板**；fit 种子不相交；3 seed、8.31 CPU（帽 1,000）。

## 2. 读数（[回执](../../reports/taiji_u2_action_prior_20261121.json)）

| seed | 训练拟合 | **fit（留出措辞）** |
|---|---|---|

| 20261121 | 1.000 | 0.703 |
| 20261122 | 1.000 | 0.781 |
| 均值 | 1.000 | **0.784** |

- **replay_learnable ✗**（0.784 < **0.80 门**；仅 1/3 seed 过门）；
- train_fit 1.0 而 fit 0.70–0.87 ⇒ **过拟合留出措辞**，不是「不可学」，是**泛化不足**；
- ⇒ **`action_prior_not_learnable`**（按预注册门判负）。

## 3. 判读与披露（如实）

1. **按裁定，A2 未过门** ⇒ **闭环 / 多步动作保持关闭**，不得重开；
2. **不是「动作任务不可学」的结论**：训练拟合 1.0 说明可拟合，失败在留出措辞泛化；
3. **本卡仅 3 模板训练、1 模板留出、每模板只 128 fit 样本**，单模板留出方差大（0.70/0.78/0.87）；
4. **若要重试**，需新预注册：更大训练覆盖（≥5 模板训练、≥2 留出模板）、更大 train、同 0.80 门——**不得在同一卡内调阈值**；
5. 不签动作接地、闭环、多步、final/C/D/J/模型成型。
