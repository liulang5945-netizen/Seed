# Seed「生命」页视觉方向

更新：2026-10-25。现行版本：发展观测台；路径保留兼容已有引用。信息、状态、字段和开发子包以[生命页实施设计](UI_LIFE_UX_SPEC_20261003.md)为准，本文件只管视觉和组件呈现。旧2026-10-03整份CSS/固定六卡版从`c97d74d00:plans/reference/UI_LIFE_VISUAL_DIRECTION_20261003.md`恢复，不再作为当前样式的整片替换模板。

## 1. 方向与保留项

保留白灰平面、Seed色用于焦点/活跃、系统字体和路径代码字体。用“观察对象→当前重点→选择/结果→证据/资源”建立阅读层级，取代所有功能同权的长卡片流。生命页展示真实发展状态，不能用拟人插画、情绪表盘或发言动画代替原生能力证据。

不改变品牌、现有明暗主题、静止Seed标志、全局对话字体设置。视觉重组不会自动激活模型、创建训练或改写状态来源。

## 2. 颜色与排印

生产样式只取当前`packages/client/ui-theme/src/styles/design-platform.css`与`base.css`中已定义的token，继续使用CSS Modules；下面是角色映射，不复制一份主题值。

| 角色 | Token | 用法 |
|---|---|---|
| 页面/标题栏 | `--dsw-alias-bg-base` | 单一稳定底色，标题栏遮住滚动内容 |
| 内容层 | `--dsw-alias-bg-layer-1` | 当前重点与详细视图，仅一层面板 |
| 主/次文字 | `--dsw-alias-label-primary/secondary` | 正文、关键数值/来源、说明；关键小字不取caption/tertiary |
| 分隔/hover | `--dsw-alias-border-l2`、`--dsw-alias-interactive-bg-hover` | 表格、分组和可交互表面 |
| 焦点/正在执行 | `--dsw-alias-state-business-primary` | 当前视图、焦点、已核验的进行中操作 |
| 成功/警告/错误 | 对应`state-success/warn/error`已定义token | 分别表达已验证成功、需要关注、执行/读取失败；不能由兴趣/压力大小臆造 |
| 代码/数值 | `--ds-font-family-code`、`tabular-nums` | 路径、identity、费用与可对齐读数 |

页面标题22/30、视图标题16/24、正文13/20、辅助12/18，遵守全局内容字号轴。小号彩色文字不承载唯一信息，状态同时带文字。单位紧随数值；无数据用“尚未获取/未提供”，不用0或假进度条。

## 3. 布局

标题区固定包含页面名、观察对象、来源状态、最近成功读取与刷新。观察对象切换器用可见标题，不能只用一个未知含义图标。连接/权限故障在标题下形成一条恢复带，技术详情折叠；正常连接不展示大面积成功色。

总览采用一个主重点区和三个平面摘要组：目标/承诺、最近选择与结果、资源与保持。每组摘要提供对应详情入口，不再重复列出整张表格。其余四个视图各自承担完整范围。详情可以用现有Drawer/Modal或页内展开，复用ui-primitives，不新写通用弹层。

宽屏内容上限1100px；仅在内容列足够宽时让互相独立的摘要并列。面板内宽不足560px改为单列；320px内容列的页签使用同一“视图”选择器，保留同样的语义名称。页面无横向滚动，宽表只在自己的`.tableScroll`中滚动；目标、候选、资源以行/定义列表呈现，不把每个标量装成独立卡片。

## 4. 来源与证据的可见性

- 标题里始终露出范围：“对话运行时/研究任务/兼容工具”，身份细节可展开。研究候选的“未采用”标签不能藏进tooltip。
- 估计与事实通过标签区分：原型估计、模型预测、执行中、结果未知、已核验、证据不足。它们不是从红到绿的一条成长等级。
- 目标→选择→执行→反馈→学习用有序事件列表及关联id定位。只有已发生的事件才画节点，缺环显示缺项，不用连续发光连线制造完整闭环印象。
- 学习卡展示声明范围、parent/child身份、新任务/保持结果及成本；没有行为读数时显示“尚未验证”，不显示“能力+N%”。
- 调节原型若显示curiosity/fatigue/stress，值旁常驻方法/来源与“原型”标签；主视图不画拟人情绪仪表。

## 5. 动作与危险确认

每个动作与对象同组，写清“刷新研究任务”“取消此目标”“暂停自主窗口”等范围；不共用含混“停止”按钮控制不同进程。每组最多一个主操作；查看/筛选/刷新用次级操作。删除、强制解锁、checkpoint采用及其他危险操作保留既有原地确认与影响列表，并以服务端许可/锁为最终依据。

不可用动作显示就近原因，不用点击后才告知整项服务不存在。首版未实现原生自主窗口时，不呈现可点的“开始自主生活”占位按钮。读取中的旋转/圆点只代表读取，不能伪装模型正在思考。

## 6. 交互与可达性

现有`life`入口及旧`#life-*`深链继续可定位。视图切换后保留逻辑焦点；键盘能到达观察对象、视图、详情、动作与回退入口。loading/error/unknown与已知空闲分别可被读屏识别；异步事件只在实际变化时播报，轮询时间更新不每5秒打断用户。

折叠由内容可用性和用户选择决定：连接恢复入口始终可见；未知区域只有摘要，已知详情可展开。用户已经展开的可用内容不因普通轮询重新折叠；来源/身份切换时恢复相应视图状态，不把上一个模型的选择痕迹套给下一个。

减少动效时禁用非必要过渡。正常模式仅使用现有100–150ms过渡表达展开、状态替换和焦点，不能用跳动、旋转或情绪动画表达没有测量依据的生命状态。

## 7. CSS和组件落地范围

当前`LifePanel.module.css`是已实现样式源，本文件不再提供可粘贴的整体CSS副本。按VX6.2逐个重构页面布局、摘要、来源条、事件行与表格；避免用`nth-child`、中文文本或固定DOM相邻关系区分业务状态。滚动边界、sticky上下文、宽度/层级及状态tone必须由组件的显式类或数据属性表达。

继续保留：`box-sizing`、单滚动容器、局部表格滚动、键盘focus ring、骨架说明、未知/不可用文字、主题token和reduced-motion。废止：固定六张全展开卡、只按旧组件行号改CSS、不允许新增必要文案、把整段旧CSS称为唯一权威。

## 8. 视觉验收

VX6.2的有限验收面固定为五视图×三种内容列宽（320/640/1100）×明暗两主题，共30个状态布局；另以键盘和减少动效复核观察对象切换及一条完整详情路径。内容用明确标记的测试fixture，不能用演示文本冒充真实发展日志。

确认页面不横向溢出、关键文字和单位可读、焦点不被sticky遮挡、来源和当前重点先于长表、未实现功能不伪装可用、同一事实不在多个卡片反复出现。真实原生闭环和能力是否成立由VISION对应VX包及VX7验收，视觉通过不补发模型结论。
