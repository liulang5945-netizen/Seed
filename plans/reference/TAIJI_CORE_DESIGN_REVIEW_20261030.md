# Taiji核心设计重审：从分段器官验证转向共同内容学习核

日期：2026-10-30，Asia/Shanghai。审计基线`25892a935`（其父为N178b运行器提交`9b7cae0b9`）。范围：核心需求/原生目标架构、TSK实现、N177当前联合候选、F与N178训练/评分、已发布聚合证据及有关Git版本。**只读重审与方案修订；未修实现、加载模型、运行实验、读取新sealed或改动当前进程。** 本文是设计评审建议，不是已冻结的新实验或采用批准。

## 1. 结论与裁决范围

1. **保留长期目标，重审当前主计算图。** 持续状态、原生认知所有权、合法反馈、精确来源和可恢复性仍合理；现有证据没有否证这些目标。当前实现更接近若干独立可训练/规则化组件的串联，还不是已验证的共同认知学习核。
2. **不建议继续把“硬解析成功→离散值入库→冻结语言模型的固定字节偏置”作为唯一主候选。** 它可以作为可审计的模块化基线，但最终任务不能有效塑形其内容写入/时间选择/完整生成过程。修parser覆盖或一个值编码器，不等于改进整个认知链。
3. **当前失败不足以给整个架构判死刑。** F1/F1b有训练目标、时间语义和指标解释的直接混杂；当前失败也不位于旧fabric共享场的唯一必经路径。不能从这些结果推出byte、稀疏或局部学习必败。
4. **唯一推荐重构方向：共同可学习的事件/内容状态＋查询/时间条件读取＋动态内容条件生成。** 结构化解析作为辅助视图/约束，不再是所有内容进入记忆和接受任务信用的唯一门。精确来源、权限、版本和恢复仍由明确合同约束。先定义可解释的任务/训练/生成/评分闭环，再考虑新投入；不承诺某算法必胜。

原[核心需求](../active/TAIJI_CORE_REQUIREMENTS.md)和[原生架构§0.2/§2](../active/TAIJI_NATIVE_ARCHITECTURE_V1.md)已经允许替换具体算法及成熟编码/寻址/优化组件；“原生”不要求永久保留TSK、固定稀疏支持或byte作为唯一内部表示。

## 2. 必须区分的三个对象

| 对象 | 实际职责 | 本轮能否据F/N178裁决其完整上限 |
|---|---|---|
| Taiji目标架构 | 状态、记忆、世界/目标/选择、表达、反馈与发展由同一认知主体拥有 | 不能；多数长期能力未进入当前试验 |
| TSK-v8核心/器官 | 稀疏预测误差动力学、局部更新、共享场/identity等实验底座 | 不能整体否定；已有窄任务正证，也有确定的支持/投影限制 |
| 当前N177 F/N178候选 | F冻结producer/V4、训练value encoder与bias；N178另做parser辅助加压 | 可以直接审计实际可学习路径、任务/目标/读出失配；其局部失败不等于目标架构失败 |

### 2.1 当前实际学习图

```text
raw bytes/Percept → producer(slot/act/encoded) → 硬解析/离散值
                            ↑ parser辅助CE         ↓
                      N178更新producer       Python版本事实store
                                                  ↓ current(entity,attr)
                                         色名字节→value encoder→bias
                                                  ↑ F回答CE      ↓
query + 累积hidden → 冻结V4 next-logits ────────── 相加 → 输出
```

这不是“全部模块都不学习”：producer有embedding/BiGRU，值encoder有GRU，语言父模型也经过训练。问题在于**各次训练允许改变的函数族、实际持久的信息和被要求完成的任务没有共同对齐**。N178不更新V4，F不更新producer/V4，不能将两份局部学习结果拼成端到端信用闭环。

## 3. 直接代码事实与核心设计问题

### 3.1 硬解析同时成为内容准入门，错误却到不了该门

[producer](../../taiji/joint_input_producer.py)将slot/act离散化、detach并经Python数据结构持久化；[原trainer](../../taiji/joint_t1_trainer.py)以辅助CE更新producer。F还冻结producer。解析失败导致事实/查询被拒收时，回答目标没有途径纠正该次门控；任务反馈只能训练已被允许进入的下游部分。

N178改善实体抽取是正信号，但只检验一部分实体span，不验证act、时间解释、选取历史、语言生成或旧保持。原评分器按预测act=query统计的约44%未解析实体说明重要缺口，但不是课程金标定义的全部query分母，也不能证明它解释全部低正确率。硬门并非原则上不可用，**将它作为唯一内容与信用入口而缺替代/纠偏通路，才是当前待重构的设计选择**。

### 3.2 持久的主要是离散色名，不是已被共同任务训练的连续内容状态

F评分器[建store](../../scripts/training/evaluate_taiji_n1_plan177_f_f1_holdout.py)写入`continuous=[0.0]*64`，source ID/SHA由(entity,value,turn)重新合成；回答时再将store的value字符串交给`_Arm.feature`编码。这条具体链没有验证“producer连续内容写入→持久化→查询消费”的共同训练，也不能用重建元数据代签原InputTrace来源链。

F任务信用训练的是取出的色名→新encoder/偏置，不是原感知、事实写入或选择。组件存储/恢复合同仍可继承，但应退出“当前F已经检验共同持久连续表示”的解读。

### 3.3 旧值目标与当前值接口不匹配，selector没有时间选择能力

[课程](../../taiji/joint_state_consumption_course.py)的旧值查询目标是`family.old_value`；[F1b训练](../../scripts/training/run_taiji_n1_plan177_f_f1.py)和[评分](../../scripts/training/evaluate_taiji_n1_plan177_f_f1_holdout.py)却统一用`store.current`取最新值。store虽有`history`，这条主路径不使用它。

[selector](../../taiji/joint_state_consumption.py)先按entity/attribute精确过滤，候选分数也只来自同两个lookup。同实体同属性的不同版本因此无法靠该分数区分；它没有把query的“之前/现在”、来源或revision放进选择计算。[E2c候选](../../taiji/joint_state_credit.py)再hard argmax，回答CE不更新selector，模块说明也承认这条边界。真实F主回答路径直接取current，甚至不通过这个selector。

所以，**补齐实体解析不能补出旧值读取或任务驱动的时间选择**。这并不证明整个网络永远不能从hidden猜旧值，而是说明被声称的状态消费通路没有表达任务必需的选择条件。

### 3.4 生成学习被限制为每步相同的字节偏置

实际形式为`logits_t = frozen_V4(query, hidden_t) + bias(encoder(current_value))`。[F运行器](../../scripts/training/run_taiji_n1_plan177_f_f1.py)对整句每步加同一个bias，F1不更新V4；该内容特征没有作为逐步查询的记忆进入递归状态/注意力读出。

它可以调制某些字节倾向，并非毫无表达力；但它是一个受限输出调制试验，不能等同“完整语言/记忆核心已联合训练”。相同偏置也作用于答案框架、值字节和结束部分。把整个状态条件生成目标押在这一窄路径上，是比单纯parser剂量更高层的待比较约束。

### 3.5 显式query-only不等于信息上query-only

F的`_replay`跨轮累积joint；`_answer`只过滤evidence sources，仍使用同一language_state。[V4 next_logits](../../taiji/conditional_language_v4.py)从`state.hidden`初始化decoder，递归输入路径可将先前事实保留在hidden。

因此当前F没有证明“答案只能从所选状态特征获得事实”。这是可用旁路，不等于已经证明模型实际依赖它。新设计必须明确：原始历史、recurrent hidden、workspace、source cache分别可见什么；要隔离通道就重建相应状态，不能只过滤一张引用表。

### 3.6 训练/生成和评分语义存在直接不一致

| 检查 | 源码事实 | 对证据的影响 |
|---|---|---|
| byte时间对齐 | F的`answer_loss`先取当前next-logits、后observe当前symbol，却对齐`target[1:]`并跳过首字节；原trainer同一调用顺序对齐完整target | 当前代码及`957e77fcd`、`f65cfe13b`两相关Git版本有一位错位。聚合件未钉执行code SHA，不能仅凭当前源码证明运行字节，但这是必须先解除的直接混杂 |
| 训练/主分母 | F1b只训可解析、有当前状态的query，`answer_exact`却计整个8轮；部分query指标又按预测act和实体存在筛选 | 低总分是真结果，但不是纯下游信用效应；固定评分分母不能依模型是否解析成功而缩小 |
| cut/rescue | cut计“颜色与baseline不同”；rescue计“恢复原输入后又等于baseline” | 错误baseline也能rescue=1，只证明敏感/重放一致，不能称正确性下降/恢复的任务因果收益 |

这些是**用户待实施的目标/接口修订项**，本轮不修复、不补训、不重评分。原FAIL标签、原分母及费用保留；另附本重审限制因果解释，不能把污染实验改称成功，也不能由它们给整条架构判死刑。

## 4. TSK原生核心：保留什么，不能默认什么

| 设计 | 已确认事实/反证 | 裁决 |
|---|---|---|
| 稀疏局部预测 | local_update只改现边；但有实际重连、完整支持的慢巩固及多跳递归 | 保留底座/对照；不以“拓扑彩票”概括全模型，也不默认其已形成任务语义核心 |
| 共享场读出 | 默认192→48不可逆投影；动作有local/dual旁路，默认寿命置信衰减为0 | 保留受限机制；不选其为所有内容唯一承载，也不无证据全面替换它 |
| 感知/assembly | 已有可学习embedding/递归与局部关系证据 | 保留；自监督预测/对比目标不自动保证任务所需绑定/时间语义 |
| identity/精确内容 | 窄任务可形成受控因果增益；原字节保留有独立价值 | 保留可损伤/可回退的精确引用通道，不把复制当一般语义学习 |
| 世界/规划/生命/成长 | 长期目标与部分结构化接口资产存在，不是当前F/N178完整被测对象 | 不据本轮通过或失败整体判绿/判死；按实际任务需要实施、分主张验收 |

最强保留证据包括[M1-63](../../reports/taiji_m1_63_identity_organ_promotion_20260902.json)的窄绑定/负控制/保持门，[M1-64](../../reports/taiji_m1_64_foundation_memory_20260903.json)相对memory lesion、identity lesion及frozen parent的受限记忆优势；它们反驳“旧核心毫无可学性”，但不是通用中文/跨任务优势。

[M1-40](../../reports/taiji_m1_40_binding_substrate_20260902.json)中直接动作读出替代也未过原门，反驳“去掉一个瓶颈就足够”。当前F/N178的TSK输入由learn=False/cache提供，值encoder另走字节GRU；故不能将它们的失败直接归为旧192→48场或fabric固定支持。

## 5. 累积结果应怎样改变设计判断

| 证据族 | 支持的结论 | 不足以支持 |
|---|---|---|
| N170–175 | 已见复现、消费缺口及自由滚动困难分别有证据 | 四题TF提升不是语义泛化；N174前缀0/48不是语义0；N175未判S不能补0 |
| N177.6 | 旧固定切片Correct数值门通过，commit路径有部分查询收益 | 复合分不作模块贡献率；permuted仍近满分，不能证明规范world成为必要答案依据 |
| F0a/E3 | 小值encoder可拟合已知颜色、指定组件链可恢复 | train满分、copy满分和恢复一致不是未见机制净收益 |
| F1/F1b | 原报告answer_exact约1.56%/4.10%，未取得要求的净优势 | 训练/任务/指标混杂下，不得把全部失败归parser或将FAIL_NO_LEARNING等同无梯度 |
| N178 | face2实体抽取由7/64改善，记录22/29/24、中位24/64，仍未达原目标 | 只验实体覆盖，非回答或一般新实体泛化；八实体本就在train。共同父的采样seed不是独立全参数初始化 |

N178 seed1机器账本/成本缺项与早期RNG重复轨迹保留；face2用于决定剂量后，后续结果作为开发诊断，不重新算独立确认。`rank<类别数`也不能独自证明类别不可线性分：保留具体原型/分类读数，不再用rank2/7本身宣告八色不可识别。

当前还缺同数据/输入权限/资源的普通端到端学习基线，以及明确标注的正确状态/解析工程上界。多个臂若共用同一个冻结前端、错目标或窄输出路径，会一起失败；这不能区分“共同前提有问题”与“新机制无效”。

## 6. 保留、重构与退出的设计决策

| 处置 | 本轮建议 | 理由 |
|---|---|---|
| 保留 | 认知所有权、持续状态、来源/权限、版本/恢复、有限资源和保持合同 | 是研究诚信/模型身份与长期能力的必要约束，不是造成低分的替罪对象 |
| 复用为可比较资产 | TSK、感知、identity、离散状态、精确原始引用、已有GRU/解码器 | 有局部价值，原证据保留；不由“原生”身份获得主路径必留资格 |
| 重构主候选 | 任务可塑形的共同事件/内容状态、带时间条件的查询读取、逐步内容条件生成 | 直接对准当前硬门、版本选择、信用和窄输出通路问题 |
| 退出默认假设 | 辅助解析收敛就意味着回答表示有用；恢复/同名模块装配就意味着共同认知；逐步补局部头即可保证扩展 | 累积结果不支持，当前源码还有目标/测量混杂 |
| 暂缓 | 自动加剂量/seed、泛化扩面、同时重写全部器官 | 未有完整净收益，且原跨包重审线已触发 |

这不是“先修一个off-by-one再照原节奏继续”的结论。目标正确性是有效实验的前提；解除它也不会自动赋予现门控、时间读取和静态bias路径缺少的功能。

## 7. 唯一推荐的新主候选方向（design-only）

| 选择 | 价值与代价 | 建议 |
|---|---|---|
| 仅修目标/评分，再沿硬解析与局部头续推 | 是建立可解释基线的必要工作，但不改变时间选择与共同内容学习的限制 | 留作修正后的基线，不继续作为唯一主候选 |
| 重构共同事件状态、查询读取及动态生成 | 允许任务反馈直接塑形必要表征，代价是新计算图/状态迁移与严格对照 | **推荐新主候选方向** |
| 同时推倒TSK、语言、世界、记忆与所有训练机制 | 变量与成本一起增加，不能定位收益来源，且丢失既有窄正证的对照价值 | 当前不选 |

```text
原始输入 → 可学习的上下文/片段编码
         → 带精确来源、时间和版本的持久事件/内容表示
query/Goal/时间意图 → 可学习内容读取 → 当前/历史及关系条件context
context + 生成前缀 → 每步重新消费内容的语言/行动头
合法任务反馈 → 指定编码/写入/读取/表达参数与状态
```

- 结构化span/act/WorldObject作为可校验辅助视图和训练约束，**不再要求先完整解析成封闭词表事实，才能让任何内容进入记忆和获得任务反馈**。保留歧义/未知与来源，不等于无条件接受任意内容。
- 记忆保留当前与历史，query应表达实体/关系/时间条件；连续状态与离散引用对应同一内容身份。若声称学习型选择，须在有竞争的合法候选上验证，不能由宿主先选好答案后把单候选当学习证据；合法的精确entity索引仍可作机制/对照。
- 精确引用/复制是独立可控的内容保真通道；模型必须学选择何时/读哪条，不能用gold地址或宿主模板代认知。来源/安全/用户隔离仍可硬约束，不要求所有离散接口有autograd。
- 表达在每步以query、时间/目标和生成前缀消费内容；允许训练必要的表达/读取模块，不将任务适应永久限为冻结V4旁的同一logit偏置。
- 用整体任务目标与辅助目标共同训练声明必需路径，明确谁保持冻结、谁可更新；离散写入/选择可选合理信用机制，但不能无证据声称回答已训练它。持久latent记录encoder revision，参数更新后的旧latent须重编码、失效或明确迁移；checkpoint不保存autograd图，状态与训练重建边界先写实。

推荐它是因为更直接表达任务需要、反馈责任更可检验，不是因为已证明优于现系统；具体编码/记忆实现尚待用户决策和新合同，不在本文虚设参数/数据/预算。

## 8. 下一份合同的先后顺序与退出

1. **先统一任务语义与训练/生成/评分约定。** 对齐第t步目标，当前/旧值与合法来源，固定评分分母；切断/救援报告正确性变化，不能只报输出变化或确定性复现。绑定执行code SHA、数据/父模型/配置及测量口径。
2. **再定义一个完整候选与可信比较。** 推荐主候选对现硬门/静态bias基线及同资源普通学习基线；共同数据、权限/范围、父能力保持与资源。正确状态/解析只作明确隔离的工程上界。拆开任务/表示/读出改造与信用on/stop的因果问题，不把所有变化混成单因素证据。
3. **只用公开开发/合成面做语义与零步合同验证。** 包括旧值/当前值、竞争候选、真实hidden/历史隔离、必要路径信用与恢复；工程通过不算学会。不得重用已消费face2或旧sealed选择最终门值。
4. **在比较前决定失败怎样结束。** 一个同版本、完整原生入口的独立未见任务，联合行为/保持/恢复与真实成本为主证；无净收益、退化、不可判或工程失败分别有限结案。没有有效比较就不追加正式训练预算。

F合同的跨包重审线已触发：它是投入治理，不是两次干净的架构否证。发现混杂、parser局部进步或换阶段名均不自动重置原成本与计数。当前已授权N178b仅按原边界保存/结案，本轮不停止或改它；剂量读数不能自动放行下一包。

### 10.1 判断与实际研究对象

**递归路线值得保留；当前GRU实现是可替换的研究基线，尚无其作为长期最终核心的优势证据。** 更有研究价值的候选是持续递归状态、可学习可寻址记忆、按内容写入/遗忘、动态读取/表达与合法任务信用的组合。认知所有权和恢复/来源合同不绑定某个RNN单元。

### 10.2 外部证据与可迁移范围

- [RecurrentGemma](https://arxiv.org/abs/2404.07839)的2B/9B模型以线性递归结合局部attention，在论文设置中达到与相近规模Gemma可比表现，支持递归/混合路线可形成有用语言模型。它不是单层GRU，也不是对态极小规模训练的保证。
- [Gated Delta Networks](https://arxiv.org/abs/2412.06464)将遗忘门与定向delta更新结合，并研究可并行训练及混合attention，论文报告检索/长上下文等任务的改善。可借鉴的是如何写入、遗忘和减少覆盖干扰，不是把“门控”名称移植即继承收益。
- [RWKV-7](https://arxiv.org/abs/2503.14456)展示广义delta更新、动态状态演化与并行训练的递归语言建模证据。其状态跟踪理论结论有模型/计算假设，既不等于通用推理保证，也不证明目前GRU配置具有同样能力。

据这些一手研究，可合理保留“现代递归/关联记忆或递归与attention混合”的方向；不能据此宣称纯GRU、纯SSM或纯递归一定胜过合理Transformer基线。attention作为读取/局部处理算子与态极原生认知所有权并不冲突。

### 10.3 当前证据更支持哪一个解释

R5到R5b在已消费同面上的answer_exact约0.323→0.505，均保留GRU骨干；R5b仍以`FAIL_BEHAVIOR`结案。因此已有证据支持内容通路和训练机制有可改善空间，尚未完成“GRU对替代骨干”的因果比较，不能据此判GRU已到上限或已经优越。普通端到端基线也采用V3字节骨干，其差异不是GRU与Transformer的差异。

R5b选择诊断只对train-only范围的首个非空选择进行分类；其“选择正确但答案错误”结果支持优先审表达执行与目标，但不能证明全部生成步骤、未见任务或其他范围的寻址永远正确。发散点诊断在所检查端点/样本上发现正确前缀下仍选错，提示相应误差不全由自由前缀漂移解释；不能由此穷尽训练信号、容量、结构或优化等竞争原因。

### 10.4 有前途需要补齐的能力与资源证据

1. **状态容量与寻址**：短期递归态、关联/工作记忆、带来源的长期经历分工；测试干扰、长距离、多版本和组合，而不只看小世界已见模式。
2. **训练可扩展性**：当前非线性GRU和逐byte解码有串行依赖，不能自动获得现代线性递归的并行算法优势。递归hidden大小固定也不等于整个模型常数内存/常数单步成本；显式store、逐字节证据及每步读取/复制的成本随可见记录/字节增长，须按实际实现测量。
3. **信用与持续学习**：保存hidden、写入事实或使用递归都不等于跨会话参数学习；持久latent断图、编码revision、反馈许可、实际接收者和父保持需分别验证。只换一个RNN单元不能自动补齐这些协议。
4. **独立任务证据**：现有同面回归不作为新确认；必须在新范围内比较任务正确性、真实机制效应、父能力保持和总资源，而非以cell名称、理论可表达性或train loss裁决。
