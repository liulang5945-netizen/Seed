# PLAN-N3-07 · R4 生长阈 τ 的**口径升版**：τ 是 `pressure_ema` 的阈值，不是原始加压量的阈值（2026-10-08，零算力定义件）

> **来源与效力**：DEBT-G53（[05 台账行](../active/roadmap/05_TECH_DEBT_REGISTER.md)）＋[PLAN-N3-06 判读](PLAN-N3-06_ADJUDICATION_20261008.md) 的实测。
> 本件**升版**的是 [PLAN-N3-03](PLAN-N3-03_tau_definition_20261008.md) 的 §1 第 1 项与 §4 第 2 项那两句——它们把 τ 定义成
> "五信号**原始**加权和的 p90 向上取整到 0.05 格"，而闸实际比的是**五个 EMA 的加权和**（`taiji/adaptive_residual_growth.py:388-395`、:437-444）。
> **旧件不删、不改写**（本仓纪律：已入库件只登记不代改），本件是它的后继定义件；两者冲突时**以本件为准**。
> 本件**不冻数值、不动常量、不开跑**——它只把"τ 是什么的阈值"重新写对，好让下一步owner 点的候选值不是错口径的数。

## 1. 定义（逐字替换旧 §1 第 1 项）

一次生长提议被放行，需要**同时**满足（全部锚点为 `AdaptiveResidualGrowthTrigger.observe`）：

1. **`pressure_ema ≥ τ`**，其中
   `pressure_ema = 0.30·residual_error_ema + 0.25·fast_slow_conflict_ema + 0.20·activity_saturation_ema + 0.25·utility_gap_ema`
   （:388-395）——注意这是**四个 EMA 的加权和**，`resource_state` **不进合成量**，只作为第五道分项闸单独比；
2. 五个分项闸 `*_ema ≥ minimum_*` **同步**满足（:439-443）——六项是一条 `and` 链，**任一不过则整条不过**；
3. 上述合取**连续** `required_pressure_steps` 步为真（默认 3，:448-450）；
4. `structural_budget ≥ growth_resource_cost`（:454）。

⇒ τ 的完整名字是六元组：**（设备, 链路, checkpoint, 装配, 生成预算, 口径）**。
第五元"生成预算"旧件已有；**第六元"口径"是本件新增的**，缺它就会出现 ㊵-499 那种"够得着但不触发"的伪谜团。

## 2. 一条把两个口径连起来的**恒等式**（不是近似，是可推的）

EMA 更新是线性的、权重是常量，且四支 EMA 初值都是 `0.0`（:359-362）：

```
Σ_i w_i · EMA_i(n)  =  EMA( Σ_i w_i · x_i(n) )        （w 与初值同为 0 时两边逐位相等）
```

⇒ **`pressure_ema` 恰好等于"原始合成压强的 EMA"**，两边只差在"先加权再平滑"还是"先平滑再加权"。
这条恒等式的用处有两个，且都必须按它说话：

* **可以**：在只有原始值的旧面上重放出 `pressure_ema` 的分布（PLAN-N3-06 走的就是这条路，并由产品自己的
  `pressure_digest`／`should_propose` 两条逐行锚点核对过）；
* **不可以**：把旧面上原始分布的 p90 当成 EMA 分布的 p90。平滑会把尾部压扁——实测同一批四张面，
  原始上界 0.701569／0.705043／0.709197／0.709126 而 EMA 上界只有 **0.67813／0.679165／0.685877／0.680911**，
  默认 τ=0.70 在 EMA 口径上**整场一步都够不着**（`meets_pressure` 真步数 0/3,999）。

## 3. warmup 必须显式处置（旧件没这一条）

四支 EMA 从 `0.0` 起步、`ema_rate = 0.25`（:188），于是**前若干步在算术上不可能过阈**：
一支恒定为 `v` 的信号，其 EMA 到 `(1 − 0.75^n)·v`，要离渐近值 1% 以内需 `n ≥ log(0.01)/log(0.75) ≈ 16.0` 步
（**本件推导，非实测**）。而 `consecutive_pressure_steps` **不被 `reset_dynamics` 清掉**
（:1825-1842 只清 bridge 与 `_state`，不碰 trigger）⇒ 同一次长跑里跨回合的连续段会累加。

⇒ 冻 τ 时必须二选一并写进面件自述：
（甲）**前 K 步不计入 τ 的分布**（K 与推导过程写明）；或
（乙）**不剔除，但必须同时报 warmup 段占比**。
不处置的后果＝把"平滑还没爬上来"混进"分布的低分位"，τ 会被系统性定低。

## 4. τ 的冻结判据（本件冻**规则**，不冻数值）

> 本节**替换**旧 PLAN-N3-03 §4 的第 2 项；其余四项沿用旧件并在下面逐条重述，以免"两句分家"。

1. **面**：改装配后的训练流符号链（`--readout predictive`；answer/self-answer 档走 `learn_bytes`，一个压强读数都不会有——旧 §4.1，不变）。
2. **取法（本件改）**：τ ＝ **对 `pressure_ema` 序列**取 p90 后向上取整到 0.05 格；**不许**对原始 `pressure` 取。
   若该面未自述 `pressure_ema`（＝DEBT-G53 修法②未落地），则只允许用 §2 那条恒等式**重放**出来，
   且**必须同时通过两条逐行锚点**（重放 `should_propose` 与面内布尔全等、重构观测的 `pressure_digest` 与面内全等）——
   锚点不过 ⇒ 该 τ 不得发表。
3. **动态范围先测（旧 §4.5，本件升级为可判的读数）**：τ 候选值必须在同一张面上给出
   "六道合取为真的步数与最长连续段"，且最长段 ≥ `required_pressure_steps` 才算这把尺有动态范围。
   实测今日两档（PLAN-N3-06 §5）：**beta 链 0.65 ⇒ 36/34 步真、最长 6 ⇒ 有动态范围**；
   **circuit 链 0.70 ⇒ 0 步真 ⇒ 无动态范围，该候选值作废**。
4. **口径否证支（旧 §4.3，不变）**：`|residual_error p90 − (1 − online_accuracy)| > 0.10` ⇒ 判口径不同源；
   ㊵-484 两条链都触发过 ⇒ **τ 不得由 accuracy 侧任何数推得**（第三次确认见 ㊵-499）。
5. **搬运禁令（旧 §4.4，本件加一句）**：τ 绑六元组；报 τ 必须点名链。**但"点名链"不许被读成"该定在哪个格已被链决定"**——
   两链的 EMA p90 集合不重叠（间距 0.007085＝0.656156 − 0.649071，最大跨链差 0.009236），
   而冻结规则的格宽 0.05 是它的 **5.4–7.1 倍**（见 §6.2 那条粒度缺陷）
   ⇒ 链的差别**测得到**，但"落到 0.65 还是 0.70"**是格宽决定的**；搬不搬都得先升规则才有意义。
6. **首次触发点限定（本件新增，跟着任何"会不会触发"的读数一起写）**：重放或推演出的
   `would_have_triggered` 只在**首次触发点之前**有效——一旦真放行生长，产品会清连续段、`proposal_count` 进位、
   并挂载候选 ⇒ 其后轨迹与原始跑必然分岔。**任何"把 τ 定在 X 就会进化"的主张都要另立单变量跑来坐实。**

## 5. 今日**不得**发表的数（把边界画死）

- `0.65`（beta 链）是本件的**候选值**，不是 τ 的定案：它取自 4,000 符号预算、`gate` 两档、出厂冷底链的面；
  换预算换装配都不许搬（§4.5）。**动 `minimum_pressure` 常量＝改产品默认放行面 ⇒ owner 签字**（旧 §3 甲档同样受这条约束）。
- 六道分项闸的其余五道阈（`minimum_residual_error` 等）＋`ema_rate` **今天没有任何面自述过**
  （`train_seed_corpus.py:535-539` 只写三项）⇒ 本件引用它们时一律标"取产品默认"，
  并且**DEBT-G53 修法②（把六道阈＋五支 EMA＋`reasons` 写进面件）必须先落地，τ 才有"面内自述"的发表资格**。
- 本件不选装配（乙/丙之争归 owner），不承诺"τ 定好后 N5 就能开工"。

## 6. 出口（本件之后能接的两格，都不需要重跑训练）

1. **修法②的预注册**（零算力起草）：面头补齐六道阈＋`ema_rate`，面行补记五支 EMA 与 `reasons` 与
   `consecutive_pressure_steps`——decision 就在 `_record_pressure` 手边 ⇒ 纯加披露、零重算。跑面另批（会改权重）。
2. **owner 若点 (乙)**：按 §4 用 EMA 口径在两链各冻一份 τ。但本件必须先记下规则本身的一处**粒度缺陷**——
   四张面的 `pressure_ema` p90 分别是 0.649071／0.648624（beta 两档）与 0.65786／0.656156（circuit 两档），
   两链集合**不重叠**（间距 0.007085＝0.656156 − 0.649071，最大跨链差 0.009236），而冻结规则的格宽 **0.05 是它的 5.4–7.1 倍** ⇒ 向上取整把 beta 链送到 0.65（在其可触发上界 0.678 之下，有动态范围）、
   把 circuit 链送到 0.70（在其上界 0.6859 **之上**，零动态范围、按 §4.3 该候选作废）。
   ⇒ **两链 p90 确有差别（两个集合不重叠），但"该落到 0.65 还是 0.70"是取整格宽决定的**——差别只有格宽的 1/5～1/7；
   在 0.05 格上比较两条链＝用一把比信号还粗的尺。
   下一步该动的是**规则**（格宽／分位数选哪个），而不是先动常量；规则改动要先解决"旧格宽冻出的数怎么办"（既有纪律：升版＋索引标作废，旧件不删）。
