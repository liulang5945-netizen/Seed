# R2 A2.3 预注册：**召回条件发射训练——让模型自己学会"何时抄、抄哪条"**（2026-09-25）

前件：`M5_R2_ARCH_COPY_CIRCUIT_PROJECT_20260925.md` §3-A2.3/§4.2（§4.1 存在性判据已过，
`taiji_r2_copy_circuit_existence_20260925.json`）。所有者 2026-09-25 裁定：**开，但时间预算不要过长**
⇒ 本预注册按"短预算＋硬止损"冻结。

## §1 问题与假设

剪贴板通路已存在但**出厂全关**（gate 零初始化）。本实验要回答：**局部学习规则能否让模型学会**
①寻址（提问状态下把 query 指向内容里正确的字节位置）②开关（何时让复制参与发射）。
假设 H：以「告知→提问→答案」结构训练后，寻址 top-1 命中率与 |gate| 显著上升，且 CAP D+E > 0。

## §2 学习规则（冻结；全局部、无 autograd，与 motor/predictive 同族）

每个答案字节步（`ctx`=F1 上下文 48 维，`cue`=当前皮质状态）：
- **寻址**（交叉熵局部更新）：`delta = onehot(target_pos) − softmax(scores)`；
  `query_state += lr_a · ctx ⊗ (delta·keys)/√ew`；`query_content += lr_a · embedᵀ·(delta⊗query)/√ew`。
  `target_pos` = 目标字节在内容中**下一个未发射出现位**。`content_embed` **冻结**（随机投影只做基）。
- **开关**（反事实优势，policy-gradient 形，与 `learn_reward` 同族）：
  ~~`A = clamp(log p_with[byte] − log p_without[byte], ±2)`~~ **rev2（smoke 实测后修订）**：
  `A = clamp(log p_full[byte] − log p_off[byte], ±2)`，其中 p_full/p_off 是读出层在
  `base_evidence + 1.0·copy_dist` / `base_evidence` 下的分布——**反事实固定为"全开"**。
  修订原因（smoke v1 实测，`taiji_r2_copy_circuit_training_smoke_20260925.json`）：rev1 用
  "当前开度"作反事实，而 gate 零初始化 ⇒ `p_with ≡ p_without` ⇒ 优势恒 0 ⇒ gate 永远学不开
  （零锁死）。rev2 与当前 gate 解耦：开对方向就长，开错方向就压；gate 参数仍零初始化（位级不变不破）。
  `gate_state += lr_g · A · ctx`；`gate_content += lr_g · A · pooled`；`gate_bias += lr_g · A`。
- 织物/F1 权重**全程冻结**（本实验只训 5 个 circuit 张量）；fabric 动力学照常推进。
- 所有更新后 clamp 到 `max_weight_norm`。

## §3 语料（冻结；防泄漏）

- 模板族＝CAP D/E 同构（`given_then_ask`／`with_distractor`），**实体表与评测集不相交**：
  名字（阿蒙/晓雨/子昂/青禾/若谷…）、城市（成都/厦门/敦煌/丽江/曲阜…）、数字（42/7/2025/13/96…）、
  项目（星舟/春潮/山丘/拾光…）。评测集实体（阿岩/杭州/17/Seed）在训练中**永不出现**。
- 每 episode：喂告知段（learn=False）→ `record_told_content(告知原文)` → 喂提问段 → 答案字节 teacher-forcing。
- 组合全量 ≈ 数百模板 × 实体，够 90 分钟预算取用；取样顺序固定 seed。

## §4 预算与止损（所有者裁定＝短）

| 阶段 | 模型 | 预算上限 | 通过判据 | 止损 |
|---|---|---|---|---|
| S0 自检 | 小模型 (64,48) | **2 分钟** | circuit checkpoint 存/取 digest 逐位一致（训练前必查） | 不过即停 |
| S1 smoke | 小模型 | **≤20 分钟**（300 episodes） | 寻址 top-1 命中率 ≥50%（起点≈随机 1/P）且 mean\|gate\| > 0.05 | 任一不到 ⇒ 学习规则问题，停、报告、不加预算 |
| S2 判读 | base_16M（seed_beta.pt） | **≤90 分钟**（episode 预算按 S1 实测速率折半预留） | ①同上两读数；②**CAP D+E 抽查 > 0**（T6 仪器，S 判据线沿用）；③成句率不塌（A 维抽查） | 到点即停，出报告；追加预算需所有者再裁 |

- 墙钟硬顶：S1+S2 合计 ≤ 110 分钟；stop 文件优雅停机（同 readout_retrain 纪律）。
- 写靶隔离：`output/taiji_r2_copy_circuit/`；`checkpoints/` 只读，基底 sha256 跑后复核逐位不变。
- 断点续跑：每 N episodes 落 circuit payload（含 digest），重启自动续。
