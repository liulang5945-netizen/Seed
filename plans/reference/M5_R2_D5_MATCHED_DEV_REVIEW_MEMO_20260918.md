## §2 两因子的裁决读数

- **H-M 驻留（A10）**：dev 读数与 A00 **逐项相等**（M3 0.178、first-byte 0.529、completion 同值），bias 在无多字节压力的 train 上几乎未离开初值 0。机制预测完全兑现：train 无需求 → 偏置不学习 → dev 无变化。**H-M 判否（在缺乏覆盖时驻留偏置无自发效果）**。
- **H-E 覆盖（A01/A11）**：probe 全绿（train 多字节 72/72）但 dev **崩至 0.008/0.004，比不扩数据的 A00 差 20 倍**——扩 train 值域不仅没修好多字节外推，还摧毁了 v1 训练下已有的部分泛化（A00 的 12/76 白值行正确在 A01 归零）。**H-E 判否，且为有害判否**。
- **A11 交互**：bias 终值 **−0.044（负）**——即使 v2 多字节 train 给足了持续 copy 的样本，模型也未使用驻留 bonus（train 用独立寻址即可拟合琥珀/珊瑚/翡翠的固定位置模式）。机制+数据组合无协同。

## §3 dev 失败模式的精细刻画（seed 20260919，A00 vs A01 checkpoint 只读重放）

- A00：`米`→`米色`、`不是灰`→`不是灰白`——首字节正确、**截断**（D4 特征）。
- A01：`灰紽`、`米索`、`白索`、`盾索`——**首字节仍正确**（灰/米/白 3 bytes 对），第二字复制**错位/乱码**；白值行正确数 12→0。
- 解读：v2 train 的值词固定、对象固定，模型把「值第二字 = 第一字位置+1」拟合成了**与具体词面绑定的位置模式**（mis 崩至 0.053 也印证第二字节置记忆而非序列规律）；dev 新值词的字节序列落进错误位置。v1 训练下「单字节值 + 提前 boundary」的策略至少蒙对一批白值行，v2 把这条路也堵死。**模型没有「字（3-byte 符号）/值行」层面的组合表征，字节位置模式才是它的可学性边界**——这正是 B 方案（对象槽位/显式指针/token 化）的动机证据，且现在有了它必要性的直接实验支持（纯数据+纯目标+纯偏置三条线均已判否）。

## §4 流程记录：canonical 索引事故（已修复并制度化）

首版 v7 把 `copy_persist_bias` 插入 `_CANONICAL_PARAMETER_ORDER` 中部（answer_start_bias 后），使 `decoder/decoder_bias` 的 canonical 索引 23/24→24/25——per-name 初始化生成器随索引变化，**所有既有图族的 decoder init 漂移**。后果：A00 漂移复核 max_abs_diff=0.82 中止 matched 首跑；三臂 probe 首跑数字作废（已在修复后重跑，门读数不变、bias 终值更新）。修复=新名一律追加至表尾（代码注释已记录）。**教训制度化**：任何 graph 版本升级的冻结实现门必须包含「shared 张量 init 逐位不变 + 历史 checkpoint 重放断言」——本包靠 matched 的 A00 复核抓住了，但应在**实现门**阶段就有此断言（D3 gate 有 H=1 逐位等价，但同 codebase 两侧同漂移，无法发现跨版本 init 漂移；历史 checkpoint 重放是必要一道，D4 已加入、D5 依赖其 matched 版）。
