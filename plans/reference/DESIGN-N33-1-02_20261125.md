# 预注册卡：N33.1.02 学得自主选择策略（仅在模拟器奖励上学习，不模仿脚本）

> [预注册·探索] — 2026-11-25（D-20261125-557；owner「全批」授权 N33.1，首批 ≤1,200 CPU）。前置 [N33.1.01](RESULT-N33-1-01_20261125.md)（`sim_ready`，D-556）。**策略必须由主体内部学得；脚本基线只作对照，不用于模仿/蒸馏；不读确认 seed。**

## 1. 问题

一个**从模拟器奖励里学出来**的策略（MLP 7→64→6，REINFORCE＋回报基线＋熵正则），能否：
1. 显著超过随机策略并接近/不低于脚本基线（能力）；
2. 表现出**状态相关选择**（低能量→休息、高不确定→求证/求助、有未完成任务→继续/回忆）；
3. 在**状态被置零**时明显变差（证明它真的用了状态，而不是常量输出）？

## 2. 设置（冻结）

| 项 | 值 |
|---|---|
| 训练 | 3 个独立训练种子（1001/1002/1003）；每种子 4,000 episodes；REINFORCE（回报-to-go，均值基线，熵系数 0.01），Adam 1e-2；训练用模拟器 seed = 训练种子×10,000＋episode 序号 |
| 评测 | 固定 40 个**评测 seed 5000–5039**（训练从未使用）；三臂同种子：学得策略 / 脚本基线 / 随机策略 |
| 网络 | `state(7) → Linear 64 → Tanh → Linear 6`，softmax；无 task_id |
| 抑制捷径 | 脚本策略**不参与训练**（无行为克隆）；状态置零控制臂用同一训练好的网络 |

## 3. 门（每训练种子；3 seed 全过才算正例）

| 门 | 定义 | 达标 |
|---|---|---|
| **G1 能力** | 评测均值回报 | ≥ 随机均值 **+10.0** 且 ≥ 脚本均值 **−2.0** |
| **G2 状态相关选择**（行为探针） | 低能量（<0.35）时 rest 占比；高不确定（>0.55）时 verify+ask_help 占比；有未完成任务（pending>0 且 progress<0.3）时 continue+recall 占比 | 三者均 **≥0.50** |
| **G3 使用状态** | 正常输入回报 − 状态全零输入回报 | **≥1.5** |

## 4. 出口（读前写定）

| 出口 | 条件 | 后续 |
|---|---|---|
| `learned_policy_positive` | 3/3 训练种子通过 G1∧G2∧G3 | 可申请 N33.1.90 确认（seed 20261501–03，另行授权）；并在结果卡声明「策略由奖励学得、状态相关」 |
| `learned_policy_partial` | 3/3 过 G1，但 G2 或 G3 未全过 | 记「能力成立但状态条件性不足」；下一步只改一个预注册变量 |
| `learned_policy_negative` | 其余 | 记「学得策略未成立（当前设置）」；结线，不追加 |
| `engineering_failure` | NaN/超预算/缺种子 | 修复后重跑本卡 |
