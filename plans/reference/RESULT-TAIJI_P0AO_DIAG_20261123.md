# 结果卡：P0-AO 线性读出巩固（`p0ao_flip_not_learnable`；冻结线性读出的单元巩固使翻转崩塌）

> [结果卡·探索诊断] — 2026-11-23（D-20261223-377）。脚本 [diag_p0ao_20261123.py](../../scripts/training/diag_p0ao_20261123.py)；回执 [report](../../reports/taiji_p0ao_diag_20261123.json)。**1 seed、198.48 CPU、零 check；探索诊断。**

## 1. 设置

P0-AN 管线（修正评估）＋**线性读出巩固**：先用最小二乘在 1024 样本上拟合闭式线性读出 $w$，冻结 $w$ 后只训单元＋适配器 **800 步 lr 1e-2**，目标是让翻转在单元状态上线性可分；随后检查翻转/线性探测/迁移/休眠唤醒/适配器因果/旧中文。

## 3. 判定

**`p0ao_flip_not_learnable`**（G3–G5、G7 不过；G0/G1/G2/G6/G8 过）。

## 4. 判读

1. **冻结线性读出的单元巩固反而破坏翻转**：翻转 0.998 → **0.443**，线性探测 0.894 → **0.777**，适配器因果也消失（drop 0.045）。
2. **原因**：$w$ 在旧特征上拟合后被冻结，单元以 lr 1e-2 训 800 步会向「适配旧 $w$」方向漂移，与原先 MLP 头学到的映射冲突；且适配器梯度经旧 $w$ 反传被误导 ⇒ 灾难性干扰。
3. **对照**：P0-AN 的「冻结 MLP 头只训单元」是更稳的巩固方式（0.998/0.894），距线性门仅 0.006。
4. 休眠/压力/旧中文保持不受影响。

## 5. 下一轮

1. **回退到 P0-AN 的 MLP 冻结巩固**；
2. 既然 0.894 距门仅 0.006，用**多种子（3 seed）**测 P0-AN 管线的分布（若部分 seed ≥0.90，说明该卡点处于种子噪声带，需要更强方法或更合理判据）；
3. 之后的改进再考虑温柔版线性巩固（lr 1e-3、200 步、每 50 步重拟合 $w$）。
