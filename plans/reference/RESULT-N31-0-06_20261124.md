# 结果卡：N31.0.06 颜色重标号增广泄漏审计（P0-DU / DV / DX / EB → `data_invalid`）

> [结果卡·审计] — 2026-11-24（D-20261124-471）。阶段级工作（N31.0），零训练、0 check/final。依据 [阶段验收与停止规则](../active/STAGE_GATES_AND_STOPPING.md) 与 MAINLINE §1.3 出口 `data_invalid`（「泄漏、跨区……或评分真值进入可见输入」）。

## 1. 发现

`diag_p0dw_pressure_precision_20261124.py`（及其前身 P0-DU / DV 的同一 `revision8`）第 86–96 行的顺序是：

1. 采样颜色对 `(c1, c2)`；
2. **先**按 `(c1, c2) not in HOLDOUT` 过滤；
3. **再**对通过过滤的样本施加颜色置换 `c1, c2 = perm[c1], perm[c2]`。

置换后的 `(perm[c1], perm[c2])` 可以落在 HOLDOUT 中。HOLDOUT = {(0,1),(1,0),(2,3),(3,2),(4,5),(5,4),(6,7),(7,6)}，占 56 个有序对的 1/7；均匀随机置换把任意有序对映到任意有序对。

## 2. 泄漏量（按同一协议模拟：2,400 步、每步 24 样本、偶数步增广）

| 项 | 值 |
|---|---|
| 增广样本中落在 HOLDOUT 的比例 | **0.144** |
| 每个 seed 阶段 B 训练中带正确标签的留出对样本 | **约 4,150 条** |
| 被暴露的不同留出对 | **8 / 8** |

评测集 `eval8_unseen`（不加置换、只取 HOLDOUT）本身无误；问题在于这些「未见」对在训练里已经以正确答案出现过数千次。

## 3. 判定

| 卡 | 原结论 | 审计后 |
|---|---|---|
| P0-DU（D-459） | 主判据 3/3 达 0.80 | **`data_invalid`**：aug 臂未见对读数不能作为泛化证据 |
| P0-DV（D-460） | 主判据 6/6 | **`data_invalid`** |
| P0-DX（D-461） | full 6/6 | **`data_invalid`**（压力门精度修复本身有效，未见对读数无效） |
| P0-EB（D-463） | 比较失配 | **`data_invalid`**：两臂都用同一泄漏增广，未见对比较无信息 |
| [阶段性收束计划 v2](PLAN-STAGED-CLOSURE_20261124.md)（D-462）「T8U 可签署 full 6/6」 | — | **撤回** |

- base 臂（不增广）读数不受影响，仍有效：8 色未见对基线约 0.73，「≥0.60 有界、≥0.80 未成立」的表述维持。
- 颜色重标号作为方法**没有被否定**，只是尚无有效证据；修复后的生成器见 N31.2.01。
