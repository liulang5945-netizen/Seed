## §0 一条必须先纠正的事实（本次实测，2026-09-15）

`scripts/training/train_seed_corpus.py` 的文档声称"对话结构已经在文本里（**问：/答：** 标记）"，
但**实测语料不是问答格式**：

- `data/simple_zh/simple_zh_texts.jsonl`（**1,394,775,610 B**）每行是 `{"text": "…"}`；
- 内容是**「角色名：内容」的多角色脚本**，例如
  `作者：佚名\n\n\n\n老师：同学们，今天我们要学习的是《诗经·关雎》…柔煦（温柔地朗读）：关关雎鸠…`；
- **抽样 2000 行中，同时含 `问：` 与 `答：` 的只有 1 行**。

⇒ **不能**依赖现成的问答对做对齐；对齐目标只能落在**"角色对话的续写形态"**上。
（该 docstring 与语料事实不符，已记入本预注册，供后续修订该文件时参考。）

## §1 问题与假设

P3a 已把**可读性**从 `0/4` 修到 `4/4`（链路可用），但**能力分数**仍远低于最低线：
C `0.00`、D `0.0625`、E `0.15`（最低线 70% / 80% / 70%）。

- **H-P3b**：缺口主要来自**训练数据分布** —— 当前 16M ticks 的字节流里"对话/回答形态"密度过低，
  模型学成"**字节续写**"而非"**回答续写**"。在**对话密度更高的数据**上继续训练，
  能在**不改架构**的前提下提升 C/D/E。
- **反假设**：若在对话侧重数据上仍无提升 ⇒ 缺口在**序列建模能力 / 架构**层
  （另立议题，**不属**本预注册范围）。

## §2 协议（冻结项）

| 项 | 取值 |
|---|---|
| **起点** | `checkpoints/seed_beta.pt`（`tick = 16,000,000`；需放宽 legacy 守卫才能加载） |
| **数据** | `data/simple_zh/simple_zh_texts.jsonl` 中**筛选多角色文档**（含 **≥2** 个 `角色：` 前缀）构成的子集；**筛选规则、命中行数与产物 sha256 必须随报告归档** |
| **目标函数** | **不变** —— `observe(symbol, learn=True)` 的字节级下一符号预测。**本包不改架构、不改损失、不改加载器** |
| **推理链路** | **必须与 P3a 完全一致**：进程内放宽 legacy 守卫 + UTF-8 约束解码（否则前后不可比） |
| **评测节奏** | 每 N 个检查点在同一**冻结评价集 v1** 上评测；`trained_during_eval = false`；原始回答留档 |
| **预算** | **先标定**：小规模试跑测吞吐后冻结总机时；**标定前不承诺任何机时数字** |

### §2.1 数据侧与吞吐标定结果（2026-09-15，**已完成**）

数据侧已就绪、吞吐已实测，产物：
[子集 manifest](../manifests/p3b_dialogue_subset_manifest.json)、
[标定报告](../../reports/taiji_p3b_throughput_calibration_20260915.json)；
构建脚本 `scripts/training/build_p3b_dialogue_subset.py`、标定脚本 `scripts/training/calibrate_p3b_throughput.py`。

| 项 | 实测 / 外推值 |
|---|---|
| **对话子集** | `data/p3b_dialogue_subset.jsonl` —— **282,581 行 / 534.3 MB**（源 787,399 行中 **35.89%**），sha256 `2abf6f03…` |
| **训练吞吐** | **273.7 steps/s**（≈ **98.5 万符号/小时**） |
| **过一遍完整子集** | **≈ 568 小时（23.7 天）** ⇒ **不可行**，必须只用部分数据 |
| **复现 16M ticks 量级** | **≈ 16.2 小时**（与既有 `seed_beta.pt` 的规模量级一致） |
| **建议预算档** | **16 h ≈ 1576 万符号**；**48 h ≈ 4728 万符号**（均**远小于**"过一遍"） |

⇒ **P3b 的可行规模是「部分数据 + 16–48 小时」量级**，**不是**"过一遍"。
训练脚本须用已有的 `--max-symbols` 从子集截取，并按此设预算；**标定值一旦用于正式运行即冻结**。

### §2.2 执行时确定的双臂设计（2026-09-15，**判据与停止条件不变**）

单臂前后对照在本链路上**分不清三件事**，故正式执行采用两臂：

| 混淆源 | 实测证据 |
|---|---|
| **放宽 legacy 守卫会挂上一个全新的随机 identity organ**（P3a 基线也是这样评测的，但训练会把它一起训练） | 从 `seed_beta.pt`（4.1 MB）续训 12,000 符号后保存的检查点是 **88 MB**，多出的正是新生成的器官载荷 |
| **任何预算本身都等于"又多训了一遍"**，与数据分布无关 | 273.7 steps/s 下 16 h/48 h 档分别是 1,576 万 / 4,728 万符号 |

| 臂 | 语料 | 其余条件 |
|---|---|---|
| **treatment** | `data/p3b_dialogue_subset.jsonl`（对话子集，sha256 与 manifest 强绑，不符即拒跑） | 同起点 `seed_beta.pt`、同预算档、同目标函数、同链路、同评测节奏 |
| **control** | `data/simple_zh/simple_zh_texts.jsonl`（**16M ticks 原本训练用的同一条原始流**） | 同上 |

**主效应读法**：`treatment − control` 才是"对话密度"的效应；任一带对 P3a 的单边差值**不得**被表述为
"数据分布导致的提升"。**J2/J3/J4/J5 仍按 §3 原文对 P3a 基线判定**，两臂各判一次；
两臂**必须**在完全相同的链路上（`chain == {relax_legacy_guard: true, constrained_decode: true}`），
否则 J1 直接不通过。

**仪器与产物**（本轮新增，均有契约测试）：
`scripts/training/train_p3b_aligned.py`（**从检查点信封重建 `SeedConfig`**——实测没有任何 `--scale`
画像等于 `seed_beta.pt` 的 v8 配置，故 CLI 的 `--resume --scale` 路径不可用；机时档与冻结标定值绑定；
**拒绝写受保护检查点**：`seed_corpus.pt`（产品默认入口）与 `seed_beta.pt`（起点））、
`scripts/training/run_p3b_campaign.py`（逐检查点调用 `eval_taiji_cap0_baseline.py` 评测、
把 §4 停止条件的**定义**写进报告、崩溃可续、收尾核验受保护检查点未被改动）、
`tests/taiji_native/test_p3b_campaign_contract.py`。每臂独立的
`checkpoints/p3b/seed_aligned[_arm].pt`、`reports/p3b_aligned_progress_<arm>.jsonl`、
`reports/p3b_stages/<arm>/cap0_tick_<tick>.json` 与 `reports/taiji_p3b_campaign_<arm>_20260915.json`。

**预算档取值**：按"上限优先"取 **48 h 档（47,280,000 符号）**，两臂并行；
停止条件仍可能在连续 3 个检查点无改善时提前止损（§4.2）。

**§4.3"出现退化"的可机检定义（新增定义，不改判据）**：每个维度 20 项 ⇒ **单题翻转 = 0.05 是噪声**，
不能拿它砍掉 48 小时的跑（冒烟阶段就是这样在 1 小时误停的）。因此"退化"取二者之一：

- **material**：任一机检维度 ≤ 其 P3a 值 − **0.10**（即至少两题）；
- **persistent**：**同一维度**连续两个检查点低于其 P3a 值。

另加一条：B/G 的**待人工复核数**高于 P3a 也算退化。该定义随每份 campaign 报告的
`stop_definitions` 字段落盘，并由 `test_p3b_campaign_contract.py` 钉住；
**J4 判据原文一字未改**（它约束的是最终报告的零回归，不是中途止损的门限）。

## §4 停止条件

1. 预算耗尽；**或**
2. **连续 3 个检查点** C/D/E 相对 P3a 基线**无改善** ⇒ 停，按**反假设**结项并记负结果；**或**
3. 出现**退化**（B/G 或 A/H 退步）⇒ 停并**回滚**到起点检查点。

## §5 明确不做

- **不**下调最低线；**不**换模型/换入口凑分；**不**把 E/T 模式算作 N 能力；
- **不**在看完成绩后调整判据（07 §4.2）；
- **不**修改冻结评价集；**不**改加载器与 binder（WP-6）。

## §6 与其它工作的关系

- **P3a 是前置**（已完成）：保证"有可读输出可比"；
