## 4. 判读

1. **奖励驱动的选择确实学到了东西**：无规划器标签、无 BC，AWR 在 7680 回合内把效用从随机水平推到 **2.895**（超启发式 +0.076、距 DP 仅 0.070），且能量=0 时休息率 1.0、使用 3 类动作 ⇒ 「从真实回执改进负责机制」有正面证据。
2. **G2 失败点单一且可解释**：零化「已解」通道后效用 2.959（略升 0.064）——策略主要靠能量/置信/剩余步选择「休息/求助/继续」，已解通道在最终策略中近乎冗余；该消融假设（每个通道都必须有用）在学到的策略上不成立，属判据过强，而非「状态盲」。
3. **未学出求证/等待**：动作占比 0 —— AWR 收敛到「休息+求助」的局部策略；求证/等待需要更长链式信用分配。
