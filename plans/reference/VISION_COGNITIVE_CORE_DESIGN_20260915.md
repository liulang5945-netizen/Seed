# VISION：Taiji 可替换认知核心详细设计候选

> 2026-09-15；仓库核对基线 8198717b。状态：design-candidate，非冻结实验、非实施授权。
> 用户认可训练方向，但明确保留当前主线。唯一执行顺序见 [03](../active/roadmap/03_CURRENT_EXECUTION.md)；本文挂在 [VISION](VISION_FUTURE_TECHNOLOGY.md)，不能替换正在执行的 B1/B2。

## 1. 目标、证据与不变量

目标是让表示、持续状态、记忆、动作后果预测与选择形成可训练的共同计算链；不是增加一套绕过 Taiji 的外部决策器。

| 已知问题或风险 | 证据范围 | 设计响应 |
|---|---|---|
| 池化能力画像丢失差异 | c 系列和 B1 标定的窄任务证据 | 条件化表示，训练目标与实际选择效用一致 |
| 时间保持、检索、信用分配被混写 | vision 旧条目的设计问题，非本轮新实验 | 三者分别定义载体与验收，不只调整 decay |
| 现有 region 逐步依赖与原地更新 | neuron_region.step 目前消费自身 activity/membrane | 新核心用显式函数状态，提供流式和分段训练路径；不声称旧非线性递推可直接 scan |
| 模块有接口不等于共同学到能力 | 架构风险，尚未全面归因 | 用一条端到端任务链检验表示是否被后续模块有效消费 |
| 运行适应可能破坏基础能力 | 设计风险，非已证明的必然失败 | 快速状态/参数与长期参数分账，训练后仍测在线适应和保持 |

保留：Taiji 参数、记忆、目标与选择的所有权；Seed 权限和外部执行；真实/想象来源区分；完整 checkpoint、保持和回滚。允许评审替换：特定神经元方程、固定时间尺度、单一局部更新实现、固定专家划分。旧内核可以是主干、局部器官或对照，位置由实验决定。

## 2. 第一版核心边界与状态

以下是接口设计，不是现有类或固定参数规模。B 为并行独立 episode 数，D 为表示宽度，K 为工作空间槽数，R 为记忆头数；具体维度由预算标定后冻结。

| 状态 | 建议形式 | 所有者与保存规则 |
|---|---|---|
| 慢参数 θ | encoder、转移、查询/写入投影、选择和生成头 | Taiji 核心；离线与巩固更新版本化 |
| 循环状态 h | 多尺度张量组，每组 [B,D_s] | episode 独立；不得因 batch 共享污染；显式 reset |
| 工作空间 w | [B,K,D] 加有效位/对象引用 | 活跃目标、对象和待验证条件；槽分配不能读答案标签 |
| 关联记忆 A | [B,R,d_k,d_v]、衰减/置信状态 | 快速内容关联；写入有来源/预算，容量有限，不宣称无损 |
| 情景存储 E | 原始观察/行动/结果记录与可索引表示 | Taiji-owned 记忆合同；底层存储可由宿主托管，内容选择不能由隐藏 oracle 决定 |
| 快速参数 φ | 受限读出/低秩更新等候选 | 与 θ 分离；可关闭、撤回、巩固；第一版可先只用 A 而不启用 φ |
| 运行元数据 | RNG、时钟、数据游标、版本、预算、工具状态引用 | 全部影响继续行为的状态进入快照或显式外部依赖清单 |

原始字节、路径和精确文本保留可审计引用，不强求 D 维状态无损存储。模型选择引用、预测绑定；读取器忠实取数据，不按任务答案生成内容。

## 3. 一个实际认知步

1. 编码带来源与时间的观察片段，输入上次真实 outcome、当前目标和合法可见工具 schema。
2. 查询记忆，结合循环状态更新工作空间；查询记录包括来源 ID，拒绝访问 sealed/test 答案。
3. 生成候选：动作类型、目标对象、参数或参数引用、预期状态变化、停止/求助选项。
4. 世界模型以当前状态和候选动作预测短程后果、失败与不确定性；第一版不强求长程搜索。
5. 选择器比较冻结定义的效用/风险/成本。Seed 只验证权限与执行，不能替模型挑正确候选。
6. 真实 outcome 回写状态、情景及允许的快速更新；想象轨迹单独标记，不能变成真实成功证据。

候选接口：observe(observation,state)、propose(goal,state,budget)、feedback(outcome,state)、snapshot/restore。训练端增加 forward_sequence 与 losses；使用同一前向数学，避免训练专用 oracle 路径。

## 4. 计算结构的首选与对照

首选一个共享选择性循环核心，加可关闭的关联记忆路径、短程动作条件预测头与选择头。不要第一版同时加入大量独立专家、结构扩容和异步调度。

| 决策 | 首选 | 替代与取舍 |
|---|---|---|
| 时间载体 | 可学习输入门控、显式多尺度状态 | 固定 τ 便于解释，作基线；慢状态不能保证长期信息可读 |
| 关联载体 | 门控定向写入/纠错 | 纯循环压缩更简单但有干扰；检索存储更精确但有检索延迟和来源风险 |
| 工作空间 | 有界动态槽＋内容寻址 | 纯池化易丢对象绑定；大规模全连接关系计算成本高 |
| 行动 | 条件化选择＋参数绑定/生成 | 脚本参数可用于早期隔离验证，但必须标注，不能当完整生成 |
| 协作 | 先共享表示和显式交接，再检验专门化 | 先建多个专家可能把表示问题转成通信问题；不预置永久语义角色 |

门控 delta-rule 的遗忘与定向修改、并行训练可参考 [Gated DeltaNet 原论文](https://arxiv.org/abs/2412.06464)，只借鉴机制，不直接继承其 benchmark 成绩或完整模型。任何算子引入均需符合 Taiji 所有权与资源边界。

## 5. 学习设计：发展训练与在线适应共同定义

发展训练候选使用成熟自动微分和优化器，但当前 taiji/ 的禁令仍有效：原型训练置于经评审的隔离实现，正式迁移前修改合同与测试，不能绕过禁令冒充原生等价。

任务采样过程：采样训练任务族 → 适应前评估 → 给适应经历并更新 A/φ → 在该任务族的新经历上评估 → 用后续表现更新 θ/适应机制。训练族内的适应/查询划分不同于最终未见测试族，三者严格隔离。

损失候选包括：观察/事件预测、动作条件转移、任务结果、有效参数/内容生成、旧任务保持。权重在开发集标定后冻结；latent 预测需防常量表示，不能仅靠低预测误差结项。第一版对离散执行用真实轨迹监督或明确的策略学习估计，不假装梯度可穿过文件操作。

跨时间训练先用有界展开和完整状态传递，记录截断长度；若做 scan 或 chunked 训练，先验证与流式语义一致。自动微分只是工具，若更新边界仍限于末端，不能宣称解决长期信用。

运行期分层：h/w 更新是推理状态；E/A 写入是记忆适应；φ 更新是参数适应；θ 更新是长期巩固。四类独立消融。运行期不自动对全部 θ 反传；巩固需稳定收益、保持和可回滚门。自主唤醒须在适应收益可测后才引入，novelty 高不等于值得学习。

## 6. 世界模型与语言生成的专门边界

世界模型必须预测行动后果，不只下一观察。短程滚动后真实重观察；不确定性高时拒绝长程自信规划。用模型预测取得高分而真实失败，按模型利用漏洞记录。

用户看到的文本必须区分：模型选择/生成、确定性格式化、外部 provider 输出。完整自然语言生成需要专门的内容/表达目标、训练数据和未见提示验收，不能由 B1 的 pair 排序自然推导。

第一版可输出结构化行动和受控内容，但不得称通用聊天模型。后续语言头训练应测试未见约束、非背诵表达、内容与真实执行一致性；纯渲染文本不得计入生成分数。语言质量与协作能力分开评审。

## 7. checkpoint、迁移与运行

保存 θ、h/w/A、E 索引与内容摘要、φ、优化器、RNG、数据游标和预算；训练前先零步保存、全新进程恢复、继续一步验证。设备迁移按预定义数值容差与任务等价测试，不无条件要求不同硬件逐位一致。

旧/新核心通过同一观察、候选、outcome、快照接口接入隔离宿主。先观察/回放，再沙箱执行；不改默认产品路径。旧权重未必能映射到新数学结构，不承诺无损迁移；旧报告、数据、权限、任务和恢复经验可复用，能力继承须重测。

## 8. 原型交付与否决条件

| 交付 | 可运行产物 | 出口 |
|---|---|---|
| V0 设计审阅 | 状态/schema、训练边界、预算标定方案 | 所有权、禁令调整与比较范围明确后，才授权原型 |
| V1 最小核心 | observe/propose/feedback/restore 与三种配置 | 旧核心、新核心无关联记忆、新核心完整版都能实际运行；保存预检通过 |
| V2 端到端任务 | 延迟线索、新组合、中断、失败重规划、少量经历适应 | 新测试上的真实收益与保持；参数/训练量/成本同账，报告失败 |
| V3 替换评审 | 能力矩阵、旧能力回归、迁移和风险报告 | 独立批准采用、继续研究或否决；不靠更多模块延续负结果 |

失败分流：表示塌缩回损失/输入；预测有效但执行失败查绑定/选择；适应快但遗忘查 φ/θ 边界；成本不划算则保留旧核心。禁止把数据泄漏、脚本帮助或不同计算预算当架构收益。

## 9. 与当前主线及迷你模型的关系

当前 B1/B2 继续冻结路线；其结果作为新核心必须超越的基线。vision 设计现在可做，V1 实施等阶段出口独立决策；主线负结果不等于新核心已获批准。

[迷你模型交付](../active/roadmap/07_MINI_MODEL_DELIVERY.md)先复用现有主线，不等待 V1。它让用户实际看到参数驱动的输出与失败；若当前能力不足，直接展示不足，不用新架构承诺延后交付。

本方案未确定参数规模、硬件采购、训练量或性能倍数；这些必须标定，不凭模型名字或生物类比估计。
