## 1. 一句话

**内容监督也没能打破常量。** 底座 194 张量逐位不变、只加一条零初始化内容头（36 参数）与 λ=1 的四类 CE：字节输出仍与 P3.10／P3.13 **逐项相同**（0／0／8／8、train 0／0／16／16、每点 1 种输出），而**辅助头自己在每个剂量点都只有 0.25**（fit 与 train 同时）——直接监督都学不动，说明瓶颈不在"信用没到"。

形式出口：`content_supervision_insufficient`（末点 fit 0.25 ≤0.35 且 train 0.25 ≤0.35）。

## 3. 这个"头也不学"意味着什么

辅助头是**直接**接在读出上下文上的线性四分类，有自己的优化器、零初始化、λ=1；它拿到的梯度不经过字节路径。它仍然停在 0.25，等于说：**上下文没有把四类位置分开，而且直接监督也没能把它推开**。所以"信用没到读出"这一支被排除——不是梯度送不到，是送到也分不开。

## 4. 一次仪表缺口与补测（v2 → v3，如实入账）

v2 跑完并给出 `content_supervision_insufficient`，但**没有记录辅助头本身**，无法区分"上下文没带标签"与"字节头无视上下文"。v3 在同一条臂上补记头准确率并保存头状态，判据、剂量点、帽、授权、λ **一字未动**；v2 的报告与运行根保留为 `_v2_uninstrumented`。v3 的字节读数与 v2 逐项相同（确定性复现）。

首次运行（v1）在 `save_learner` 处失败：单优化器覆盖了模型＋头，而 `load_learner` 只重建 194 参数的 body 优化器。改为 body／head 两个优化器后通过；失败报告与运行根保留为 `_engineering_failure_v1`。

## 5. 补测：信息在 patch 里，但很小（对 P3.11 读数的限定）

在同一 1844 bundle 上直接量编码器输出（`tanh(encoder.rgb + metadata + modality)`，32 个 fit 场景 × 16 patch × 8 维）：

| 量 | 读数 |
|---|---:|
| 逐 patch 跨场景逐维 std（均值） | **0.0443** |
| **均值池化后**跨场景逐维 std（均值／最大） | **0.0060／0.0092** |
| 求和池化后跨场景逐维 std（均值） | 0.0955 |
| 场景内 patch 间 std（均值） | 0.0584 |

- 场景信息**确实存在**（逐 patch 0.044），池化后仍有 0.006，不是被抹平。
- **对 P3.11 的限定**：P3.11 报的 `mean_dim_std=6.0e-4` 是**四模态 32 维拼接**的平均，被近常量的 audio／proprio／outcome 拉低；**RGB 单独是 6.0e-3**，大一个数量级。P3.11 的探针结论（线性不可解码）不变，但"几乎不变"这个描述要按此限定引用。
- 综合：信号存在但幅度小（池化后约为场景内 patch 波动的 10%），线性探针在 64 样本下读不出。

## 7. 下一卡：P3.15 聚合结构归因（零训练，第三次也是最后一次探针）

只回答一个问题：**把 patch 身份保留下来的读出（对 patch 做加权查询，而不是均匀池化）能否把同一批编码解出位置？**

- 测法：在 1844 bundle 的编码上，用**同一批 8 维 patch 编码**做「查询加权」读出（闭式 ridge，查询＝可学习/固定的 patch 权重），与 P3.11 的均值池化探针对比；训练 64、测试 32，附洗牌对照。
- 出口：`aggregation_is_the_bottleneck`（加权读出显著高于均值池化且洗牌接近机会）／`representation_is_the_bottleneck`（两者都低）／`inconclusive_aggregation`。
- 这是本线第三个条件化探针，**按规则到此为止**；无论结果如何，下一张必须是机制卡（改聚合结构或改任务），不再加探针。
