## 2. 结论与边界

- **效率达标、指代反降**：`Conv1d + Turn-GRU/SDPA` 将单 seed CPU 从 `~174` 降至 `127.5–133.2`，但去掉 token-level `BiGRU + 2×MHA` 后，开放中文未见句式指代（`0.5000–0.7222`）反而不如 `NCH.3.04`（`0.7593–0.7778`），说明细粒度 token 级跨回合注意力对中文指代不可或缺。此外 `weights_exact = false` 的根因是 `nn.Dropout(0.10)` 在训练中消耗了全局 PyTorch RNG，而 `train_arm` 内未重置 `torch.manual_seed`（`SessionStore` 往返仍保持 `store_roundtrip_exact = true` 逐位一致）。
- **不进 `N35.1.91`**：备用确认 seed `20261911–13` 严格未读；`check/final` 保持 `0` 读取。

零 check/final；零确认 seed。
