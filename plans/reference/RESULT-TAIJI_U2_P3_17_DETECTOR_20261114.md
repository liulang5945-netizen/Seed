## 3. 判读

1. **不是结构不行**：训练集满分说明「查询→注意力→读位置」这条路可以表达颜色×位置的合取，之前 P3.10–P3.16 的 0.39 天花板是**池化表示**的上限，不是任务的上限。
2. **不是优化不行**：1844 步内单调到 1.000，注意力同步锐化（2.77→0.16），说明梯度路径健康。
3. **是迁移不行**：fit 停在机会（0.28），且 fit 的注意力也锐利（0.118）——它在 fit 上**自信地看错地方**。最可疑的是切分本身：train 是 1–2 个对象，fit 是 **3 个对象**（`generate_examples` 里 `objects = 3 if partition == "fit" else 1 + (index//4)%2`）。

## 4. 可复现性处理（两次工程修正，产物保留）

- **v1**：训练后未保存检测器产物，守卫无法独立重算 ⇒ 保留为 `_v1_no_artifact`。
- **v2**：补存产物后读数变化（fit 8/32→12/32）——原因是注意力模块的初始权重取自**全局 RNG**，进程间不确定。**v3** 在构建前 `torch.manual_seed(candidate.seed)`，判据／剂量／帽／授权一字未动；v2 保留为 `_v2_unseeded*`。
- 三次运行的结论一致：train 恒为 1.000，fit 8／12／9 都在机会附近。v3 为权威读数。
