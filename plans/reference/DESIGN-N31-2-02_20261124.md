# 预注册：N31.2.02 8 色未见对失败模式分解（N31.2 线计划内最后一张卡）

> [预注册] — 2026-11-24（D-20261124-476）。探索卡，零 check/final，只用探索 seed。

## 1. 动机

N31.2.01（无泄漏增广）与 P0-BI（不增广）在两个 seed 上的未见对准确率**逐样本数相同**：

| seed | P0-BI base | N31.2.01 aug | 已见对 | 4 色 warm-up |
|---|---|---|---|---|
| 20261121 | 0.607421875（311/512） | 0.607421875（311/512） | 0.994 / 1.000 | 0.991 / 0.990 |
| 20261122 | 0.732421875（375/512） | 0.732421875（375/512） | 1.000 / 0.997 | 1.000 / 1.000 |

训练轨迹不同（已见对、warm-up 读数都不同），未见对却完全一样。这提示未见对上的输出可能是一个**与训练细节无关的固定规则**，比如「未见对一律翻转」。如果是这样，问题出在表示的组合方式，而不是噪声或训练量，后续方法应当针对这一点。

## 2. 设计

- 脚本 [n31_2_02_unseen_breakdown.py](../../scripts/training/n31_2_02_unseen_breakdown.py)：管线与 N31.2.01 相同，另为每个评估样本记录 flag、模板侧（前者 / 后者）、normal 色、other 色。
- 分解指标（未见对与已见对各一份）：按 flag=0 / flag>0、按模板侧的准确率；预测等于 normal / other / c1 / c2 / 都不是的比例。
- 无模型规则基线（同一评估集）：始终答 normal、始终答 other、始终答 c1、始终答 c2 的准确率。
- 只跑 **seed 20261121 × aug 臂**（最弱 seed，约 420 CPU）。

## 3. 读法（读前写定）

| 结果 | 结论 |
|---|---|
| 某条规则基线与未见对准确率相差 ≤1/512，且对应的 `pred_is_*` ≥0.95 | 未见对输出是固定规则（如「始终翻转」）→ 失败在 flag 与颜色身份的组合，记为 N32 task 轴的已知缺口 |
| flag=0 与 flag>0 的准确率差 ≥0.30 | 失败集中在 flag 一侧 → 同上，指向 flag 条件化 |
| 以上都不成立 | 无结构性解释，按 seed 方差处理 |
