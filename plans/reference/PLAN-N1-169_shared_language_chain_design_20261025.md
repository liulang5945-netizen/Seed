# N1-169：可学条件语言主链候选的设计交接（待路线讨论）

日期：2026-10-25。状态：**设计建议，不是新训练/正式评价执行合同**。前置为[N1-167](PLAN-N1-167_execution_closeout_20261025.md)与[N1-168](PLAN-N1-168_execution_closeout_20261025.md)的完整实证；不再追加同质微探针来代替路线选择。

## 为什么到这个决策点

已看到输入依赖和部分更新责任，尚未看到基本完整字符/句子拟合。8轮小集TF字节从24.85%到32.10%，自由生成几乎不改善；这要求比较训练量与目标/表示/信用效率，而不能只用loss、参数变化或更多运行时控制判断智能成长。

| 选择 | 价值与代价 | 推荐 |
|---|---|---|
| 原局部规则继续增加assistant剂量 | 改动少，尚有字节学习趋势；当前没有完整语言习得证据，继续加量可能重复放大统计拟合 | 保留作固定预算对照，不单独作为唯一主线 |
| 只切换decoder/plan来源 | 改动小；N1-167已无明确救援，不能绕过可学性问题 | 当前不优先 |
| **共享任务状态＋明确序列信用的新语言主链候选** | 直接针对条件表示和学习收益转化，支持后续世界/记忆共用；需要真实重接前向、学习与checkpoint，工程与公平对照复杂度较高 | **唯一推荐，原链作为对照一起验收** |

这不是宣布整个Taiji需要推翻，也不是保证新候选必胜；优先上限高、信息路径与学习责任可验证的路线，parent资产和已有能力/失败均保留。

## 实现边界与文件责任

承接VISION的VX0/VX1/VX3及J1/J2，工程编号不替代L2/L3/L4能力等级。

| 文件/接口（拟） | 要落实的实际变化 | 工程验收 |
|---|---|---|
| `taiji/task_state.py::TaskStateV1` | 明确临时生成态/持续任务态、证据引用、版本及reset域；连接已有CognitiveState，不重复另一套真值 | scope/reset/序列化/拒绝不兼容与下一步恢复一致 |
| `taiji/task_core.py::TaskCoreV1` | 对真实输入产生可学习共同状态；首候选按VISION的门控递推/工作空间方向，序列误差能到达声明的编码/状态参数 | 同输入状态干预、无关对照、更新接收者和截断边界逐一可见 |
| `taiji/conditional_language.py`及候选adapter | 字节/片段消费者直接读取共同状态和证据，输出未经模板改写的原生byte分布；训练与推理共用step/概率入口 | 同前缀TF和真实生成装配一致，不让renderer补答案 |
| 现有`language_alignment.py/model.py/contracts.py`候选接入 | 用显式条件序列目标核对损失→参数组→真实输出的关系；原局部链保持可运行对照，不以`grad=None`预判它无效 | 端到端或明确局部信用均须实际更新/行为收益证据，不能只有字段或loss |
| native checkpoint/加载器/容量台账 | 新组件、工作状态、RNG、优化器/快参数及游标完整保存；旧parent不可覆盖，新schema不得伪装旧格式 | zero及一次更新后的新进程恢复先过，参数总量/活动量/实际调用分别报告 |

候选初始宽度/槽数承接VISION建议值，但实际容量、计算与对照在VX0-R一次train-only标定后冻结。不能凭“增加一个头”宣称同资源，也不能以最终容量/总参数不匹配比较出主链优势；必要时替换旧语言计算块，而不是无限叠加。

## 一个有界开发包的结束条件

1. 工程E：一份输入/状态/输出和更新责任合同；共用训练/推理入口；全状态恢复；无隐藏外部LLM/答案renderer；合成集成与真实装配一致。到此只算可测，不算语言能力。
2. 可学性B：先在明确的已知train小集上验收完整字符、完整输出与自由生成，保留同资源原局部链；再按另行预注册的合法独立任务评价。不得重读旧W5b或N1-166来选结构/超参。
3. 对新收益、旧能力保持、参数/计算成本和恢复分别裁决；不把新器官单独的最好分拼成整模型成绩。负结果/不可判/工程失败都有限结束，避免为等待正收益无限续训。

本文件交接了下一模型路线与工程触点；正式学习算法、容量公平控制及单包资源在路线讨论后一次落实为同一N/VX实施合同，不拆成多个互相覆盖的“唯一下一步”。下一阶段默认模型不替换、原checkpoint不动；现有身体/记忆/工具等资产继续复用，不把完整自主性或UI作为语言主链前置。
