## 2. 参数级预读（circuit-final.pt 实测，2026-10-07；实现常数非面读数，作假设空间裁剪）

- `gate_bias`＝**+2.5（饱和）**，`gate_state`/`gate_content` 范数 23.9/22.5、格值饱和 ±2.5 ⇒ **门大开**，H-B"证据从未参与"否证；尺度成分（证据压倒基底）并入 H-A 分账。
- `copy_induce_bias`＝**+2.5（饱和）** ⇒ 序贯诱导信号**在场且强**，H-C"诱导缺席"参数级否证——剩下的问题变成"强诱导为何仍然赢不了"，指向 #4 的聚合与 #3 的重数。

## 3. 假设与判别读数（仪器＝探针 v43 `--trajectory-following`，只读包裹器，行为必须与基线逐位同）

**逐预测步读数**（对齐：环内第 i 次 evidence 调用的分布决定第 i+1 个发射字节；succ_byte＝权重最大的 `codes[p]==prev` 位置 p 的后继 `codes[p+1]`；chance＝该后继字节在事件内的重数占比）：

- **F1 轨迹跟随率**：`emitted == succ_byte` 的步占比。
- **F2 质量命中率**：`emitted == argmax(evidence)` 的步占比。
- **F1c 随机基线**：chance 的步均值（跟随率若≈随机 ⇒ 顺序信号未驱动发射）。
- **F3 末字节发射率**：`emitted == content[-1]` 的步占比（"走不到末字节"的量化）。
- **F4 gate 分布**（中位/p90，分账用）＋ **F5 后继位置权重** `succ_w` 中位（序贯信号在权重里是否在场）。

**分组**：被困 never-LF 拖写行（主群）／全体拖写代／stoppers（对照）。

**冻结判别规则（H-A 池化质量淹没序贯＝P1 主因形态）**：
- **H-A 成立** ⇔ `F2 − F1 ≥ 0.20` **且** `F1 ≤ F1c + 0.10`（发射跟着最高质量字节走、跟随率不高于随机＋10pp）⇒ 修法约束写进 PLAN-N1-01：S1 读取形态必须**位置级/序贯**（不做字节质量池化；§15.3 方案 A"逐位置证据＋回答可重新读取"直接采纳），不重开字节聚合参数的局部调参。
- **H-A 非主因** ⇔ `F2 − F1 ≤ 0.10` **或** `F1 ≥ F1c + 0.20` ⇒ 转解码/训练层归因（§4 分流第二行"流畅但内容错误查依据"同型），S1 设计另议。
- **中间带** ⇒ H-A"贡献但不唯一"：双读数如实登记，第二判别实验另立预注册（不在本件加码）。
- **H-D 终点不可达**：F3 直接登记（不分判级），供 S1 的末字节可达性设计。阈值带（0.10/0.20）＝"顺序信息损失"占预测步 10/20 个百分点的保守判别，先于数冻结。
