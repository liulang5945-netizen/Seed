# N1-172：fit-first 曝光探针（同题同折，只改更新预算）

日期：2026-10-25，Asia/Shanghai。状态：**实施前冻结**。承接[N1-171 结案](PLAN-N1-171_execution_closeout_20261025.md)§7。N1-171 的唯一直接结论是「64 次整批更新训练侧未拟合」，本包只改更新预算与停止规则，不改选题、不改折分配、不改判据形状，先让训练侧拟合，再读留出绑定。

## 1. VISION 条款对账

- VISION §89：**「loss 下降不等于自由生成或未见绑定有效」**。本包把「训练侧拟合」降为**前置可判性条件**，把留出题的自由生成 + 错配对照作为唯一绑定判据。
- VISION §81：绑定必须由模型实际读取被选证据产生；本包用「留出 prompt 对自身 target 的熟悉度必须高于错配 target」检验同一读取路径，而不是看 loss 或 TF 均值。
- VISION §93：保持面独立；本包不把留出题当保持面，不改默认模型，不写 L2。

## 2. 证据：只改这一处

N1-171 在同一 16 题上：训练 TF 中位数 .535–.578（门 .90），训练损失 5.55→1.59–1.69 且 48→64 步仍以约 0.85 nats/16 步下降；留出自由匹配命中 0/16。与 N1-170（4 题、64 步、损失 0.301）对照，最可能的直接瓶颈是**12 题整批平均梯度在 64 次参数更新内未收敛**，而不是证据架构或位置寻址失效。因此本包不改结构、不改数据、不改 seed/学习率，只延长更新预算并在拟合时提前停止。

## 3. 设计（单一变量）

- 沿用 N1-171 的 16 题、16 family 与 4 折分配（selection digest 必须等于 `5db33945cd22ce71…`），不重新选题。
- 只跑**折 0 与折 1**：每折 12 训 / 4 留出，合计 8 个留出题；两个折的模型分别新建、互不共享参数。
- 每折仍是 12 题整批、target 前 128 byte、AdamW lr 0.001、wd 0、clip 1；更新上限从 64 提到 **176**。
- **早停**：在更新数 32、48、…、176（每 16 次）只用**12 个训练题**测 TF top-1；中位数首次 ≥0.90 即停止该折。留出题不参与任何停止或超参决定。
- 停止后再测：该折 16 题的 TF 与自由 128 byte、留出题的对照 A（同折下一道留出 target）与对照 B（训练 target `(3i+1)%12`）、错配 target 的 TF。0 步读数只测一次（两折零模型逐位相同），避免重复计费。

## 4. 预注册判据

- **前置 P**：两折都在上限内达到训练 TF 中位数 ≥0.90。任一折未达 → `INCONCLUSIVE_UNDERFIT`（仍发布全部读数，不称绑定失败）。
- **主判据 G**：8 个留出题中，自由 128 byte 前缀匹配 ≥0.20 的题数 **≥4**，且这些题自身匹配同时比对照 A、对照 B 各高 **≥0.15**。满足 → `PASS_BINDING`（已见分布内的题-答绑定）。
- **次判读 S**：逐折 ≥0.20 题数、留出 own vs 错配 TF、A/B 均值、不同自由输出数、训练题自由匹配分布（只报告）。
- 两折均拟合但 G 不满足 → `FAIL_NO_GENERALIZATION`（记忆/复现而非绑定）。

## 5. 费用与停止线
