## 0. 先把这条债读清楚：这不是"没写实现"，是**三轴里只有两轴能自由取值**

巩固暴露量由三个量决定：`唯一篇数 U`、`每篇平均符号数 L`、`每篇被访问次数 R`，而符号预算 `S ≈ U · L · R`。
§2 冻的对照要"参数量变、数据不扩（U 变）**且**暴露量同（S 同）"⇒ 由恒等式，**R 必然跟着变**（`R = S/(U·L)`）。
⇒ DEBT-G52 那两条"天然实现"（截语料⇒S 不等；抬 epochs⇒R 成第二自变量）不是两个可选坑，
而是**同一个约束的两种违约**。任何形状都必须明写"哪两轴对齐、第三轴怎么读"，否则就是把隐藏变量当对照。

**这是本件最有用的一句**：形状的选择问题真正的解法是**换掉要证的那件事**（下面 §4 的 C 形状），
但 C 不是 §2 冻的否证支 ⇒ 走 C 必须整件升版重冻。owner 裁的是"先定形状"，
所以本件把**可执行形状 B** 冻死、把 **C 作为需 owner 重冻的另一格**登记在 §4，不当场替 owner 选。

## 2. 形状（B＝可执行那一支，逐字冻死）

* 新旗标 **`--max-unique-documents K`**（默认关＝不限），语义＝**取流的前 K 篇构成一个"篇池"，之后循环重用这个池的字节流**，
  直到调用方按 `--max-symbols` 的预算停（`:677` 那条支）；`K <= 0` ⇒ 响亮拒绝（`parser.error`），
  未给 `K` 时行为与今天**逐位相同**（新键只能加，不许动旧列取值＝㊵-508 的 G-N3c-2 同源）。
* 面内必须自述**三轴**（进度行与 exit 件各一份，键名钉死）：
  `unique_documents`（池内唯一篇数）／`document_visits`（到达篇次）／`mean_revisits`（＝前两者之比，由取数侧算，不由人抄），
  外加既有 `corpus_fingerprint`、`budget_max_symbols`、`reached_budget`。
* **判对条件（这条是 B 的全部纪律）**：两臂必须 **`S` 同、`U` 不同**，且**必须**同时报出两臂的 `mean_revisits`；
  两臂 `mean_revisits` 若相等 ⇒ 说明 `U` 其实没变（仪器坏），**响亮失败而不是出版**。

## 3. 判据与读数边界（先冻）

* **J-N3a（沿用 PLAN-N3-02 §2 那条，一字不改）**：斜率 > 自取噪声带 ∧ 末段均值 > 基线较大者 +0.02；
  合取项 J-N3a-保＝holdout 退化 ≤ +0.02。
* **J-N3a-读法（本件新增的边界，不是新判据）**：由于 §0 的恒等式，乙臂相对甲臂**同时**多了 `R`。
  ⇒ 两臂对照**只允许**回答"×16.8 容量在**等符号暴露**下是否把斜率抬出噪声带"，
  **不许**回答"封顶在容量还是数据"——后者需要 §4 的 C 形状。
  这句话必须原样印在判读件的 `interpretation_limit` 字段里，缺字段 ⇒ 判读器 rc=2。
* **判级不合并**：两臂都报，不许只报赢的那条（§2 原纪律）。

## 4. 另一支形状（C＝更干净但代价是整件重冻）

等数据量、变参数量：`--scale 2` 与 `--scale 10` 吃同一段前 K 篇（`U`、`R`、`S` 三轴全对齐，唯一变的是参数量）。
⇒ 这才是"容量 vs 数据"的可分辨对照，但**它不是 §2 冻的那条否证支** ⇒ 走 C 要按本仓纪律
**升版重跑＋索引标作废，旧件不删**（㊵-419⑥ 同族）。本件只把这条登记成待裁格，不替 owner 选、也不当场改 §2。
