## 3 结论（带范围限制）

1. **指针头能学训练集、但不泛化**：train 0.96–1.0，fit 0.56–0.80；错误查询让它崩到 0.04–0.12，说明它不是"忽略查询"，而是**查询携带的信息不足**——问题通道只有实体 one-hot，没有"这个实体是什么颜色/在哪一列"的内容；实体→颜色的绑定只能从训练场景学，未见 fit 场景的组合不泛化。
2. **共享 W_q 最小二乘不构成另一条路**：病态解、范数 10^5–10^6、fit 0.56–0.72；它只是用每场景偏移把训练集记住。
3. **值侧仍然可读**：答案列位置头 3/3 达双门（V 复核）；所以不是"列 value 没信息"，而是**查询/列 key 的表示不足以在未见场景选出答案列**。
4. **范围限制**：本卡只测了这三种机制（线性/双线性指针、共享 W_q 最小二乘）与当前实体 one-hot 查询；不证明所有选择机制不可能。`neither_reaches_gate` 不得写成"选择原理不可行"。
