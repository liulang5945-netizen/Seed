## 2 另外两处结构性改动（已落地）

- **fixture v2**：所有分片固定 3 体（`first_a_support_22_5_v2.py`），去掉"训练 1–2 体 / 评测 3 体"的迁移混淆；v1 未动，历史读数仍可复现。

## 4 当前卡点：δ 里有「中」，发射端一个都不出

**发射混淆（fit 32）**：

| 真值→ | 左 | 中 | 右 | 未知 |
|---|---:|---:|---:|---:|
| 左边 | **8** | 0 | 0 | 0 |
| 中间 | 5 | **0** | 3 | 0 |
| 右边 | 0 | 0 | **8** | 0 |
| 未知 | 0 | 0 | 0 | **8** |

**δ 上的线性探针**：train **1.000**、fit **0.9375**，其中「中」7/8 正确。

- 直接查首字节：8 个「中」样本里 7 个 `byte_head` 已选中 E4，混合后仍是 E4 —— 说明单步上它会说「中」；
- 但完整解码后输出里 **一个「中」都没有**，且三轮各 2000 更新后 fit 恒为 **24/32**、输出逐字相同；
- `delta_readout` 权重范数 72.5，行范数：E4 **2.08**、E5 **2.09**、E6 **10.27**、EOS 1.72 —— δ 专用通路把大部分容量用去判「未知」，中与左/右几乎不分。

⇒ **δ 可分，但 257 路发射头不把这份可分性用在中上**；把权重从 1.0 调到 2.0 只是在"从不出中"和"几乎全是中"之间翻转，边界不随样本走。
