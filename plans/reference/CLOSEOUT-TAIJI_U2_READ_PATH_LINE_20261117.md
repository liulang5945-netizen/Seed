## 3 累计残留（收束随身携带）

1. **聚焦 2/3**（U.1r2 seed02 0.389147；seed03 0.514639）。
2. **值侧可读但读出不可读**：答案列位置头 3/3 达双门；attended/oracle/masked/concat 的 fit 0/3。
3. **选择上限**：基线 0.76／0.44／0.64；V.1 训练后 0.84／0.52／0.64；V.2 指针最好 0.80／0.56／0.72、共享 W_q 0.60／0.56／0.72；**0/3 达 0.95**。
4. **查询表示不足**：问题通道只有实体 one-hot；错误查询把指针打到 0.04–0.12，说明它用了查询，但查询里没有"该实体是什么颜色/在哪一列"的内容；内容查询**未测**。
5. **三变量不可归因**：U.1r2 同时动温度标量、W_q 2× lr、注意力监督，帽内无消融臂。
6. **外推口径被证伪**：3 步线性外推 `log_tau` 13.06／15.06／13.09 对实测 4.58／4.67／4.06。
7. **U.1r2 verify 仪器缺陷**：`temperature_starts_at_zero` 出生期不变量误用于训练后胶囊（实质复算 15/15 一致；冻结件未改）。
8. **V.1 预算停止**：5.0625 CPU > 4.7812 帽（+5.9%），seed03 83/384；同一配置不重跑。
9. **定价缺口**：V.1 实测 2.3906 vs 实际 5.0625（2.12×）；完整 run 的逐更新/评估/干预被低估。
10. **V.1 读出/控制失败**：fit/train/双控制 0/3；选择与读门都未达。

## 4 可复用教训

1. **尺度不是默认杠杆**：U.1r2 把尺度加到设计目标，fit 三 seed 零增益；先做冻结权重的温度扫描，再决定是否训练。
2. **值侧与选择要分开验收**：答案列 3/3 可读、attended 0/3，说明"值在列里、读出/选择丢了"；只测端到端读门会把两类缺口混在一起。
3. **选择机制先零训练定上限**：V.2 用 9.05 CPU 就证明当前查询下指针/共享 W_q 都到不了 0.95，避免了又一次训练；这个顺序应成为标准件。
4. **实体 one-hot ≠ 内容查询**：查询需要携带"该实体是什么颜色/在哪一列"的证据，或由场景读出后再匹配；否则未见场景的组合不泛化。
5. **定价要测完整 run 回路**：V.1 只测 64 更新＋单面评估，低估完整评估/干预路径 2.12×；以后定价必须覆盖实际 run 的评估与干预次数。
6. **同出生配对与仪器正对照**：U.1r2 与 r1 出生权重逐位相同；几何正对照 1.0／1.0；这两件让负结果可归因、不可造假。
