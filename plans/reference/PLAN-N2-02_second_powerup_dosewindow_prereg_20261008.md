## 0. 为什么必须另立一件（而不是回到 PLAN-N2-01 补两句）

第一次通电留下两处**只有改判据形状才能修**的东西，而"判据文本一经冻结不追改"是本仓纪律：

1. **读数窗口与剂量不同窗**：通电那支 pass 的经验预算是 `max_symbols=64`（`run()` 现行默认），
   而 J-N2b 用 `SeedJudge.score()` 打的是**整篇**——一条几千字节的交互里模型这轮只活过前 64 字节 ⇒
   分子里绝大部分字节是**这轮没碰过的**，读数天然被稀释（㊵-487⑥ 已点名，事后诊断臂只是旁证）。
2. **保持侧的"跌破"没有单值定义**：第一次实测**恰好跌破 1 项**（复述面 2.0 档成句 25→23），
   而 §2 只写了"无一项跌破"与"跌破 ≥2 面判有代价"，中间那格无定义 ⇒ 我当时按最严读法判不成立（DEBT-G46 第二类实例）。
   本件把它写成**单一数值条件**，并**为拖写行数这列指定方向**（不再沉默，DEBT-G46 第三类实例在这里结清）。

## 1. 假设与面

**H-N2'（加速点① 的可持久化形态）**：在同一次真实离线巩固之后，
①**产物能被产品自己的装载器读回来**（这一条第一次是失败的，原因是 DEBT-G47），
②**新收益在同一剂量窗内可检出**，且③**旧能力按单值定义不跌破**。三条合取才判"经验→能力这条通道今天能走通"。

|---|---|---|

## 2. 判据（先冻；每条都是单值可判，不留中间地带）

- **G/J-持久化（本件的入场券，先于能力判据）**＝`save → load` 必须成功、且 load 后 `content_digest` **等于**通电后的内存摘要。
  不过 ⇒ 整件不判能力（因为"巩固后能力"根本读不出来），直接判"通道仍断在持久化边界"，并回记 DEBT-G47 为未修好。
- **J-N2a'（旧能力保持，单值式）**＝对 CAP-0 与两张 ×24 面的**每一档每一列**（CAP-0 逐维 `machine_scored_correct`、复述逐惩罚档 `strict_hits` 与 `well_formed_texts`、停摆 ×24 主列），
  要求 `巩固后 − 巩固前 ≥ 0`；**任一列跌幅 ≥1 ⇒ 判"通电有代价"**（这就是第一次含糊的"跌破 1 项"在这里的唯一读法）。
  停摆面**主列方向预先指定**＝`never_lf_eaters_counted` **越小越好**，故 `巩固后 − 巩固前 ≤ 0` 记为不跌破——这条是判据的一部分，不是事后解释。
- **J-N2b'（新收益，剂量同窗）**＝`Δquality = 治疗窗内均值 − 对照窗内均值`（窗口＝每条夜文本的前 `max_symbols` 字节，与经验预算同式子）：
  **`Δquality > 0` 且 `Δaccuracy ≥ 0`** ⇒ 成立；`Δquality ≤ 0` ⇒ 不成立；
  `Δquality > 0` 但 `Δaccuracy < 0` ⇒ 记 `not_resolved`（不许挑对自己有利的那一把尺）。
- **整篇那一列照旧取，但只作旁证**，不参与判级——写清楚是为了下次不再需要用"事后臂"解释结论。
- **合取**：J-持久化 ∧ J-N2a' ∧ J-N2b' ⇒ 判"加速点① 在这一剂量档上成立且可持久化"；任一不过 ⇒ 负结果入库、按 09 §4 第四行归因，不换次要指标。

## 3. 守卫（五条；前三条沿用第一次的锚点，后两条是本件新增）

- **G-N2-1 回退路径再真演示一次**＝还原母状态后 `content_digest` 与母逐位同，且**回退档落盘→独立 load** 与母摘要同；
- **G-N2-2 默认位不动**＝仍跑一支默认参数 pass（`organs=False`），要求 `organs.ran=false` 且权重摘要不变；
- **G-N2-4 惊讶度调制披露**＝报"调制前/后被选夜文本"的集合差与分数分布（第一次实测：去掉 `mean_surprise` 权重后 8 条里 3 条换人）；
- **G-N2-5（新）产物可载＝正向**：通电后 `save → load` 成功、摘要等于内存态；
  **反向**：对**没睡过觉**的母档做同样的 save→load，要求摘要逐位不变——这条防的是"修法是靠覆写有效状态换取可装载"；
- **G-N2-6（新）不产对齐件**：本件**禁止**再用 `--phase align` 那条路径代答装载性（第一次靠它读出了能力，代价是把结论限定在"对齐之后的候选权重"）；
  如果产物仍不可载，就要这个红，不要绕。

## 4. 预算与执行顺序（批文即此）

顺序＝①母状态（内存 mapping＋磁盘母档）→ ②G-N2-2 守卫臂 → ③**巩固前** CAP-0＋两张 ×24 面 → ④通电一次（`reason="n2-powerup-2"`，四参数一律沿用 `run()` 现行默认，与第一次同剂量）→ ⑤G-N2-5 双向装载测 → ⑥新收益两臂（治疗/对照，同窗）→ ⑦巩固后同面复算 → ⑧G-N2-1 回退演示＋回退面复算。

| 项 | 冻结值 / 实测依据 |
|---|---|
| 通电剂量 | `cycles_per_text=1`、`max_symbols=64`、`max_texts=8`、`max_records=200`（全部＝`run()` 现行默认，与第一次同） |
| CAP-0 | 每张面 100 项／147 轮、模型内 83.4–163.9 秒＋每项一次子进程 load（2.46 s）≈ **6–10 分钟/张**，共 3 张（前/后/回退） |
| ×24 两面前后 | 停摆面历史 ×96 档约 10 分钟，×24 档按其预算线性取下界 ≈ **2.5–3 分钟/张**，共 4 张 |
| 通电本体 | 第一次同剂量实测 643,934 ms ≈ **10.7 分钟**（大头是 200 条全池逐条 `judge.score`） |
| 磁盘 | 母/候选/回退三枚 ≈ **38 MB**（12.7 MB/枚）；语料与 spec 落 `data/`（gitignore 内） |
| 合计 | ≈ **45–60 分钟**本机 CPU，零外部配额，判据级不重跑；机械修复 1 次仅限仪器 |

## 5. 出口交付

一次可持久化的真实离线巩固（产物被产品自己读回来）＋剂量同窗的新收益读数（含 `Δquality`、`Δaccuracy` 两把尺的合取）＋旧能力的单值保持判定；
若 J-持久化 绿而 J-N2b' 不成立 ⇒ 结论是"通道能走通、但这一剂量档买不到新收益"——那是**容量/剂量**问题，转 09 §4 第五行（保留旧内核、把质量—成本曲线记下来），不再靠低阈凑触发。
