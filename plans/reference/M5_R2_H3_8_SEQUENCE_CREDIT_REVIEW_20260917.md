## 1. 本轮证据纠偏

H3.7 三 seed 无内容收益、final 前停止的结论保持不变。失败的是这份具体实现与实验条件，不是所有工作空间架构。不得修改旧报告、旧 checkpoint 或重跑同质训练来覆盖失败。

本轮 `tests/test_response_plan_geometry_audit.py` 两项合成测试通过，无训练、无 final 能力读取：

- 24 个“中”字的 target chunk 边界是 15/30/45 byte，运行 phase 边界是 16/32/48。UTF-8-safe chunk 与固定 byte schedule 不同；概率面随 phase 改变不证明内容与阶段对齐。
- 任意正 slot scalar 在逐槽 L2 归一化后抵消（浮点容差内）。更换 scale 会改变 payload digest，却不实质改变目标方向。因此 train-bound 是血缘约束，不是已学得的语义几何。

源码审阅另发现：phase>0 的前向是 0.75 当前槽＋0.25 槽0，planner 更新只落当前槽，未包含这两个混合系数及槽0信用。此为近似局部规则，不应称完整链式梯度；尚未用数值差分量化整个更新误差。训练逐 byte 重算 plan，推理不做参数更新，两条轨迹也不能默认等价。名为 slot-credit 的只读消融实际移除了推理贡献，不是关闭训练信用的因果对照。

已有 cosine 0.24943 与 phase JS 只说明表示相关及接口敏感；没有机会水平、空槽基线、时间对齐与完整梯度验证，不能推断 target 有效或排除训练实现问题。这些限制不改变停止决定，但收窄其架构解释。

## 2. 整体项目定位

M5/R2 继续是主线；checkpoint、来源隔离、原生 byte 输出、UTF-8 边界及宿主权限资产继续复用。M4 结构成长、M6 产品采用、M7 发布、M8 设备优化不因语言研究而消失，也不在本实验中晋级。Mini 验收继续延期。H3.8 不同时推进记忆适应、工具执行或新设备，以免失去可解释性。

## 3. 选择与唯一推荐

| 选择 | 可以回答什么 | 局限与代价 |
|---|---|---|
| 修补 H3.7 后再次训练 | 对齐修补是否改善当前局部规则 | 仍受哈希监督、固定 phase 和信用截断限制；会继续消耗小探针预算 |
| 联合序列目标训练可学习工作空间 | 回答误差能否同时形成内容表示与原生生成能力 | 需要明确跨时间计算图、训练/运行参数一致性及独立训练合同 |
| 立即替换整个认知核心 | 更广泛核心是否有效 | 同时改变过多变量，失去旧资产归因与迁移边界 |

唯一推荐第二项：隔离的联合序列信用原型。不要把第一项包装成更高上限架构，也不直接执行第三项。H3.7 修补仅在需要验证诊断时做，不成为新的无限补训支线。

## 4. 计算图与所有权

首个原型：可见 prefix bytes → Taiji-owned 可训练因果编码器 → 内容工作空间 W → 可训练循环 byte renderer → 下一 byte logits。renderer 每一步用自身状态对 W 做内容寻址，不按隐藏 reference 长度或固定中文 chunk 选择槽。工作空间先在回答起点生成，在单个回答内不修改参数；renderer 隐状态逐步推进。全部参数归 Taiji，禁止外部模型代答、答案表和 task/family/split 输入。

训练样本只含当时可见 prefix 和右移的 response 输入；预测 y[t] 只能读取 prefix 与 y[:t]。完整回答仅作为损失标签，不能先编码成运行时 W。目标为真实下一 byte 交叉熵，包含结束标记；不再把随机哈希向量拟合当作内容能力目标。首版不加多重辅助损失，避免靠调权救结果。

发展训练沿 renderer→工作空间→prefix 编码器回传。必须画出每个 detach、mask、状态重置和截断点；若 prefix 被冻结或截断，报告明确称局部原型，不称整模型训练。初版短序列全展开；超长截断另合同。推理用同一参数与前向公式，不含 optimizer、不更新长期参数。运行期持续适应仍是 VISION 后续设计，不在此轮冒充已完成。

## 5. 实现门（能力训练之前）

1. 明确隔离路径、参数清单与 native AST 合同适用范围；不静默解除 taiji/ 禁令，不把另一认知栈藏在脚本中。
2. 用合成输入做 prefix/renderer 梯度数值差分；检查所有声明参与训练的参数确实收到有限非零梯度，禁用连接时相应梯度消失。
3. 验证因果 mask：修改未来标签不能改变当前 logits；teacher-forced 与逐步前向在同一历史下逐步一致；中文、空上下文、结束标记、最大长度各有测试。
4. 零步原子保存→新进程加载→同输入 logits 一致→继续一步与不中断运行一致。保存参数、optimizer、RNG、数据顺序、课程游标、配置及代码内容摘要；缺失或不兼容拒绝，不静默随机初始化。
5. 缺权重拒绝、打乱 prefix、屏蔽 workspace 的合成检查；它们只能证明接线，不能证明能力。默认入口与旧 checkpoint 不受影响。

## 6. 数据、比较与停止门

旧 12/8/4 fixture 只用于工程回归，经过多轮开发的 dev 不再作为泛化证据。新数据先冻结来源许可、去重、模板/实体/组合分离和独立 final；生成规则不得暴露给模型。必须含上下文事实替换、否定、未知信息、组合约束和同开头不同内容，防止只学回答形式。

两臂使用相同的新数据、种子、更新数和 byte 预算：可训练循环编码器/renderer 基线，与加入可学习工作空间的版本。旧 H3.7 只作历史参照，不能跨语料或预算宣称纯架构胜利。匹配有效参数与推理成本；匹配不了就分账，不用“同300k”掩盖真实训练差异。

训练合同冻结前写明三个 seed、精确参数/步数/墙钟/存储上限、checkpoint 周期、恢复与异常停止策略；数值不能从本提案推测。先过实现门，再小规模 train-only 可学习性检查，再正式 matched dev。train 可拟合而 dev 不迁移时优先审数据与表示，不继续加 epoch；train 都不可学时回计算图，不扩大数据。

晋级必须是逐 seed 的内容正确性提升且边界/保持不退化；不能只看 surprise、敏感性或非重复。推理 workspace lesion 与关闭 workspace 训练信用的重训对照分别命名、分别记账；先存在真实收益，再判断撤销收益。确切指标、阈值和统计规则在看新 dev 前冻结。未过门不读 final、不进入 L2/Mini；final 仅用于冻结版本的一次独立验证。

## 7. 决策点与后续执行

需要确认的不是再次授权训练，而是是否采用上述“联合序列信用＋可训练 prefix 编码器”的隔离原型作为下一研究包。这比修补现有 readout 更大，改变发展训练计算图；不能从继续推进推断为默认核心迁移授权。

确认后唯一下一步：冻结 H3.8 隔离实现合同与前向/梯度/恢复测试，然后实现原型；已有训练授权沿用，但只有实现门、数据及数值预算冻结完成后才启动相应训练。默认架构采用仍另行评审。
