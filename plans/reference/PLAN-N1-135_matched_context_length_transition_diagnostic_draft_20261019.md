# PLAN-N1-135：同题匹配的转向上下文长度诊断

**状态：待批准的方案草案。** 本方案提出一张新的零训练测面；未获批准前，不生成题面、不查询模型或更新参数。N1-133未通过与N1-134描述性结果均保持原状。

## 依据与问题

N1-132训练transition输入只有2条观测，目标事实固定在索引0/1；N1-134在同一批当前endpoint上测了16行上下文，候选position为45/120，seed13正确项只落在west答案格。候选相对同seed position父档仅+2/120，N1-134报告又没有逐题生成文本，无法判断错误时模型实际输出了什么。

历史N1-89的v5面是2行上下文，三个position seed在transition上均8/8，但那些checkpoint、训练配方和题面不同，不能隔离长度效应。下一步应在**同一模型、同一模板、同一目标事实**上成对改变干扰行数。

## 拟议设计

- 新seed117，四个正确方向（north、east、south、west）各构造两个不同转向模板；每个方向的两个模板分别使用left与right turn。实体邻近距离`d=1`；不同基准模板间不重用实体，2/8/16行配对版本按设计共享目标实体和两条目标事实，干扰实体与材料不跨模板重复。
- 每个模板构造2、8、16行三个版本，共24项。三个版本共享实体、问题、两条目标事实和正确方向，目标事实都位于索引0/1；8行版在目标事实后追加6条干扰事实，16行版保留相同6条并再追加8条。这样同一模板形成嵌套的长度对照。
- 所有模板与干扰名称/材料均排除v3训练及已消费v5-v16面；面外值全部新鲜，seed117须经账本验证未使用。内部配对共享目标事实是设计要求，不作跨face泄漏。
- 在12个冻结endpoint（N1-132 position三seed；N1-120 position、terminal、cut三组控制）上各查询24题，共288条。CPU≤600秒，训练、参数/优化器更新和dev查询为0。
- 查询前重核12个完整checkpoint bundle；计分前后核对参数、Adam、RNG与history。结果文件保存每endpoint×模板×长度的exact、原始生成字节/生成方向、停止原因和配对ID，支持无需重查的离线归因。

## 判读与停止规则

主要比较同模板在2→8→16行时自由生成结果的变化，并按seed和方向分层。它用于判断干扰上下文增长是否降低转向输出；不设能力通过线、不作显著性主张、不改写N1-133/N1-134结论，也不支持模型晋升。

来源、题面合同或checkpoint恢复任一失败即记录失败并停止；题面与查询均只执行一次，不重抽、不重试、不训练。无论结果如何`can_promote=false`。此方案含新测面和最多288条查询，须先获owner批准。
