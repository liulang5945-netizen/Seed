# R2 T4 预注册：把四笔 fabric 写入**一起**放慢，跑过退化起点（判据先冻结）

前件：`M5_R2_T3_FABRIC_WRITE_PREREG_20260923.md` §9（读码结论）与 §8（延长轮）。
所有者 2026-09-24 批"跑 `t4-slow-all`"。

## §1 问题

**`t1` 的结构在 4.25M 台阶开始系统性跌破初始化范围（首两个连续低于 0.5790 的测点是 4.25M/4.50M；
其后 16 点里 13 个低于下界）。这个退化对"整体写入强度"敏感吗？**

T3 的"三臂全不中"**不能**回答它：那三条各 1M，而 **1M 里根本没有退化**（退化从 4.25M 才开始）
—— 那是否定"强度调不动 1M 内的游走"，不是否定"强度调不动退化"。

而且读码（`fabric.py:392-470`、`model.py:1993`）确认：**四笔权重写入被 `learn_scale` 一起缩放**，
醒来路径没传 `learn_scale` ⇒ 从 `observe` 无法单独缩放任何一笔；
配置层能做的等价物就是**四项一起设**。所以本件是"整体强度"的判别，不是"某一笔"的判别。

## §2 臂（纯 config，不动 `taiji/`）

`--set predictive_learning_rate=0.005 --set transition_learning_rate=0.0024 --set lateral_learning_rate=0.004 --set synapse_decay=2e-6`

（四项各 ÷5，配置等价于 `learn_scale≈0.2`。）预算 **5,000,000**，每 250k 一测，
与**既有 `t1` 曲线同 tick 对比**（同 seed、同语料、同 id 约定 ⇒ 训练逐位确定，配对成立）。
参照系与冻结基线**都不用重跑**（`t1`@各 tick 与 `abl-none`@各 tick 已有）。

## §3 判读线（**开跑前冻结**）

**必要（在学）**：1M 处在线准确率 **≥ 0.30**（`t1`@1M = 0.3441）。

**主（筛选集）**：**4.25M / 4.50M / 4.75M / 5.00M 四点的 screen `context` 全部 ≥ 0.5790**
（初始化 8-seed 下界；`t1` 同四点 = 0.5706 / 0.5367 / 0.5093 / 0.5261，**全部低于**）。

**确认集**：同样四点的 confirmation `context` **全部 ≥ 0.6312** ——
用的是确认集**自己的 8-seed 中位数**，不是下界（下界 0.4194 没有判别力，见 §4）。

**两条族集判据 + 必要项都要过** ⇒ 记 **"退化是强度敏感的"**，下一步把四笔**逐一**分离（各 ÷5、各到 5M）
找具体是哪一笔 —— 那需要另立预注册（4 × 5M ≈ 22 h）。
**任一不过** ⇒ 记 **"整体写入强度无法把退化推迟到 5M"**，**不挑部分满足的臂**；
下一步才轮到改 `fabric.py` 的写入规则，并**在方案里承认靶点不明确**。

## §4 ⚠️ 先自报一条对 §11 的削弱（本件动机的一部分）

这也正是为什么本件的确认集判据用**中位数**而不是下界（下界在这个集上没有判别力）。
