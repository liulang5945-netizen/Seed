- **16 单位（4 群×4）→ 20（每群 +1，+25%）→ 24（每群 +1，+20%）**，共 2 代，每群每代 +1 ≤3，比例 25%/20% ≤25%，落在 22.7.0 全部上限内；

## 3. FLOPs 估计器（可手算复核）

单 tick 每样本 forward：
`6×(8×8) 输入编码 + 6×(8×8) 投影 + N×8 驱动 + N×N 入边 + 8×N p 投影 + q×8 query + q×24 读出`（q=4）；
训练 = 3× forward（前向 1＋反向 2）。N=16/20/24 分别对应每样本每步训练 FLOPs `[19,380 / 22,260 / 25,140]`（以报告 JSON 为准）。G0 前 750 步@16，其余步数按预算在 20 单位上补足；G4 全在 16 单位、G5/G6 全在 24 单位，均按总 FLOPs 反解步数，因此各臂比值 ≈1。

## 4. 判读与边界

- **机制门与工程门全过**：出生中性（读出与旧状态逐位不变）、新生儿在 5 步内可学（p 首步有梯度、r 第 2 步起有梯度、权重变化/活动非零）、capsule 恢复摘要一致、生长上限合规、七臂等 FLOPs 可行；
- 本卡**不签生长收益**：H1 尚未测（S2 七臂行为窗）；S1 只证明「可以开窗」；
- 噪声警告：`live_entry_birth` 内部有 `float(tensor.norm())` 告警（会打印建议 detach），属既有实现提示，不影响读数；未改核心 `u2_neural_units.py`；
- 零 check/final；预算：S1 实耗 1.27 CPU ≪ 300。
