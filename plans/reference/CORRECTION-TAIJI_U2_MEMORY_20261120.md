# 更正备忘：记忆探针 fit/train 种子泄漏（D-20261119-199；更正 194/195/196/198/199）

> 文档状态：[更正] — 2026-11-20（D-20261119-199）。**零训练、零 check**；本备忘更正已发布的记忆探针读数与判词。

## 1. 缺陷

`run_s2_working_memory / wm_gap / wm_update / wm_load / wm_heavy` 五个合成探针用：

- train：`build(TRAIN, seed)` → episode 种子 `seed + i`；
- fit：`build(FIT, seed + 1)` → episode 种子 `seed + 1 + j`。

**fit 的种子区间与 train 完全重叠**（fit 的第 j 条 = train 的第 j+1 条），即 **fit 几乎是 train 的副本**——所有 fit 读数被记忆泄漏抬高，尤其让「无状态臂」和「携带臂」看起来远好于真实水平。

**修复**：fit 改用 `seed + FIT_OFFSET`（`FIT_OFFSET = 10_000_000`），与 train 种子区间不相交；其余协议不变，全部重跑。

## 4. 教训与规则

- 合成探针必须**显式分区种子**（fit 与 train 种子不相交），并在结果卡中记录 train/fit 种子区间；
- fit 读数不得高于 replay 上界；出现时应先查泄漏，再解释机制；
- 已发布但被更正的卡：194/195/196/198 加更正横幅；MAINLINE §4.1 与包 22 总账相关条目追加更正说明；九轴「记忆使用」按更正后结论重述。
