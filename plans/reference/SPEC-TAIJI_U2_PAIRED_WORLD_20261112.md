# 可识别配对小世界合同

> 22.5.P3.5.1，2026-11-12。fixture_and_protocol_accepted。此合同冻结数据与正常接续协议，学习剂量由后继卡冻结。

## 1. 任务与分区

train/dev各18个物理世界，覆盖六种可见颜色实体×左/中/右三个位置，每世界一个静止实体。每个可见实体与另外五个缺席实体全部配对，每对以两种相反问题顺序构成episode。因此每分区180个episode、360个应答轮，每episode两问共享同一持续goal与一次公开观测。

每个实体问题具有左/中/右各10次、未知30次监督；每个轮次上分别为5/5/5/15。全部24个实体×答案组合均有支持。全局未知先验0.50，位置答案各1/6。监督字节目标为左边/中间/右边/未知，推理沿257字节、UTF-8/EOS及64字节上限自由生成，候选词集不进入推理选择器。

每个分区有3个几何/噪声母体，每母体产生六种颜色的反事实世界，几何、材料、传感器随机流及所有非RGB公开输入逐位相同。world与family seed均在train/dev间分离。此开发集测同一对象数与同一因子支持下的新世界，未来多实体与组合未见轴分别设置。母体数量小，本任务承担训练内可学性定位。

世界由既有PhysicalWorld生成及执行一次真实elapse。颜色、位置及规范id在genesis中登记为实验因子。RGB由原物理渲染器产生，公开oracle从模型实际可见patch还原图像后定位实体。引擎私有状态及oracle留在数据审计侧。

## 2. 72轮草案的历史旁路修正

原草案用j=(i+p+1) mod6指定缺席实体，问题×轮次先验虽为0.50，完整问题历史结合非RGB位置可在第二问识别部分实体角色。枚举该草案得48/72，即2/3正确，无需RGB。

当前遍历全部五个缺席实体，同时共享非RGB母体。对于相同非RGB观测与相同问题前缀，存在标签互换的可见颜色世界，遵守输入边界的固定参数策略，其自身历史输出不能添加这些公开输入没有的信息。无真实标签反馈时，其最优平均准确率为0.50。两种问题顺序同时覆盖，消除轮次捷径。

冻结后的经验同输入类上界均为180/360。

| 可用输入 | 上界 |
|---|---:|
| 当前问题 | 0.50 |
| 当前问题与轮次 | 0.50 |
| 截至当前的完整问题历史 | 0.50 |
| 除RGB之外全部公开观测及完整问题历史 | 0.50 |
| 完整公开观测与轮次，屏蔽全部问题 | 0.50 |

该上界针对分区中规定的等权episode、固定参数评测与公开协议。逐轮gold反馈不在评测权利内。训练teacher prefix用于训练监督，不能用来代签此自由接续上界。

## 3. 正常输入及状态接续

public只包含goal、observations、coordinates、outcome、action、t_start/t_end。question以原始UTF-8字节单独提供。world/episode id用于协议追踪，seed、可见实体、缺席实体、目标、索引及oracle不进入模型语义输入。

第一问在公开观测后发起。第一回答的实际生成字节进入模型状态，EOS结束后在同一state上设置第二request并开始下一utterance；goal、world_time、主体身份及唯一感知包保留关联。第二问没有新外部观测和真值反馈。训练两问NLL沿同一图求均值，第一问teacher prefix仅在训练路径使用。

自由评测两轮完整计分。第一问正确与否都将其实际输出接入第二问。若第一问到64字节仍未结束，第一问计错，第二问记blocked_by_prior_round并计错，分母仍为2。无效UTF-8或空错答计错；异常接口按工程出口报告。评测不会用gold修复状态。

每episode从同一研究候选的明示初始边界建立状态，episode之间的参数在终点评测中固定。当前同主体连续性范围是单世界的两个请求，跨会话持续学习由后继资格承接。
