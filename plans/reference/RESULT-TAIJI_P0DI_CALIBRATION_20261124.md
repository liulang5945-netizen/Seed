## 1. 目的（对齐 objective 的「按真实收益、损伤和成本调整生长选择」）

此前 P0-DB/DC/DG 的回收决策使用**先验损伤常数 0.20**；P0-DF/DG/DH 已提供**真实回收损伤**读数。本卡从已提交回执校核该常数，得到可复用的决策规则。

## 2. 测量（成功的回收事件）

| 事件 | 被覆写能力 前→后 | 实测损伤 |
|---|---|---|
| DF 回收 D（R3） | 1.000 → 0.495 | 0.505 |
| DG 回收 E（R4） | 1.000 → 0.442 | 0.558 |
| DH 回收 E（R4，二轮） | 1.000 → 0.399 | 0.601 |
| DH 回收 F（R6，二轮） | 1.000 → 0.372 | 0.628 |

- **均值 0.573、标准差 0.047、范围 0.505–0.628**；先验 0.20 ⇒ **低估 0.373（约 2.9×）**。
- 后两次回收损伤更大（0.60/0.63），说明损伤可能随回收次数/队列角色上升（小样本，取保守先验 **0.60**）。

## 3. 修正后的效用（同一成本口径）

| 选项 | 净效用 |
|---|---|
| 生长（预算未满） | **+0.56**（0.75−0.10学习−0.09重校准） |
| 回收（预算已满，实测损伤 0.573） | **−0.013** |
| 仅退役 | −0.72 |

**决策规则**：
- 预算未满 → **生长**（+0.56）；
- 预算已满 → 回收效用约 0（−0.01），仅在“必须换能力且无其它容量”时执行，且应预期 ~0.57 的旧能力损失；否则 **等待**；
- 仅退役 → 负效用，仅用于释放容量（不学新能力）。

## 4. 判读

1. **先验损伤被实测否定**：真实回收损伤 0.505–0.628 远高于 0.20，旧效用对回收**系统性高估 +0.37**（此前 DG/DH 的「回收 +0.45」实为 ~−0.01）。
2. 修正后与观察一致：**只要还能生长，生长优于回收**；回收是容量满时的次优路径（损伤 ~0.57、净效用≈0）。
3. 该常数应写入后续生长/回收决策（**EV_RECYCLE_DAMAGE=0.60** 保守值）。
4. 本卡为**分析校准**（用已提交回执，无新训练），用于把成本模型从先验常数升级为实测校准。
