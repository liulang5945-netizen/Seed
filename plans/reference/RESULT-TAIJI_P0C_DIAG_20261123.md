# 结果卡：P0-C 机制 B 输入适配器（`p0c_adapter_not_learned`；路由即够、适配器无需学习）

> [结果卡·探索诊断] — 2026-11-23（D-20261123-336）。[P0-B 压力任务](RESULT-TAIJI_P0B_DIAG_20261123.md)（新传感器 32:36 被 base 编码忽略，旧表示/新生状态探针均 0.25/0.24）；本卡在该任务上实现**机制 B**：给新生单元一个可训练适配器，把原始传感器 one-hot 投影到 base 能传输的通道组（0:8），与新生单元/新生-only 读出联合训练 200 次交互。**1 seed、117.48 CPU、零 check；探索诊断，不出能力结论。**

## 3. 判读

1. **机制 B 的「路由」作用是决定性的**：把新传感器投影进 base 能传输的通道组后，新生单元＋读出 200 次交互到 **1.000**（无适配器仅 0.246）⇒ 解决 P0-B「信息通路」问题。
2. **但适配器不需要「学习」**：冻结随机投影同样 1.000 ⇒ 对 4 类 one-hot，随机线性投影已保持可分性，真正缺的是**路由/接线**而非适配器参数学习。G2 失败是信息性的（预注册假设「冻结应失败」被推翻），不是工程失败。
3. **新生单元因果成立**：休眠 24 个新生单元 → 0.297（drop 0.703），旧任务保持 0.0039。
4. **下一步**：① 用**不可线性解码的传感器编码**（如类标签经非线性码/组合码）检验「适配器必须学习」的版本；② 在该压力任务上做 **D（快慢时间尺度）**：快通路 8 次纠错 → 巩固回放训练新生单元 → 读出重置为线性后保持 ≥0.75、重置新生参数掉点 ≥0.15。
