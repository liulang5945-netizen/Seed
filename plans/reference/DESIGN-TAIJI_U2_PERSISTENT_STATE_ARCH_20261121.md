# 架构级持久状态预注册（待批；零训练、零 check；不运行）

> 文档状态：[预注册/待批] — 2026-11-21（D-20261121-223）。上游：[状态解码](RESULT-TAIJI_U2_STATE_DECODE_20261121.md)、[写入门/键值槽失败](RESULT-TAIJI_U2_BOUNDED_STORE_20261121.md)、[A1 裁定](MEMO-TAIJI_OWNER_DECISIONS_20261120.md)。**未批准、未冻结、未运行、零训练、零 check。**

## 1. 问题（已证）

- 单位状态 `z/a` 是**共享向量**（非按样本），batched 调用把 batch 当时间步；
- 逐样本（batch=1）序列下 `z` 在 t1 即回落机会、`a` 仅 t1–t3 弱残留、`H` 不演化（D-217）；
- 实验层写入门（0.333）、有界键值槽（0.372）**均未超过无存储 mean（0.469）**（D-218/219）。

⇒ 要让「模型自身机制承担记忆使用」，必须在**架构层**提供按样本持久状态或可学习有界存储。本卡是唯一可测路径的预注册。

## 2. 两个候选方案（择一或先后）

### 方案 A（推荐先做）：按样本持久状态
- **改动面（最小、加法式）**：给单位图增加可选 `per_sample_state` 模式——`z/a` 形状由 `[N]` 改为 `[B,N]`，H 由 `[G,D]` 改为 `[B,G,D]`；默认关闭，旧行为逐位不变；
- **不改**：单位更新规则、连接、生命周期、读出接口；旧胶囊 schema 保留、新增 v2 字段；
- **测试**：同 D-217 干净 fixture（无下标碰撞）、逐 tick 解码 t0 目标；3 seed；
- **门**：
  - G1 `state_final`（只读末 tick z/a）在 t=5 与 t=10 解码 ≥**0.60** 且不低于 t=5 的 0.90 倍（**无断崖**）；
  - G2 对照 `external_history_select` 仍 ≥0.80（任务可学）；
  - G3 旧三技能损伤 ≤0.02、恢复 diff ≤1e-10、旧胶囊可载入旧图（逐位一致）；
  - G4 架构中性：关闭新模式时，现有所有探针读数逐位不变。
- **出口**：G1+G2+G3+G4 全过 ⇒ `per_sample_state_verified`（有界）；G1 不过 ⇒ `per_sample_state_negative`（记忆轴最终收束）；工程失败 ⇒ `engineering_failure`。

### 方案 B（备选）：改进的有界可学习存储
- 16 槽×32 维、多头写/读地址、3,000 步、加**写后重建**辅助损失（要求从槽读回写入时的活动）；
- 门：同 A 的 G1（只读存储解码 ≥0.60）＋对照 mean/history；失败则记录「可学习有界存储在最小形式下不可行」。

## 3. 纪律（强制）

- **A1 口径**：状态保持只认 `state_final`（只读末步状态）；任何全历史序列只叫 `external_history_select`，仅作对照；
- 无下标碰撞、目标不得恒 t0（加入随机目标时刻）、fit 种子分区；
- ≤1,500 CPU、零 check/final、3 seed；新 pin 单卡报价；
- 方案 A 若改核心，须登记**新候选版本**（capsule schema v2、lineage 记录）；不改单位更新规则，不构成结构生长、不签 25/26。
