# 预注册卡：N32.6.01 研究线 R1（`ModalityEdgeHop` 任务无关共享 `S` vs 外控分列 `RT`）

> [预注册·探索] — 2026-11-25（D-20261125-544；owner 选定 `1: R1-Go`）。前置：[N32.3.03](RESULT-N32-3-03_20261125.md)（`Q2 learnable`）与 [N32.5.04/05](RESULT-N32-5-05_20261125.md)（`ModalityEdgeHop` `Q3 3/3 = 0.9899 / 0.9868 / 0.9874 learnable`）已全部齐备。本卡以无架构混杂的同口径对比，直接检验核心研究命题 **`R1`**：在 `taiji-23-composition-v2` 同输入格式三任务（`Q1 → Q2 → Q3`）上，单一任务无关共享 `ModalityEdgeHop`（`S`）相对互不共享的外控分列 `ModalityEdgeHop`（`RT`），在 `Q3` 学习与跨任务保持上是否存在正迁移收益。零 `check` / 零 `final` / 零 `confirm`。

## 1. 臂与无混杂对照设计（冻结）

| 臂 | 结构与参数量 | `task_id` / 分列 | 回放 |
|---|---|---|---|
| **S（共享主臂）** | 单个 `ModalityEdgeHop(10, d=64, de=64, 2L, 2H)`（`121,612` 参数，单一 10 类头） | ❌ 完全任务无关（仅用输入自身模态旗标 `scene_flag=9 / query_flag=42`） | ✅ `Q2` 期每步回放 `Q1`（`B_rep=64, w=0.5`）；`Q3` 期每步回放 `Q1+Q2`（各 `B_rep=64, w=0.5`） |
| **RT（外控分列对照）** | 三个互不相交的独立 `ModalityEdgeHop` 列（`q1 / q2 / q3` 各 1 列，合计 `3 × 121,612 = 364,836` 参数） | ✅ 由外部 `kind` 选择对应列，每列单任务同容量 | ❌（结构隔绝零干扰） |

与 `N32.2.03` 不同，本卡两臂使用完全相同的单元架构与单列容量，彻底消除了骨干能力混杂。

## 2. 数据、标准化与课程（冻结）

- 数据：`taiji-23-composition-v2`（`train 6,000` 世界 × `×3` 换名增广 → `Q1 24k / Q2 96k / Q3 288k`；`val 1,000` 世界无增广 → `Q1 1k / Q2 4k / Q3 12k`；`confirm 1,000` 世界封存不读）；
- 所有题型零填充统一至 `T=20`；布尔模态掩码 `(scene_mask, query_mask)` 在标准化前由原始 tick 提取；标准化 `(mu, sd)` 在 `Q1+Q2+Q3` 全部训练 tick 并集上以 `float64` 统一统计；强制校验 `Q3` 原始摘要与 `N32.5` 逐位一致；
- 课程与优化器（两臂完全一致）：`Q1 = 1,500` 步、`Q2 = 3,000` 步、`Q3 = 6,000` 步；`B = 256`；每阶段重建 AdamW（`lr=3e-3, wd=1e-4`, `200` 步 warmup + 余弦退火至 `10%`, grad clip `1.0`）；`Q3` 检查点在 **`(1000, 2000, 4000, 6000)`** 步同步评测 `S` 与 `RT`。

## 3. 门与混合批次等价审计（读前写定）

| 门 | 定义 | 达标 / 正信号 |
|---|---|---|
| **G1（分布内能力 + 混批等价）** | `S` 终态在 `Q1 / Q2 / Q3` 全 val 的准确率，及 `Q1+Q2+Q3` 混合打乱批次的预测一致审计 | 过门 `min(G1) >= 0.85`；正信号 `min(G1) >= 0.90`（余量 `>= +0.05`）且混批 `mismatches == 0` |
| **G2（共享迁移收益）** | `Q3` 四个检查点 `(1000, 2000, 4000, 6000)` 上 `mean(S_q3(t) - RT_q3(t))` | `>= +0.05`，且未触及天花板（`RT_q3(1000) < 0.95`） |
| **G3（持续保持）** | 相对各自阶段峰值：`BWT_q1 = S_final[q1] - S_after_q1[q1]`，`BWT_q2 = S_final[q2] - S_after_q2[q2]`（基于峰值的 `D-513` 修复口径） | `BWT_q1 >= -0.05` 且 `BWT_q2 >= -0.05` |
