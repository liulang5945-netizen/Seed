# 预注册：任务条件化子群路由与保护（S1-RT；待授权，零训练）

> 文档状态：[预注册/待授权] — 2026-11-21（D-20261121-244）。上游 [失败归因](ATTRIBUTION-TAIJI_U2_CORES_20261121.md)。**未冻结、未运行、零训练、零 check/final。**

## 1. 问题（归因结论）

新核 per-axis 成立，但 joint 失败的三条机制：共享单位顺序训练 → 覆盖；冻结单位 → 表征不足；生长 → 无功能绑定。根因：**缺任务条件化容量分配与保护**。本卡验证最小机制能否解除该瓶颈。

## 2. 范围（合成受控面；不改单位更新规则）

三任务小面：P-A 中文（8 类）、P-B 四类纠错（4＋conflict）、P-D 遮挡物理（4 类）；单一 48 单元 `SelectivePersistentGraph`，任务专用读出头。

**两阶段**：

- **阶段 1（机制烟测，≤600 CPU）**：固定分区——单元 0–15 给 P-A、16–31 给 P-B、32–47 给 P-D；训练时仅激活本任务子群（gate mask），学完后**全部门在各自 mask 下复核**。对照＝共享全单位同协议（预期复现覆盖）。
- **阶段 2（仅当 G1 通过，≤900 CPU）**：把固定分区换成**学习式路由**（每任务 k=16 top-k 单元，路由 logits 由任务标识/首 tick 特征生成），重跑同门；通过后把路由作为可选字段写入 `capsule_v2`（加法式，旧胶囊可载）。

## 3. 门（读前冻结）

| 门 | 指标 | 判据 |
|---|---|---|
| **G0 控制** | 共享臂 | P-D 准确率 <0.65 或旧技能损伤 >0.05（证明干扰真实存在） |
| **G1 共存** | 分区臂 | P-A `masked_bi` ≥0.95；P-B overall ≥0.85；P-D ≥0.80 |
| **G2 旧技能** | 分区臂 | 全阶段后 P-A/P-B 相对各自峰值损伤 ≤0.02 |
| **G3 功能绑定** | 分区臂 | 某任务 mask 单元休眠后，该任务准确率下降 ≥0.20，其他任务下降 ≤0.05（特异性） |
| **G4 恢复** | 分区臂 | capsule_v2 前向差 ≤1e-6；断点重连 ≥0.90 |
| **G5 预算** | 全程 | 阶段 1 ≤600 CPU、阶段 2 ≤900 CPU、3 seed、零 check/final |

**出口**：G0–G5 全过 ⇒ `s1rt_routed_verified`（有界机制）；G0 不过 ⇒ `control_interference_absent`（归因需重做）；G1–G4 任一不过 ⇒ `s1rt_partial`；超帽 ⇒ `budget_stop`；工程失败 ⇒ `engineering_failure`。**任何门不得读后调整。**

## 4. 披露与限制

- 阶段 1 的**固定分区是实验层机制**（不改变图内核），用于验证「分区可解除覆盖」；若成立，阶段 2 才把路由加法式写入核心并重测；
- 分区/路由是**容量隔离**，不是「协同」；本卡只验「同一主体共存＋功能特异性」，**不签**协同/联合增益/生长收益；
- 不签 check/final/C/D/J/模型成型；旧核继续冻结。
