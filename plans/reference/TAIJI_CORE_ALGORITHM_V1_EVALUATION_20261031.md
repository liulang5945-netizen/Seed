## 0. 结论摘要

**裁决：设计层有条件接受；09.1 合同部分满足；09.2.1 可以开工但须先冻结 6 项接口约定并修 3 个缺口。**

- **可以接受的部分（独立复算成立）**：v1.1 的四处方程修订——近端非扩张擦除、状态/查询归一化尺度地板、整体损失尺度下的出生信用、变时长 TD/资格迹——在各自声明的局部条件下全部成立，且未发现新的反例；§22.4 的四点见证数值精确；E1 新增的 `F^Tq` 多头读取公式与 `χ` 局部导数也成立。22+11 项既有核验能按其原条件复现（逐项数值、脚本 SHA、numpy/torch 版本、write-once 行为全部一致）。
- **不能接受的部分（证据上限）**：22 项只是**合成耦合代理**，不是正式方程全图；33 个检查中判别力为 strong 的只有 8 个，weak 10、identity 3、trivial 1。正式规格的连续 `χ`、群间 `Q_i/Q_g/K_j/V_j`、查询共同读出、§7.2 逐字表达、float32 实际更新与元学习均未实现——E1 §21 已自行撤回"按方程耦合已核验"的措辞并列出差集，本评估确认该表**且再补 3 条它未写的弱项**（见 §3）。
- **设计仍有 3 个实质缺口**（E1 未覆盖）：①出生算子 `B_new=cU[:,1:r]` 在 `r>rank(C_i)` 时多余单元的启动梯度恒为 0，draft 只写"奇异值非零则有梯度"，没有 rank-aware 的 `r` 规则；②`χ` 同时门控衰减/擦除/写入整个编辑差量，写许可关闭或写强度趋零时记忆**不会衰减**，陈旧语义未被合同约束；③条件化出生（§22.3）的四点见证是存在性证明，不是可学性保证：内容无关随机门期望为零但单次方差大（2000 抽中位启动梯度 0.0347，真门 0.0539），"无监督内容分簇"必须证明与残差结构对齐，否则出生信用是噪声。
- **新颖性**：只能算**已有算子的重组与稳定化**（近端擦除≈RLS/隐式梯度变体；擦除+写入解耦已有 Gated DeltaNet-2 先例），不能主张新快权重算子或首次解耦；可主张的贡献是组合耦合、稳定化条件与受限写入反例。
- **方案质量**：7 项核心主张目前全部处于"设计假设/合成局部代数"层级；E1 的 P_R/P_A/P_C 三角色与累计暴露上限是实质性补强，但 §14/§15.3/§19 仍缺预注册判据与资源/经历配平，R5c 负结果到新设计的推断链不可识别。

**一句话**：数学修订是真的、证据纪律是好的、E1 的自我收窄是对的；但"算法已可验证其核心主张"仍不成立——09.2.1 是把差集补成正式图的第一步，不能跳过。

### 2.2 新发现的边界与缺陷

1. **rank-deficient 出生（major，draft §11.2 第 429 行起）**：`C_i` 的秩小于请求单元数时，`B_new=cU[:,1:r]` 的多余列对应启动梯度**严格为 0**。独立复算：16 步加权损失、`r=2` 时每单元梯度 `[0.0290, 0.0]`；`r=4` 时 `[0.0290, 0, 0, 0]`。draft 只说"相应奇异值非零则有入边启动梯度"，没有规定 `r` 与 `rank(C_i)` 的关系，也没有死单元检测。建议：`r_eff=min(r_req, rank(C_i))`（或在压力下按内容簇分别出生），把"每个新单元启动梯度非零"写成算子准入，并进 09.2.3 测试。
2. **内容无关门的方差陷阱（major，draft §22.3/§22.4）**：均匀门 0.5 的负对照确实给出严格零信用，但随机内容无关门（2000 抽，均匀 [0,1]）期望为零、单次却不小：中位启动梯度 0.0347、p90 0.0479、最大 0.0638，真门 0.0539。即"零全局信号"被条件门修复的前提是门与残差结构**对齐**；"可来自无监督内容分簇"目前是假设。4 点玩具优化探针（手选门、300 步 Adam）把损失从 0.5 降到 4.3e-15，而均匀门完全停在 0.5——这只证明机制存在，不证明门能被学到。
3. **χ 的遗忘语义（minor→major，draft §6.4 第 222 行起）**：E1 已明确 `χ` 缩放"衰减/擦除/写入的整个编辑差量"。其直接后果是：写许可关闭或写强度 `s_χ→0` 时记忆既不写也**不衰减**（1000 步后范数保持不变，而独立衰减会到 1.3e-4）。这不是数学错误，但"陈旧记忆何时失效"必须写成合同条款（允许无写许可时衰减 / 或声明不衰减并补陈旧性测试），否则长期运行时快记忆可无限期停留在旧内容。
4. **非扩张保证依赖 B(x) 归一（minor，实现风险）**：v1.1 的界在 `‖k‖<1` 时成立；若实现沿用旧 ε 归一化，微小 key 会被放大约 10⁶ 倍（1e-8→9.9e-3 范数），证明失效。draft §5.4/§6.2 已写"不再用 ε 归一化"，09.2 需要在代码里可检查地保证这一点。
5. **元导数检查的判别力（minor，draft §23.1 自认、§23.1.1 补法正确）**：作者元导数信号 9.37e-9，而审计判据 atol=1e-7，阈值是信号的 10.7 倍——相对误差 >1000% 仍可"通过"；且 autograd 与有限差分的一致性只验证实现，不验证公式。独立玩具中我们复现了同类结构。§23.1.1 的"数值可分辨/更新可发生/任务可受益"三道门是正确的补救方向。

**判别力评级（Lead 阅读断言与实测余量后的判断，不是自动规则）**：

| 评级 | 数量 | 代表项与理由 |
|---|---|---|
| strong | 8 | 出生中性=0、聚合信用 5e-20、出生方向导数 1.9e-13、二阶导 1.2e-18、原式放大反例复现、v1 出生中性/启动信用/写门到后继损失 |

| identity | 3 | 半马尔可夫 TD、持续时间资格迹、单锚点投影：比较的是同一手写算术的不同写法，不是学习规则实现 |
| trivial | 1 | 终态 bootstrap=0（零乘子算术） |

**覆盖差集**：E1 §21 已列 5 行（连续 χ、正式快读取、群间 Q/K/V、查询读出/表达、float32/元学习）。本评估在其外再补 3 条：
- 三项半马尔可夫检查是**算术恒等式**——仓库里尚无 TD/资格迹实现，它们不能验证未来实现；
- 有限差分只比较每个参数的**第一个坐标**（`reshape(-1)[0]`），不是全坐标/方向；
- 多处通过条件为"有限/非零/有序"这类弱判据，见上表。

**结论上限**：现有证据能支持"局部代数性质与合成耦合代理行为已按原条件核对"；不能支持"正式方程全图已核验""联合信用成立""出生有效""活动有价值""保持/恢复成立""中文能力"。E1 撤回过宽措辞是正确处置，本评估建议 §21 把上述 3 条也写进差集表，避免未来把 22/22 当正式门。

## 6. 实现就绪度与 09.2

**评级：09.2.1 有条件开工；完整 09.2 需补规格；现有证据不足以直接定价或训练。**

- **规模量级**：按 n=4、d=128、m_i=256、每群 2 个 32×32 F 头（低秩 rank=16 为假定）估算约 **1.80M 参数**、前向微步 ~3.5e7 FLOPs 量级、K=32 BPTT 窗口激活 ~1.2MB 量级（不含计算图/二阶/元学习与重放）；成长后按 r、m_i、n 线性增加。仅供立项，不构成定价。
- **09.2.1 前必须冻结的接口约定**（否则不同实现者会写出不同模型）：
  1. 事件编码：字节 patch（8 字节）→ `e_t∈R^d` 的池化位置与投影；
  2. `ν` 的 8 项归一化与 `D_ν` 映射（ν→d）；
  3. 情景读取打分器（两层 tanh、null 候选、legal mask）与 `r_i` 的 value 投影；
  4. 群间 `Q_i/Q_g/K_j/V_j` 的逐项形状与缩放（§5.2 给了 α 公式但矩阵定义散落）；
  5. §5.4 查询读出 `z_t` 的拼接顺序与各头维度；
  6. §7.2 复制/生成混合的位置先验 `coverage` 递推与无可复制目标时的退化路径。
- **09.2.3 前必须补**：rank-aware 出生规则（§2.2 第 1 条）、死单元检测与"启动梯度非零"的算子准入。
- **09.2.1–09.2.4 可执行验收清单（建议直接进合同）**：
  1. 方程对照：每个参数/状态按 §4–§7 公式的前向值在 float64 下逐项对齐（固定 seed、容差 1e-12），并记录"哪条公式→哪行源码"；
  2. 连续 χ：0/端点/内部值、sigmoid 导数、无写入插值非扩张、投影外侧与边界分别测；
  3. 读写时序：同一步读旧 `F_t`、写后下一步可见；禁写时逐值不变且写门梯度为 0；
