## 2. 校准门（读前写定）

| 场景 | 要求 |
|---|---|
| 完美标定（10 箱各 1,000 样本，准确率=置信） | ECE ≤0.01 |
| 过度自信（conf 0.9、acc 0.5） | ECE ≥0.30 |
| 信心不足（conf 0.3、acc 0.7） | ECE ≥0.30 |
| 平坦 0.5（acc 0.5） | ECE ≤0.01 |
| 温度拟合后 | 校准 ECE ≤ 原始 ECE |
| 中文四级表达 | 4 个不同短语 |
| 确定性 | 重复计算数值一致 |
