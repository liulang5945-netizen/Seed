# 14.4起：记录关系读取与原生字节表达修订

> 文档状态：[算法与实施提案·未执行]。日期：2026-11-02。一个内容路径修订候选，接续已结案的14.3；本次只交设计和静态核对，不授予训练或模型采用。实际队首只在[MAINLINE](../MAINLINE.md)。

## 1. 决定与证据范围

**停止旧“冻结局部字节编码＋槽平均＋末端动作排名”配方的追加。下一候选改变记录内关系的表示、记录/位置寻址以及读取到表达的接口，并让答案目标训练这些负责参数。** 同一递归主体的H/F、继承式生长与恢复仍是基础；既有实现/权重是可复用资产，不是必须保持的认知接口。

其他影响归因的协议差异也登记：14.3源码固定4个dev world、9描述词，产生108个条件格；不是设计估算的8×5。`rotate`对整张对象/地点表循环，可能跨类型；D1汇总混入映射轮换项且测的是slot距离；D2缺席阈值0.10低于本次1/9，最终状态由D3先行分支决定。这些不把原负读数翻正，但不得引用为“全部测量解释已排除”。

## 2. 唯一机制假说

当前接口让同一字节位置同时承担“匹配描述词”和“提供实体值”。描述词位置在实体之前，因果编码看不到后缀；远端实体位置又只有有限前缀。新读取投影没有机会重塑该冻结表示，且动作分类没有直接训练中文字节表达。

**假说H：可塑的整记录上下文、显式记录边界内的内容定位、共享的读出/复制分布，能在同一资源合同中改善未见映射的原始中文答案。** 新记录上下文消除已知局部依赖限制；是否学会关系、是否值得成本，仍由实验判定。主张只落在这个接口包；不主张新RNN门类、新快记忆算子或已证普遍组合能力。

## 3. 输入与主体所有权

输入仍为原始UTF-8字节、完整目标及已有RawSource来源/时间/权限。记录边界来自真实观察事件，允许用于分组；不由宿主按“是”拆key/value，不提供实体ID、描述词span、正确记录或正确字节位置。若一个事件含多个事实，首版仍按一个事件编码，不能悄悄给出理想事实分割。

同一主体注册一个新内容子图`record_relation_v1`，替代本候选内的局部源读取与独立复制注意力。旧模型及其bundle保留作为历史对照。禁止只把新表征送到外部答案模型，或把候选动作index经宿主渲染成答案。

不再把两个人工命名的角色槽作为永久内容接口：每个输出前缀与主体状态产生下一次读取查询。首包仍用对象/地点任务，但记录数、记录长度与输出步数是受资源约束的变量，原始内容不必全部压进一个定长槽再解码。

父资产固定为09.8 bundle `output/taiji_core_09/subject_bundle.pt`，SHA-256 `ce4c62685d55bb518d234e7407e19b05257d1d761a0430432f7d0f09641321cf`；父参数候选`feb0cbcb00e2e16bb66b77db530ae566ce40eecaf2e14852b7cc1661292139dd`。这是继承起点，不是新候选摘要。新内容接口、参数和来源视图schema均须产生新revision/manifest；不把旧H/F的数值恢复相等当成新编码语义相同。

前向输入按类型与字段白名单注册，训练loss和评分上下文单独持有标签；不把带全部gold字段的fixture对象直接传给模型，也不通过全局表/闭包/缓存绕行。标准字节解码与概率采样允许，中文模板拼接、别名查表、按gold span复制或生成后补写内容不进入候选端点。

14.4在已有两条公开工程夹具和原费用上限内加入四项负对照，不增加训练数据、优化器次数或新预算：

1. **标签隔离**：参数、原始输入及状态相同，只交换评分视图的target/正确source/span，前向分布不变；loss/评分可以改变。训练标签影响后续更新属于合法监督，与本检查的固定参数前向分开。
2. **身份隔离**：一致重命名来源ID及其coverage索引，保持原文/权限/时间不变，分布应在声明数值容差内相同。不能靠ID或缓存键选答案。
3. **原始输出负对照**：把模型端概率替换成预定错误输出或EOS分布，端点必须保留该错误/终止，不能仍返回正确动作句；记录原始字节与模型概率后再做任何展示加工。
4. **边界审计**：记录从RawSource到forward的实际字段/调用路径，验证没有语义拆分、gold span、答案候选索引或评分器回调。字面量/AST扫描仅作辅证，不能用“没找到某几个词”代签整个依赖路径。

仍有一项任务偏置需明确承认：首包使用固定句式，夹具大多每记录一个事实；模型可能学到位置/模板规律，哪怕宿主没有语义代码。现有映射置换、反序和组件干预只支持已声明范围，不能代替自由措辞、多事实长段落或自驱策略验证；这些外推须另冻合同，不在本次悄悄扩面。

## 4. 计算定义

### 4.1 整记录上下文

默认d=128、寻址维k=32、双向编码每向h=64。对每条**已完整观察到且合法**的记录独立编码，目标也使用同一编码器：

```text
a_ij = BytePatchEncoder.context(record_i)[j] + record_local_position(j)
f_ij = GRU_forward(a_i1 ... a_ij)       # hidden=64
b_ij = GRU_backward(a_iL ... a_ij)      # hidden=64
u_ij = a_ij + W_c [f_ij; b_ij] + b_c  # width=128
w_ij = softmax_j(v_pool^T tanh(A_pool u_ij + b_pool))
r_i  = sum_j w_ij u_ij
```

双向只遍历本次已观察事件，不读取未来消息或尚未释放的反馈。GRU层不是主体生命状态的替代品；H/F仍跨主体微步存在。这里改变的是描述位置与实体位置在同一记录内的可学习联系。所有参数与初始化在14.4登记，新增矩阵非零fan-in初始化；不声称本次接口替换是函数中性出生。

旧embedding/input/causal convolutions在本候选内可塑；不得制作脱图的固定编码缓存。`r_goal`为目标按同一pool得到的摘要。来源视图保存`record_offsets / source_id / raw bytes / metadata / u`；ID只做身份/掩码，不作为语义特征。记录序无位置ID嵌入，字节位置只在记录内部定义。

首轮每个研究样本使用同一参数版本的隔离零H/F副本，合法records先进入该副本的raw来源视图；完整目标的u按连续8字节块均值经继承event层逐块作为输入事件，mode=0、previous=EOS，以本件同一读取/H推进过程消费目标。这些观察步不计答案、不累积输出coverage；开始答题时coverage置0。输出首步event=0，后续event是上一实际输入字节经同一新编码/event层得到的向量，mode仍为0。训练用上一目标字节、开发/确认用上一生成字节，禁止当前待预测字节进入查询。副本/重置及新优化器矩初始化都登记，不能称把旧生命状态完整迁移到了新编码。

### 4.2 先选记录，再定位内容

每个输出微步t，先由H_(t-1)、上个实际输入字节和目标产生查询，再推进H，避免循环定义：

```text
xi_t = inherited_xi([r_goal; embedding(previous_byte); mode; nu])
s_t  = inherited_QueryRead(H_(t-1), xi_t)
g_t  = Attn(Q_goal s_t, K_goal U_goal, V_goal U_goal)
q_t  = Q_read [s_t; g_t; embedding(previous_byte)]
alpha_t = softmax_i(q_t^T K_record [r_i; metadata_i] / sqrt(k))
q_value_ti = Q_value [q_t; r_i]
beta_tij = softmax_j(q_value_ti^T K_position u_ij / sqrt(k)
                    - softplus(eta) * coverage_(t-1,ij))
pi_tij = alpha_ti * beta_tij
c_t = sum_ij pi_tij V_position(u_ij) + alpha_t,null * null_value
```

alpha含一个可学null记录；beta只在各条合法非空记录内归一化。无记录时alpha_null=1；空目标用一个固定零特征goal-null，经过同一K/V映射，避免空softmax。来源合法性过滤在编码前进行；不允许已撤销记录先进入H、再只在输出端mask。

`K_record`不带共享bias，以免加入softmax公共平移死参数。记录长度不直接产生额外地址数优势；beta和alpha分开后，长记录不再单靠字节数抢整表的概率质量。时间/version采用原合法字段，超出首包时间范围不宣称已学会时态。

### 4.3 读取、状态与表达共享一份内容分布

将c_t送入原递归图的recalled输入位，替代该候选中的旧EpisodicRead结果；首版各群接收同一c_t（广播为groups×d，范围明确）。其余消息/F读取/生长残差/H泄漏方程复用，得到H_t及原QueryRead的z_t。原CopyExpression的独立base注意力、continuation/prior混合在此候选路径停用，旧参数保留但不进入优化器或信用声明。

复用可塑的生成头与mix头形状：`p_gen=softmax(generate([z_t;previous_embedding]))`，`gamma=sigmoid(mix([z_t;c_t;previous_embedding]))`。最终字节概率必须为：

```text
P_t(byte) = [gamma_t + (1-gamma_t)*alpha_t,null] * p_gen_t(byte)
          + (1-gamma_t) * sum_(i,j: raw_ij=byte) pi_tij
coverage_t,ij = coverage_(t-1,ij) + pi_tij
```

来源中无EOS，EOS只能由生成支路输出；null质量回到生成支路，因此全分布严格归一。不能把未归一的复制质量当概率，也不能把null重新分配给一条答案记录。coverage按(source_id,version,byte_offset)恢复/对齐，新增位置为0。

此接口有可核验的通路上界：若模型选中正确记录/字节且gamma=0、alpha_null=0，就能输出该原始字节，不要求把实体先压成能跨任务解码的槽向量。这个代数性质证明通路存在，不证明模型会学会选择。oracle只能在诊断视图强制同一正式图的alpha/beta，不能另造宿主答案生成器参加候选评分。

## 5. 恢复与持续状态

训练前先验证新schema初态保存和独立进程恢复，再作工程微更新；更新后核对下一次前向、下一次更新、optimizer/RNG/cursor/预算。H/F、位置coverage、合法来源、增量参数及旧optimizer归档均有身份；不以旧R027回执代签新接口。

首轮14.6为独立world研究样本，允许声明式重置，不声称已经跨会话生活。编码参数更新后不得复用旧latent缓存；缓存只可保存raw bytes、来源和预处理索引，或带完整encoder_revision的推理值。新revision中H/F的语义迁移不能仅靠赋revision+1：14.8持续任务设计必须选择受预算约束的完整活动窗重放并同时重建H/F/coverage，或拒绝此次在线更新并保留父状态；不许只清F、直接沿用H而称保持已验证。

### 6.1 14.4应先证明什么

- **关系路径**：只改同一记录后部实体时，前部描述位置的u可受影响；局部编码对照对后部字节嵌入的导数为0，原始字节置换另作离散干预。只改其他记录时，原记录u逐位不变。这是正式结构的依赖检查，不以随机大距离过门。
- **内容通路**：强制正确/错误alpha、beta使用正式模块的干预入口；原始字节复制分布归一、null/EOS合法；正常/错映射/恢复对照准确反映所改来源，不能重抄一套oracle算式。
- **宿主语义隔离**：按§3.1验证标签/身份隔离、错误输出负对照及真实字段调用路径；检查真实候选前向与原始输出端点，不能只看函数签名或字面量扫描。
- **任务信用**：f64对每声明组作坐标/方向FD（三eps 1e-4/1e-5/1e-6，atol1e-10/rtol1e-4），分辨信号须>10atol；置零/翻符号反例必须拒绝。f32逐组报实际delta/ULP/优化器矩，未分辨记未分辨，主实验用f64。
- **状态参与**：读取送入H及原QueryRead，核验到负责递归参数的任务信用；状态切断/错序作为功能对照。若答案只依赖当前来源且状态干预无效，记录范围限制，不称连续认知。
- **先恢复后学习**：先过新初态独立恢复，工程更新后再验下一输出/下一更新一致；未过不进入定价。工程loss变化不是任务能力。

### 6.2 三臂与优化器提案

三臂共享同一父、原始训练数据、输出端点与优化配方：

1. **A_full**：完整本候选。
2. **B_local**：同一容器/初始化，令`u=a`，停用双向上下文残差，其他记录寻址和表达相同。披露停用参数；不能称有效容量完全相等。
3. **C_flat**：同一整记录编码和表达，位置分数直接在所有合法位置上统一softmax；用可学null位置，取pi后相同方式输出。保留但停用的记录级寻址参数单列。用于判断整记录编码是否足够、层级寻址是否还有增量。

C_flat具体为`score_ij = q_t^T K_position u_ij/sqrt(k) - softplus(eta)*coverage_ij`；null用同一null_key。alpha只用于A/B；C的每条记录质量为其位置概率之和。所有臂的input/状态/字节copy/generate边界相同；没有宿主标签通路。

结构配对需要初始化语义相同：共享张量相同、新模块seed固定为27031/27032且摘要必须不同；父固定，不宣称独立父seed。数据顺序seed37031/37032。主候选预定27031，不挑最佳seed。优化统一float64 Adam(lr=1e-3, betas=.9/.999, eps=1e-8, weight_decay=0)、全局clip=1.0，无网格/开发挑终点。所有臂用答案字节监督，不能混入动作类别CE。源编码在同次更新可复用**有图**张量，不能缓存脱图值跨更新。

### 6.3 数据、评分与控制

沿用10.21的192训练/160开发world分组及原名字/描述清单，输出目标改为原始27字节规范动作句＋EOS；输入不含完整答案或目标实体名。开发面已反复消费，明确为开发证据，不当新未见确认。confirm仍未打开：在新候选/协议冻结后按原独立生成规则释放160例，若原面有实际暴露则登记失效并先重新立独立确认协议。

复用前核对实际world/source身份、映射重叠及留出轴；若物化面不符合声明，按instrument_invalid退回数据合同，不通过改写切分口径消除红牌，也不为新候选悄悄加样本。原始数据hash与生成器版本在定价前绑定。

主评分为自由生成`completed_action_exact`，最多64输出字节/65次预测，strict UTF-8、规范单句且EOS结束；空答、解析失败、超长、截断、列举多动作均保留分母计错。另报实体字节exact、完整句exact、EOS率、source top-1及NLL；无输出的选择分数不能充当主评分。

真实/域内置换（对象与地点分开，期望答案随真实映射变化）/记录反序/全图无来源/错误记录分布/错误位置分布/rescue均为预先固定条件。来源标签和实体字节跨度只用于评分与oracle，不能喂模型。改变真实records时须从相同初态重建全部受影响H与缓存，禁止真世界H泄漏到假世界对照。

任务门提案：两个增量seed的主分总体≥0.80、未见描述组合及未见目标实体各≥0.60；真实与映射反事实两侧同时正确≥0.60；反序选择/答案一致≥0.95。数值在执行前冻结，不借旧0.40动作分类门升级中文可靠性。

结构贡献另判：A对B/C各自总体增益≥0.10，逐seed按world配对bootstrap2000次、95%区间下界>0（统计seed57031）；错误记录/位置及全图无来源各降低主分≥0.10，预定8例rescue逐位恢复分布。若A与某对照均成功但增益不成立，只否定相应结构的必要增量，不抹掉任务正结果；若都接近满分则机制比较记饱和不可判。保持未有合格父能力集时记`retention_not_admissible`，报告旧行为及有符号NLL变化，不签保持通过。

### 6.4 具名出口

工程/评分/恢复失败：`engineering_failure`或`instrument_invalid`；价格超限：`budget_not_admitted`；运行耗尽：`budget_stop`；任务正确性未过：`native_byte_task_failed`；任务成立但组件增量不成立：`task_supported_component_gain_unresolved`；无源/错误读取不损任务：`content_path_not_necessary`；任务、对应机制及确认均成立：`record_relation_supported_on_declared_task`。所有出口仍不签一般中文、L3/L4、开放自主或生长收益。没有下一次追加seed/步数的默认出口。

## 7. 14.8必须交付的长期目标接力

本次接口修订直接承担原生中文端点；跨session/在线反馈/主动性不靠此推定。14.8在同一成功父候选上写实一段有上限的生命片段：session A观察来源、作原始回答；合法更正带id/source/version/反馈权利；session B不重给旧记录而从主体store取得经验，分开问当前与历史；有未结目标的无新提示窗口由模型选择继续/求证/等待，环境只给合法候选与成本。

下一包必须包含同记忆冻结参数、合法更新、置换反馈三种控制；旧任务保持与纠正旧错误分别结算；选择的真实任务收益在下一query测，不能用“做了多少内部活动”发奖励。奖励/准入/确认面独立，预算和自适应次数不重置。在线编码更新的H/F迁移成本、活动信用时程及checkpoint恢复先验，不能沿用lambda=0即时奖励或只恢复权重的旧通过证据。

生长/回收仍属同一主体目标：先让这条内容任务产生可核验残差，再按有效信用秩、保持和同最终容量对照评估结构干预。当前包不从旧小NLL净收益推出新任务应出生，也不永久冻结规模。若14.6/14.7失败，14.8收束为负并重审根假说，不继续叠头或绕到12/13声称根目标已有进展。

## 9. 先验工作与贡献边界

本轮交付限于代码路径审计、上面两个静态数学事实和实施设计。信息可达、学会表达、长期保持和递归发展分别举证，不能由一份方案互相代签。
