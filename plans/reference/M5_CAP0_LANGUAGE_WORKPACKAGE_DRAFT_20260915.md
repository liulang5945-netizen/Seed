日期：2026-09-15。状态：**草案**。
依据：[07](../active/roadmap/07_MINI_MODEL_DELIVERY.md) §2/§4.2/§5/§7、
[CAP-0 基线](M5_CAP0_BASELINE_RESULT_20260915.md)、

纪律：本草案只做**排期与出口定义**，**不启动训练**、不改加载器 / binder、不做产品采用。

## §1 基线给出的三个事实（本工作包的输入）

1. **默认入口（tick=2）在 C/D/E 上全部 0.00**（0/14、0/16、0/20）⇒ 基本问答、上下文、
   简单指令**完全缺失**，不是边际不足；
2. **最训练过的 16M-tick 状态输出与 tick=2 逐字相同**（反事实实测）⇒
   **缺口不在"加载不到训练态"这一层**；
3. **该入口的输出形态是固定模板**（`我已收到你的问题："<PROMPT>"。…`），而语言器官文档
   明写"任意预测字节不得当作语言呈现" ⇒ 缺口在**语言产出的上游**（训练目标 / 语言表层）。

## §2 工作包目标（对齐 07 §4.2 最低线）

**目标等级 = L2 基础可对话**（07 §2）：短回答、基本问答、简单指令、上下文与边界意识达线。

| 维度 | 目标 |
|---|---|
| C 基本问答 | ≥70% |
| D 上下文与工作记忆 | ≥80% |
| E 简单指令与推理 | ≥70% |
| B 基本对话 | 人工复核达标（0/1/2 量表） |
| G 安全 | 硬安全失败 = 0；恰当拒答与过度拒答分别报 |
| A / H | 全通过；**性能门须标定后冻结** |

## §3 前置条件（缺一不可）

1. **B/G 人工复核完成** —— 复核清单已生成：
   `reports/cap0_bg_review_worksheet_20260915.md`（40 项，含题面、原始回答、打分位）；
2. **加载策略拍板** —— legacy 守卫是否落地（CAP-0 §7.1 的 a / b / c）。
   否则"可加载的训练态"不存在，任何语言训练都无处落盘；
3. **H 门标定并冻结**（07 §4.2：「不可留空就宣布通过」）；
4. **训练授权** —— 本工作包必然涉及训练，**当前未授权**。

## §4 候选路径（按投入从小到大，均需新预注册）

| # | 路径 | 做什么 | 能得到什么 | 风险 |
|---|---|---|---|---|
| **P1** | **诊断先行**（只读） | 查清 16M-tick 的训练目标里**是否包含语言/表层监督** | 判定是"没训过语言"还是"训了但没接出来" | 低 |
| P2 | **语言表层接入** | 若 P1 显示表层数据已存在：把已有候选接进 `chat()` 的可读判定 | 可能让**已有**能力变得可读 | 中（触及 `language_organ` 判定） |
| P3 | **语言学习训练** | 在可加载的训练态上做受监督的表层/序列训练 | 直接冲击 C/D/E | 高（新训练，需预算与预注册） |
| P4 | **换评价对象** | 若 P1 证明该链路根本不含语言目标：改 bundle / 入口 | 让"实际模型"被看见 | 中（换对象须先冻结） |

**推荐顺序：P1 →（据 P1 结论）P2 或 P3 / P4。**
理由：P1 **只读、成本最低**，却能避免在错误假设上投入训练 —— 这与"先修测量仪器再投入"的既有纪律一致。

## §5 出口判据（可机检）

1. 本工作包的 **CAP 复评报告**存在，C/D/E/B/G/A/H 各维度**有分数或明确 `untested`**；
2. 目标维度达到 §2 最低线；**未达则如实记未达，不降线**；
3. 评测期间 `trained_during_eval=false`；
4. **原始回答留档**，机检判分与人工复核分列。

## §6 明确不做的

- **不**用"修好加载器"冒充语言能力（反事实已证二者独立）；
- **不**临时换模型凑分（07 §4.3）；
- **不**在看完成绩后下调最低线（07 §4.2）；
- **不**在未授权时启动训练或改默认产品行为。
