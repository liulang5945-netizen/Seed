## 1. 一个问题、两个臂、明确的非目标

**问题**：在完整来源复制保留的条件下，可学习对象/关系内容状态是否使未见实例的事实翻转与关系组合更可靠？

- B：可学习竞争绑定＋对象对关系计算＋每步内容条件化生成，作为唯一候选。
- A：同输入表示、同数据/目标/选择预算、同输出机制的隐式内容对照，不做显式对象槽和对象对关系计算。历史char-v1仅作可加载资产和旧dev回归锚，不冒充同预算对照。
- 这是**内容结构包比较**，不是只增加一个参数的单变量研究。输入编码、优化与数据都比D8有所改动，A/B共同使用；B/A的参数/计算差异必须披露，不能声称“纯槽位因果”或“参数量无影响”。预算不足时不偷删A并保留优势主张。
- 不做：D8-v5/LR扫参延伸、外部模型代答、运行期在线更新、真实工具动作、全套世界模型/规划、多模态、Mini交付、默认模型替换。对象/关系切片服务R2，不另立主线。

## 2. 拟定计算规格：开工实现不得暗改

本节是首版具体选择，未经实现/静态数据审查仍可能发现不相容；此时先修订版本与理由，不先训练再调设计。尺寸是有界原型选择，不是架构上限或已验证最优值。

| 部件 | 首版规格 | 实现必须证明 |
|---|---|---|
| 公共输入 | 材料、问题分别输入，显式字段边界；字符嵌入48维，递归隐藏64维、证据投影48维；保留来源位置与原始码位 | 运行时只见材料/问题，不见shape、答案、配对标签或金角色；不按题型调用外部解题器 |
| 未见字符身份 | 字符嵌入外，所有字符统一加入UTF-8字节特征：最多4字节、每字节8维、按位置拼接，加5维字节长度one-hot后投影48维，再与字符嵌入相加；padding独立于byte 0 | 不仅在未知字符时走另一条任务分支；原始字节/长度是合法输入，不是语义标签。不同未见字符在投影前可区分；参数可训练，不能保证仅凭编码即有语义泛化 |
| B绑定 | 6个48维可学习初始槽，3轮共享GRU更新；对每个证据位置的槽分配先沿槽轴softmax，再在每槽内沿位置归一化汇聚；只对材料绑定 | 给出空材料、分母epsilon、mask和padding语义；槽是潜在表示，不能称已学成人类对象；本包每材料最多3个实体，槽数不是金实体数 |
| B关系/内容 | 全部有序槽对通过共享MLP（输入两个槽与问题向量，隐藏96、输出48）；问题条件化汇聚槽和关系，投影为48维内容C | 相同/不同、否定、未知由学习计算，不用金shape选答案头；不硬编码“两个值相等就输出相同” |
| A内容 | 问题条件化的6路独立证据汇聚（每路沿位置softmax、不跨路竞争），拼接后MLP形成48维C；无迭代槽更新/对象对关系 | 公共编码/生成结构与B一致；独立初始化内容模块，共享模块按稳定名称同seed初始化，禁止参数添加顺序改变公共初值 |
| 公共生成 | 64维生成状态；每步消费上次字符特征、C、来源读取；词表生成与来源copy混合，copy查询和混合门也消费C；沿用动态码位候选、重复字符概率合并及边界符 | TF与自由生成共享同一前向；未知字符输出保留真实码位，下一步也使用它的输入特征，不退回单一UNK；EOS纳入损失与评价 |
| 来源访问 | 保留全部材料字符H；内容C条件化选择来源；两臂同用可学习发射后继bonus，初始0 | bonus不是对象绑定；重复字符/跨值同字/无匹配时行为有单测；无材料时copy关闭且分布有限归一 |

不直接改旧char-v1格式或旧checkpoint解释。拟新增独立模块 `taiji/sequence_content_workspace.py`，独立config/model/state/trainer格式；公共工具可抽取但必须保持旧图回归。输入最多256字符、自由输出最多32字符；超限记显式范围错误而非静默截断，确认集所有预定题须在范围内。

**保存内容**：参数、train词表、原始字符候选构造版本、配置/数据digest、优化器/RNG/采样状态、当前更新数、选择规则与完整来源身份。每个episode重置临时W/R/C，不把本包叫跨会话记忆能力。首版两臂均从头训练，复用的是机制/测量资产，不迁移旧优化器；warm-start不在本版。

## 3. 数据与经历：先静态验仪器，再训练

建立新namespace，不改D1/v3/v4或读取旧final。物理分离train、calibration和sealed-confirmation；训练进程无确认题路径，词表只由train建。calibration属于训练开发用途，可以选择配方但不能称能力确认。

### 3.1 题组配额与生成约束（拟冻结）

一个组恰含两题；同组只在一个split，组内反事实必须保留配对。7类组：事实值翻转、提问对象交换、关系同异翻转、否定作用域变化、无关干扰不变、缺失信息→补足信息、已知信息/未知边界。最后一类是一对不同表述、答案均为未知的保持组；其余变化/不变的预期关系由生成规则明确，不含答案含混的自然文本。

| split | 每类组数 | 总组数 / 题数 | 用途 |
|---|---|---|---|
| train | 256 | 1792 / 3584 | 成组采样、答案与copy学习 |
| calibration | 32 | 224 / 448 | 两个候选配方的有界选择，不用于主要能力声明 |
| sealed-confirmation | 64 | 448 / 896 | 冻结候选后一次性评价两臂各三seed |

这些是拟议数据规格，不声称已生成。有可见值的组中单字/双字值各半；未知保持组无须伪造不存在的值长度。材料含1–3对象，目标顺序、干扰位置平衡，最大长度与各分母由静态报告核验。组合池不足、重复、冲突标签、无法满足划分时实现门失败，不复制行凑数。

答案语义也须可执行：事实/对象交换答完整值；关系同异答“相同”或“不同”；否定作用域题在明确封闭事实下答“是”/“否”，例如把“甲不是红，乙是红”改为“甲是红，乙不是红”后，同问“甲是红的吗”应翻转；无关干扰组答同一完整值；缺失→补足组从“未知”转为完整值；未知保持组均答“未知”。不从“未提及红”推导“不是红”，正负冲突材料不纳入首版。标签只用于训练/评分，推理无答案类型字段。语义定义不等于已解决自然语言歧义或开放世界推理。

同组原型及其改写/排列共享group_id；按实体/完整值词面、模板家族、关系组合做组级留出，calibration与确认独立。字符允许共享，但确认必须单列未见完整值与含train未见字符两种切片（各至少64个可复制回答）；模板变化保持语义合同，不能只换标点后声称独立模板。split清单/生成器版本/digest在模型选择前冻结，确认内容不打印到训练日志；任何泄漏导致该确认身份作废并记账。

### 3.2 静态实现门

可复用D1评分定义和独立参照解题器的思想，不把参照解题器接入模型。检查去重、答案唯一性、组内变化、split泄漏、OOV身份、mask与EOS、各切片分母；参照器与标签生成逻辑独立实现，在全部题组正确。固定未知/最近值/首值/对象位置策略在事实/对象/关系三类的成对正确宏平均不得超过0.25，否则先修仪器且不训练。基础策略不能涵盖所有捷径，后续仍需逐题反事实与干预。

## 4. 学习目标、优化和有限选择

- 基本损失：逐题按答案长度均值的CE（含EOS）＋1.0×可复制值位置的copy NLL；非复制题copy项为0，各组两题等权、7类组均衡。两臂完全相同；首版不引入金槽/金关系辅助头，以避免候选靠额外监督赢对照。
- 成对训练首先通过共同采样和两题答案目标实现，**不另称已实现对比损失**。未来若需辅助绑定目标，必须另版而非本轮默加loss。
- 每次微批4组=8题；固定seed下按类别均衡、组级洗牌，记录实际暴露/重复次数。不得拆散组跨split，不能逐轮固定题型顺序。训练与记录同时保留CE/copy/总loss、分组自由输出、梯度及更新范数。
- 拟议两配方：AdamW、weight_decay=0、全局梯度范数裁剪1.0；峰值lr分别0.001与0.003，前5%更新线性warmup，其后余弦衰减至峰值10%。其他参数使用显式冻结的AdamW betas=(0.9,0.999)、eps=1e-8。它们是新包候选配置，不是已验证的D8修复。
- 标定seed=20260920，两臂各2配置，每次最多2000更新；在500/1000/1500/2000保存与评价calibration。每臂按“满足复制≥0.90、未知≥0.90且无非有限值的候选中，前三类成对宏平均最大”选择；并列优先低lr，再较早更新。不合格即停止该臂，整包不进入确认，不补第三配方。
- 正式seed=20260921/20260922/20260923，每臂独立重训3次；使用各自选定配方及同一最大2000更新预算，只取第2000更新checkpoint，不按确认结果选epoch/seed。标定较早checkpoint只用于配方评分，不缩短正式臂的共同更新预算。
- 每100更新记录健康/训练统计；每500更新保存。非有限loss/参数/梯度、checkpoint写入/续训失败立即停止；超过资源上限安全退出为incomplete，不把已选早期权重冒充规定终点。固定15%单点CE跳幅不是新图永久门，但所有异常曲线与晚期行为变化必须报告。

## 5. 确认门与因果声明边界（预设工程目标，待冻结）

以下阈值是能力价值与保持的工程目标，**不是已估计的统计功效**。静态仪器完成后、任何训练前确认采样分母与阈值版本；如需修订必须记变更理由，不看模型确认成绩后调门。不用旧M4名称指不同分母。

| 门 | 拟定定义与通过条件 |
|---|---|
| 主能力BIND | 事实值翻转、提问对象交换、关系同异翻转各64组；一组两题全对才正确。B三seed总体成对宏均值≥0.50，每类跨seed均值≥0.40，每seed宏均值≥0.35 |
| 对照优势DELTA | 以同seed同题组配对，BIND宏均值B−A≥0.10，至少2/3 seed差值>0；按原型组聚类、在每类内重采样10000次（bootstrap seed=20260924），三个训练seed固定，95%区间下界>0。只描述题组抽样不确定性，不冒称覆盖所有训练随机性 |
| COPY保持 | 确认集可复制完整值率：B均值≥0.80、每seed≥0.70；未见完整值和未见字符切片各均值≥0.70；相对A各对应切片跨seed均值下降不超过0.05。TF概率不能抵扣自由输出 |
| 其他切片 | 否定、无关干扰不变、缺失→补足三类各成对跨seed均值≥0.50；未知保持组两题全对率≥0.80；所有seed无非法码位/NaN，EOS正确停止率≥0.98 |
| 旧dev回归 | D1旧98题仅诊断：完整多字值B均值≥0.30、每seed>0，且相对本包A均值下降≤0.05；报告与旧v3的描述性差异，不作为独立确认或纯结构因果证据 |
| 内容消费 | 在相同词面/长度的成对材料间，交换C但保留本题H/来源映射，记录事实/关系错误变化；同时做无关干扰保持。预声明诊断，不靠破坏后下降单独证明绑定语义；若消费测试显示C未连到两条输出通路，判实现失败 |
| 真实性/恢复 | 同一正式checkpoint新进程生成逐题一致；manifest、评价、健康证据绑定到各自checkpoint/配置/数据身份；所有未测A05/F/性能阈值等显式列出，不自动宣称CAP全过 |

全部所需门过才支持本次**有限内容结构包**；不以总体均分抵扣关键切片。两臂都好但DELTA不够：有限内容可学有证据，显式结构优越性不获支持；B绑定好但copy退化：保持不合格；B无绑定收益：本候选结案，不自动增加槽数/步数/数据；预算/仪器不满足：不可判。任何结论均不自动晋级L2/M5、切换默认或重启P3b。

## 6. 资源、checkpoint与授权闸门

拟议运行上限：标定4次＋正式6次，总计最多20000统计训练更新；保存/续训单步测试另记测试账，不计能力训练，耗时仍纳入全包。单次最多90分钟、全包最多12小时进程墙钟（包含标定、评价与恢复，串行累计；不以并行掩盖总投入），独立产物最多10GiB。最多使用一个已批准本地执行设备，不租云、不新增硬件、不自动跨主机。**这些是请求审批的上限，不是耗时预测或本轮授予的预算。** 设备/线程/精度/实际内存与每步时延在预检后填入run manifest；预计不能满足上限则回到资源决定，不自动缩题或改门。

拟用隔离目录 `reports/r2_content_binding_v1/<arm>/<seed>/<config>/`，避免复用旧D8或产品基座。目录只在实施时创建；保存atomic temp→rename，manifest含SHA-256；零步保存、新进程加载、继续一步与不中断对应路径核对，是训练前条件。最少保留zero/latest/selected/final及异常现场；循环保存可按预声明淘汰非selected的中间快照，不能删除失败报告和已引用权重。

**允许分步但不跨权**：当前仅合同设计。下一步可以交付静态数据/评分器和计算图/恢复实现门，不启动统计训练、标定或确认；单步梯度/保存测试需在实施包明确为测试、隔离产物。待实现门、manifest与预算审批齐备后，才能将本草案升级FROZEN并运行标定。确认集评价须在全部正式候选身份锁定后一次授权批次执行，不能边读确认边调参。
