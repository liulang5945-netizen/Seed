# 预注册卡：N32.3.02 R1 可学性诊断 v2（预编码＋大 batch＋MLP 参照；G1–G3）

> [预注册·探索/诊断] — 2026-11-25（D-20261125-519，owner 授权 ≤600 CPU；**编号说明**：起草时暂记 D-518，与同日 owner 复核条目 D-20261125-518 冲突，按台账以本条为 D-519）。回应 N32.3.01 `precheck_fail`（Q2 6,000 步 0.342）。**本卡只做可学性诊断；不比较 S vs RT、不改成绩单、不读确认 seed。**

## 1. 问题

Q2（一跳方向关系）在 N32.3.01 里学不动，是**优化/步数/编码开销**的问题，还是**任务对循环结构本身的难度**？具体问三件事：

- **G1 单任务可学性**：去掉逐批编码开销（预编码）＋大 batch 后，GRU 能否在 Q2 上达到 **0.85**？
- **G2 循环结构收益**：同一预编码输入上，GRU＋read_gate 相对**MLP 参照**（展平 24×48=1,152 维 → 256 → 10）是否有增益？
- **G3 课程保持**：Q2→Q3 顺序学习后，Q2 的 BWT 是否 ≥ −0.05？

## 2. 设计（冻结）

| 项 | 值 |
|---|---|
| 数据 | 合同 v2；Q2 训练 24,000 行、Q3 训练 24,000 行（**固定子集**，seed 20261120 生成，分层按答案类别）；验证各 1,024 行（与 N32.3.01 相同） |
| 预编码 | 一次性把 tick 张量编好存 **float16**（Q2 24k＋Q3 24k ≈110 MB），训练时每批 cast float32；不再逐批调用编码器 |
| batch | **256**（MLP 参照 512）；Adam lr 3e-3 余弦→10%，梯度裁剪 1.0 |
| 臂 A | **GRU u48**，Q2 单任务 2,500 步（G1 的低容量对照） |
| 臂 B | **GRU u96**，Q2 单任务 2,500 步（G1 主判） |
| 臂 C | **MLP 参照**（1,152→256→Tanh→10），Q2 单任务 2,500 步（G2 对照） |
| 臂 D | **课程**：GRU u96，Q2 1,500 步 → Q3 1,500 步（Q3 类均衡 CE）；记录 Q2 学后峰值与 Q3 学后 Q2，用于 G3 |
| 初始化 seed | 20261120（探索 seed；非确认 seed） |
| 预算 | **≤600 CPU**；先冒烟（每臂 40 步）外推，超帽即停 |

## 3. 指标与门（读前写定）

| 门 | 定义 | 达标 |
|---|---|---|
| **G1** | 单任务 Q2 准确率（臂 A/B） | ≥ **0.85**（任一臂；两臂都报） |
| **G2** | 循环收益 = max(臂 A, 臂 B 的 Q2 准确率) − 臂 C 的 Q2 准确率 | **> 0** 记「循环有增益」（诊断，不设硬门） |
| **G3** | 课程 BWT = 臂 D 学完 Q3 后的 Q2 − 臂 D 的 Q2 学后峰值 | ≥ **−0.05** |
| 附报 | Q3 准确率（臂 D）与「未知」预测率 | 诊断 |

## 4. 出口（读前写定）

| 出口 | 条件 | 后续 |
|---|---|---|
| `learnable` | G1 达标且 G3 达标 | 可写 S vs RT 正式卡（沿用本卡步数/容量/预编码），须 owner 另授预算 |
| `learnable_no_retention` | G1 达标但 G3 不达标 | 先解决保持（回放/EWC 卡），不得直接比较两臂 |
| `not_learnable` | G1 不达标 | 记「R1 前置不成立：Q2 在预编码＋大 batch 下仍不可学」；建议重设任务或改用 Q1 型任务 |
| `engineering_failure` | 缺臂、NaN、超预算 | 修复后重跑本卡 |

## 5. 说明

- G2 只回答「循环结构是否带来增益」，**不是** R1 的共享收益；R1 仍需 S vs RT 的独立预注册卡；
- 预编码与固定子集须写入回执（sha256），后续卡复用同一子集；
- 范围标签：`data=synthetic; vocab=closed; diagnostic=learnability; no_shared_gain_claim`。
