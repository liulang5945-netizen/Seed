# 问题、公开感知与Native状态的局部单位联合表征

> P3.7.3a／b，2026-11-13。研究候选。源码`taiji/u2_joint_tokens.py`定义局部算子，主体集成与任务收益由P3.7.3c之后签署。

## 1. 采用依据与责任

[24步更新结案](CLOSEOUT-TAIJI_U2_FIRST_BINDING_UPDATE_20261113.md)确认原生混合信用可达，但当前固定组合目标的float32交互增益无法稳定分辨。现行reader先将完整问题压缩为d维，再执行共享两次注意力，输出采用0.1×W_out(current−initial)。请求对新输出的直接残差随initial相减消去，其影响主要经过注意力权重及H。该路径的行为代价由已有弱交互读数提示，完整函数类表达能力继续按实际范围判别。

新算子先让局部问题单位与公开证据／分支内H相互作用，再形成供递推和表达共用的d维条件表征。它采用已有的多头注意力、RMS归一化、残差和MLP，贡献范围按当前耦合路径及实证登记。

## 2. 唯一输入与前向

Q∈R^{L×d}为现有text_units对原始问题的输出，E∈R^{N×d}为已获准公开感知单位，μ∈R^{N×8}为同一单位的元数据，v∈{0,1}^N为合法mask，H∈R^{B×G×d}为分支内Native状态。当前d=8、两头、两层，L≤512、N≤128、1≤G≤16、1≤B≤8，每层注意力元素B·heads·(L＋N＋G)²≤8388608。

各输入与模块同dtype／device。有效输入必须有限，缺失E行及其元数据在投影前置零，且在每层key支持中屏蔽。问题和H为有效单位。空问题输出B×d零张量；空证据时仍允许问题与H参与，输入必要性留给行为对照。

\[
R(x)=x/\sqrt{d^{-1}\sum_jx_j^2+10^{-4}},\qquad
X_b^0=[Q+e_Q;\ E+W_\mu\mu+e_E;\ H_b+e_H].
\]

每层ℓ=1,2使用独立参数，按两头拆分Q/K/V。

\[
(Q_\ell,K_\ell,V_\ell)=W_{QKV,\ell}R(X_b^{\ell-1}),\quad
A_\ell=\operatorname{softmax}_{valid\ keys}(Q_\ell K_\ell^T/\sqrt{d/2}),
\]
\[
U_b^\ell=X_b^{\ell-1}+W_{O,\ell}A_\ell V_\ell,\qquad
X_b^\ell=U_b^\ell+W_{down,\ell}\operatorname{GELU}(W_{up,\ell}R(U_b^\ell)).
\]

FFN中间宽度4d。所有Linear无bias，role为三行可学习d维向量。线性权重Xavier uniform，role标准差0.02，实际随机身份由候选初始化与源合同绑定。

只在融合后的问题行上池化。

\[
Z_b=R(X_{b,Q}^{2}),\quad a_b=\operatorname{softmax}_{L}(w_s^TZ_b),\quad
u_b=\sum_{j=1}^L a_{bj}W_vZ_{bj},\qquad
c_b=u_b/\sqrt{1+d^{-1}\|u_b\|_2^2}.
\]

源码在层输出及读出后检查有限性。d=8时参数1696个、12张量，全部归Θ，共享于所有分支、问题长度及证据数量。分支之间独立计算。顺序信息由输入局部单位编码及元数据提供。

## 3. 数学及结构合同

R的Jacobian谱范数≤100，零点值和导数均有限。最后的径向映射满足RMS(c)<1，Jacobian谱范数≤1。Native继续以tanh后的凸泄漏更新保持H逐分量有界。完整耦合Jacobian、长期稳定性和学习后任务收益继续独立核验。

合法E行连同元数据重排应保持读出；分支内H单位重排应保持该局部读出；改变一个分支的H不影响其他分支。无效NaN行应与被屏蔽的有限行等值，无效行梯度为0。完整缺失E与空E等值。问题／E共同替换须存在混合响应，逐参数和Q/E/μ/H信用均可测。

局部导数检查用加权输出的完整参数和输入方向差分，并用反号导数作负对照。该合成检查只签模块映射。正常answer_loss、全部状态和恢复由主体集成覆盖。

## 4. 同一表征参与递推和表达

拟集成定义为c_t=Fusion(Q_t,E_t,H_t)，Native事件输入改为e_t＋c_t，原递推中的其他输入、FP1和R/P参数保持其既有责任。表达上下文使用z_old(S_t,q_t)＋c_t，二者共享同一Fusion参数。状态变化后重新计算当前c，参数版本内沿同一可微图传递任务信用。

融合query取当前有效request的局部单位；缺少有效request时取persistent goal的局部单位；两者都为空时局部增量为0。参数配平控制始终取persistent goal，原request及旧Native入口仍保留。原D profile作为基线。新参数采用非零初始化以获得启动信用，采用相同新参数初始化的配平控制。关闭新算子的显式切片应恢复原父行为，开启态作为新函数身份单独登记。

这里的共享表征可同时受到直接表达损失和经过H递推的任务损失塑形。原Ψ范围及资格迹继续按旧定义，新增Θ不得自动加入actor资格。真正的自主选择、发展信用与生长收益按后继任务验证。

## 5. 事件顺序、恢复及生长边界

| 入口 | 联合表征读取的输入时点 | 必验条件 |
|---|---|---|
| initial／set_goal | 当前已保存的goal／request与已提交证据前缀 | 空输入中性、目标版本和父源 |
| predict／action | 当前已提交证据与转换前H | 单次Native转换、动作身份保持 |
| assimilate／receive内部Native | 当次转换可见的已登记证据前缀；新packet仍走原事件编码路径 | 未提交packet不进入目录读取；保留原两次绑定纠正和一次快记忆后整合，融合不追加转换 |
| packet提交后 | 新证据经既有注册／来源校验可供下一次转换及表达读取 | 同一canonical包、撤销、超窗、缺失和非法来源 |
| set_request／accept_byte | 当前request及其实际字节历史，转换前H | 实际历史保留、EOS／状态边界一次推进 |
| output／policy | 当前H与合法证据，按当前query来源重算 | 表达和递推参数共享，分支隔离 |
| 编码器更新／恢复 | 当前参数版本下重新编码原公开记录 | 无跨版本缓存，原始来源及44字段全部核验 |

当前设计使用既有原始证据目录和H，新增派生特征不持久化。集成需检验中间事务的目录一致性，并提供方程→源码→参数／状态→检查矩阵。恢复模式、祖先摘要及query来源绑定显式schema／factory。

固定G下的R/P中性出生若保持H及公开输入相同，Fusion输出也相同。新增群体、改变G或扩大证据窗口会改变注意力归一化支持，需独立的出生／成熟／保持协议。现有局部形状可变性按其接口范围解释。
