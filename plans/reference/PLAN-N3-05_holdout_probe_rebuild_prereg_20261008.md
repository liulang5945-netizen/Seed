# PLAN-N3-05 · 独立探针重建预注册（DEBT-G49 修法①；2026-10-08 起草，**判据先冻、不开跑**）

> **来源与效力**：owner 2026-10-08 第四次弹窗裁 DEBT-G49＝"**要求零命中重建**"（09 §3.2 第 3 条、㊵-498 同批）。
> 缺陷本体与实测在 [05_TECH_DEBT_REGISTER 的 DEBT-G49 行](../active/roadmap/05_TECH_DEBT_REGISTER.md)：
> 现用探针 `HOLDOUT_PROBE`（`train_seed_corpus.py:57-61`，163 B 常量）切成 35 个 24 字节窗口后，
> **5 个窗口原样命中训练语料 ⇒ hit_rate=0.142857**（读数件 `reports/taiji_n3a_data_face_scale10calib_20261008.json`）。
> **效力**：冻验收式、冻取法、冻守卫形状。**本件不构成改产品/改训练器常量的授权**——它动的是
> `train_seed_corpus.py` 的 `HOLDOUT_PROBE` 所在那条链（判据所在的链），实施前先回 owner。
> 成熟度：这是一件**测量仪器**的预注册，不声称任何能力结论。

## 0. 为什么"重建"不等于"换一段文字"（三条硬要求）

1. **"独立"必须由读数保证，不由命名保证**。验收式只看一把现成的尺：
   [audit_taiji_n3a_data_face.py](../../scripts/training/audit_taiji_n3a_data_face.py) 的 `_disjointness(corpus, windows)`
   （流式扫 108 MB 语料不进内存，本机已跑通）。**不新写第二台重合仪**——那是重抄同一把尺的两个版本。
2. **旧探针不许删**（反事实锚点）。历史上一切引用 `holdout_surprise` 的读数（㊵-482 的"泛化侧缓慢退 +0.041/+0.066"、
   ㊵-484 压强面的 accuracy 侧对照、以及每张进度件的最后一行）都绑在旧常量上；
   把常量原地换掉＝**删掉那批结论唯一的复算入口**。⇒ 本件走"**加新列、不动旧列**"，不走"就地改值"。
3. **新探针的文字来源必须披露**。候选文本是**为了零重合而新写的**，不是从任何外部语料里摘的——
   这句话就是 `hit_rate=0` 的成因说明；不写，"独立"又会退化成命名。

## 1. 冻结的验收式（每条都能为假，且有已知的正例/反例）

| 编号 | 条件 | 取法 | 已知对照 |
|---|---|---|---|
| **A-1 零窗口命中** | 对**每个**候选，`_disjointness(真实语料, 候选的 24 字节窗口)` 的 `windows_found_in_corpus == 0`（⇒ `hit_rate == 0.0`） | 现成仪器 `_disjointness`，语料＝`DEFAULT_CORPUS`（`data/simple_zh/dialogue_extended_clean.jsonl`，108,327,171 B） | **反例已知**：同一台仪对旧探针给 `5/35` ⇒ 这把尺有判别力，不是恒真 |
| **A-2 量级不跳档** | 新探针字节数落在旧探针同档：`64 B ≤ len ≤ 512 B`（旧＝163 B） | 直接取 `len(HOLDOUT_PROBE_V2)` | 不做这条就会"探针变长 ⇒ surprise 天然变高"冒充"泛化变差" |
| **A-3 形状同类** | 新探针必须与旧探针同类（中文事实句 ＋ 一条问答对 ＋ 一条指令句），逐段写明 | 件内写死形状，不做统计检验 | 换题型＝换测的不是同一件事 |
| **A-4 零命中要重复两次** | A-1 在同机连续跑两趟，`hit_rate` 两次都 `== 0.0` | 同命令跑两次（语料 sha 两次都要进件） | 防"读到一半语料被换"——`corpus_fingerprint` 已有现成字段 |

**选择规则（预先指定，不许事后挑）**：候选**全部**过 A-1..A-4 才入件；
若多枚都过，取**字节数最接近旧探针（163 B）的那一枚**——用一条已冻的排序键选，不用主观判断选。
若**无一通过** ⇒ 本件判"今天造不出零重合探针"，如实入库，并把 N3 甲的前置退回 owner（**不许放宽 A-1 凑过**）。

## 2. 落地形状（加新列，旧列一字不动）

- 新增常量 `HOLDOUT_PROBE_V2`，与 `HOLDOUT_PROBE` 并存；`_flush` 的进度行**新增** `holdout_surprise_v2`＝
  `model.score_bytes(HOLDOUT_PROBE_V2)["mean_surprise"]`，`holdout_surprise`（旧列）取法与值**不变**。
- **面内自述两把尺同时在场**：进度/exit 件里新增
  `probe_v2_disjointness`（＝A-1 的读数：窗口数、命中数、hit_rate、`window_bytes=24`、语料 sha）
  与 `probe_v1_disjointness`（旧探针的同一读数，`hit_rate=0.142857` 那条）⇒
  **每一张未来进度件自带 G49 限定**，不再靠引用它的人记得加脚注。
- **代价说清**：每次 `_flush` 多一遍 `score_bytes` ⇒ 周期收尾的墙钟上升。这与既有那条纪律不冲突
  （`--progress-every 200000` 的跑法下只有收尾那一格付这个钱），但**必须报实测差**（新旧两臂同参对照的 `elapsed_seconds`）。
- **会被现有守卫拦住的一条**：`test_periodic_lines_keep_their_old_shape` 钉着进度行的键集。
  本件**故意**放宽它一次——只把新键 `holdout_surprise_v2` 加进允许集，**且保留它"未知键必须红"的方向**
  （放宽与保留要同时测：造一枚带野键 `bogus_key` 的行，要求它仍红）。
  这条改的是"钉键集"的仪器，不是判据；改之前先跑一次让它**真红**，红过才算知道自己在动什么。

## 3. 守卫（四条，任一不符即整件不结项）

- **G-N5-1 旧列逐位不变**：同参两臂（加 V2 前／加 V2 后）的进度行里，**除** `holdout_surprise_v2`、`elapsed_seconds`
  之外所有键必须逐位同（含 `online_accuracy`、`mean_surprise`、`holdout_surprise`、`ticks`、退出记账四键）——
  这条防的是"多打一遍分把 RNG 流或情节计数带偏"，是本件唯一会**改变模型可见状态**的动作（`score_bytes` 应当只读）。
- **G-N5-2 打分器只读**：`score_bytes` 调用前后取一次权重摘要（现成的 `content_digest` 那一套），必须逐位同；
  不同 ⇒ 说明它不是只读探针，**整件停下回 owner**（不许"那就顺便接受它会影响权重"）。
- **G-N5-3 验收仪能为假**：A-1 对旧探针必须报 5 命中（已在库实测），对新候选报 0 ⇒ 同一台仪在同一件里给出一正一反。
- **G-N5-4 不动产品件**：一切验证跑都写 `output/`，且**显式给 `--progress`**
  （DEBT-G50：冒烟的默认 progress 落点会覆写 `reports/` 里被文档锚定的件）。

## 4. 预算（零算力报价，除两次语料扫描）

| 项 | 值 | 依据 |
|---|---|---|
| 候选撰写 | 3 枚（同类形状、不同长度：≈160 B／≈230 B／≈320 B），全部由本件自写并披露 | §1 的选择规则需要候选集 |
| 语料扫描 | 每候选每趟一次 108 MB 流式扫（本机对旧探针那趟是秒级完成），上限＝**3 枚候选 × 2 趟 ＝ 6 次扫描** | `_disjointness` 已跑通 |
| 验证跑 | 1 支 4,000 符号（出厂链，≈46 秒）只为看新列在场＋G-N5-1/2 的逐位对照 | §5quater 同底 |
| 磁盘 | 读数件若干枚（KB 级）＋验证跑一档（≈14.7 MB） | 在库先例 |
| 判据级 | 不重跑；机械修复 1 次仅限仪器 | 既有纪律 |

## 6. 本件不做什么

不改旧常量、不删旧列、不重算任何历史 `holdout_surprise` 读数（那些数连同 0.143 的污染率一起留在原地）；
不做"更短的窗口重合检验"之类的口径扩张（A-1 是 24 字节**窗口级**的声明，不是"逐字符零重合"的声明——
把这句写清是为了不让人以后拿它当更强的结论引用）；不动 `sleep_pass`、不动生长阈值、不动装配旗标。
