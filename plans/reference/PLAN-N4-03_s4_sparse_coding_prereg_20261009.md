前置事实：H-N4a 已在真材料上成立（`wrong_top1_rate=0.06`，近邻干扰查询，`ruler_usable=true`，㊵-575/577）

## 0. 痛点与假设

* **痛点**（H-N4a，已在真材料上成立）：现行 `EpisodicMemoryStore` 用**稠密余弦**检索——相似经历的 cue 向量互相干扰，近邻扰动查询下 6% 的 top-1 取错（0.06 ∈ (0,1)，有动态范围 ⇒ 可测）。
* **S4 假设（H-N4b）**：写入端对 cue 做**稀疏编码**（脑参照＝齿状回的模式分离：相似输入映射为更少重叠的稀疏码）后，近邻干扰查询的 `wrong_top1_rate` 相对稠密基线**显著下降**，且非干扰查询的正确率不降。
* **反向**（H-N4b-）：稀疏编码不降低干扰错误率，或降低的同时伤害非干扰查询 ⇒ S4 对本母量无收益，登记负结果。

## 1. S4 编码设计（冻）

| 项 | 冻结内容 |
| --- | --- |
| 变换 | `cue' = WTA(RP(cue))`：`RP`＝固定随机投影 `d_in=32 → d_out=256`（矩阵由 `seed=20260822` 现数生成，入档钉死）；`WTA`＝保留 top-`k=16` 个分量的符号与幅值、其余置 0（k-sparse，保留系数 16/256＝6.25% 稀疏度，脑参照齿状回的稀疏比） |
| 应用点 | **写入与检索同变换**：store.write 前对 `record.cue` 做 `cue'`；retrieve 的查询向量同样 `cue'`——变换对称是余弦检索不变量的前提 |
| 实施层 | **面仪器层**（`measure_taiji_n4_addressing_surface.py` 加 `--cue-encoding sparse` 旗标，默认 `dense` 逐位不变）——不在产品 `EpisodicMemoryStore` 里改排序语义（N4-01 §2"不改 retrieve 的排序语义"边界沿用）；产品级 S4 实现是后继格 |
| 对照臂 | **稠密基线**＝已入库的同跑配对读数（`wrong_top1_rate=0.06`，`reports/taiji_n4_addressing_n2c1_20261009.json`，材料 sha `44dd189f…` 钉死）——S4 臂用**同一份 materials/queries**（sha 复核），只变换编码 |

## 2. 判据（先冻）

* **J-S4-1（干扰改善）**＝干扰敏感查询子集（`expected_memory_id` 的近邻条目存在于库中的查询）上，`wrong_top1_rate(S4) < wrong_top1_rate(dense) − dense 面自身噪声带（0.15）`；
* **J-S4-2（无伤害）**＝非干扰查询上 `wrong_top1_rate(S4) ≤ wrong_top1_rate(dense) + 0.02`；
* **J-S4-3（尺活着）**＝`ruler_usable=true` 且 S4 面的 `wrong_top1_rate ∈ (0.00, 1.00)`；
* **出口（三写法互斥）**：①三条全达 ⇒ "S4 稀疏编码在真材料干扰查询上有可检收益"；②J-S4-1 不达 ⇒ "稀疏编码对本母量无收益"，登记负结果；③J-S4-3 不达 ⇒ 整件不判。

## 2b. J-S4-2 在本材料上的操作化（诚实披露）

已入库的 100 条查询**全部**是近邻干扰查询（写入时按"末位近邻替换"构造）⇒ 本材料不存在"非干扰查询"子集，J-S4-2 退化为：**精确 cue 查询**（未扰动原件）上 S4 变换不得把 top-1 从正确变为错误——这由余弦检索的自匹配性质近乎恒真，**只作为无害性冒烟**，不作为收益证据；收益证据**只**来自 J-S4-1 的干扰子集对比。若下一批材料引入真正的非干扰查询子集（例如与所有 stored cue 正交的新题），J-S4-2 恢复独立判据地位。

## 3. 守卫（先冻）

* G-S4a：`--cue-encoding` 默认 `dense` ⇒ 面件输出与已入库基线**逐位同**（sha 复核）；
* G-S4b：投影矩阵由 `seed=20260822` 现数 ⇒ 两次构造逐位同（矩阵入档钉死）；
* G-S4c：WTA 后每行非零分量恰 `k=16`（全零行单列披露，不许静默）；
* G-S4d：S4 臂的 `materials_sha256` 必须与稠密基线**相同**（同一份材料，只换编码）。
