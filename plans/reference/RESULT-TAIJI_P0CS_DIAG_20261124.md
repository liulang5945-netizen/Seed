# 结果卡：P0-CS 单位级并行队列（**负结果**：训练后再生长会破坏旧规则 M，0.547）

## 1. 设计

在 M（规则 R0，96 单元）学成后：
1. **生长新队列 B（96→120）**，冻结旧队列（mask 0:96），只训 B 参数；
2. 新建 head_b 只读 B 队列特征（96:120），仅凭二值奖励适应规则 R1；
3. 测：R0（旧头读 A 队列 72:96）、R1（新头读 B 队列）、**lesion 分离**：休眠 B 应只掉 R1、休眠 A 应只掉 R0。

## 3. 判读（重要负结果）

1. **训练后再生长会破坏旧能力**：M 从 1.000 掉到 **0.547** —— 新增 B 队列经跨组连接**反馈进 A 队列的状态演化**，A 队列特征分布改变，旧读出头失配。⇒ **生长不是免费的**：结构新增会扰动既有队列的持续活动状态。
2. 因此本卡的「单位级并行」不成立：R0 被破坏、R1 也无法适应（特征/读出都被扰动，监督上界也只有 0.52）。
3. 对照：P0-CR 的并行头在**不生长**时成功（0.99/1.000）；P0-CA 的多能力在**先生长再训练**时成功。⇒ 正确顺序是「**先规划生长，再共同训练**」，不能「先学后生长」；若必须后生长，需要**隔离新队列的反向影响**（单向边/冻结旧队列输入）或**重校准旧读出**。
4. lesion 分离形式上成立（B 影响 R1 不影响 R0），但两能力均在随机水平，不能算功能证据。

## 4. 下一轮

1. **P0-CT**：修正设计——训练前先长到 120，令 A/B 两队列分别承载 R0/R1（各自由其专属读出与专属输入连接），验证 lesion 分离在**高准确率**下成立；
2. 或生长时**阻断新队列→旧队列**的反向边（定向连接），保护旧队列状态；
3. 记录「生长扰动」为新机制项：后生长需要重校准（用旧数据微调旧读出）并测量代价。
