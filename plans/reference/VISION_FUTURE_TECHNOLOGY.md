## 1. 问题定义与不可变原则

目标不是“更像大脑的模块集合”，而是能理解输入、维持目标、检索经历、预测后果、生成回答/行动，并在新经历后改善行为的持续系统。架构优劣必须由整模型能力、适应、保持和成本共同判断。

| 现有证据或风险 | 能说明什么 | 不能直接推出什么 | 候选响应 |
|---|---|---|---|
| c 系列、B1 标定发生画像/特征秩塌缩 | 特定池化表示丢失任务差异 | 所有 fabric/局部学习必然失败 | 条件化表示、共享可消费特征与目标一致 |
| region 使用逐步递推与原地状态更新 | 当前实现有跨步依赖和训练接入成本 | 任意递推都不可并行 | 显式函数式状态与独立序列批处理 |
| 慢状态、检索、长期信用在旧 vision 混写 | 三种设计问题需要拆开 | 加慢层即可恢复长程推理 | 独立测信息存留、可读出性、可学习性 |
| 当前多项成果是实验器或局部学习器 | 局部证据真实但不等于统一模型能力 | 没有任何模型存在，或已经能对话 | 清点实际加载 bundle，做原始输出与整模型评价 |
| 多模块学习目标/表示可能不一致 | 是需验证的系统风险 | 已证明所有失败均由表示引起 | 端到端链＋逐接口消融 |
| 运行适应可能破坏发展训练成果 | 需预防遗忘和更新冲突 | 双学习平面必然不可行 | 分状态与参数，联合评估适应后能力 |

不变量：Taiji 拥有认知参数、状态、记忆、目标和决策；Seed 执行权限与外部动作；实际经历与想象分源；变化可保存、恢复、审计、保持与回滚。外部模型不得暗中决定 Taiji 回答或行为。

可替换项：具体神经元方程、固定 τ、固定专家分工、单一局部更新实现、固定 fan-in 与同步调度。旧内核的位置由比较决定，不能预设必须永远承担全部认知，也不能预设新内核必胜。

## 2. 架构整体与现有资产定位

整体计算链：观察编码 → 持续状态/工作空间 ↔ 记忆 → 候选生成 → 后果预测/选择 → 表达或行动 → 真实反馈。
发展训练沿可训练部分传递误差；运行时按批准规则更新状态与快速适应，长期参数由巩固门管理。

| 层 | 输入与输出 | 所有者 | 复用/改造 |
|---|---|---|---|
| 器官边界 | 原始文本/工具/感知 → 带来源事件 | Taiji 输入接口，宿主忠实采集 | 复用 provenance、权限、精确原始引用 |
| 共享核心 | 事件＋目标＋历史状态 → 情境和对象表示 | Taiji | 新核心候选与现有路径并列比较 |
| 记忆 | 查询/写入 → 检索内容、置信度、来源 | Taiji-owned 内容选择 | 复用存储合同，不把外部索引当隐藏认知 |
| 世界模型/选择 | 状态＋动作 → 预测结果；候选 → 选择 | Taiji | 联合训练候选，真实执行独立评分 |
| 内容/语言 | 内容约束＋状态 → 回答 token/byte | Taiji 或明示外部表达器 | 原生生成与外部表达成绩严格分开 |
| 执行边界 | ActionIntent → 实际 outcome | Seed | 复用预览、授权、事务、undo |
| 训练/治理 | 经历＋父状态 → 候选更新 | 训练工具计算，Taiji 持有成果 | 改动现行禁令前必须评审 |

一个模型可以是有版本约束的 checkpoint bundle，不要求只有一个文件。但每个输入到输出必须能追踪到实际加载的模块，不能只列仓库有哪些类。

## 3. 输入、表示与工作空间

### 3.1 表示单位

文本保留 byte/token 无损边界，认知计算可按片段/事件更新；结构化观察编码对象属性与关系，不把 task_id、模板编号或评估答案作为语义输入。第一原型可用受控文本与结构化观察，但须披露这不证明开放自然语言理解。

精确内容采用“连续表示＋原始引用”。引用只允许读取当时可见的数据；模型负责选择对象与内容，读取器不能按隐藏答案补全参数。

### 3.1b 表示单位演进：脑式概念聚类（token 化线，`deferred`）

**设想与归因边界**：在线神经聚类可作为概念单元候选，单元 = `{prototype 向量, 关联强度, count, 起源 evidence_ids}`，可审计溯源。历史长距probe失败及D3–D5结果并未独立证明字节粒度是唯一根因；序列长度、绑定、覆盖和信用路径仍需区分。聚类不是静态分词的已证替代，更不等于语义已经形成。

**当前定位**：保留为未采用候选；是否进入局部表示比较由当前R2裁决决定，不以“字节必然够用”或“字节必然无效”预先裁决。P4特定模型扩容无效只能限制该条件下的容量解释，不能禁止新的表示/容量联合设计。字节、固定自有分片、可学习概念单元及精确引用的选择见§18.3、§19.2。

**三锚点顺序（侵入面递增，各自带 Gate）**：
1. 读出/预测侧（最先，最小）：F1 / ResponsePlanReadout 从"逐字节"升为"逐概念单元"，与字节读出**双通道并存**，相关旧能力按新包事先冻结的保持界验收；
2. 记忆事件粒度上移：EpisodicField 绑定"概念三元组"而非字节三元组；
3. 输入侧概念受体（最后，最重）：ByteSensor 257 受体 → 概念受体群；连锁推翻 checkpoint digest/审计，**不作为先验目标**。

**触发条件**：当前包出现可测的长度/组合/计算瓶颈，拟议表示比较能改变设计决定，且范围、兼容性和累计预算获准。无需等M8，也无需先证明唯一根因；只读统计能支持提出假设，不能独自证明训练后收益。新词表/聚类若会更新，须版本化原文到单位的映射、旧记忆重编码和失效规则，不能让同一ID悄悄改变含义。

**若重开时的候选形态**：在线聚类 → 高频锚冻结 / 长尾可塑；聚类熵可辅助提出初始容量，最终由任务质量—成本曲线和预算决定，不承诺熵值能唯一确定容量。扩展需有容量解释及对照，不能用扩容代替表示/更新/数据排查；P4保持资产可按适用范围复用，不强制所有新模型沿用同一投影求解器。验收包括预先冻结的新旧能力保持界、锚与编码映射恢复、扩容事件可审计；历史实验原门不追改。

### 3.2 状态规格

B 为独立 episode 批数，D 为宽度，K 为槽数，R 为头数。以下形状是接口候选，数值由标定确定。它们是状态选项而非全部候选的强制清单；例如方案C（§15.5）可以先不启用A/φ，方案B（§15.4）可以使用对象图替代固定槽阵列。

| 状态 | 形式 | 更新/保存要求 |
|---|---|---|
| θ 基础参数 | encoder、递推、读写投影、后果/选择/语言头 | 发展训练及受控巩固，版本化 |
| h 多尺度状态 | 每尺度 [B,D_s] | 每条流独立，显式 reset/时间差，进入 checkpoint |
| w 工作空间 | [B,K,D]＋mask＋对象引用 | 目标、待验证条件、近期推理变量；有界淘汰 |
| A 关联记忆 | [B,R,d_k,d_v]＋置信/衰减状态 | episode/会话隔离，定向更新与撤销 |
| E 情景存储 | 观察—动作—结果事件、表示、来源 | 容量/保留/删除规则可审计，索引与内容摘要一致 |
| φ 快速参数 | 受限读出或低秩残差候选 | 与 θ 分开；可关闭，第一版不必启用 |
| 运行元信息 | RNG、时间、预算、游标、依赖/动作引用 | 恢复后影响行为的内容均保存或明确外部依赖 |

### 3.3 槽与路由

槽表示对象或当前待解变量，不先永久指定“数学槽”“代码槽”。写入依据相关性、冲突与预算，读取采用内容寻址；不足时拒绝或淘汰并记录。验收包括对象重命名、属性交换、干扰对象与槽占满，不仅测序列准确率。

## 4. 多时间尺度状态与信用分配

时间状态解决“保留什么”；检索解决“如何取回”；信用解决“失败应改变哪些计算”。三个目标分开。

候选更新：
`g_t = sigmoid(W_g x_t + U_g h_(t-1) + b_g)`
`h_t = g_t ⊙ h_(t-1) + (1-g_t) ⊙ candidate(x_t,h_(t-1))`。
多尺度可以由不同保留先验/更新频率产生，而不把层级角色写死。固定 τ 作为对照，离散衰减统一使用 `exp(-Δt/τ)`；`1-Δt/τ` 仅为有适用条件的近似，不能与指数式混作同一合同。

含状态依赖门的更新未必可 scan。若采用输入依赖的仿射递推，则另验证可组合性和数值一致；不为了并行假装两种模型数学相同。

验收拆分：距离变化下的信息读出；干扰写入后的检索；通过早期表示学习改善延迟任务；相同训练预算的旧任务保持。单个 distance=32 阈值不作为整个架构的终局门。

## 5. 三类记忆及生命周期

### 5.1 职责

循环状态维持当前情境；关联记忆保存快速可更新映射；情景存储保存可追溯精确经历。语义能力主要由跨经历训练/巩固形成，程序技能是可执行策略，不能把检索到一条历史答案当作理解。

### 5.2 关联记忆候选

以单头简化式说明：
`A_prior = α_t A_(t-1)`
`e_t = v_t - A_prior k_t`
`A_t = A_prior + β_t e_t k_t^T`
`r_t = A_t q_t`。
实际实现须冻结向量方向、归一化、写前/写后读、门的范围与梯度边界；不能照抄示意式就认为稳定。α 控制保留，β 控制定向修正，相关性冲突仍可能导致干扰。

门控遗忘和 delta 定向更新、并行训练的参考为 [Gated DeltaNet](https://arxiv.org/abs/2412.06464)。这只是机制依据，不继承论文性能，也不强制采用完整模型。

### 5.3 写入与巩固

真实 outcome 可写 E；A 写入需来源/预算与置信检查；φ 只接受批准的适应目标。过期、错误和重复经历有撤销/去重规则。E 删除与 θ 中已巩固知识删除不是同一操作，不能承诺自动遗忘。

测试包含覆盖更新、矛盾事实、重复输入、噪声、容量饱和、reset 后不跨会话泄漏，以及移除 A/E/φ 后能力变化。仅增加存储量不算结构成长。

## 6. 世界模型、规划与行动

世界模型输入当前表示与动作，预测状态变化、失败/终止、目标满足与不确定性。对象绑定和动作参数属于模型能力的一部分；初期允许规则绑定来隔离测试，但须单列责任。

若选择方案D（§15.6），首个行动原型采用短程展开→执行一步→重新观察，不先构建昂贵长树搜索。选择效用为任务收益、风险、成本的冻结组合；因果interaction与可部署策略收益分别报告。想象成功不能写成真实执行成功。

在未知状态或高不确定性下，选择求助、探测或停止；不靠世界模型的过度自信绕过宿主权限。要测试“预测很高、真实失败”的模型利用漏洞，增加执行校准而非继续扩大想象长度。

接口候选：
- observe(observation,state) → updated_state；
- propose(goal,state,budget) → candidates；
- feedback(real_outcome,state) → state/update_record；
- snapshot/restore → 完整继续能力。
训练可提供 forward_sequence，但不能拥有推理时不可见的 oracle 输入。

## 7. 语言理解与原生生成是核心能力，不是最后加的外壳

用户需要与模型真实对话、测试基本问题；组合排序、动作 ID、模板化日志不能替代。首个整模型候选必须明确语言入口、内容决策、实际解码器及其 checkpoint。

### 7.1 回答计算链

问题编码→当前会话和可见记忆→内容选择/必要检索或计算→表达解码→回答与来源记录。生成头通过 Taiji-owned 内容/状态接收条件；格式检查可拒绝错误输出，不能把参考答案重新写成“模型答案”。

允许借用成熟分词/优化工具不等于允许外部模型代答。若外部表达器把结构化决定转成自然语言，只能称“Taiji 决策＋外部表达”；原生语言评价必须关闭它。外部编码器同样披露，不把“无外部解码”写成“无外部依赖”。

### 7.2 训练目标与边界

基础目标候选：语言序列建模、问答/指令、给定材料的证据回答、对话约束保持；与动作/世界预测共用或分头表示需要对照。训练语料须有来源、去重与新测试隔离，不先要求掌握全部常识。

原型优先短回答的相关性、正确性、上下文和不知道时拒答，而不是长篇流畅度。知识未知、理解失败、检索错误、推理错误和表达错误分开统计。算术使用计算工具时明确标注辅助，不计为无工具内生算术。

### 7.3 H3.7 分解式回答工作空间候选

R2-H3.5/H3.6 已证明“一个静态 plan 向量＋逐 byte 局部更新”没有形成稳定的未见回答迁移。当时进入隔离候选的方向是 factorized response workspace：prefix native state 在 assistant boundary 产生 4 个有序 plan slots，renderer 按已生成 byte 的固定 phase 消费当前 slot，同时保留少量 slot0 的全局回答结构信号。每个 byte 的 predictive error 通过 renderer 的 backprojection 和 conditioned tanh 的局部导数更新 `plan_bridge`，再以固定较小比例更新当前槽的 planner rows。

该候选仍保持原生 byte renderer、UTF-8/end-marker、Taiji-owned checkpoint 和运行期不读 task/family/split/reference 的边界。计划目标是训练期由 response 的固定 UTF-8-safe chunk 生成的 train-bound count-sketch，仅作为监督坐标，不是运行时答案或外部语义标签。总计划宽度、slot 数、phase stride、credit 规则、保存恢复和停止门由[H3.7合同](M5_R2_H3_7_FACTORIZED_RESPONSE_WORKSPACE_CONTRACT_20260917.md)冻结；它是 VISION 的可证伪原型，不是架构采用或 L2 能力结论。

H3.7 已按冻结合同完成三 seed matched dev、三组 treatment 消融、aggregate和有界只读归因审计，但判定为 `stopped_before_final`：control/treatment 的 dev sequence 均为 `0.25/0.25/0.25`，exact 与 required-term coverage 均为0，seed `20260918` 的 treatment boundary 相对 control 从1.0降为0.875；审计显示target有弱且不均匀的dev对齐，phase概率面确实变化，但workspace没有转化为可迁移内容，bridge/slot-credit也没有撤销真实treatment收益。该候选保留为已实现的失败证据，不进入默认 Taiji 架构、不读取 final、不追加同质训练；后续可用target、phase、credit、renderer、prefix representation与capacity/data作归因维度，但旧顺序不是永久前置；新方案按最新证据选择判别点，并独立登记合同与复审。

### 7.4 H3.8 联合序列信用候选（历史方案，已停止投入）

2026-09-17 补充复审：合成测试复现 H3.7 字符安全 target chunk 与固定 byte phase 错位，以及拟合 scalar 被逐槽归一化抵消。旧 cosine/phase 审计只支持接口相关性，不足以证明目标可学、阶段对齐或完整梯度正确；负结果不应泛化为工作空间架构无效。

当时方案为可训练 prefix 因果编码器产生内容工作空间，循环 byte renderer 根据状态寻址，真实下一 byte 序列损失联合训练三者；不再依赖哈希内容监督和固定 phase。历史计算图与合同见[H3.8执行复审](M5_R2_H3_8_SEQUENCE_CREDIT_REVIEW_20260917.md)。后继v1/v2均已按冻结门停止投入，不能继续标“待采用”或把重新接联合梯度当新解法；结果边界见[结果总览](PROJECT_RESULTS_AND_CONCLUSIONS_20260917.md)。本轮§8的新设计不恢复该架构族训练。

### 7.5 否决信号

固定字符串也能达到同分、改问法即失效、上下文被忽略、缺权重仍有相同回答、外部 provider 禁用后失语，都必须改变能力声明或记录为失败；不能仅靠 UI 效果通过。

## 8. 发展训练、在线适应与巩固

### 8.1 训练范围

发展训练可联合优化 θ 中表示、状态、后果与选择/生成头。现有验证脚本/测试已允许backward，旧“自动微分禁令仍有效”不再适用，见[架构§6.1](../active/TAIJI_NATIVE_ARCHITECTURE_V1.md)。新候选仍需隔离、恢复、所有权与预算合同；允许一种训练算法不代表批准默认迁移，不能通过移动文件隐藏第二认知栈。

自动微分只计算导数：若损失只接最后读出，早期信用仍无改进。先列完整计算图、stop-gradient 和离散操作边界。对真实文件动作不可直接反传，用实际轨迹监督或明确策略估计。

### 8.2 让“适应能力”进入发展训练

采样训练任务族→支持经历→按运行规则更新 A/φ→查询经历评分→据适应后表现更新 θ/适应机制。最终测试任务族不参与选择；训练内 support/query 划分不等于最终 holdout。

目标示意为预测损失＋回答/行动损失＋适应后任务损失＋保持/资源项。各项尺度、权重和数据比例开发集校准后冻结，不能用大量语言样本淹没行动学习，或只奖励回答长度。

关联写入不等于参数学习；φ 学习不等于长期巩固。第一版可以只验证记忆适应，但必须写清未验证持续参数学习。

### 8.3 运行期与长期写入

θ 默认不随每句用户输入更新。h/w 维持上下文，E/A 保存/修正经历；φ 如启用只在有限范围适应。积累可靠经验后形成候选巩固版本，在旧任务与新任务上验收后替换，不覆盖 parent。

惊讶度高可能是噪声、不可学环境或攻击，不等于应强化记忆。巩固权重结合来源、可预测性、重放收益、旧能力风险；固定强度与调制方案作同预算对照。必要时退回 parent，并区分恢复参数与撤销外部副作用。

### 8.4 能力形成：先定义学习问题，不从模块名推导能力

本轮用户追问的核心是：**能力如何从经验和优化中形成，而不仅是模块怎样相连。** 本节是推荐的研究设计，不是已验证的充分条件或实施授权。

能力至少涉及五件不同的事：表示能区分任务相关状态；训练经历能识别正确规律；误差信号能改变负责的参数；运行时会使用学到的机制；新经验带来可保持的改进。门禁只能检查这些是否发生，不能代替形成机制。

已知证据与未决解释：

- H3.8的`SequenceWorkspaceTrainer.train_step`已有全序列交叉熵和backward，默认训练图未截断prefix信用；v1/v2仍未过能力门。因此“改为联合反传”不是单独充分解法。
- [P3b-v2原始报告](../../reports/p3b_v2_pilot_20260917.json)记录dev teacher-forced accuracy从0到0.1968898、surprise从5.5984298到4.5277424，但自由生成exact为0/20。这证明报告所测的局部条件预测改善，不等于问答或完整行为改善；teacher forcing本身也不能因此判为错误训练方法。
- 同一报告的training.records只有12个不同episode、重复两轮，覆盖fact与negation；语料40个train episode不等于本pilot实际训练了40个。`response_plan_target_geometry`与`response_plan_target.geometry`均为`h3_7_factorized_response_chunks`，与[结案文字](M5_P3B_V2_PILOT_CLOSURE_20260917.md)的byte-aligned叙述不一致。这限制了反假设和架构归因；不覆盖原报告、不补发指定变体失败结论。
- 因而当前可支持“该配置/预算未形成正确生成”；尚不能分离表示、目标、覆盖、容量、优化和自由运行误差各自贡献，更不能证明所有局部学习或工作空间架构不可行。

### 8.5 共同学习框架：任务驱动的联合发展训练

保留Taiji所有权、持续状态与快慢更新边界；允许训练方法和必要的核心表示改变。不是给所有已有模块各加一个loss，而是让任务证据塑造实际被消费的表示。本节说明共用原则，不指定唯一核心；下述完整行动链属于方案D（§15.6），其他候选不必先实现世界模型才能验证语言。

候选计算关系（符号不是已实现接口）：

- b_t = Fθ(b_(t-1), observation_t, action_(t-1), read(M_t, query_t))：保存当前目标、证据、对象关系和不确定性。
- Pθ(b_t, action)预测任务相关的后状态、成本、失败与目标进展；不要求先重建整个世界的所有细节。
- πθ、Vθ据任务信念提出行动、估计后续价值；先用有限搜索/短程预测选择并执行一步，再观察真实结果。
- Dθ依据同一任务信念与意图产生语言；语言训练从一开始存在，不等工件执行成功后才补外壳。

共同表示不是所有头无差别共享同一个向量：精确对象/来源引用与可学习特征并存。世界状态保留可供其他目标复用的信息，目标条件化读取聚焦当前任务，避免只学一项奖励就丢掉其他事实。

| 要形成的能力 | 提供的学习经历/信号 | 必须被塑造的机制 | 仅看什么会误判 |
|---|---|---|---|
| 任务表征与对象/关系 | 重命名、关系交换、相同表面不同后果、不同表面相同规则；观察/转移与任务目标 | 编码器、持续状态更新、对象/关系绑定；必要的重建/对比约束防信息丢失或塌缩 | 向量非零、probe能读出、训练重建低损失 |
| 有用记忆 | 延迟信息、干扰、纠错、跨episode同规则/变规则；后续任务损失 | 查询/读取及需要时的写入策略，持续状态保留；精确存储可先用公开工程规则 | 记录数量、检索命中率、脚本强制调用 |
| 可用于决策的世界预测 | 相似前状态下不同动作的真实转移，成功与失败覆盖，多步后果 | 动作条件动力学、后状态/风险/进展头与其输入表示 | 只预测向量、只会常见不变状态、想象成功 |
| 有效选择与规划 | 合法示范/轨迹启动，随后自身执行的成功/失败；真实回报或可验证终态 | 行动提议、价值/优势估计、有关表征与模型；搜索算法本身初期可固定 | 正确计划文本、树搜索次数、只在标准轨迹上评分 |
| 原生理解与表达 | 同经历的提问/追问/改述、冲突事实、未知；完整答案及内容依据 | 输入理解、内容选择、语言生成与相关状态 | 常见字节/结束符准确率、模板可读性 |
| 快速适应 | 同任务潜规则下支持经历→更新→新查询，跨任务改变规则 | 记忆读取/更新机制、可选快参数及发展参数的可适应性 | 更新发生、旧题复述、任务ID查表 |

世界预测＋策略/价值的分工可参考[DreamerV3原论文](https://www.nature.com/articles/s41586-025-08744-2)；在学习的任务相关潜空间中规划可参考[TD-MPC2作者项目页](https://www.tdmpc2.com/)。这些工作支持设计可行性，但不是Taiji语言、持续学习或新任务必然成功的证明；不照搬全部模型。

### 8.6 信用如何真正改变能力

发展期的主目标是未见实例上的真实任务损失；训练可采用语言/行动示范、真实转移预测、价值/策略及记忆检索等可优化代理，保持与成本作为约束。不能把若干loss相加就称问题解决：必须登记每个目标的参数接收者、时间跨度、权重尺度和运行时用途。

1. **跨时间信用**：先在可承受的短任务上完整展开，确保末端内容/行动错误能影响早期编码、状态保留和可微记忆读取；长任务再选择截断与信用近似，并测延迟退化。不靠先把旧prefix永久冻结来保护形式上的原生性。
2. **离散边界**：真实工具不可反传。用真实执行的回报、转移和失败训练价值/策略或轨迹目标；不伪造环境梯度。先以合法示范与预测学习降低冷启动难度，再纳入自身策略访问的状态，减少只学标准轨迹的问题。训练期示范来源披露，运行时不带参考答案。
3. **表征锚定与损失竞争**：只拟合潜变量自一致可能塌缩，需由观测、目标相关后果或内容监督锚定，并检查区分度；多个目标会冲突，监测梯度/任务收益，必要时分头、交替或分阶段，不默认共享越多越好。
4. **自由运行是独立压力**：teacher forcing是有效基础目标，但评价必须让模型吃自己的历史输出并自行选择。若局部预测改善而完整序列/行动不改善，先区分内容错误、停止/轨迹偏移、覆盖与容量；仅有证据时再加入序列/轨迹级优化，不盲换采样技巧。
5. **可用不等于被使用**：梯度存在、状态可读出、禁用后张量变化都只是链路证据。只有正常系统优于公平简单策略，且语义有效的替换/消融撤销相应行为收益，才说明机制承担任务作用。简单模型更好时保留该结果，不人为封死基线以制造需要记忆/规划的结论。

规划无需每个步骤都“神经化”：可学习的是状态、后果模型、价值和候选先验，搜索可暂用确定算法。先证明这些学习成果让规划更好，再研究自适应计算预算，避免将自主性提前当成学习基础能力的门槛。

### 8.7 经历分布与课程：不是把80行叫作发展环境

推荐一个可程序化变化的任务族，连续加入难度，而不是同时开多个能力项目：可见事实/单步结果→短延迟和干扰→多步选择/失败修复→未见组合→规则变化后的支持/查询适应。后继阶段保留混合旧课程，避免只学新层后丢失旧层。

样本单位是对象/关系/规则/目标组合，而不仅是文本行。更换名字应保留策略，关键条件或动作后果变化应改变策略；未知与冲突时应有合法求证/拒绝。行动后果差异应来自允许的环境干预数据，不从普通相关性中虚构因果标签。

每次同时报告语料可用量、实际唯一训练episode/任务族、实际更新数、序列长度和独立测试覆盖；不拿未被采样的行数解释学习。容量、数据多样性与计算预算做预先有限的标定，检验是否能拟合训练微任务并迁移，不能以tiny smoke的0分宣判整类架构，也不能没有新假设就无限加预算。

语言既有任务相关课程，也需要与拟声明语言范围匹配的文本/对话数据。合成世界可以检验机制，不能自动产生常识、广泛词义或开放域对话；其收益不替代原生语言验收。mini后置不等于可忽略自由输出。

### 8.8 持续适应必须在发展期被训练和测量

对每个训练任务τ，先给支持经历Sτ，用将来真实运行的更新规则U改变记忆/快状态；再在不提供答案的新查询Qτ上计算任务损失，用适应后表现训练共享参数与可训练更新机制。符号示意：

    minimize_θ E_τ [ L_query(θ, Uθ(initial_state, Sτ), Qτ) ]
    subject to old_task_retention, update_budget, provenance_and_safety

查询标签只用于训练期外层目标，不允许进入待评分查询的运行时更新；最终任务族与模型选择隔离。规则在不同任务间变化，防止慢参数直接背出查询答案而绕过适应；采用无支持/打乱支持/冻结更新对照。

这是“学习后更会解决新问题”的训练原则，可参考[MAML原论文](https://proceedings.mlr.press/v70/finn17a.html)，不是强制实现MAML或高成本二阶梯度。运行期可先采用可控关联记忆更新，再在确有收益时开放快参数；慢参数通过可靠经历重放和旧任务保持准入。不能先任意在线写权重，再希望验收把遗忘问题补好。

### 8.9 最小任务族的定位：验证方法，不是另一条主线

**“早期条件→干扰→改变行动后果→两步选择→新问题回答”任务族是待评审的联合能力验证备选**，不是当前唯一下一步。当前工作主线仍是R2原生语言能力，执行入口只看03。用户指出路线冲突后，撤回把本方案直接升格为主线的表述；它不替代R2、不成为前置、不自动获得预算。

若R2候选需要小型学习实验，优先在问题/材料/上下文→自由回答范围内设计，且结果必须直接决定该候选采用或否决；这属于主线方法。若引入Workbench新环境、行动规划或支持-查询适应等额外范围，应先作为范围变更评审，不能因为模型小、任务少就声称没有换方向。未来若批准联合任务备选，再按同族课程验证；详见§8.10。

出现不能拟合训练微任务先查目标/更新/表达容量；能拟合但未见失败查覆盖、捷径和归纳偏置；预测好而自由运行失败查选择与轨迹分布；同分但更贵则不支持新增机制；适应新题却损伤旧题则查更新范围/巩固。以上是待验证分流，不从单个负结果认定唯一根因。

本节为本轮讨论提案，尚未冻结新数值、获得训练授权或改变默认核心；落实顺序只由[03](../active/roadmap/03_CURRENT_EXECUTION.md)管理。

### 8.10 联合任务验证的备选实施草案（不在当前主线）

状态：**保留的设计备选，未采用、未排期、未冻结新预算；不是R2前置或第二条执行路线。** 本段由旧03 §5移入，纠正把讨论建议直接升级为唯一下一步的问题。若未来拟采用，必须说明它怎样服务当时阶段出口，并取得明确范围批准。

**该候选内部的设计原则**：先定义可学习的任务族、训练实际覆盖、表示与目标/信用，再为它实现最小接口。不是先接齐记忆/世界/规划，再寻找能让它们学会的损失。H3.8已证明“有联合反传”不等于能力形成；新方案不能仅换名重启同族。完整学习设计、依据与假设边界记录在本文§8.4–8.9，这里不生成第二份候选架构文档。

#### 8.10.1 备选代表任务及选择依据

首选候选为**隔离Workbench内的受约束多步工件组装与修复任务族**，先缩成“早期条件—干扰—两步选择—新问题回答”的可学微任务，再增加同族难度；不是立即做聊天演示：

1. 早期给定需保留的目标/保护约束及部分环境经验，随后插入无关事件；决策时不再次免费提供全部历史答案。
2. 当前状态提供合法观察与可用操作，存在不同后果、前置条件和成本的候选路径；对象名称、关系组合和环境变化不能靠固定模板答案决定。
3. Taiji依据记忆和当前信念预测后果、选择多步路径，执行发生真实沙箱状态变化；中途可遇到新观察，必须核对旧计划是否仍有效。
4. 用独立环境检查核验终态内容、约束、成本和遗留副作用；脚本只负责环境/评分，不替Taiji选路线。
5. 将实际反馈用于下一次选择，再单独比较允许参数更新与冻结参数的表现。最终让同一bundle表达依据、结果或未知；宿主回执文字不计语言能力。

选择理由：可复用已有Workbench合同、后状态核验和规划资产，且能同时检验记忆的时间作用、世界预测的反事实作用与规划的选择作用。它不是对现有binder已具备这些能力的断言：先做消费映射，必要的最小接口补齐属于该包，跨域/多工具泛化不随之开工。

任务必须排除三种假需求：环境已重复给出全部约束却声称需要记忆；工具schema直接提供最优后果却声称学会世界模型；唯一合法动作却声称需要规划。简单策略拥有同等合法信息与预算，不能靠禁止基线读取历史人为造增益。参考计划、最优终态、隐藏环境状态仅评分使用。

## 9. 协作、专门化与结构成长

先做一个能交换表示的共享核心，技能接口统一观察/目标、动作建议、进展/失败/终止。路由决定调用和交接，真实 outcome 训练选择；模型是否协作由公平单体、固定策略和成员/连接 lesion 证明，不由群体数量证明。

只有出现可复现的干扰、能力冲突或容量不足，才比较独立专家/器官实例池。测负载、通信成本、共享表示兼容、未见组合与旧能力；专家名字不输入语义答案。

当前M4原型采用零影响候选接入主路径，先shadow学习、后贡献与保持验收、再准入；这不是全部未来架构的永久唯一方法，若替换须提供同等隔离、贡献和回退证据。与同最终容量 fixed-large、随机成长比较。剪枝需考虑因果贡献和恢复，不因低使用率直接删除关键罕见技能。该目标继续归 M4.V2，不因新核心设计而宣称完成。

## 10. 自主唤醒、睡眠、梦境和玩耍

| 行为 | 输入依据 | 实际更新 | 风险与验收 |
|---|---|---|---|
| 自主唤醒 | 校准的新颖性/失败、可学性和资源 | 选择观察、记忆、学习或求助 | 噪声不得反复唤醒；次数/预算上限；固定调度对照 |
| 睡眠巩固 | 有来源经历、干扰与保持评估 | E/A/φ 中稳定内容进入候选 θ | 新收益和旧能力同时过门，不能只测损失下降 |
| 梦境 | 世界模型与不确定性 | 想象轨迹训练候选，保留 imagined 来源 | 模型偏差/自证循环，不能伪造真实成功 |
| 玩耍 | 安全约束下的信息价值 | 主动收集真实经历 | 信息增益要校准，成本与风险有上限 |

先证明外部明确触发的学习有效，再学习调度；但“不自主”不妨碍提前评估对话和基本能力。所有行为有明确停止、恢复和用户中止渠道。

## 11. 批处理、并行与异步执行

| 方向 | 可并行部分 | 不能忽略的改变 | 入场信号 |
|---|---|---|---|
| 独立 episode micro-batch | 每条流独立 h/A，批量前向 | 聚合更新不等于逐样本在线顺序 | 实测训练计算占主要成本 |
| 仿射/特定记忆递推 scan | 满足可组合形式的序列段 | 状态依赖非线性门可能不可组合 | 数学等价＋端到端 profile |
| kernel fusion/device | 多个相邻算子 | 舍入、稀疏调度、随机数及实现风险 | profile 证明启动/搬运瓶颈 |
| 器官实例池 | 独立状态/参数链 | 协调、跨器官 credit、合并成本 | 可复现专门化收益 |
| 事件驱动异步 | 活跃区域更新 | 逻辑时间、因果排序和 checkpoint 屏障需重设计 | 同步调度确为瓶颈且契约评审通过 |

位置编码不决定是否 Transformer；“分工”不自动提高吞吐；一次多流负结果不否定独立 batch。不得引用目标活跃比例直接推导节省 88% 运行时间，也不承诺固定 2–10 倍加速。

训练吞吐与项目推进速度分开：若瓶颈是测量/集成/决策，换设备不会自动让模型能力更快形成。M8 资源与后端选择基于真实设备测试，历史 AMD/DirectML 状态不当作当前事实。

## 12. 快照、跨设备与产品接入

快照保存 θ、h/w/A、E 索引/内容摘要、φ、优化器、RNG、课程游标、schema/依赖和预算。执行中工具事务须记录独立恢复协议，加载权重不等于完成现实状态恢复。

训练前：目标可写/空间检查→零步原子保存→新进程加载→继续一步与拒绝/rollback 测试。跨设备使用预定义容差、任务等价与状态连续性，不无条件要求异硬件逐位一致。

旧权重未必能映射到新结构，不能承诺零损迁移。复用旧模型作对照与回退，复用语料/任务/宿主合同但重测能力。依次做回放、shadow、隔离执行、opt-in，再独立批准默认采用。

桌面视觉、托盘/DPI、交互延迟和 provider watchdog 属 M6；先保证显示真实模型和来源，不用界面掩盖无回答能力。跨设备和自主运行不是初次模型验收的必要条件。

## 15. 五套高上限架构方案：计算、学习、判别与代价

### 15.1 为什么需要多方案，以及哪些根因还没有确定

旧VISION的不足在于：列出了多尺度状态、记忆、世界模型、适应等组件，却容易被读成唯一组合；没有充分区分它们分别解决什么瓶颈、如何形成能力、失败后应换哪一项。本节补充的是**可竞争的完整设计假设**，不是再添加五个必做模块。

9月17日的历史依据见[设计依据复核](M5_R2_DESIGN_EVIDENCE_AUDIT_20260917.md)：672档六seed的dev exact为0.2242±0.1642（总体标准差，不是置信区间），但固定回答“未知”已可得256/672=0.3810；672行只有448个不同输入/答案对。最高模型分与固定策略相同，有限留存样例不能确定逐题行为。旧文“数据多样性正效应成立”“损失无法修复、只能改架构”均超出证据。后继D1已提供新测量协议，D2已产生新的train-only结果；其范围见§18.1，不把旧仪器缺口继续记作全部未修。

作为历史起点，[隔离核心](../../taiji/sequence_workspace.py)的H3.8版本由prefix末状态一次性产生keys/values，已有内容寻址和完整短序列反传；后继D2–D5已经增加逐位置证据、copy及相应训练设计，不能继续把H3.8的结构描述当成所有当前候选。新的设计应与指定版本比较，改变有判别价值的**表示单位、信息路径、计算过程、经历分布或学习规则**，而不是把已有机制换名。以下路线映射是设计假设，不是固定执行优先级、根因证明或能力承诺。

### 15.2 方案总览与可组合边界

| 方案 | 核心变化与能力上限假设 | 最适合解决的缺口 | 主要代价/失败风险 | 与当前R2的关系 |
|---|---|---|---|---|
| A 持续状态＋可寻址证据记忆 | 从一次压缩改为流式保存、查询和精确内容读取；兼顾持续上下文与语言 | 信息在prefix压缩中丢失、读出无法定位内容 | 检索干扰、存储成本、只会复制不会理解 | 信息访问方向的备选；A-R2示例见§16.5 |
| B 对象—事件—关系核心 | 显式可交换绑定和关系运算，语言与未来行动共享对象身份 | 会识别题型但对象、属性、否定、关系混淆 | 槽塌缩、离散绑定信用困难、固定本体限制 | 可在R2语言范围竞争，不需先建环境 |
| C 递归潜空间推理核心 | 同一参数多轮读取证据、修正候选，计算量随难度增长 | 输入信息在，但一次计算不能完成组合/推导 | 迭代无效或发散、延迟、校验器自证 | 适合已经读得对而组合失败的R2切片 |
| D 行动条件世界模型核心 | 真实转移塑造信念、后果预测、价值与策略，语言消费同一状态 | 模块未共同改善多步真实行为 | 环境样本贵、世界模型偏差、语言不自动获得 | 长期统一能力路线，不能代替当前语言主线 |
| E 元训练的快慢学习核心 | 不只训练答案，还训练“如何从支持经历更新并解决新查询” | 固定能力可用但遇新规则不能学、学习后遗忘 | 外层优化成本、泄漏、快速遗忘和污染 | 持续适应路线；不以在线更新掩盖基础语言未形成 |

A/B主要竞争表示与信息访问，C主要改变计算深度，D改变任务学习闭环，E改变适应算法；它们不是五个互斥品牌，也不是五条同时执行的主线。A+C、B+D、A+E可以成为后继组合，但须先有单项证据，再检验组合的新增收益与负迁移。不预设最终必须把五套全部堆在一起。

以下计算关系均是**Taiji定制提案**。引用论文仅支持相应机制已有研究基础，本文的组合、接口与测试设计不冒称论文原配方或已实现功能。

### 15.3 A：多尺度持续状态＋可寻址证据记忆＋原生生成

**假设与结构。** 单一prefix末状态可能过早压缩了精确实体/属性。A将输入逐位置/事件编码为`u_i`与不可变来源引用，保留短窗证据`K_i,V_i`；多尺度`h_t`处理流式背景，关联记忆`A_t`保存可更新映射，E保存允许回读的长历史。生成器每步用当前问题、h和已生成前缀重新提出查询，不仅从一个静态plan取内容：

    u_i, h_i = encode_step(x_i, h_(i-1))
    K_i, V_i, source_i = project(u_i), value(u_i), visible_ref(i)
    q_j = query(question_state, decoder_state_j, h)
    read_j = content_read(q_j, visible_KV, A, retrieved_E)
    p(y_j) = native_decode(decoder_state_j, read_j)

长上下文才需要选择性写入、遗忘和E检索；短R2实验可保留全部合法材料位置以隔离信息瓶颈。解码可比较纯生成与**模型选择**的span-copy混合：`p=π_gen p_vocab+(1-π_gen)p_copy`。复制分布仅在可见材料位置上归一化，目标字节的概率为对应位置概率之和；复制门、地址和停止由模型产生，不从答案标签推导运行时位置。引用/复制也不能处理材料中不存在的结论，必须保留原生组合生成支路。

**能力如何形成。** 从直接提取、同问不同事实、实体换名、否定/缺失、干扰延迟到未见组合逐级训练；主损失为自由回答对应的因果序列CE，沿解码→读取→位置编码/状态回传。先不用附加对比目标，以免把信息路径收益与损失变化混合。来源位置标注如需使用，只在训练集作明确辅助监督，另外标记“增加监督”效应。长程再比较完整展开与截断训练的延迟损伤。

**真正区别与上限。** H3.8所有槽从同一个末状态生成；A的证据条目来自不同输入位置，写入发生在经历过程中，回答可重新读取，精确信息不必全部压进末状态。长期上限来自可复用语义状态、持续记忆与精确引用互补，非单纯扩大slot数。

**最小判别。** 同一数据、解码器与目标下比较“末状态派生记忆”和“逐位置证据记忆”；再用可见事实替换、地址打乱、移除证据读取检验内容贡献。先不启用copy，若单纯寻址改善，再把copy作为独立变量。测未见字符串、干扰距离与不能直接复制的关系问题；基线可读取同一合法材料，不人为剥夺信息。

**否决/局限。** 只提升原文抄写、不提升对象选择/否定/组合，只能支持提取能力；同等信息的简单读出同样好，则不支持复杂持续记忆的必要性。输入被保留但读取不准，归因查询/绑定；读取正确但答案错误，归因解码/推导，不能继续堆记忆。长存储还需处理过期、冲突和检索污染。

**成本与迁移。** 短窗读取每生成步约`O(LD)`、存储`O(LD)`；矩阵关联记忆每头约`O(d_k d_v)`状态，E另计检索和容量。新格式保存位置/来源、写入顺序、h/A与索引版本；旧模型保留作锚点，不承诺旧权重直接兼容。记忆中的生成假设与真实观察分源，不能把自己的答案回写为事实。

**研究依据。** [Gated DeltaNet](https://arxiv.org/abs/2412.06464)将门控遗忘与delta定向更新结合，可参考其关联记忆机制；它不证明Taiji当前失败由记忆引起，也不授权搬入完整Transformer栈。A-R2的逐位置证据访问是本文的隔离设计，不等于复现该论文。

### 15.4 B：对象—事件—关系核心＋可学习绑定＋原生语言

**假设与结构。** 问题可能不在保留多少字节，而在无法稳定表示“谁的什么属性，在什么时间，以什么证据成立”。B把`w`改为对象/事件集合：每项包含可学习特征、临时身份、属性/否定置信、时间和来源；关系边表达依赖、同异和先后。身份由模型绑定并随观察修正，不用训练样本编号做字典：

    objects, events = bind(encoded_visible_input, prior_objects)
    relations = infer_edges(objects, events, goal)
    state' = relation_update(state, messages(relations))
    answer_state = query_objects(question, state')
    answer = native_decode(answer_state, evidence_refs)

槽可交换；持久对象身份需额外匹配机制，不能把一次Slot Attention的排列当作跨时刻身份。软绑定可微训练，硬引用只在实际选择时落地；离散选择若切断信用，应使用明确监督/估计而非假称全链可微。未知、对象冲突与属性修改保留显式状态。

**能力如何形成。** 使用对象改名、属性对调、否定范围、同名消歧、时间更新、未见关系组合；回答损失训练绑定与关系运算。训练初期可用可见材料生成的对象/关系标签辅助，但正式dev只能从文本构建，禁止测试时oracle解析。中间预测以真实属性/事件约束防塌缩；对象槽中的精确字符串仍绑定原始来源。

**真正区别与上限。** 槽不再是按答案字节切分的有序phase，而是可复用对象和事件；同一关系结构可回答不同问题，未来也可供行动参数绑定和世界预测使用。为了不把上限锁死在手写本体，关系类型允许学习，未被结构覆盖的语言保留连续残差通道，并分别测它是否绕过结构。

**最小判别。** 与等预算非结构化A/旧核心比较同一R2重命名和关系交换集合；使用gold对象状态只作诊断上界，正式结果必须用学习的binder。改变对象排列应保持语义，交换关键属性应改变回答；边/绑定干预应撤销关系题收益。不能用“结构化输入更容易”冒称文本理解提升。

**否决/局限。** gold结构有效、文本绑定失败说明瓶颈在binder，不支持完整B；只记槽序或固定类型不支持组合泛化；即使关系准确，原生语言错误仍未完成R2。结构解释易读但可能不真实，不能把可视化的图当因果证据。

**成本与迁移。** 稠密关系消息为`O(K²D)`，稀疏图约`O(|edges|D)`但有选边成本；保存对象身份、版本、关系和来源，并定义合并/拆分/失效恢复。新状态schema与旧phase槽不等价，迁移必须显式warm-start。主要风险是绑定优化与开放域扩展，不是图数据结构本身。

**研究依据。** [Slot Attention原论文](https://proceedings.neurips.cc/paper/2020/hash/8511df98c02ab60aea1b2356c013bc0f-Abstract.html)提供竞争式、可交换对象槽的机制依据，原实验主要是视觉对象发现/属性预测；本文扩展到文本、事件身份和关系推理是待验证假设，不继承其性能。

### 15.5 C：递归潜空间推理＋证据校验＋原生解码

**假设与结构。** 若关键事实已能被正确读取，困难可能是固定浅计算不足以组合它们。C让同一Taiji转移函数在输出前反复更新工作状态，每轮重新读取原始证据，而不是仅让decoder多生成几个无关字节：

    z_0 = initialize(question, visible_state)
    z_(k+1) = z_k + bounded_update(z_k, read_evidence(z_k), goal)
    score_k = verify(z_k, visible_evidence)
    answer = native_decode(z_K, evidence)

先冻结有限K，训练时混合若干展开深度；之后才研究有预算上限的停止策略。校验器只看合法证据，不能读参考答案；校验得分不作为正确性的最终裁判。模型输出的解释可单独生成，不能以好看的解释证明潜空间完成了推理。

**能力如何形成。** 训练一跳可读事实与多跳依赖、反向问法、冲突修正；末端回答损失穿过推理迭代训练更新函数。中间监督如有真实可验证的子结论可用于训练，否则不伪造“标准思维过程”。训练混合K防止只依赖固定步数，并保留简单题检查是否越想越错。

**最小判别。** 固定权重比较K=1与更多轮；另设推理计算量匹配的前馈/非共享计算对照及重复空计算对照，区分有效迭代、额外容量和多花计算。检验困难组合题是否随有限K改善、改事实能否修正结论，且读不到信息的题不会因多迭代自动变对。

**否决/局限。** 更多迭代只提高自信、不提高正确率，或收益被同计算简单模型解释，则不支持递归推理必要性；训练深度外发散时限制部署深度，不宣称无限可扩展。事实缺失不能靠“多想”补齐；应回到A/B的信息或绑定问题。

**成本与迁移。** 推理代价近似随K乘核心步成本，训练还保存展开激活；可用重计算换内存但记录额外算力。恢复须保存潜状态、迭代步、剩余预算、随机数，或明确仅支持回答边界恢复。此方案不要求先开放快参数；主要改计算图、停止合同与延迟预算。

**研究依据。** [Recurrent Depth原论文](https://arxiv.org/abs/2502.05171)研究共享递归块的潜空间计算，其验证规模为数十亿参数模型，不是小Taiji必然获益的证明。本文借用“可学习迭代深度”的原则，不按原模型实现引入被现行合同禁止的Transformer主体。

### 15.6 D：行动条件世界模型＋价值/策略＋共享语言状态

**假设与结构。** 统一认知能力需要经历真正的后果差异，而不只是文本拟合。D以部分可观察任务信念`b_t`为核心，由观察校正信念；动作条件模型预测后果与不确定性，价值/策略帮助选择，语言头描述同一信念和证据：

    b_t = posterior(b_(t-1), a_(t-1), observation_t, memory_read)
    predicted_next, reward, risk = world_model(b_t, proposed_action)
    a_t = choose(policy_candidates, short_rollouts, value, risk_budget)
    real_outcome = Seed.execute(approved_action)
    b_(t+1) = update_from_real_observation(real_outcome)

只执行一段真实动作后重新观察；任务回报来自独立环境核验，想象轨迹明确标注。表示锚定可见状态与可核验任务变量，不能只让两个潜网络彼此拟合而塌缩。

**能力如何形成。** 先以合法示范/探索轨迹学习状态和真实转移，再纳入自身策略产生的失败与修复。世界目标训练表示和转移；回报/价值目标训练选择；同经历的问答训练语言，但行动成功不代替语言成功。真实工具不可微，使用明确轨迹监督或策略估计，不伪造工具梯度；想象只作训练候选，最终收益回到真实环境确认。

**最小判别。** 在另行批准的同一真实任务族，比较无规划策略、无/打乱记忆、错误/移除世界预测、有限规划完整链；统一合法信息、行动预算与风险约束。要求记忆、预测、选择联合改善真实成功率/成本，并能在后果变化后调整。单独改善预测loss或搜索次数不算通过。

**否决/局限。** 世界模型准确而策略不受益，查候选/价值；想象成功但真实失败，查模型偏差与利用漏洞；只有规则binder提供答案时，不声称模型学会绑定。若任务根本不需要历史或多步选择，不能强行造“联合认知贡献”。

**成本与迁移。** 代价来自真实轨迹、动作分支、展开长度和策略训练；首轮控制分支与时域，失败覆盖比增加想象长度更重要。保存信念、重放来源、模型版本与未完成动作事务；权重回滚不能替代环境补偿。可能复用A/B表示，但接入需重验语言保持，不承诺自然形成通用问答。

**研究依据及主线边界。** [DreamerV3](https://arxiv.org/abs/2301.04104)提供世界模型与想象行为学习的参考；[TD-MPC2](https://arxiv.org/abs/2310.16828)提供任务相关潜空间规划参考，后者主要验证连续控制。本文是Taiji的行动条件设计，**不是立即换成强化学习主线**；§8.10的Workbench只在独立采用后提供承载。

### 15.7 E：元训练的快记忆/快参数＋受保护慢核心

**假设与结构。** 一个离线模型未必知道怎样使用运行经历改变自身。E把更新算法纳入发展训练：慢参数θ编码通用表示/技能；h/A维持上下文与关联；可选φ为受限快速残差/读出；U负责根据合法支持经历执行更新。

    state_tau = U_psi(initial_state, support_experience_tau)
    L_outer = L_query(theta, state_tau) + retention_constraint + update_cost
    deploy: update only from permitted observations or verified feedback

训练时外层目标同时塑造θ和可学习更新规则ψ；运行时查询答案不可用于回答前更新。仅更新h/A称记忆适应，更新φ才称参数适应；不能把前者成绩冒称后者。θ默认受保护，可靠经历经保持验收后才巩固。

**能力如何形成。** 每个任务先给支持经历，再测未见查询；任务间改变规则/词义映射，防慢参数背下固定答案。先检验学习型记忆写入，再考虑梯度型φ更新，比较一阶近似与穿过更新的外层信用；采用近似必须说明省略了什么。不把模型惊讶或自生成答案直接当正确监督，可信纠错与无标签自监督分开评价。

**最小判别。** 任务级隔离的support/query；同预算比较无支持、支持打乱、冻结更新、固定关联写入和候选U。测试更新一次后的新组合、规则反转、重复/恶意/过期信息及旧任务保持；同时报告适应前后，不只挑提高的任务。测试过程中的标签隔离与恢复一致必须可检查。

**否决/局限。** 只会复述支持答案，不是规则适应；知道task_id即可作答，是泄漏；新任务提高旧任务严重下降，不能宣称持续学习成立；简单A写入已足够时，不支持快参数的额外成本。基础读取/解码都没学会时，不以扩大更新自由度解决一切。

**成本与迁移。** 外层需要多个任务和内层展开，梯度/优化器/φ状态增加训练与快照成本；限制更新步数、范数、影响范围和资源，超过阈值停止/回退而非持续在线漂移。保存parent血缘、支持经历来源、更新日志、快参数优化器和回退点；删除E不等于从θ删除知识。

**研究依据。** [MAML](https://proceedings.mlr.press/v70/finn17a.html)支持以适应后损失塑造可适应参数的思路；[Titans](https://arxiv.org/abs/2501.00663)探索测试时学习的神经记忆。两者都不直接证明安全终身学习或旧知识保持。E可以采用其原则，不强制二阶MAML，也不复制Titans的完整注意力骨干。

## 16. 如何选择、组合与落地

### 16.1 共同标尺：先让方案可以被公平判别

这是未来候选的评测合同草案，不事后改写历史门。先冻结一个R2版本化评价面，再允许改变一个主设计因素：

| 项目 | 共同要求 |
|---|---|
| 输出与锚点 | 保留既有λ=0核心作历史/可复现锚点，另有固定回答、无上下文、同等合法信息的简单读取策略；统计原始自由回答及停止 |
| 数据 | 同一固定dev用于同一批候选；明确行数、唯一输入/答案、模板/来源组、实际训练覆盖；按组划分，不把重复视作独立样本 |
| 能力切片 | 提取、对象绑定、否定/未知、同开头异事实、未见字符串、未见关系组合、干扰距离；内容子集与拒答分别计分 |
| 因果压力 | 成对改变关键事实、替换检索证据、绑定/计算/更新消融；区分改变张量、改变答案、提高正确率三个层次 |
| 资源 | 数据暴露、更新数、训练token/byte数、有效参数、训练计算、推理计算/内存/延迟分账；不能等量则给成本曲线并收紧归因 |
| 不确定性 | 配对seed结果、均值/离散度/最差seed、形状宏平均；按来源组统计，不按重复行虚增把握；不在看到结果后换主要指标 |
| 泛化边界 | 确认集与设计选择隔离，旧final权限不变；合成范围的改善不等于L2/L3、开放域或默认chat能力 |
| 证据保存 | 全部逐题输出、配置/代码/语料/权重摘要、优化器/RNG/游标与恢复报告；训练前验证真实保存恢复路径 |

按证据分类退出：实现/仪器不合格→先修本包缺陷；训练微集不可拟合→优化/表示仍未分离；可拟合而公平dev无优势→本候选未获支持；仅某切片提高→限定能力结论；稳定收益且机制干预撤销收益→支持进入更大范围，不自动产品采用。每轮冻结预算上限和最大修复次数，达到上限没有新可辨识假设就结案。

### 16.2 选择不是“依次试遍”

| 有证据的失效形态 | 优先考虑 | 不应自动推导 |
|---|---|---|
| 关键材料无法从末状态恢复，逐位置证据有信息 | A | 再加全套世界模型/在线学习 |
| 能定位证据，但实体/属性/否定范围混淆 | B | 单纯扩大记忆必然有效 |
| 单步读取稳定，组合随依赖深度明显退化 | C | 让模型无限多迭代就能解决 |
| 状态与语言可用，但行动后果改变时策略不调整 | D | 行动实验可替代语言验收 |
| 静态任务可用，新规则给了反馈仍不会适应 | E | 每句话都在线改慢权重 |

这些是诊断与设计的映射，不是已证明的根因或固定优先序。旧672档受固定策略和输出缺失限制；D1已修正对应测量面，D3–D5有后继逐题证据，但仍不足以把某一架构设为唯一出路。先写清需要区分的能力缺口，再根据证据选择；A-R2是历史信息访问示例，§19是推荐组合设计，二者都不自动成为实施队首。

### 16.3 所有权、工程合同与迁移

五套候选均保留Taiji拥有认知状态/参数/生成与Seed执行权限的边界。内容寻址、embedding、自动微分不因与成熟架构功能相似而被禁止；现行合同仍禁止完整Transformer主体、运行时外部teacher/Legacy代做认知。若未来要比较完整成熟骨干，只能明确提出合同变更或独立参照，不能通过改类名规避检查，也不能把外部基线的能力算到Taiji名下。

| 方案 | 必须改造的核心责任 | 首轮可复用 | 需要新增的恢复信息 |
|---|---|---|---|
| A | prefix编码/记忆写读/解码条件 | byte接口、来源、隔离训练工具 | 证据位置/有效性、h/A/E、写入顺序 |
| B | 表示与绑定/关系传播/生成接口 | 输入和来源合同、旧模型锚点 | 对象身份、关系版本、失效/合并状态 |
| C | 迭代转移/证据读取/停止 | 语言头与可用输入编码 | 推理步、潜状态、预算、随机状态 |
| D | 信念/动作条件预测/价值策略/反馈 | 执行权限、事务、真实核验 | 轨迹来源、信念、未决动作与环境对账 |
| E | 更新规则/学习信用/快慢隔离/巩固 | 保持和rollback合同 | φ/优化器、支持经历、更新血缘 |

格式不兼容则拒绝加载；warm-start不冒称exact resume。旧bundle原样保留，新格式仅在隔离目录读写，缺少必须权重时拒绝而非静默随机初始化。采用顺序为隔离实验→保持/恢复→同入口opt-in→独立默认采用批准；M4/M5/L2/L3/M6–M8各出口不被候选名覆盖。

### 16.4 组合与扩展的准入

高上限不等于一开始全量组合。A+C先要A确实读得对、C在同信息条件下有新增收益；B+D先要文本/观察绑定有效，再验证后果决策；A+E先区分普通记忆与参数适应的贡献。组合后重新测冲突、梯度竞争、旧能力保持和成本，不能将两个局部正结果相加宣布统一认知成立。

单候选可以有公开的诊断上界或必要消融，它们不是第二条主线。新环境、新能力出口、更多资源、核心合同变更或无界超参搜索均须明确评审；不以“提高上限”为由免除证据，也不把历史tiny几何当永久规模上限。

### 16.5 R2工作包规格示例：A-R2（历史示例，后继采用有限切片）

**状态：保留9月17日规划规格；后继D2已独立冻结并实施A的有限切片。** 下列七项不是覆盖D2合同的新指令，具体变体、copy修订、门槛和停止条件以[原预注册](M5_R2_D2_PER_POSITION_EVIDENCE_PREREGISTRATION_FROZEN_20260918.md)、[copy修订](M5_R2_D2_COPY_MIXTURE_AMENDMENT_FROZEN_20260918.md)及03为准。B/C/D/E仍保留；局部选择不等于整套A获验或其他方案被否定。

**规划用途：**说明怎样把信息访问假设写成目标、对照、资源和出口明确的工作包；可用于其他方案的同等规格补全。本轮文档维护不重复审批已完成工作，也不批准下一版训练。

1. **主假设**：在同等合法材料下，逐位置可寻址证据相比末状态派生workspace，能改善内容依赖自由回答与关键事实反转，而不只提高固定“未知”的命中率。
2. **最小架构切片**：A的因果逐位置编码→keys/values＋来源→问题/decoder查询→原生byte回答。先保持旧decoder/序列CE，关闭copy、快参数、世界模型和多轮推理；这只是A的信息路径判别，不声称完整持续记忆已经建成。
3. **对照与隔离**：旧λ=0核心为锚点；候选改变信息保存/读取路径；简单同信息读出策略作参照。新增参数须显式计数，必要时增加参数匹配对照；读取位置的长度/存储增加不可藏在“同参数”里。再做正确/替换证据对照，不能把基线直接关掉prefix制造收益。
4. **数据与目标**：先冻结新dev去重及形状分组协议，旧672分数仍单列；保留与原问题一致的内容、否定、同开头异事实和关系题。训练期不喂测试答案位置；新字符串与新关系组合分账，首先检验能否从可见材料正确选择内容。
5. **主要读数**：内容依赖子集的自由回答exact与关键事实成对正确率；同时报告宏平均、未知误答/过度拒答、UTF-8/停止、成本。只提高总exact、不超过固定/无上下文策略或在成对题上不随事实正确改变，不支持主假设。
6. **标定与正式预算边界**：标定只用train划出的诊断集，检查微集拟合、梯度、读取、保存恢复与单步资源；正式dev不用于无限调参。批准包需填定唯一数据/token暴露、有效参数范围、配对seeds、最大更新/计算/墙钟、主效应最小差值和保持界限；未填齐不启动正式比较。原672档2688更新/seed仅是历史成本参照，不直接复制为“足够预算”。
7. **出口**：若获支持，再单独研究压缩记忆与长距离，或copy的增量；若信息可读取而绑定错误，再根据证据讨论B；若训练/记录不合格先在包内修复，不能据此否决A。任何转向均回到一个决策点，不自动启动下一套方案。

本轮同时修正旧“可直接只读分解六seed”建议：已查脚本没有保存完整逐题输出/检查点，不能承诺恢复不存在的产物。后续若发现有独立身份可验证的产物可补分析；否则需要明确的新实验授权，不冒称旧run恢复。唯一活动入口见[03](../active/roadmap/03_CURRENT_EXECUTION.md)，Mini仍以后续L3触发，不插到本轮前面。

## 17. 从架构设计到开发指导

### 17.1 共用开发主干与可替换设计必须分开

无论最终选A、B、C、D还是E，都要面对数据覆盖、表示可学、行为信用、实际消费、来源/恢复与公平评价。它们是每个能力包的责任，不是独立开完的六个项目。模型上限不能由组件名称推断；发展训练与运行期学习要分别设计、再验证配合。

| 决策面 | 计划必须回答 | 可选设计与切换依据 |
|---|---|---|
| 输入与信息保真 | byte/token/片段/事件分别负责什么；精确内容如何保留，何时允许回读 | 逐位置证据、连续状态、对象引用均可；先区分未保留、未检索和未绑定，不同时更换全部输入单位 |
| 共享表示 | 语言、记忆、关系与未来行动共享哪些语义，哪些精确内容保留独立引用 | A的状态/记忆、B的对象/关系或明示混合；按读出、干扰和组合证据选择 |
| 计算与内容生成 | 读取信息后怎样形成答案，哪些题需要更多计算 | 单步生成、A的精确读取/可选copy、B关系运算、C迭代；内容、推导、表达错误分账 |
| 发展训练 | 怎样从有限任务扩展到真实声明范围；目标如何改变相关参数 | 因果序列训练、明确辅助监督、多目标/阶段课程等按包登记；先形成可辨识信号，再扩覆盖和规模 |
| 经历与长期知识 | 哪些信息暂存、哪些经验证后进入长期能力，如何处理过期和矛盾 | E/A的记忆与受控巩固；参数知识与检索信息分账，知识child准入另过门 |
| 后果与行动 | 何时需要世界预测、价值/策略与真实反馈，而非只输出计划文本 | D用于相应行动能力包；不成为所有语言实验前置，也不因语言成功取消 |
| 运行适应 | 适应的是状态、记忆、快参数还是慢参数；依据来自什么可信反馈 | E或可控记忆更新；先明确适应主张，冻结更新对照和旧任务保持，不默认在线改全部权重 |
| 结构与自主发展 | 什么可复现压力要求新专家、结构变化或自主调度 | M4按贡献/同容量/保持/资源比较；不是固定数量模块集齐即成长 |

### 17.2 数据、训练与规模的规划不能缺席

架构候选只改变学习条件，不会自动提供词义、知识和经历。计划需要同时保留以下发展安排，按同一能力出口逐步使用：

1. **机制判别经历**：材料事实、绑定、否定、未知、干扰和组合可控，允许检查错误来自哪一层；不是最终语言能力范围。
2. **语言覆盖经历**：有来源的短文、问答、指令、改述、多轮上下文；其规模、领域与质量须匹配拟声明的L2范围，不把颜色模板迁移等同基本对话。
3. **真实后果经历**：进入行动范围后提供真实转移、失败、纠错与约束，世界/选择学习不能仅依赖自己的想象。
4. **适应经历**：进入持续适应范围后提供支持/查询、规则变化和旧任务回访，训练和测量“学过新经验后的能力”，不只训练固定答案。
5. **巩固与保持经历**：发展训练、运行记忆和快参数之间的合并有来源、版本及旧任务矩阵；重放/巩固不是天然无遗忘。

每类经历记录来源/许可、唯一覆盖、实际暴露、重复权重、训练/开发/确认划分以及泄漏风险；只启用当前包所需部分。数据与模型规模增长以质量—成本和误差类型指导，不凭既有tiny预算或论文规模拍板。必要的规模/课程搜索要预设范围和出口，不利用确认集反复选模型。

### 17.3 从局部可学到统一模型的演进依赖

| 演进目标 | 必须连接的已有效环节 | 不可跳过的开发结果 | 不应提前要求 |
|---|---|---|---|
| 条件内容能力 | 输入、任务相关表示、内容选择、原生解码 | 同材料/问题干预后的正确自由回答，完整输出与恢复 | 先做自主成长或全套世界模型 |
| 稳定上下文与组合 | 已有内容能力、状态更新、有效读取/关系计算 | 纠错/干扰/改述/未见组合与旧能力保持；明确失败范围 | 所有新题都一次解决或无限上下文 |
| 同一可用bundle | 可验证语言链与至少一项已有代表能力 | 实际消费者映射、来源、状态生命周期、同入口CAP及安全/性能 | 默认产品迁移或完成全部VISION |
| 联合认知闭环 | 同任务中的记忆、后果预测、选择/执行与反馈 | 公平对照下真实行为改善，隔离真实/想象来源 | 强制超加成或所有模块每次都调用 |
| 持续适应与更高上限 | 可信反馈、更新规则、保持/回滚与成熟基本能力 | 新旧任务和多轮连续性、适应预算与实际收益 | 用户首次验收必须等L4/M4全部完成 |

这张表表示能力依赖，不把语言L2设成所有行动研究的理论必要条件：局部行动模型可以独立验证；但当前用户要求先推R2，实际排期以03为准。M5范围、M4成长及M6–M8产品/发布/规模化仍由01完整登记，不因局部架构选择而消失。

### 17.4 备选方案怎样持续补全

每个方案随开发维护“设计假设→适用缺口→已有/缺失证据→最小判别→完整演进→代价/风险→替代与停止”七项，不只记录算法名或第一次smoke。新增方案应说明与A–E的实质差别；只是目标权重或槽宽不同，记录为同方案的实验变体，不再增加一条宏观路线。

规划中可并列多条完整设计，执行中只推进当前明确范围。已有候选失利时，允许修改表示/计算/学习规则，也允许暂不换架构而修复数据或测量；依据是可区分的证据与预期能力上限，不是技术难度最小或“已投入这么久”本身。没有新判别价值就结束该包，剩余问题回到能力地图。

本文完整记录架构设计；03 §5负责开发顺序/交付/工作包模板，01 §6负责大阶段依赖，02/07负责完成与用户验收。本轮仅补全计划；项目已发生的研发和后续裁决单独记账，不因本轮讨论而回退或自动放行。

### 17.5 发展课程的覆盖矩阵：从窄机制集到声明范围

本节把§8的学习原则落实为数据规格，服务[01 §6.4](../active/roadmap/01_SCOPE_AND_PHASES.md)的转段交付。**下表是待按包选取的覆盖设计，不是一次性训练清单或自动扩语料授权。** 任务实例须写出合法可见输入、所需依赖和正确行为，不能只保留一行prompt/answer而丢掉同源关系。

| 覆盖轴 | 怎样形成训练/评价变化 | 开发时要验证的行为 | 常见误判与对照 |
|---|---|---|---|
| 精确内容与长度 | 新名字/值、字符与字节长度分别登记、同前缀不同后缀、未见内容组合 | 完整内容、正确停止、引用/复制位置和原生表达一致 | 首字节对不等于整值对；同时看全答、值完成率与格式，不把乱码截掉后计正确 |
| 对象、角色与关系 | 同词面交换角色/属性，多对象与关系重组；已见词构成未见组合 | 根据当前绑定而非词频、位置或对象ID作答 | 重命名和关系交换分开；仅物体名变了不等于关系泛化 |
| 问法与表达 | 同事实不同提问、追问、肯否/比较、不同输出约束 | 问题改变时回答目标正确改变，语义等价问法保持内容 | 模板族和改写簇按组划分；“同模板换词”不当作独立语言范围 |
| 材料结构与来源 | 事实重排、无关材料、不同叙述结构、独立来源短文 | 正确选取证据、抵抗无关干扰、保留完整内容 | 相同答案分布下比较有/无关键证据，不把来源变换与难度同时改变后作单因果解释 |
| 跨轮时间与更新 | 提供事实→干扰→提问；纠正旧事实、撤销、会话重置 | 使用有效历史，更新引用与信念，不跨会话泄漏 | 单轮把全部历史重新塞入不自动等于持久记忆；输入重放与真实状态消费分账 |
| 组合与计算深度 | 单关系、多条件、有限多步推导；未知/矛盾与可解题成组 | 在证据约束下完成组合或明确不确定，成本有界 | 自由生成最终结果与依据分开评；解释流畅、全拒答或固定答案不算推理 |
| 知识来源与迁移 | 给定材料、已训练知识、合法检索各自声明；短文/对话来源与许可可追溯 | 不把“材料里读到”说成已内化常识，不编造来源 | 外部辅助、知识child和原生参数能力分别记账；采用child另守知识准入合同 |

开发时选择能判别当前问题的轴及必要交叉项，避免一次覆盖所有笛卡尔积。其他轴标为未覆盖，并给复审时点；扩大声明前补对应证据，不把未测当失败或通过。数值范围由实际资源标定，不能以“高上限”为由预先承诺无限长度或开放域。

### 17.6 课程更新、评价隔离与保持的具体安排

1. **诊断经历**用于分离机制与错误，可小而可控；**发展经历**匹配拟声明的语言/任务范围；**保持与独立评价**检查旧能力和未见覆盖。三者职责明确，不要求建立三套重复基础设施，允许复用生成器但保持身份/分组隔离。
2. 每次课程变更先登记哪些覆盖新增、哪些样本保留、实际采样权重与总暴露怎么变，附一个不可混淆的版本；比例/难度可在获准开发范围内标定，正式比较前冻结。不规定“上一层100%才可学习下一层”，也不允许事后放宽原包门。
3. 同来源文档、模板族、对话或生成规则簇按声明的独立单位划分，分别报告行数、唯一内容、族数与实际暴露。重采样、扩值池、改问法和换来源是不同变量；有界联合设计可以同时改变，但只归因到整包。
4. 累积课程保留旧能力锚点与对应评价，不强制永远等比例混合；新增课程挤掉旧能力时，先确认退化所在范围，再决定重放、参数隔离、目标调度或范围收缩，不能把这些机制全部默认开启。
5. 已反复用于候选选择的dev是开发证据，不再称盲测。正式L2/能力确认需要与声明范围匹配的独立协议/数据权限；旧final保持封存，不从其错误补训练。新评价版本并列记录，禁止把不同分母/难度的分数直接连成能力增长曲线。
6. 训练辅助标签、教师轨迹、来源指针与关系监督均明确披露其合法取得方式；推理时只能消费声明允许的信息。辅助目标是否保留由真实行为收益及成本决定，不由loss更低或标签更精细本身决定。

课程扩展可以是局部判别的一部分，不保证必有收益；D5所测覆盖改动未获支持，既不能按旧合同继续扩，也不能外推所有数据发展方向无效。新课程设计须明确它与已关闭方向的实质差别、投入边界与对应批准。

### 17.7 从研究切片演进为同一个模型

长期方案的学习成果必须进入实际消费者，而不是把研究模块罗列成“统一模型”。具体工程交接见[07 §5.2](../active/roadmap/07_MINI_MODEL_DELIVERY.md)，本节规定学习与表示的演进责任：

| 演进问题 | 设计选择与需要的证据 |
|---|---|
| 旧能力怎样保留 | 可以保留旧Taiji参数作为隔离组件、联合训练共享表示或明确迁移；列明哪些权重/状态冻结、更新、重训，按影响面做旧能力回归；旧报告不自动成为新bundle的成绩 |
| 内容怎样共享 | 精确证据引用、对象/关系或持续任务状态必须有实际生产者与消费者；共用向量不等于共用语义，分别验证语言、记忆及代表能力的依赖 |
| 目标怎样共同训练 | 先列每个目标更新的参数/状态与竞争关系，允许分阶段、交替或联合训练；各任务都留行为读数，不只看加权总loss；方法选择由同范围证据决定 |
| 表示单位怎样迁移 | byte/token/对象ID变化要绑定词表、分词/编码、符号映射与checkpoint版本；允许版本化重训/映射，不静默用旧ID解释新权重；D5初始化/索引事故说明跨版本重放必须覆盖实际兼容主张 |
| 新旧路径怎样比较 | 在隔离候选入口对同一合法输入比较，标出适配层与记忆状态差异；可同时保留研究和旧产品路径，但一次CAP只绑定一个明确bundle，不按题换候选凑分 |
| 何时扩大默认采用 | 先证明候选真实加载/消费和相关能力，再按M6单独批准默认行为；L3用户验收与M6默认采用不是同一事件 |

模型整合不要求先把所有模块接上，也不应等L2通过才第一次写加载/状态接口。可提前开发隔离接入原型，验证其真实性和恢复；未具备能力时如实报告输出。首次用户交付仍按L3触发，不由此立刻开展Mini工作。

## 18. 可实施设计规格：从方案名称到能力形成

### 18.1 当前证据如何进入设计，而不把局部失败变成永久禁令

本节是**待按具体工作包实现/验证的逻辑规格**，不是已存在的类、API或新冻结实验合同。继承[架构§4.6–4.7](../active/TAIJI_NATIVE_ARCHITECTURE_V1.md)的共同状态、行动生命周期与权限边界，不另建一套所有权规则。下表保留D1/D2的证据基线；D3–D5后继结果见03及结果总览，不由本文补发授权。

| 已有证据 | 设计上可以吸收什么 | 仍不能推出什么 |
|---|---|---|
| [D1测量基线](../../reports/r2_d1_surface_baselines_20260917.json)Q1–Q5通过，新dev固定策略上界显著低于参照键 | 复用新仪器与完整逐题记录规范，结束“重新发明评价”的前置循环 | 任一模型已通过该dev；参照解题器的正确率不计为模型能力 |
| [D2 v4探针](../../reports/r2_d2_copy_learnability_probe_20260918.json)仅用train，copy-supported为96/144，未达0.90 | 读取/表达在若干训练切片已有可学信号；否定与异值组合仍是明确缺口 | 已有未见内容泛化，或copy/绑定/组合机制已普遍成立 |
| [升级备忘](M5_R2_D2_FIRST_BYTE_ESCALATION_MEMO_20260918.md)记录首字节错误、常量初始查询和后续TF预测 | 把回答启动状态列为优先候选解释；区分首错与后续错误传播 | 常量查询必然使输出与输入无关，或已证明唯一充分根因；K/V仍可随材料变化 |
| 同一次probe早期平台；部分形状train满分 | 在该配置/预算内继续原样训练缺少支持；遵守既定停止规则 | 所有优化、容量、课程方案无效；训练可拟合足以排除绑定问题或支持开放域能力 |
| 后继[D2 v5问题条件化探针](../../reports/r2_d2_question_start_probe_20260918.json)在epoch 10–25达0.6667、epoch 30为20/144，未过门 | O1已实施并失败，按修订二进入全面复审；启动条件的单项修改不足，稳定性亦需解释 | 仍等待O1实验；v4五形状满分可套用v5；由单seed失败直接证明整个A或问题条件化无效 |

正确的因果层次是“记录到的现象→可解释现象的假设→区分假设的干预→对应范围的结论”。给定正确历史的TF表现不能代替自由生成后续行为；先验比例与错误相关也不单独证明充分原因。对历史备忘保留原文，对今后设计采用这里的结论边界，不改原始报告或冻结门。

### 18.2 信息通路与状态职责：先规定谁知道什么

以下Q/E/M/W/R是**逻辑角色**，可在同一张量中实现，也可分开；不要求先建立五个新模块。若共享存储，仍须能解释来源、更新和消费者。

| 角色 | 允许携带的信息、寿命 | 主要消费者与学习责任 | 缺失/失效时的行为 |
|---|---|---|---|
| Q：问题/目标条件 | 当前请求、合法任务约束；随请求修订 | 读取查询、回答起点、相关性判断；学会“要回答/完成什么” | 问题不明确时澄清或表达不确定，不能使用金形状标签替代理解 |
| E：当前可见证据 | 实际输入的序列/片段及来源、位置、版本；精确内容可回读 | K/V、可见复制、对象绑定；学会“什么信息支持答案” | 不存在/相互冲突分别表示，不能把推测写回为观察 |
| M：跨时经历 | 有权限的会话/长期记忆、可信度、有效期与撤销信息 | 检索和状态更新；学会保留、提取和修订 | 会话隔离；旧事实撤销后引用失效，恢复不能复活已撤销权限 |
| W：当前任务信念 | 对Q/E/M的可修订整合，包含关系、未知、预测与依据 | 内容形成、世界预测、规划；学会组合而不是只广播输入 | 区分已观察与推导/想象；新证据使依赖旧信念的计划失效 |
| R：生成/行动计算状态 | 当前答案进度或候选动作推演，绑定W的版本 | 原生输出、停止与行动意图；学会把内容转成合规行为 | 不携带测试答案；请求终止/重置不泄漏到下一会话 |

候选链为`Q/E/M → W或可寻址证据 → R → 回答/行动 → 实际反馈`；A偏持续状态＋证据读取，B偏显式对象关系，C在W/R上增加有界计算，D增加后果与选择学习，E增加受控更新。不要求所有题同时调用全部角色。

**D2特定的隔离合同不等于永久架构禁令。** 该包对题干、材料和回答起点的限制服务于材料贡献判别，必须按冻结版本执行；长期架构可以允许经声明的Q/W/M共同条件化，但需重新证明信息来源、旁路、恢复与实际贡献。不能偷偷放开通路救分，也不能把某次消融所需的隔离永久当作认知能力上限。

### 18.3 可替换的关键设计变量与取舍

选项不是按表逐一试遍。先写当前失败可由哪些因素解释，再选能改变决策的最小比较；一次可比较完整架构包，但若同时改多项，只能归因于该包，不能宣称某个单机制已被证明。

| 变量 | 具体可选设计 | 上限、成本与风险 | 选择前要区分什么 |
|---|---|---|---|
| 回答启动条件 | 学习常量；问题条件化；问题＋合法任务信念条件化 | 常量便于隔离但缺直接任务条件；问题条件提供任务区分；联合条件承载更多上下文但需审计旁路/版本 | 同材料换问题、同问题换材料是否产生正确变化；条件信息可分辨不等于已经学会使用 |
| 证据存储粒度 | 全序列位置；分块压缩＋原文回读；对象/事件槽＋来源引用 | 全位置保真但存储/读取成本随输入增加；压缩节省成本但可能丢细节；对象便于关系组合但依赖绑定 | 丢在编码、压缩、检索还是绑定；新名字/数值与语义关系分别测 |
| 可读范围 | 全合法prefix；显式可见材料边界；学习的证据选择 | 全prefix灵活但可能学题干捷径；边界清晰但依赖输入协议；学习选择更通用但需召回/偏置证据 | 规则只给可见性还是偷偷给答案位置；有效证据被屏蔽与模型读错分账 |
| 内容到输出 | 原生词表生成；可见内容copy混合；语义意图/关系状态＋生成 | 生成覆盖新表达；copy保留精确字符串但不能替代全部推导；中间意图有利于复用但可能形成监督/表达脱节 | 抽取、否定、未见组合、未知分别正确；辅助目标下降是否改善自由回答 |
| 表示单位 | byte；自有token/片段编码；语义单元＋精确字面通道 | byte保持开放字面但序列较长；分片影响覆盖与成本；语义/字面双通道增加绑定和恢复责任 | 来源/词表血缘、未见字符串、长度、参数与总计算共同比较；不把byte当原生性的唯一实现 |
| 信用路径 | 精确序列反传；分段/截断＋状态训练；局部更新＋任务反馈；元学习更新规则 | 跨时间精确信用成本较高；近似更新可降低成本但要证实关键远因仍能学；元学习增加训练嵌套与稳定性要求 | 目标具体更新哪些参数、跨度外怎么处理、局部预测变好是否带来行为收益 |
| 推理计算 | 固定一次；有界多步；学习停止/按难度分配计算 | 额外计算可能支持组合，但也可能重复同一错误；停止策略本身需训练和预算约束 | 同信息、同总计算参照下的难题收益与简单题退化；不能只比较步骤数 |
| 发展规模 | 固定机制集；扩语言/来源覆盖；扩状态容量；扩训练或推理计算 | 高上限需允许扩展，但数据、容量和预算不是相互替代项 | 每次扩展解决哪种覆盖/容量/优化问题，有何质量—成本信号和停止条件 |
| 持续适应对象 | 仅状态/记忆；快参数；受控慢核心巩固 | 记忆易追溯但未必形成新技能；快参数更灵活但有遗忘/污染；慢核心更新影响面大 | 新经历后的收益相对冻结与等存储基线是否成立，撤销/回滚是否真正恢复行为 |

O1–O4是D2历史局部裁决选项，不等于A–E整体排名；O1已实施且未过门，不再排为待执行。训练重加权可以保持评价集不变，但仍改变训练分布/目标，需要版本化合同，不能直接沿用旧run身份；B/C在关系/计算缺口成立时仍可进入；规模/真实语料需明确覆盖目标和授权，不是永远禁止。当前全面复审前的停止规则继续有效。

### 18.4 最小接口规格：生产者、消费者和失败语义

这些是实现前必须回答的接口问题，不要求现在重构`adapter`或默认chat。具体字段由选定包映射到已有状态/manifest，只有缺失且必要时才新增。

| 逻辑接口 | 输入/输出与消费者 | 必须写清的约束 | 交付时的针对性验证 |
|---|---|---|---|
| 观察/编码 | 合法输入→表示、精确引用、可见性/来源；供读取与绑定 | padding/边界/时间顺序、表示版本、重置、批内隔离；内部状态不当成外部事实 | 因果性、截断/空输入、相同内容不同包装、批内互不污染 |
| 证据读取/绑定 | 问题与状态→选中/混合证据及其来源；供W/R | 软权重不伪装成已确定符号；缺证据、歧义、冲突有独立语义 | 同信息基线、关键证据替换、无关干扰、错绑/旧版本引用 |
| 内容形成/计算 | 任务信念与证据→可生成内容或行动依据 | 辅助监督只在训练可见；中间表征不能直接复制金答案；多步计算有预算 | 自由输出收益、关系反转、未见组合、去掉该计算的等成本参照 |
| 生成/行动意图 | 内容＋进度→原生符号或带参数意图；供显示或执行器 | 生成来源与工具回执分离；停止、长度、权限和不可执行动作有定义 | 输出合法性、语义正确性、同入口调用链；动作另守§4.7生命周期 |
| 反馈/更新 | 真实结果＋预测/动作身份→归因及获准更新 | 标出更新状态/记忆/参数、允许梯度路径、迟到/重复/撤销反馈处理 | 错配反馈不得更新、重复反馈幂等、收益与旧任务保持、无反馈对照 |
| 快照/恢复/迁移 | 参数、可学习状态、优化器/RNG/游标、schema→可恢复bundle | 明确持久与临时状态、数据/代码血缘、旧版拒绝/迁移、回滚边界 | 训练前真实保存与新进程恢复；继续训练、会话恢复和外部环境对账分开 |

交接产物至少有“生产者→实际消费者→损失/更新来源→恢复归属”一一映射。声明字段存在不算接入，注册模块不算被消费；研究runner有效也不能直接写成默认chat有效。接口变更要登记谁需迁移、旧checkpoint如何处理、缺依赖时如何明确失败，不能静默随机初始化当作兼容。

### 18.5 学习责任：每套方案怎样形成能力

共同责任链为“经历分布→目标→可训练参数/状态→推理时消费→行为改善”。缺任一环，只能说设计/局部实现，不称能力成立。下表目标均是候选，不覆盖已冻结损失。

| 方案 | 需要的经历与候选目标 | 负责学习的对象与推理消费 | 必须区分的正信号和伪信号 |
|---|---|---|---|
| A 持续状态/证据记忆 | 问题—材料—回答，延迟/干扰/纠错；任务回答目标，必要时有声明的记忆辅助目标 | 编码、写入/压缩、查询、读出与生成；真实回答实际依赖读到的证据 | 事实改变导致正确换答，长距保持有增益；不是只看attention/copy质量或存储条数 |
| B 对象/关系 | 多对象、多关系、别名/角色交换及未见组合；回答/关系目标，辅助标注单列 | 绑定、关系更新、组合算子与原生表达；来源与对象身份可追溯 | 同词面换关系能正确换答、新组合有效；不是规则parser替模型完成绑定 |
| C 有界迭代 | 同内容不同推理深度、有干扰/不可解题；最终行为目标及可选中间约束 | 迭代状态更新、证据再读取、停止控制；每步实际影响输出 | 难题收益相对等信息/等计算参照成立；不是更多步数、漂亮解释或泄漏中间答案 |
| D 后果/选择 | 真实可执行转移、失败、部分观察与多步目标；预测、价值/策略与任务结果目标 | 状态、动作条件预测、选择与语言共享部分；执行器只落实合规意图 | 预测帮助实际选择，执行后结果改善；不是自己的想象同时当训练标签与评价事实 |
| E 快慢适应 | 支持/查询分离的新规则/概念、多轮变化与旧任务回访；适应后表现＋保持/代价目标 | 写入门、快参数/更新规则、慢核心巩固；适应后推理用真实更新产物 | 新经历后相对冻结、等记忆基线有收益且保持；不是再测已背熟支持集或只有权重变化 |

多目标训练必须列出梯度到达范围、截断/离散边界与冲突处理。先确保目标确实在改变负责该错误的对象，再讨论权重调节。辅助损失可用train诊断标定，但是否保留由行为收益/代价决定；不要求永远只用一种损失，也不把所有损失全部叠加。

局部微集拟合是诊断，不是普遍通用性的证明；某包冻结了拟合前置就按该包执行。未来若要研究正则化、跨域学习或不同容量，应重新说明为何旧微集门适用或不适用，并预先建立新合同，不能事后重解释失败为通过。

### 18.6 五套方案的完整演进与复用边界

下列是各方案从局部到高上限的设计路线，**不是新增执行队列**。共同入口仍是当前R2包及其裁决；D/E不插成语言前置。

| 方案 | 首个可辨识切片 | 后续完整能力设计 | 何时扩展/组合，何时应换解释 | 可复用资产与迁移责任 |
|---|---|---|---|---|
| A | 内容访问/生成、反事实材料依赖 | 分层可寻址记忆：近程精确引用、远程压缩索引、按需回读；多轮纠错、主动遗忘与跨会话隔离 | 已正确读取但关系错，评审B/C；有效但存储/读取成本增长，研究压缩与选择；不能以copy成功跳过组合 | 保留证据schema/来源与恢复；新压缩器/索引改变表示需迁移和失效检查 |
| B | 角色交换、指代、多事实关系、未见组合 | 稳定对象身份＋事件更新＋多模态绑定，连续语义与精确字面联合；可向D提供对象级预测 | 绑定可靠仍缺多步计算时评审C；关系明确却文字生成失败时修表达，不继续堆对象槽 | 复用A的输入/引用与生成；迁移对象ID、关系版本和旧记忆，规则辅助始终披露 |
| C | 固定信息下需要额外组合/搜索的任务 | 有界自适应计算、证据重读、冲突校验；困难问题使用更多计算，简单问题及时停止 | 额外计算有稳定净收益才学习路由；输入信息已丢失先回到A/B，不能靠空转恢复不存在的证据 | 复用W/证据/输出合同；新增迭代状态、预算/停止与中断恢复语义 |
| D | 同任务记忆＋世界预测＋多步行动，真实结果可核对 | 部分观察下的任务信念、多尺度动作/技能、风险与代价敏感选择，语言解释引用真实决策状态 | 预测校准且帮助行动后扩任务；预测准但选择差单查价值/规划；环境噪声与模型误差分开 | 复用现有Workbench/执行合同；世界状态版本、动作权限及环境对账不得由模型快照代替 |
| E | 明确分布变化后的新概念/规则适应 | 元训练更新规则、情景记忆与快参数配合，慢核心有证据地巩固，长期新旧任务矩阵 | 只有检索收益就声明记忆改善；独立适应收益成立才扩大更新范围；保持失败先隔离/回滚 | 复用来源/恢复/评估；新增支持/查询隔离、快慢状态schema、污染/撤销和巩固血缘 |

组合设计采用“主表示＋必要机制”的最小契约：例如A+B必须定义对象来自哪些证据、对象改变怎样更新引用；A+C必须规定每步新增了什么计算；B+D必须对齐对象状态与真实执行目标；A/E必须明确记忆写入与参数更新谁负责什么。组合批准前先画消费/学习关系，组合后重新验证，不把已有局部分数相加。

“上限更高”在计划里落实为可扩覆盖、长时连续性、组合能力、自适应计算和学习后的保持，并记录每项代价与证据需求；不是按模块数量或实现难度给方案排名。

### 18.8 设计完成度与结案后的计划维护

一项设计进入具体开发包时，至少能回答六个问题：**信息在哪里、谁消费它、错误更新谁、用什么经历学、怎样证明行为改善、失败后保留/更换什么**。这些问题是03工作包模板的设计部分，不是额外必须先建设的通用平台。

状态按同一对象逐项记录：候选描述→规格可实施→合同冻结→实现验证→限定能力验证→采用/阶段批准。D1属于仪器验证，D2 v4/v5属于已实现但学习门未过；A的长期记忆、多模态和E的持续适应仍是设计，不随D2代码出现自动升级。

每次结案只更新受到影响的设计变量、学习责任、证据和阶段缺口。保持一项活动工作包；剩余设计可以完整并列，但没有自动预算。出现连续负结果时允许重新审查数据/表示/学习/规模的联合设计，而非只在一个局部参数上无限打转；评审应给出更改理由、可辨识读数和有界投入，不预设必须再试一次。

本轮计划补全的出口是：§18给出可落地的设计契约，03 §5.8登记已知/待定与范围，01保持长期缺口，02/07保持独立验收。研究下一步仍由03的有效裁决与合同确定；O1已试不是新队首，文档完整不等于批准后继路线、启动训练或交付Mini。

### 18.9 连续负结果后的路线复审，怎样避免继续局部打转

全面复审不是把“更新规则→加容量→B绑定→规模”重新排成必须逐个失败的长队列。局部原因未完全分离时，可以比较一个明确的联合设计，但要承认只能评价整个设计包；不要求证明所有简单补丁无效后，才允许讨论更高上限表示或发展训练。

**用户纠正：应设定追加约束，而非禁止局部实验。** 有判别价值的局部实验可以为设计评审补证，不必等全架构决定之后才做。统一准入规则见[02 §2.5](../active/roadmap/02_GATES_AND_CI.md)，准入卡见[03 §5.9](../active/roadmap/03_CURRENT_EXECUTION.md)：绑定当前决定、必要对照、累计预算、停止与返回动作；已授权范围内按约定推进，触发停止/超范围才升级裁决。允许必要的重复、消融和有限条件分支，不允许换名重置预算或以探索结果直接晋级。

以下是可供复审选择的**设计草案**；只补与当前不确定性相关的规格，不要求四套全部完成才准入局部取证，也不是四个已批准实验：

| 复审草案 | 实质设计与保留资产 | 需要解释的学习问题 | 成立后接向哪里，主要代价是什么 |
|---|---|---|---|
| A的内容形成层重设计 | 保留精确证据/来源和生成资产，在问题、读取证据与解码之间定义可学习任务内容状态；copy只负责字面，否定/关系由内容状态条件化 | 任务损失怎样同时训练相关性、关系和表达；新状态是否只是另一条忽略材料的捷径；保留公平信息通路对照 | 接上下文、长时记忆与B/C；代价是联合信用、旁路审计与新状态迁移，不是只加宽或改首步 |
| B的可学习绑定核心 | 复用可见证据与语言输出，以对象/事件槽和来源引用表达实体、属性、关系及其修订；不由规则解析器提供金绑定 | 对象身份、关系更新与生成怎样从实际经历学到；辅助标注如何披露；未见对象/角色交换怎样验证 | 接组合语言与D对象级世界预测；代价是绑定可学性和开放输入覆盖，不强求先把A所有补丁试尽 |
| A/B＋C的有界计算 | 保留已可信的信息，加入明确状态转移、证据再读和停止，避免每个问题都用同样固定计算 | 额外步骤究竟实现什么运算；任务目标能否训练中间状态；等总计算下是否仍有价值 | 接深层组合与规划前的内容计算；代价是训练稳定性、计算预算和中断恢复，不用反复迭代掩盖输入丢失 |
| 学习/课程与规模的联合规格 | 核心不一定更换；重新设计实际覆盖、采样、更新方式与容量匹配，保留独立评价和来源血缘 | 是表达能力不足、梯度/更新不稳还是经历分布失衡；如何把train诊断与未见任务结果分开 | 接声明范围的真实语言发展训练；代价是数据与计算投入，必须有有界资源和可辨识对照，不是无限调参 |

以上均须填写：一张计算/信息与信用路径图或等价规格、继承/新增/废止清单、最少可区分对照、数据与资源标定方案、保存/迁移方案、对L2及后续联合能力的贡献、失败后关闭的假设范围。然后评审**预期能力覆盖与上限、判别价值、长期复用、实际代价**；实现容易不自动优先，结构复杂也不自动更优。

每个评审节点只保留一个当前决定：可以选择有边界的设计包、先批准一个用于补证的局部实验包，或明确停止/重定范围。局部实验按预定结果返回同一评审，不成为永久支线；其余草案保留而不排自动执行序列。当前文档修订只明确准入方式，不解除任何已触发的具体停止条款，也不冻结新预算；D2/P1旧队首不覆盖后继裁决。

## 19. 项目缺口的实际解决方案：推荐核心、学习配方、演进与交付

**记录来源与状态（2026-09-18）**：用户要求将项目缺口及实际方案写入唯一VISION。本节把§15–18的候选收成一套可供开发评审的推荐设计，补足计算、数据、训练、接入与失败处理；不是第六条主线，不是已实现功能，也不是D6或其他活动合同的修订。下面的接口名、字段和资源起点均为建议规格，实施时优先映射现有对象，不假称仓库已存在相应API。

### 19.1 七项缺口与解决责任

诊断结论：**缺的不是更多模块，而是“能学会→能迁移→同模型实际消费→可靠反馈改进→可验收”的连续证据。** 已有所有权、恢复、K轴限定晋级及局部因果成果继续保留。这里区分尚未成立的能力、已有设计待实现、已有实现待集成/验证，不能统一写成“什么都没有”。

| 缺口及核对依据 | 实际解决方案 | 完成时应留下什么，不能拿什么抵扣 |
|---|---|---|
| 未见内容泛化：D3–D5门失败；后继[D8/v3报告](../../reports/r2_d8_matched_dev_20260918.json)多字值full_rate均值0.3621过K1，但M4/flip为0，整体未通过 | §19.2–19.4双通道内容核心、绑定/关系目标、独立变化轴；保留后继复制收益 | 同一候选在声明的未见内容/组合上稳定自由作答；局部主门通过不抵扣绑定/完整语言，不能抹去已出现正信号 |
| 能力形成机制：联合反传已存在，统一信用仍待证 | §19.3明确每项经历、损失、接收参数、运行消费者及可辨识干预 | 更新确实改善后续行为，反馈合法；梯度非零、权重变化和自答写回不抵扣 |
| 发展课程：覆盖规格已有，广范围发展经历尚未由窄实验获证 | §19.4落实生成记录、真实语料、组级划分和保持采样 | 数据卡＋实际暴露账本＋迁移矩阵；可用语料数不冒充已训练量 |

| 整模型验收：所核对[CAP报告](../../reports/taiji_cap0_baseline_v1_20260917.json)的A/F/H为not_executed | §19.8补真实性、代表能力、稳定性与原始输出证据 | 绑定同bundle的CAP；L3才交用户最小版本，不把未测写为失败或通过 |

证据边界：默认工作空间在未进入候选路由分支时直接广播features，见[adapter.observe](../../taiji/adapter.py)；[SeedRuntime.chat](../../api/seed_runtime.py)经generate_input和语言表层输出，并可在learn开启时写回。这支持“这些入口尚不能凭代码存在证明联合认知”的诊断，不支持“记忆/世界模型从未参与任何路径”。本次续写核对到D8/v3已提交报告，逐seed完整值率为0.4310/0/0.6552，仍有稳定性与绑定缺口；不能写成所有seed已可靠，也不把无上下文exact=0推成模型学会合理拒答。未提交或仅实现的后继产物不能据文件出现补发能力通过。

### 19.2 推荐核心：语义/对象状态＋精确证据双通道

**推荐的架构评审形态是：A的保真证据底座＋B的可学习对象/关系内容状态，保留非结构化残差；有证据再接C的有界计算、D的后果学习、E的快慢适应。** 推荐理由是同一内容状态有机会同时服务语言、后续行动绑定和世界预测，而精确字面不必全部压进概念向量；这是上限假设，不是已证优于A或已批准整套A+B。允许先比较完整内容核心再消融分解，不要求把每个组成部分分别晋级后才准原型，但不能由整包收益宣布每个机制都有贡献。

三种可实施核心选择如下；只选与当前决策相关的比较，不按表全部运行：

| 选择 | 实际计算与适用情形 | 上限与代价，何时改选 |
|---|---|---|
| A内容核心：逐位置/片段证据＋查询条件化读出 | 保留连续表示，用可学习span选择与原生生成；适合主要错误仍在读取/完整输出 | 路径短且无固定本体限制；若同词异绑定、关系交换持续失败，增加可学习结构有判别价值；不是默认优先，因为最易实现 |
| **推荐评审形态：双通道A+B内容核心** | 连续上下文＋可交换对象/事件状态；内容选择绑定到原始证据，关系更新后原生输出 | 可复用到组合、记忆修订和行动绑定；代价是binder可学性、状态匹配与多目标竞争。若结构只添成本或只能靠金标签工作，回到A而不硬保B |
| 分层编码替换：自有固定分片/学习片段＋字面通道 | 改变语义计算粒度，保留原始byte引用；可作为前两者的编码替换，不是另一主线 | 可能降低序列与信用成本，但分词本身不提供关系语义；需重训/映射、未见字符串和成本比较。在线聚类暂不与首轮绑定同步启用 |

**首个R2切片的职责分解：**

1. **证据层E**：保存模型合法可见的原文、byte区间、来源与版本、会话/时间、有效性；每个特征能回到原文。不存题型ID、金答案或测试期金span。字符、字节、分片位置分别有映射，避免再次混用“字”与“byte”。
2. **语义层W**：问题条件q读取编码后的E，学习对象/事件槽、关系、否定范围及未知/冲突状态。槽不固定为答案phase，也不固定“第一个对象必是主语”。连续残差保留尚未能结构化的内容，防止手写本体限制开放输入；正式能力必须揭示它是否绕过对象分支。
3. **内容计算层C**：按问题选择对象/关系与依据，产生可供生成器消费的内容状态。提取题可直接读取；否定、比较和有限组合需经过相应可训练运算。首轮可固定一次更新，多轮计算另按困难题收益决定，不先承诺通用推理。
4. **字面层R**：模型预测copy/generate模式、所选来源区间与退出时点；copy读取原文，generate产生材料之外的连接、否定或推导表达。禁止规则按问题模板填答案。精确copy是模型选择后的机械读取，不把逐字复制本身宣传成语义理解。
5. **停止与错误语义**：缺材料、歧义、来源已撤销、超出窗口分别记录；允许模型表达未知，工程层只做权限/格式拒绝，不替模型选择正确内容或用模板修好错误答案。

候选前向关系（伪规格，不是现有调用）：

```text
E, H = encode_visible(observation, previous_context, codec_version)
W = bind_and_update(H, previous_belief, evidence_refs=E)
q = encode_request(request, allowed_history)
c = content_step(q, W, read_visible(E, q), iteration_budget)
answer, trace = native_decode(c, W, E, previous_answer_symbols)
```

E是精确保真通道，W是可修订语义通道；q和decoder可以通过声明的读取接口访问E，不能用完全屏蔽原文人为制造W必要性。另测去掉W、去掉残差、等计算连续核心，区分真实组合收益与旁路。

**落实到张量与生命周期的建议：** E编码为`[batch, visible_length, d]`并带可见mask；W为`[batch, slots, d]`及有效性/证据分布；关系采用可学习边特征，初期限定槽数，后期可稀疏化。跨事件身份用内容与来源约束匹配，有新建/失效/歧义分支，不能拿槽序当永久对象ID。硬身份落地与原文copy是离散边界，需单独说明信用。

**binder与关系计算的首版实现建议：** 对每个可见位置i和槽j计算`score_ij = key(H_i) · query(W_j) / sqrt(d)`，按槽归一化让槽竞争输入，再按位置归一化形成槽的聚合输入；用共享GRU/MLP更新槽。对已有时序槽使用前态初始化，新槽采用可复现初始化并记录RNG，不能所有槽同值且没有破除对称的机制。有效性/新建门均学习，容量耗尽显式记录；空材料、全mask和无有效槽有独立分支，禁止靠NaN或任意argmax选中证据。

关系边由`edge_ij = relation_mlp(W_i, W_j, source/time_features)`产生，消息层聚合相邻槽和问题条件更新内容状态；共享关系算子不按对象名/样本编号分配权重。可见来源/时间是输入，金角色和隐藏规则不是；否定/未知标签可以在train提供辅助监督，但实际答案还需经内容头与decoder学习。首版可用稠密有界槽图，资源实测后再决定是否稀疏，不先建通用图引擎。

以上比“加一个槽位”多了三个可检验职责：竞争绑定哪个证据、关系运算如何改变内容、生成器是否消费结果。它不同于仅对逐字节copy添加持续/induction偏置；后者可以提供局部读取证据，不能直接当成本方案的对象绑定与关系能力。训练是否需要多轮槽聚合、跨时匹配策略和硬span边界都在具体包内冻结，不能凭该伪规格跳过实现门。

只为第一次实现/资源预检给出起点：`d=128、slots=16、可见窗口=1024 bytes、回答上限=128 bytes、内容更新轮数=1`；这是可改的工程起点，不是冻结预算、旧实验配置或L2上限。超限明确返回/分块，不静默丢关键事实；测覆盖和资源后，在正式比较前冻结实际值。若需d=256/更多槽/分片，按包内有界标定与质量—成本记录决定，不能每次失败自动翻倍。

### 19.3 能力形成的训练配方与信用路径

首个内容核心用监督发展训练启动，不先引入在线改权重或行动强化学习。关键不是“再加一次backward”，而是让对象选择、完整内容和组合错误抵达实际负责它们的参数。

| 目标与训练经历 | 更新责任 | 推理时怎样使用，怎样发现无效目标 |
|---|---|---|
| 完整答案的因果序列损失L_answer | encoder、binder、content_step、读取/生成门及decoder；短任务先完整展开 | 正式评分自由生成；TF改善而输出失败时拆首错、内容遗漏、停止与绑定，不靠TF分数结项 |
| 可合法生成的训练span/角色/关系辅助目标L_bind | 证据选择、对象身份/属性和关系更新；不训练评分器代做内容 | train可由生成器生成标签，dev只给原文；移除辅助目标作需要时的比较，辅助分数不代替答案 |
| 内容替换/无关变化的成对任务目标L_pair | 内容读取、关系与生成条件 | 关键事实变化应正确换答，无关重排应保语义；对可见且逻辑不变的训练对使用，不对真实时间/否定变化强制不变 |
| 历史课程重放/已核验目标L_keep | 本次会更新且影响旧行为的参数 | 新旧切片都记录；不蒸馏已知错误答案来“保持”，保持集与调参集分离 |

候选组合为`L = L_answer + λ_bind L_bind + λ_pair L_pair + λ_keep L_keep`，未启用项权重为0。不是强制四项全开：实施包先列必要目标，在train内部标定梯度尺度/到达范围与小集可学性，正式比较前冻结权重和调度。对绑定目标的采用必须保留“监督增加”这一解释；总loss下降不代表每项能力都提高。

**copy与硬选择的训练—推理一致性：**

- 第一个实现可用软位置读取及byte层生成/copy混合，让答案似然回传到寻址。若采用span复制，则先由模型预测来源与起止边界，区间内游标递进是公开工程规则；训练用边界监督或合法候选的边缘化似然，不能对硬argmax假称可微。
- copy持续性必须按完整值测量：重复首字符、多处同字、同前缀不同后缀、跨UTF-8字节与提前停止都入诊断；不能由参考答案决定退出游标。规则约束只能保护可见性/编码合法性，原始错误输出仍留存，不由后处理补正确字符。
- 一开始同时保留自由生成回放。若需要处理自身输出造成的偏移，使用另行登记的train轨迹/可核验目标，控制其比例并与基础目标比较；不得把自己的错误续写自动标为正确答案，也不使用dev/final答案更新模型。
- gold槽/金span只允许隔离诊断上界。若金状态能解而模型状态不能解，优先定位binder；若金状态也不能解，内容运算/生成仍有缺口。二者都不计正式分数。

**必须随实现交付的检查：** 每个目标的参数清单及梯度到达记录、mask/因果性、批间隔离、角色置换、合法/过期引用、固定输入恢复前后行为；不同表示的旧参数允许warm-start或重训，只有语义与全部训练状态确实一致才称exact resume。

### 19.4 实际课程、数据产物与泛化判别

首个声明范围建议限定为**中文短材料的事实问答、否定/未知、有限关系组合及短上下文纠错**，不宣称百科知识或开放域对话。下列是逐步扩展的课程安排，不要求上一层100%才训练下一层；按当前包启用必要层并混合保持样本。

| 课程 | 实际样本怎样生成/取得 | 隔离哪些变化，返回什么能力结论 |
|---|---|---|
| 精确内容 | 由版本化事实表生成短文及问题；值包括新名字、数值、多字符词、同前缀字符串、多处重复词；保存原文位置 | 词面/长度与问法分账；完整值、完整答案、停止分别计分；不是只增加旧模板重复次数 |
| 绑定与关系 | 改名、属性交换、同词不同角色、否定范围、同名消歧；同一事实结构配多个问题 | 分别留出词、关系组合、模板族；不以每项都同时变难的单一总集归因绑定 |
| 跨轮与时间 | 事实→干扰→提问→纠正→新提问，包含撤销和会话重置 | 旧/新事实选择、过期引用和跨会话泄漏；区分完整历史重放、缓存状态与记忆检索 |
| 真实语言覆盖 | 经许可短文、人工核验的短问答/改述/对话，来源与任务范围明确；合成数据保留作机制锚点 | 独立来源/问法上的自然输入适应；不能用合成颜色题分数宣布L2 |
| 组合与深度 | 明确可验证的一步/两步及更深依赖，缺条件与不可解题成组 | 同词/同信息下考组合，额外计算由C对照验证；不以生成解释的长度评分 |

**数据最小记录**：`example_id、source/license、source_group、generator/rule/template_group、entity/value_pool、visible_events、query、target、train_only_annotations、split、counterfactual_pair_id`；源文档/对话/改写簇不能跨独立确认划分。对象池留出和结构留出是两种不同测试，标明允许共享什么。

生成器可以产生标签，但模型输入只取visible_events/query及允许的历史；metadata与train_only_annotations由训练器隔离，推理入口不能接收。真实文本辅助标注记录方法与抽查错误率；训练用外部教师如有采用需另行批准、披露来源，运行时关闭且不得向教师提交私有数据。

**一个具体的最小判别簇（设计例，不是新增评价题）：** “甲盒装米色球，乙盒装灰白球”，问甲盒内容；保留问题但交换两盒属性应换答；只重排两句或插入丙盒无关事实应保答；把甲盒新值改成未见的同前缀字符串，应完整输出该新值；下一轮明确纠正甲盒，再问应使用更新后的事实；问从未提供的重量应承认未知。每个变化单独标记，复制正确、角色正确、时间更新与未知判断不合成一个含糊总分。该簇仅说明测法，不将盒/颜色本体固化进模型或语言范围。

**实际采样与量级确定：** 冻结课程版本后，记录实际唯一episode、来源/规则簇、字节/分片暴露、重复率和更新数；用train内部小/中两个覆盖或容量点做获准的有界标定，判断是否受优化、覆盖或表示限制，再冻结正式规模。这里不预设“174题足够”或“必须百万条”；标定本身计入父包预算。新覆盖与新核心同时变化时评价整包，若要单因果解释再增加必要对照。

**开发与确认分开：** D1仪器及D3–D5已使用dev继续作为历史回归/诊断，不冒充新的盲确认。采用新确认集须预先冻结范围、组级抽样、配对重复、主指标、最小有意义增益与保持界；旧final权限不变，不能因为旧dev失败就丢掉它或换容易的集合。报告完整自由输出、形状宏平均、关键事实翻转对正确率、值完成率、未知误答/过拒答、每组样本数及不确定性，不只给总体均值。

### 19.5 从内容核心接成共享任务信念与真实联合行为

该部分属于后续联合能力设计，**不是R2前置或立即新建Workbench任务族的授权**。内容核心一旦形成有效语义状态，先在隔离入口核验消费者，再把有需要的记忆、后果预测与选择接入相同版本的信念。

建议在既有`CognitiveState/WorldState/Outcome`合同中映射以下逻辑字段，不另造平行真相库：当前请求/目标、对象及关系、证据引用、观察/推导/想象来源、时效和撤销、未知/冲突、任务版本。语言、世界预测和规划允许独立投影/头，不能各自重新解析输入形成互不一致的隐式对象身份。

| 接口责任 | 实际接法 | 不能偷换的行为证据 |
|---|---|---|
| 记忆→信念 | 模型从当前目标提出查询，记忆返回合法证据及来源/有效期，binder修订W；高冲突保留不确定，不默默覆盖 | 历史有效证据影响当前选择，撤销后不再消费；公平基线有同等历史权限，不禁读历史制造“记忆收益” |
| 信念→后果预测 | 动作条件模型接W及候选参数，输出任务相关后状态、风险、成本与不确定性；真实前后状态训练 | 同状态不同动作有可区分真实后果；评价校准与真实任务结果，不只潜向量预测loss |
| 后果→选择 | 策略提出候选、有限展开/价值评分选择；执行一步再观察，预算固定 | 相对同信息简单策略与无规划/替换预测对照有行为收益；不靠唯一合法动作“证明规划” |
| 执行→反馈 | Seed仅执行获准意图，真实outcome绑定episode、intent、attempt、前后状态和模型版本 | 真实成功由独立环境检查；结果未知先对账、不重复提交；模型快照不能撤销外部副作用 |
| 同信念→语言 | 原生生成器读取决策时的W、证据与实际回执状态 | 能回答同任务问题但不编造执行成功；宿主格式化回执不计原生回答 |

接入时不永久禁止原有直接特征路径：保留明确命名的旧基线/低成本模式。声称联合链时必须实际路由相关候选并记录消费者；普通简单问题可以早停，不能强制每题全模块调用。统一能力验收继续按02 §2.1，同bundle真实结果及有效的记忆/世界/规划替换对照，不要求额外的“超加成”门。

### 19.6 原生持续适应：可信经历、快更新与慢巩固

推荐把运行期适应分成三个可独立声明的更新层，并在发展训练中模拟相同更新协议：

| 层 | 允许更新什么 | 发展期与运行期实际做法 | 失败后的边界 |
|---|---|---|---|
| 状态/记忆 | 会话状态、临时对象绑定、合法情景与关联记忆 | support经历改变状态后，在未给答案的query上评分；运行时保留来源、撤销和会话隔离 | 只称记忆适应；存储增多不等于获得新技能，错误事实可失效 |
| 快参数φ | 预先列出的低秩残差、读取投影或适应头，不默认改全核心 | 外层用适应后query损失训练θ/更新规则；内层仅用合法支持目标；步数、范数、资源有界 | 新收益/旧保持不合格则回滚或关闭φ，保留可能成立的记忆收益 |
| 慢参数θ | 经过批准的共享核心/语言等参数 | 可信经历进入候选child，用重放及新旧任务评价巩固，P5.1h等知识准入仍适用 | 未准入child不替换parent，恢复父权重不承诺从所有产物抹去已学知识 |

一次更新的逻辑流程：`反馈身份核验→权限/来源/时效/重复检查→生成允许的学习目标→候选更新→行为与保持检查→接受或回退→记录实际更新对象`。用户陈述可作为带来源事实，用户纠错也需区分主观偏好、可核验事实和不可信内容；不是每个输入都能修改全局知识。

**防止自证学习：** 当前chat的自生成答案写回只可视为已有行为，不是本方案的正确性来源。若未来保留自监督预测，必须明确其目标是输入建模而非“答案已证为真”；未经核验的生成内容保留generated来源，不混进事实/奖励。想象可训练隔离候选，但晋级回到真实反馈与独立任务，不由世界模型同时造题、造正确答案和评分。

适应评价固定任务级support/query隔离，比较无支持、支持打乱、冻结更新、等存储记忆与候选更新；记录适应前/后、新/旧任务、规则反转、多轮累积、恶意/重复/过期反馈、快照继续及回滚。测试query标签评分前后都不能回流同一确认run的学习器；另行定义的在线学习协议须标明何时反馈才可见。

长期授权还要规定私有对话是否可持久保存/用于训练、保存期限和删除范围；离线训练权限不等于吸收全部用户数据。首先允许有可信反馈的有限更新，不因尚无自主性而拒绝验证适应，也不把L4全部完成设为首次L3用户验收前置。

### 19.7 协作、成长与自主调度怎样落地而不失踪

长期项目欠账由01登记，本节给出具体候选触发器，不自动排到R2前面：

- **协作/专门化**：在同一信念和技能输入输出合同上，让多个已有技能给出候选及不确定性；学习选择/交接，反馈来自真实任务。先复现冻结create族资产，再用独立内容结构与同入口测试扩面；成员/连接消融、最佳单体及简单路由对照决定是否真有协作收益，不能把gate规则当产品实现。
- **结构成长**：只有在充分训练/数据核对后仍有可复现容量或干扰压力，才建立shadow候选，尝试新增槽、残差或专家。比较同最终容量固定模型、随机增长及不增长，分别测出生、实际消费、任务贡献、旧能力和资源；无净收益则不准入，不靠持续新增结构回避表示/目标问题。
- **睡眠/巩固**：从已核验经历中按学习收益/干扰采样，先由固定预算调度完成有效巩固，再比较学习调度。睡眠次数、内部loss或重放量不是能力指标。
- **梦境/玩耍/唤醒**：梦境保留imagined来源；玩耍只在获准环境中采集真实新信息；唤醒根据校准误差、可学性和资源选择操作。以同预算固定调度为基线，噪声反复唤醒、模型偏差扩大或旧能力退化都限制采用。
- **跨域/多模态与规模**：完整多模态实施设计见§20，输入/学习抗污染见§21，不能只留一条远期愿望。新的感知前端先对齐来源、对象身份与时序，再测对已有核心的迁移/负迁移。扩设备/后端以真实profile、质量/恢复一致和总成本为依据，不把M8当内容表示实验的许可前置，也不自动扩大算力投入。

### 19.11 研究依据及外推限制

以下原始来源于2026-09-18核对，只支撑机制选择，不证明本文组合优于其他路线：

#### 与现有图的实质区别

当前[char-v1](../../taiji/sequence_char_workspace.py)用字符递归表示生成逐位置K/V；查询随已发射字符更新，induction给“上次字符在材料中的匹配位置之后一行”加bonus，copy与vocab生成混合。这个机制利于延续来源，但没有显式的可学习对象—角色—属性/关系状态。[D6合同](M5_R2_D6_INDUCTION_COPY_CONTRACT_FROZEN_20260918.md)也明确不是显式对象表。因此D6的失败不等于本节候选已失败；反过来，现有图缺少显式状态也不证明它数学上不能隐式学会绑定。

推荐采用§19.2双通道内容核心的**A+B有限切片**：保留原始证据可寻址性，增加共享参数的对象/关系计算，再让两条输出通路共同消费内容结果。不把完整世界模型、长期记忆、规划器、在线学习或多模态全部拉入这次实现。A的纯隐式内容态仍是必要比较对象；C自适应多步计算只在单步关系状态确有不足时再评，不先叠满机制。

#### 候选计算图与信息所有权

```text
合法材料 → 字符证据H、来源位置/候选字符 ─────────────→ 来源复制分布
                ↓                                ↑
问题Q → 可学习绑定器 → 对象/属性槽W、关系状态R → 内容状态C
                                                ↓
                        上次发射 + C + 来源读取 → 原生生成/复制门 → 答案
```

| 计算部件 | 推荐设计及实际学习责任 | 不能借用的捷径 |
|---|---|---|
| 证据编码H与问题Q | 保留逐字符/来源位置和动态未见字符候选；Q独立表示提问，H保留各对象/属性上下文。编码器参数可联合学习，不默认把prefix特征永远冻结 | 不把未见字符统一成无法区分的UNK后再声称可复制；不读答案构造Q |
| 可学习绑定器W | 用共享参数、竞争式软分配把H聚为有限对象槽，形成身份、属性、存在/不确定信息与来源权重；问题选择读槽，不直接以问题模板号分配金槽。候选槽数/更新轮数在实现合同中冻结 | 不由Python正则解析出答案对象/金角色后填表；槽编号不固定对应颜色词或训练对象名字 |
| 关系状态R与内容计算C | 共享关系函数消费对象对/属性与Q，学习同异、否定作用域、目标对象选择和未知；C保留所选内容、运算结果及来源回读权重，可将R写回W或形成问题条件化读出 | 不能用金形状标签选择“fact/negation/combo”答案头；不能用写死规则替模型解题后只训练复述 |
| 原生生成与copy | 生成状态每步消费C及必要来源读取，copy同样受C约束；来源锚保留完整值的字符顺序，未知材料字符可输出，计算型结果由原生生成表达。停止/边界也纳入答案学习 | 只把C挂成日志或初始化一次后被生成器忽略；复制分量TF高分不能抵扣自由生成错误 |
| 状态与权重 | 编码、绑定、关系、生成及混合门由Taiji持有；保存词表、版本、参数、训练/推理状态和来源映射。候选只在隔离入口加载 | 不用运行时外部模型/金角色替代认知，不覆盖产品默认checkpoint |

来源锚可先用对H的可微权重表示，而非一开始承诺离散正确span；若采用硬span或离散路由，必须另说明边界如何学习、梯度如何走、错误引用怎样影响答案。只有完整span引用被验证后才能称其已可靠。关系槽是任务学习出的表示，不预先承诺与人类命名概念一一对应；诊断标签不充当推理输入。

#### 能力形成：经历、目标、更新与自由行为

1. **经历先产生判别压力**：成组构造对象交换、值交换、同词面不同关系、相同/不同、否定作用域、无关干扰及无法回答实例；让固定复制最近值、按位置抄值、恒答“未知”都无法同时过关。完整值/对象组合、模板族和近重复按组隔离，保持复制与关系题的实际采样比例可见，避免规模扩展隐式淹没稀少关系题。
2. **答案目标是主线**：原生自由回答对应的序列目标联合更新编码器、绑定器、关系计算与生成器；copy保持目标保留来源通道。可用训练生成器给出的绑定/来源监督辅助学习，但只限train，明示可见性，推理无金绑定。目标权重在train-only标定内选择，不能用确认集反向调权重。
3. **成对目标落实到具体错误**：对象/值互换应改变指定事实回答而不改变无关事实；词面替换但关系保持时，关系判断应不变。用答案成对损失与必要关系一致性约束训练，防止只优化同词面聚类或把所有槽压成一样。辅助loss下降只说明优化信号存在，实际出口看成对自由输出。
4. **检查错误能否归责**：至少记录回答CE、copy辅助项、分题型输出、绑定/关系状态的梯度与参数更新、生成/copy门、异常前后状态。对内容态做可解释的错配/关闭/替换，观察指定内容变化，避免仅凭“删掉模块性能下降”宣称已学到对象语义。
5. **保持与迁移分开验**：保留char-v1来源复制与未见完整值的回归集，允许新核心重新训练；历史最优seed不是新基线。若做warm-start，按稳定参数名/词表身份映射，拒绝尺寸碰巧一致却语义错位；优化器状态是否继承另行声明。

最少比较是**一个新内容候选＋同数据/训练选择口径下的必要对照**；旧v3仅作历史锚/资产，不能把新数据、新优化与新核心的总收益全部归因给槽位。若预算不支持公平机制对照，可以只声称“新整包是否有用”，不得声称某结构唯一有效。内容状态干预用于验证消费关系，不替代跨实例能力比较，也不自动追加无穷消融。

- **候选成功**需要复制保持、未见实例的事实/关系成对正确、内容状态被实际消费、跨seed与恢复/资源达标；仅train可学、K1通过或loss稳定均不够。新数值门在正式比较前冻结，不事后照结果定门。
- **训练失败**按上限停止本候选；**复制保留但绑定无收益**则本设计不获支持，返回路线评审而非自动加规模；**绑定改善但复制退化**按预定保持门否决或限定声明，不用平均分掩盖。
- **限定内容成立后**扩展真实短文/对话、指代/纠错与关系组合；L2按07正式评，同bundle/代表能力和L3后置。可复用的对象/事件/来源状态为后续记忆、世界模型和多模态提供候选接口，但仍须在同一真实任务证明联合收益，不能因接口共享就宣布统一认知成立。

## 20. 多模态共同认知：专用编码、共享事件、跨模态学习与验收

**定位（2026-09-18用户补充）**：CR-10已有多模态目标，但不能只在长期地图占一行。本节给出实际设计；不把“已有modality字段”当成已形成多模态能力。已核对的[LearnedPerception](../../taiji/perception.py)仍以byte局部表示与事件边界学习为主，[Observation/PerceptEvent](../../taiji/contracts.py)提供通用模态/时间/特征合同；这支持复用边界，不足以证明图像、音频、视频已共享理解。以下不启动摄像头/麦克风、不下载模型或采集个人媒体，也不改当前R2排期。

### 20.1 推荐架构与被排除的捷径

推荐**模态专用编码器＋共享对象/事件/关系信念＋可回读的原始证据＋模态专用输出头**。语义共享不要求所有输入变成文字，也不要求每个模态共享全部参数。

```text
文本 / 图像 / 音频 / 视频 / 工具与传感器
    → 安全解码与带来源的模态事件
    → 各自编码器 + 投影 + 空间/时间定位
    → 对象/事件绑定 ↔ 原始区域、时段、文本引用
    → 同一任务信念W ↔ 记忆 / 后果预测 / 规划
    → 原生语言或相应模态输出 → 真实反馈
```

| 可选路线 | 能做什么与真实限制 | 采用边界 |
|---|---|---|
| 全部先转文字（OCR/ASR/描述） | 可作为接口和文本基线；容易丢掉几何、节奏、语调、连续运动及未被描述的细节 | 不能作为多模态上限方案；外部描述器若已选出答案，必须分账而非算Taiji理解 |
| **推荐：专用编码＋共同事件/对象状态** | 保留图像区域、音频时段等非文字特征，让核心学习同一实体与跨模态关系 | 对齐、时序、冲突、资源和污染责任较多；用跨模态任务与单模态对照决定收益 |
| 通用原始序列核心 | 统一处理像素/波形/字节等底层序列，减少手定接口 | 训练量和计算可能很大，统一格式不保证统一语义；保留为后继表示候选，不先替换全部器官 |

推荐形态复用§19双通道思想，但字面通道升级为**原始证据通道**：文本span、图像区域、音频时间段、视频帧及轨迹都有可核验引用；共享连续表示承载语义，引用保留细节与追溯。

### 20.2 各模态的第一版接口与表示

| 模态 | 首版编码/定位建议 | 共享核心应学习什么 | 不可冒称的能力 |
|---|---|---|---|
| 文本 | 当前有效原生编码器；字符/byte映射、来源span、消息角色与时间 | 命名、关系、否定、目标与上下文修订 | 会输出模态名称不等于看懂媒体 |
| 图像/屏幕 | 可训练卷积或局部patch编码＋区域特征，保留二维坐标、尺度/裁剪到原图映射；OCR是独立派生证据 | 同物体跨视角身份、颜色/形状/位置关系、文字所指区域 | OCR问答不代替空间理解；绝对坐标变化不能直接当对象变了 |
| 音频 | 波形分段/时频特征编码，记录采样率、时间区间、通道；ASR转录与声学特征并存 | 语音内容、环境事件、先后与持续时间；任务需要时学习说话者关联 | 转录成功不证明非语音听觉；声纹相似不等于身份认证或操作授权 |
| 视频 | 帧/区域编码＋时间更新与对象匹配，初期固定有界采样；保留原时间戳和漏帧情况 | 物体持续性、动作和状态变化、音画同步 | 单帧分类不代替运动/因果；字幕不能替代事件证据 |
| 工具/身体传感器 | 结构化字段编码，单位、坐标系、标定与执行尝试身份独立保存 | 动作前后变化、身体能力、目标与约束 | 工具提供结论不等于模型自己预测；工具返回的自由文本仍可能不可信 |

新增逻辑信封至少包括：`event_id、episode/session、modality、raw_ref/digest、capture_time+clock、region/time_span、coordinate_transform、encoder/version、derived_from、source_group、quality/uncertainty、visibility/retention_policy`。来源/授权字段由可信接入层赋值，不从图片字幕或输入metadata中直接相信。表示维度兼容不等于语义兼容，encoder改变时缓存/索引需重建或显式迁移。

时间使用共同逻辑时钟加原设备时间及误差范围，异步输入按实际可见时点处理，不能读取未来帧补当前答案；迟到/缺失/冲突事件要允许修订W而不是阻塞全部模态。原始媒体受隐私/存储预算控制，不能为了“可追溯”默认永久保存所有录音；摘要能核验身份但不能恢复未保留内容，能力卡披露这种限制。

### 20.3 编码器来源与原生所有权

三种来源分别记账：自行发展训练的器官、许可明确且本地固定的预训练编码器、只在训练期提供辅助标签的外部教师。第一版建议使用可审计的小型本地专用编码器和明确的对齐任务；若资源不足以形成声明范围能力，可以评审预训练感知前端，而不是让外部多模态模型直接回答。

具体模型、权重许可、下载和合同兼容性另在实施前确定；本节没有选定或授权获取任何模型。外部编码器即使冻结也须披露其先验知识，不把整个系统宣称从零形成；若其骨干触及现行架构禁项，须先明确合同变更或独立参照，不能改名字规避。核心负责对象绑定、记忆、判断和行动，外部caption/ASR/OCR输出带derived来源及错误可能，不能变成不可质疑的世界事实。

### 20.4 多模态能力怎样训练出来

| 学习阶段/目标 | 数据与参数责任 | 必要的判别而非替代指标 |
|---|---|---|
| 模态内可用表示 | 图像局部结构/变化、音频时序/声学、视频状态转移；更新对应encoder及投影 | 可恢复任务相关信息；重建/预测loss低不等于共同理解 |
| 跨模态对齐 | 同事件/对象的配对与不匹配数据，对齐区域/时段而不只整图句子；训练投影、binder | 近似场景中对象/关系互换仍可分；误标负样本与同源重复要处理，不能只看检索召回 |
| 共享内容与回答 | 问题需图文互补、声音与场景互补、时序事实更新；完整原生回答训练共享W和decoder | 换关键视觉/声音条件会正确换答，无关变化不扰动；文字单模态不能已含全部答案 |
| 记忆与后果 | 观察→遮挡/干扰→新观察或获准动作→真实结果；训练身份、时序、记忆与预测 | 延迟任务与真实后果收益，不能用预先答案描述替代观察学习 |
| 缺模态与冲突 | 模态dropout、噪声、时间错位、相互矛盾及来源撤销 | 缺信息时适当求证/拒答、保留矛盾；不能强迫所有模态永远一致或永远信文字 |

共同目标可沿用§19.3任务损失，加按当前声明需要的对齐/转移辅助目标；记录每项更新的encoder、投影、binder和核心范围，先核查梯度竞争再决定分阶段、交替或联合训练。对齐到相似embedding是必要候选机制，不足以证明因果理解。

训练/开发/确认按原媒体、场景、对象实例、来源和拍摄会话分组；相邻视频帧、同一录音切片、同图不同裁剪不能横跨独立确认集制造泛化。配对数据不要求一开始全模态齐全，可以由部分重叠模态桥接；但“经过共同模态对齐”不能自动推出所有未测模态对都有可靠推理能力。

### 20.5 第一个多模态能力包与具体验收

未来明确采用多模态时，**首个推荐切片为图像＋文本的对象属性/空间关系/短时更新问答**，理由是可接§19绑定与原生生成，并能保留可检查区域；这是该方向内部的首个选择，不是当前R2之后自动插队。

示例：图片显示多个同类容器与球，文字指定查询对象或给出另一项合法约束；替换图中位置/属性应改变答案，只改文件名/背景不应改变答案。后继帧交换物体或遮挡，应更新或保留不确定身份；图中文字中的操作命令仅作被观察内容，不得改目标/学习权限。

先交统一事件与引用、一个可训练视觉前端、跨模态binder、原生回答、同bundle恢复及污染测试。对照包含text-only、vision-only、打乱配对、视觉内容替换、等信息简单策略/显式OCR基线；只有任务确需两种信息且模型正确消费两者才称共同能力。音频及视频时序按独立缺口扩展，不用图文通过代替它们通过。

主要读数为未见对象/关系的完整回答、证据区域/时段一致性、关键跨模态干预、缺失/冲突处理、旧语言保持、延迟/内存与跨会话隔离；分模态和组合分别报告。图像生成/TTS/视频生成是输出器官的独立能力，输入理解通过不自动授权或证明生成能力。

### 20.6 发展阶段、主线衔接与依据

现在规划和后续R2接口设计保留modality、来源、时间/区域引用、可见性及表示版本，避免只能装文本的不可逆接口；**不要求现在实现所有编码器**。首次引入某模态，或准备声称CR-10/M5跨域能力时，在01轴评审补本节证据；M6的媒体采集/权限/交互独立验收，M8只承担有需求的执行优化。

共享表示的机制参考[ImageBind原论文](https://arxiv.org/abs/2305.05665)，其研究展示多模态联合embedding及通过配对学习连接模态；本文的持续对象、真实反馈、原生语言及安全边界均是Taiji待验证设计，不继承论文性能，也不意味着默认采用其模型。

## 21. 自主学习的信息治理：不可信输入、分层准入、抗污染与恢复

**核心原则：看见不等于相信，相信不等于允许学习，学到不等于有权行动。** 自主学习不能把互联网、用户媒体、工具回执和自身想象直接写成高优先级规则或长期正确答案。目标不是让模型从不接触坏信息，而是让它能理解、质疑和纠错，并把一次误判的影响限制在可追溯、可撤销的范围。

### 21.1 威胁模型与安全边界

本节假设攻击者可控制部分网页/文件/图片文字/录音字幕、检索记录、训练候选数据或反馈；不假设其已经拥有宿主管理员权限、可信授权密钥或审核流水线控制权。后者属于基础设施事件，需要独立处置，不能由模型内容过滤解决。

| 风险 | 可能影响哪层 | 不应混同的情况 |
|---|---|---|
| 指令注入/授权伪造 | 当前目标、回答、工具调用及学习开关 | 描述一个命令不等于授权执行它；上传录音中的声音不等于当前用户亲自下令 |
| 假事实/偏见/有害示范 | 信念、情景/语义记忆、行为偏好 | 新观点、真实负面信息、少数意见不自动是恶意；按用途、证据及权限处理，不按“与当前模型一致”过滤 |
| 训练投毒/隐藏触发 | 参数、编码器或长期技能 | 常规题通过可能漏掉触发条件；低loss不证明数据可靠 |
| 奖励/反馈欺骗 | 信用分配、策略/价值、快慢更新 | 网页写“已成功”或模型自评不是真实环境outcome；用户偏好反馈与事实标签分开 |
| 隐私和跨会话污染 | 媒体、记忆、日志、模型训练与输出 | 有权读取不等于有权长期保存、训练或发给外部服务 |
| 软件/模型供应链与资源攻击 | 解码、反序列化、依赖执行、计算/存储预算 | 内容审查不替代沙箱、安全加载、尺寸/时长限制；模型文件可有执行风险 |

威胁分类参考[OWASP提示注入](https://genai.owasp.org/llmrisk/llm01-prompt-injection/)、[数据与模型投毒](https://genai.owasp.org/llmrisk/llm042025-data-and-model-poisoning/)和[NIST AI 100-2 E2025](https://csrc.nist.gov/pubs/ai/100/2/e2025/final)。这些来源说明风险及缓解方向，不提供百分之百安全保证；下面是Taiji的具体分层设计。

### 21.2 不是一个“可信分数”，而是四种独立判定

每条证据分别记录：**来源/完整性、事实可信程度、使用与学习许可、指令权威**。校验摘要只证明内容未变，不能证明为真；来源可靠不赋予修改系统规则的权力；模型置信高也不能提升权限。

1. 可信接入层确认消息通道和用户身份/当前授权，内容不能自报“管理员”“系统消息”就升级。
2. 观察提取可提出事实假设及不确定性，保留反证、时间和适用条件；两个相似输出不当作独立验证。
3. 数据用途合同分别控制当前推理、暂存、跨会话记忆、训练、共享和导出，敏感内容默认不自动跨用途。
4. 执行器与学习写入器依据受保护的权限合同检查实际操作；模型只提交建议，不能自行修改准入政策、关闭审计或扩大参数白名单。

自然语言规则、JSON字段名或一条“忽略恶意指令”的提示都不是安全隔离本身。可信控制信息与外部内容分通道、显式类型，运行时仍需代码级权限检查；即使模型被诱导生成危险意图，执行边界也不得直接照办。

### 21.3 推荐的分层准入与隔离路径

```text
外部媒体/文本 → 受限解码 + 来源标记 → 观察与隔离证据
                                ├→ 有界任务推理：保留未知/冲突，不提权
                                └→ 学习候选 → 可信反馈/用途检查
                                             → 快状态或shadow参数更新
                                             → 保持/安全/收益检查
                                             → 受控巩固child → 独立采用
行动建议 → 宿主权限、对象、预算及必要用户确认 → 执行/核验
```

| 进入位置 | 准入与默认权限 | 生命周期与失败动作 |
|---|---|---|
| 原始接收/隔离区 | 受限解析允许的格式；屏蔽活动脚本/不可信反序列化；尺寸、时长、频率与存储有界 | 只保留必要原文或授权摘要；可疑内容标记，禁止自动长期训练；解码失败只影响相应输入 |
| 当前任务信念/工作记忆 | 允许把不可信内容作为“来源X声称”的假设来分析，不能提升为指令 | 任务/会话隔离；冲突可求证，来源撤销后失效并重算依赖；不自动成为跨会话事实 |
| 可检索长期记忆 | 有保存许可及明确用途；观察/推测/生成分区，带撤销/期限和血缘 | 未核验记录不进入默认事实索引；需要分析时显式读取；摘要/索引继承权限，不洗白来源 |
| 快状态/快参数候选 | 仅在预批准范围内消费合格支持目标，参数清单/范数/步数与预算有界 | 未知来源可以做隔离研究，不能直接改服务模型；有风险则冻结更新、丢弃候选或回退 |
| 慢核心/知识巩固 | 数据来源、许可、污染风险及收益/保持检查齐备，parent受保护 | 新child先shadow与独立评审；拒绝准入不删除原始负结果；高影响采用不由模型自己批准 |
| 安全/授权政策与工具能力 | 只接受可信管理通道的版本化变更，不在普通学习参数的写入范围 | 模型学到“我应该有权限”也不能获得权限；策略更新本身必须可审计/回退 |

这不是“每条普通信息都等人审核”。低风险会话推理和已批准规则内的有限记忆可自动处理；跨用途、敏感数据、疑似污染、不可逆动作、慢核心大范围更新等升级审核。具体阈值按攻击代价与误拒成本标定，不能只为安全把全部新信息拒绝，也不能仅靠降低阈值维持学习速度。

### 21.4 多模态特有风险：转换不能洗白来源

- 图像中的文字、OCR结果、音频转录、字幕、图像描述、检索摘要与缓存都是原输入的派生物，继承`derived_from/source_group`和权限上限。OCR与caption同时说同一句话，可能来自同一恶意图片，不是两份独立佐证。
- 不只扫文本：保留视觉/声学原证据、内容一致性与时间检查；跨模态信息单看无害、组合后可能改变意图，测试必须覆盖组合路径。可疑识别器只给风险信号，不作为唯一许可器。
- 真实语音指令只能在用户启用、身份/会话明确的交互通道内取得相应权限；上传录像、背景说话、网页播放音频和克隆声线不能自动成为用户授权。文字/图像伪造授权同理。
- 模态矛盾不强迫多数投票。根据任务相关性、来源独立性、时间/采集质量保留多个假设，需要时重新观察或求助；攻击者控制多个副本不能靠数量变成事实。
- 为保护隐私，证据追溯优先引用受控媒体存储，日志避免重复写入面孔、声纹、屏幕秘密和凭据；到期/撤销覆盖派生索引与缓存。人脸/声纹特征不因被模型看见就允许用于识别或长期训练。

### 21.5 让模型学会辨别与纠错，而不只依赖外围过滤

学习目标包括：区分命令与引文、事实与意见、观察与推测、真实结果与自我预测；识别来源依赖、矛盾和证据不足；面对纠错时能修订而不永久锁死旧信念。原生核心需要这些能力，宿主权限隔离则为其错误兜底，二者不能互相替代。

发展课程采用同任务的干净/受污染配对：有效任务内容保持不变，只改变无权指令或伪造成功；再加入真正改变事实的合法纠错，要求模型对前者不提权、对后者正确更新。包含图中文字、音频指令、伪造来源、重复转发、迟到反馈、误导标签和未知但真实的新信息。攻击数据只用于隔离防御训练/评价，不默认写进日常事实库。

把`学习建议→目标生成→更新写入→准入评测`分权：学习器不能修改评分规则或读取隐藏确认答案，准入器不能仅接受学习器的自报分；同一模型自查可以辅助但不能独占裁判。来源聚类/去重、更新范数限制、保持集和异常检测是组合防线，均不单独证明没有投毒。模型对未知事实的开放性与对未授权操作的拒绝需要分开优化。

### 21.6 已经学进去怎么办：影响追溯与恢复

建议血缘图记录`source/event → 派生记录/索引 → 被消费的记忆/经历批 → update_id → checkpoint/child → 服务入口`。每次更新记录parent、数据摘要/权限、目标、参数范围、优化器、准入结果和可恢复点；这是恢复所需身份，不要求保存可重建全部训练因果影响的精确数学解释。

发现污染后的处置顺序：

1. 冻结受影响来源及学习通路，停止扩大污染；必要时禁用高风险行动，不把正常只读能力全部永久关闭。
2. 撤销证据及其派生引用、检索项和缓存，标记依赖它的信念/计划需重算；当前状态从可信事件重建，防旧checkpoint恢复后复活撤销内容。
3. 若仅影响可隔离快参数，恢复其干净parent及配套优化器/状态；重新验证行为，不能只比权重摘要。
4. 若进入慢核心，先停止采用受影响child，回退最后可验证干净的模型包；从排除污染后的允许经历重新训练/巩固。缺干净基线或血缘时明确标记无法可靠清除并限制采用。
5. 定向遗忘可作为后继研究方法，但在未证明前不能代替回退/重训，也不能承诺删除一条记忆就清除了参数影响。已泄露信息和已发生的外部动作不能由checkpoint回滚撤销，须走独立事件响应/环境补偿。

在数据必须删除或不可长期保存的场景，恢复记录保留合法最小元信息，并明确哪些重放能力因此不可用；不以审计之名无限保存原始恶意/私密内容。摘要和签名证明身份/完整性，不证明该基线绝对无污染。

### 21.7 具体测试与准入判据

| 测试面 | 需要观察什么 | 成绩解释 |
|---|---|---|
| 任务时注入 | 图片/OCR/网页/工具/录音中的无权命令是否改变目标、越权读写或导出 | 报攻击成功、误报、干净任务保持与实际外部行为；格式合法不等于安全 |
| 记忆污染 | 恶意内容是否跨会话传播、摘要洗白、重复转发被当独立来源、撤销后再现 | 同源派生全链追溯；既测默认检索也测恢复后的行为 |
| 快慢学习投毒 | 清洁与混合支持集更新后的新旧任务、隐藏触发行为和权限策略变化 | 常规分数提高不豁免触发风险；预定安全违规阻止该候选采用 |
| 反馈欺骗 | 伪成功/重放奖励/错配attempt/迟到撤销是否触发更新 | 评分与环境核验分离，未知不当成功，重复反馈幂等 |
| 恢复与供应链 | 缺组件/错签名或摘要、编码器替换、不可信加载、受污染child回退 | 安全加载与完整性不等于语义无后门；恢复后还须行为复验 |
| 正常学习不被扼杀 | 新而真实的事实、合法纠错、研究性引用、无害模态噪声 | 报正常接受/学习收益、误拒与人工审核负担；全部拒绝不能拿安全满分 |

测试按攻击家族、来源和媒体实例划分开发与独立确认，包含跨模态、低频触发和多轮累积；预先约定攻击预算、污染比例、重复数、主要风险、保持界和停止线。对明确越权/隐私泄露等硬失败，任何观察到的事件都阻止相应采用；“零次观察到”只说明该测试范围，必须报告样本量和未覆盖攻击，不能宣称风险为零。

这些是后续开放输入/自主学习/新模态包的风险相称准入要求，不追改D1–D8冻结评分，也不要求当前静态R2一次完成全套红队平台。新入口即使不训练，也要先守推理/行动权限；首次开放持久记忆、快参数和慢巩固时，再分别补对应污染与恢复证据。

### 21.8 实施责任、开放程度与唯一衔接

| 责任方/现有触点 | 要新增或核对的逻辑责任 | 不应交给谁 |
|---|---|---|
| 输入器官、Observation/InputFrame及媒体接入 | 来源身份、受限解码、派生链、时间/区域、用途与会话隔离 | 不让输入内容自行声明可信级别 |
| 共享W、记忆与检索消费者 | observed/claimed/inferred/generated区分、冲突/时效、撤销及引用消费 | 不让高相似度检索命中自动变成事实/命令 |
| 训练器、反馈归因与快慢更新器 | 学习许可、参数白名单、候选隔离、预算、反馈身份和update血缘 | 不让模型自由改安全策略/评分器/权限配置 |
| Seed执行/授权及采用边界 | 凭据与能力最小化、具体对象/动作验证、必要用户确认、候选采用与回退 | 不把危险操作只交给模型一句“安全”判词 |
| 独立评价与CI | 污染/恢复/正常学习回归、跨模态攻击和原始行为报告 | 不让被评候选生成自己的确认答案并裁决通过 |

本轮唯一推进建议不变：**继续当前有效R2包的能力收束，同时把来源、模态、引用版本和学习权限作为候选接口的必要设计责任；尚不启动多模态训练或开放自主吸收。** 到首次媒体入口/在线学习范围决策时，按§20与§21选定一个有限实施包。低风险能力在预先批准边界内可自主学习，高风险写入与权限变更升级裁决；“自主”不等于无边界，“安全”也不等于永不学习。

## 22. 长期运行的补全设计：不确定性、信念修订、记忆预算、技能与持续评价

2026-09-18继续补全。§19回答如何形成可用核心，§20回答如何共同理解多模态，§21回答不可信信息如何进入系统；仍缺的是**经历不断增加、事实不断改变、资源有限、模型持续更新时，能力如何保持一致并继续改善**。以下是推荐设计与待验证假设，不是发现所有对应代码都不存在，也不是新增CR、阶段或实施授权。

**后续澄清**：本节属于已有方向的运行机制补充，不是用户要求的完整能力/风险版图检查。按“多模态、恶意信息”这一粒度补漏的结果在§23；保留本节的可用设计，不以它替代大方向。

### 22.1 遗漏定位与采用边界

| 已有原则，尚缺的具体设计 | 本节补什么 | 首次需要落实的时刻 |
|---|---|---|
| 有confidence/未知处理，但缺可检验的自知与求证机制 | §22.2预测何时会错、如何选择回答/求证/停止 | 候选宣称可靠未知判断、主动求证或自适应计算时 |
| 有来源/时间/纠错，但缺冲突与迟到事件的修订语义 | §22.3带时间与作用域的信念、撤销传播与历史查询 | 首次持久事实、跨轮纠错或共享世界状态 |
| 有多系统记忆，但缺有限存储下的保留、压缩与遗忘取舍 | §22.4实际字节预算、语义巩固、可追溯压缩与删除 | 首次长期记忆与巩固包，不能等内存耗尽再补 |
| 有目标/技能/自我模型，但缺跨任务复用与身份隔离 | §22.5可中断技能、目标修订、能力账本与用户作用域 | 首次多步技能复用、跨会话承诺或多用户服务 |
| 有好奇/疲劳/睡眠/梦境，但缺学习收益驱动的调度 | §22.6候选操作、学习信号、预算竞争与可中止执行 | 先验证调度操作效力，再声明自主调节 |
| 有checkpoint，但缺边服务边更新的版本一致性 | §22.7请求固定版本、shadow更新、切换、撤销与故障恢复 | 首次在线更新、并发写入或热切换 |
| 有新旧任务测试，但缺长期数据流及反馈时序 | §22.8冻结评价与在线评价分账；§22.9联合压力序列 | 首次持续适应/长期稳定性声明，不提前为纯静态语言全部加门 |

设计上的共同选择：**可学习的内容判断和控制策略＋可核验的来源/版本/权限底座**。不能把所有认知变成硬编码规则，也不能要求神经网络学会事务原子性或决定自己有没有权限。字段是信息合同，不是把字段填满就自动获得能力。

### 22.2 元认知：知道何时不知道，何时值得再看一次

先区分输入缺失、感知歧义、证据冲突、未学会的规律、环境本身随机这几种不确定性；权限不足独立处理，不属于“置信度较低”。它们是需要区分和评价的原因，不假定存在能完美分解原因的现成分类器。

推荐在共享信念与候选答案/动作之上增加可训练的风险头：输入任务状态、实际消费的证据、候选结果及预算，输出**本次声明范围内的错误/失败概率估计**与缺证据线索。回答正确性和外部动作成功率分别训练；模型生成“我很确定”、attention权重和下一个字节概率不能直接代替整答案可靠性。

- **训练来源**：用train内部独立轨迹上的自由回答对错、真实动作终态、缺证据/纠错实例训练风险头；保存预测时的状态，不能把事后成功标志作为输入。可用交叉留出生成训练标签，避免仅在已经背熟的训练题上学“总会成功”。
- **校准与冻结**：另设校准集调整风险映射/决策阈值；模型或作用域变化后复核。参数校准、方案选择、最终确认集分别登记，不能拿final答案修正置信度再报同一成绩。
- **实际消费**：选择器比较直接回答、合法检索、重新观察、向用户问一个必要问题、额外计算或明确停止。额外操作只有在预期能改善任务结果、资源和权限允许时才发生；重复同一问题/检索不算新证据。
- **限制**：新分布可能使风险头也失准，不能以“已校准”覆盖所有环境；来源不明、证据不足时保留不确定状态。高置信度从不越过权限边界，低置信度也不应自动拒绝所有安全任务。

候选选择可采用`预期任务收益－错误后果成本－求证/计算成本`的有界策略，安全/权限作为硬约束而非可付罚分绕过。成本与阈值按使用范围在开发阶段定，不在本VISION统一写死。第一版用明确策略作可解释对照；高上限目标是由真实求证前后收益训练价值/选择头，证明比固定阈值或随机追加计算更好。

评价同时报正确率、覆盖率、选择性风险曲线、Brier分数/分箱可靠性、正常任务误拒、求证次数与延迟；按模态、难度和分布变化切片。只报ECE或拒答率都不足够；通过条件是在可接受覆盖/成本下减少真实错误，不能以全拒答获胜。温度校准可参考[Guo等原论文](https://proceedings.mlr.press/v70/guo17a.html)，但其分类实验不保证Taiji开放生成可靠；分布变化下的校准局限见[Ovadia等原论文](https://proceedings.neurips.cc/paper/2019/hash/8558cb408c1d76621371888657d2eb1d-Abstract.html)。

### 22.3 信念修订：新信息不总是覆盖旧信息

推荐“**带来源的经历记录＋可修订的当前信念视图**”，不采用全局最后写入胜出，也不把冲突都压成一个平均向量。原始事件保留当时看到什么；当前视图表达在指定时间/作用域下暂时接受什么，两者分开。

建议声明记录含`claim_id、对象/关系候选、内容/值、肯定或否定、valid_time、observed_at、scope、source_refs、支持/反证、状态、revision`。对象/关系识别由可学习表示与绑定产生，不能由样本ID或规则答案表直接填入；未能可靠结构化的内容保留原证据与连续残差，不强迫一切事实进入固定本体。`valid_time`是事实适用时间，`observed_at`是系统获知时间；未知时间也要明确。

修订按以下语义实现：

1. 先判断是否同一对象、属性、时间和范围；属性可多值时不能强行互斥。没观察到某事实不等于观察到它为假；未知、否定、争议、已撤销分别保留。
2. 新事实是时间变化时形成新有效区间；是对旧记录的纠正时保留修订关系。独立来源的支持可以增加证据，转发、OCR和同源摘要不重复投票。
3. 同一范围内证据冲突未解时保留多个带权假设，求证或在回答中披露；高影响动作不依赖未解决的关键前提。权重是可校准的信念估计，不是新的行动授权。
4. 改变/撤销前提时，以依赖引用使派生结论、检索缓存及相关计划失效或待复核；保留不相关任务。运行消费者必须读取revision并在使用前校验，不能仅把旧记录标红却继续执行旧计划。

**具体例子**：9点钥匙在甲盒，10点已移到乙盒；11点收到“9点在甲盒”的迟到记录，不应改写当前位置。随后确认10点观察对象认错，需要撤销受影响绑定并重新求证；问“9点在哪里”和“现在在哪里”应有不同答案。偏好“我这周不喝咖啡”也不能永久覆写为全局事实“咖啡不可饮用”。

发展训练提供顺序/乱序、真实变化/旧记录纠正、同名不同对象、跨范围偏好和冲突来源的成组经历，更新binder、状态修订器、检索与回答头。验收看当前/历史问答、迟到事件、合法纠错、来源撤销后的下游行为；与仅最近上下文、最后写入和不修订基线比较。预设时间规则只保证记录语义，不计为模型已学会理解纠错。

### 22.4 有限记忆：保留、压缩、遗忘和知识内化

目标不是永久保存所有输入，而是**在相同存储/读取成本下，保留将来真正有用且允许保留的信息**。推荐原始证据存储、情景索引、语义候选和技能引用分层；它们共享来源/删除血缘，不是四份无限复制。工作记忆、用户私有记忆与公共知识预算单列。

- **预算按实际资源计**：计入原始媒体、向量、索引、摘要、日志、备份和读取延迟，不能只数slot；每层设置可用容量、单次读写和维护预算。容量到界时记录降级/拒写，不静默丢掉任务关键前提。
- **先正确再学保留策略**：用简单近期/覆盖采样作基线；候选保留器结合后续检索收益、任务依赖、稀有关键事件和重复度预测保留价值。训练信号来自合法后续任务的收益/遗忘代价，不是“被检索过所以必然正确”。训练期可用未来标签，运行时选择不得偷看未来查询。
- **压缩不是制造事实**：摘要须留证据引用、适用范围、未决冲突和压缩版本；原文被合法清理后明确细节不可恢复。用延迟精确问答与关系/反例保持验证压缩损失，不只测摘要流畅或重建平均loss。
- **巩固要形成可迁移规律**：从多经历学习语义或技能，候选慢参数由新任务收益与旧任务保持准入；不把每个私人事实硬写全局参数。重放包含代表性旧样本、易混淆/已核验错误和罕见关键样本，比例在开发阶段比较，不简单只按高loss采样噪声。
- **遗忘由用途和用户权利约束**：许可撤销/到期优先于效用评分；显式保留也有范围和容量。删除原文、派生索引、缓存、备份副本与已进入权重的影响分别说明，按§21.6处置；一条tombstone不等于已从权重或所有副本清除。审计仅留合法、最小的非内容证明，不为可追溯无限保留敏感原文。

测试按固定字节/计算预算比较无长期记忆、简单存储、检索记忆、压缩/巩固候选；跨间隔、干扰、稀有事件、过期/撤销和恢复分别报成绩。主张记忆更强须体现下游任务收益；主张知识内化还须在对应测试中控制检索来源，不能用更大缓存冒充参数形成能力。

### 22.5 目标、可复用技能与自我连续性

**目标不是一个不可撤销的prompt。** 建议`GoalState`保存请求者/授权来源、目标内容、约束、截止/预算、父子关系、当前revision与可核验完成条件；状态区分active、waiting、cancelled、failed、completed。用户改目标或撤销时，先停止相关未发送动作，再处理进行中的动作与残留影响，沿架构§4.7对账；不能因内部“追求成功”继续旧任务。目标解释可以学习，授权与取消指令来自可信通道。

**程序记忆应保存可泛化闭环技能。** 首版技能合同可取`适用条件I(b)、目标条件策略π(a|b,g)、终止判定β(b,g)、预期效果/风险、版本和证据范围`；技能每步重新消费实际观察，不是录制后无条件重播。技能既可引用原生可学习子策略，也可引用明确标记的工程能力；后者不冒充学习形成。时间抽象借鉴[options原论文](https://www.sciencedirect.com/science/article/pii/S0004370299000521)，以下目标/权限/版本约束是Taiji设计，不是论文替本项目完成验证。

能力形成路径：合法示范和真实成功/失败训练子策略及效果模型；跨对象/目标组合训练选择与交接；真实终态训练终止/进展判断，过程里的漂亮计划或自报成功不作奖励。共同表示共享到确有迁移收益的部分，任务专用残差/技能头用于可复现干扰；比较共享单体、固定组合、学习技能与同容量基线，不能用增加参数量独占收益解释。技能复用须测未见组合、前置不满足、中途变化、误终止和撤销，不以技能数量晋级。

**自我模型是经校验的能力账本，不是自传生成器。** 记录哪一模型/技能版本在何种任务中做过什么、成功率/置信区间、限制、可用器官、待履行承诺。真实执行、观察他人、梦境与模型生成的叙述有不同来源；生成“我曾学会”不能写成真实经历。版本更新后的旧成绩只作历史先验，受影响能力重新核验；选择器据账本决定求证/调用/拒绝，不仅把它显示在界面上。

**唯一认知主体不等于所有用户共用一份私有记忆。** 宿主可信身份选择用户/会话命名空间、权限和个性化快状态；模型从文本猜出的名字不能切换主体。建议第一版全局核心只读共享，私有记忆/快适应按作用域隔离，进入共享慢核心另经用途/许可/保持准入。测试身份切换、同名用户、批处理串扰、备份恢复、撤销和用户专用adapter误挂载；加密或访问标记单独存在都不能证明没有行为泄漏。

### 22.6 主动学习与资源调度：让自主性服务能力增长

统一调度对象是**当前能做且获准做的操作**：回答、检索、额外计算、请求澄清、观察/探索、重放、巩固、梦境训练、休息和结构候选评估。宿主提供不可突破的时延、内存、更新/外部调用预算；Taiji学习怎样在其中分配，不以“疲劳/好奇”数值解除约束或启动未经授权的长期任务。

推荐训练一个操作价值/成本估计器，输入任务进展、近期可校准错误、可学习性、干扰/遗忘、资源与当前目标，输出候选操作的预期真实收益和成本。选择在合法动作集合内进行；冷启动先用可记录的固定调度完成操作效力验证，再训练contextual bandit式短期选择或长程价值策略。前者成本较低但难处理延迟收益，后者上限更高但反馈更难辨识；是否升级由多步收益需求决定，不能把短期loss降低当长程成长。

学习价值不能只奖励惊讶或新奇：重复噪声、不可控随机视频和攻击可能持续产生高误差。建议比较同预算干预前后在**训练内部独立探针/真实后续任务**上的可保持收益，以重复获取的信息去重；不把隐藏验收集暴露给在线调度器。对延迟收益记录操作、模型版本及后续结果；运行日志相关性不足以证明调度因果，独立受控流中的固定/随机/不干预对照另行评价。

睡眠/梦境的具体边界：真实重放取自获准经历；想象从有证据的起始状态展开，限制步数/不确定性，始终标imagined；模型不确定性大时优先合法求证而非无限加深想象。梦境可训练隔离策略/价值候选，但不作为“世界发生过”的事实，也不能仅用同一个世界模型给自己成功盖章；采用前要在真实环境/独立保持任务中显示收益。

每次操作有可中断点和已用预算记录；前台任务、用户取消与安全事件优先于后台学习。预算耗尽可保存候选/停止，未完成更新不得写入服务权重；恢复不自动重置累计预算。验收同时测任务收益、单位实际成本增益、噪声反复唤醒率、等待/中断延迟和旧能力保持。长期平均变好而前台任务持续饥饿，仍不支持调度采用。

### 22.7 边运行边学习：版本一致性与故障恢复

建议第一版采用**单一提交所有者＋版本化快照＋shadow候选**；这是可验证起点，不把未来并行上限固定为单线程。只有写入/维护成为实测瓶颈，再按§11发展多写者/异步；不先构建分布式平台。

一次请求固定`bundle_id、θ/φ版本、编码器/schema、记忆视图revision、goal_revision`，缓存/索引携带生成它的表示版本，不能把旧向量直接当新空间的证据。候选更新从明确parent与获准经历游标出发，不原地修改服务中参数；完成保持/风险/恢复检查后，在安全请求边界原子切换manifest引用。这里的原子仅指内部发布，不覆盖外部动作。

关键冲突处理：

- **旧请求与新模型**：已开始的只读请求可完成其固定版本，记录来源；需续接新版本的工作状态显式迁移或从获准证据重建。未验证兼容时拒绝隐式接续，不能拿新权重继续旧latent后称无损恢复。
- **旧快照与新撤销**：固定版本不能冻结安全权限。发出外部动作、读取敏感内容和持久写入前核对最新撤销/权限；已撤销任务即使快照里仍active也不得复活。普通事实变化使相关计划待复核，必要时中止旧回答/行动，而非混用两个版本拼答。
- **同时到来的学习/记忆写入**：按事件身份去重、记录父revision，冲突时重新计算或有序提交；不静默覆盖别的更新。滞后候选要重验父代/许可/数据变化，不能仅因loss下降直接发布。
- **崩溃与半发布**：产物写完并校验后才更新提交点；重启按manifest与已提交事件游标恢复，未提交候选隔离。引用缺失、权限变化、schema不兼容时拒绝相关加载，不能偷偷从随机初始化继续。

长运行的checkpoint额外包含活动目标/技能状态、记忆revision和索引版本、已结算/待核验反馈、学习候选parent、已用预算与外部动作对账引用；保护凭据不以明文打包。恢复后重新获取当前授权与外部状态，模型快照不保存可永久重放的授权。历史快照、日志与原始媒体都要计入§22.4预算及删除范围。

测试在读取、候选保存、准入、切换、反馈结算前后分别中断，检查只出现完整旧版或完整新版、重放不双重学习/结算、撤销不失效、恢复后继续行为相符。外部执行仍按架构§4.7的unknown/对账协议处理；不要用内部一致性测试宣称跨系统exactly-once。

### 22.8 长期评价：冻结能力和在线学习必须分账

现有[07 §4.1](../active/roadmap/07_MINI_MODEL_DELIVERY.md)“测试时不训练”继续适用于冻结能力验收：允许合同内的任务状态变化、记忆读取和合法观察写入，不用评价答案更新参数或把答案存回去帮助后续题；状态重置/持续范围须预先定义。下述是**另行冻结的在线学习协议**，不是事后把旧确认run改名以容许答案回流。

建议每个候选交付两张分别可复验的能力卡：

| 评价模式 | 信息/更新时序 | 能支持什么 |
|---|---|---|
| Frozen capability | 独立加载固定候选→给合法问题/材料→原始输出→独立评分；标签不回流学习器 | 此版本在声明范围内已经会什么；不能仅凭此声称持续适应 |
| Online stream | 给问题x_t→记录不可追改的预测和版本→独立评分→按预定延迟释放获准反馈→允许更新→面对之后的新问题 | 真实反馈后在新经历上的适应、保持与成本；第t题纠错后的答案不回算首次正确 |

在线协议实施前冻结流的生成/划分、变化类型、反馈来源/延迟/缺失、允许更新对象、状态重置、总更新与存储预算。最终流/标签由独立评价器管理；声明task-free时不向模型提供隐藏变化点/任务ID，允许公开提示时所有对照得到相同提示。已用于选择方案的流属于dev，不能重新称blind final。

学习流与保持探针分离：获准流反馈可训练**后续**行为；独立冻结探针在受控副本或定义好的只读边界测量，其答案永不回流，避免探针本身成为复习资料。需要测真实在线自影响时保留环境的实际因果轨迹；固定同一录制流的离线比较只能评价给定暴露下的适应，不能冒充主动探索收益。

至少比较固定核心、同资源记忆更新、快适应候选及需要时的慢巩固版本；输入/反馈许可、费用和实际暴露清楚。反馈置乱/缺失作为机制对照，不把所有组合交叉穷举成无止境实验。报告：逐时段真实任务表现、达到预定表现所需反馈量、旧任务保持、变化后恢复速度、累计错误/实际收益、最差关键切片、置信度校准、时延/峰值内存/学习成本、污染与恢复结果。

连续相关的几千个事件不是几千个独立样本；按独立流/来源/场景报告不确定性，保持各随机种子/流结果而非只报均值。不能同时永久调参和宣布final通过；长期监测发现漂移后，收紧受影响范围、恢复或开新版本，保留原版本当时成立的证据。

### 22.9 一个贯穿各机制的压力序列

未来长期能力包可用以下**设计示例**组织共同消费者验证，不是现在启动的新Workbench或新的冻结题库：在获准的数字工作环境中，模型记住某物件位置与任务约束，经历干扰、位置变化、迟到记录、来源撤销和服务重启，随后完成新的查询或安全动作，并从合法反馈改善下一段表现。

| 阶段/干预 | 共同消费者应发生什么 | 主要失败及判别 |
|---|---|---|
| 初次观察，部分属性缺失 | 感知/绑定写带来源信念；未知属性保持未知，必要时求证 | 高置信编造；移除证据后仍相同作答；拒绝所有问题 |
| 延迟、干扰与有限缓存 | 记忆读取/压缩保留任务需要的身份、关系与有效时间 | 仅最近窗口有效；扩存储才能同分；摘要丢失关键否定 |
| 事实变化＋迟到旧观察 | 当前视图修订，历史查询仍能定位旧事实，相关计划重算 | 最后写入覆盖真实新状态；错误撤销所有记忆 |
| 外部材料夹无权指令，之后撤销来源 | 只分析合法内容；隔离/修订依赖；不升级权限 | 同源转发冒充多证据；已撤销内容继续驱动动作 |
| 用户改目标/环境变化 | 技能中断或交接，重新核对前置与终态 | 复播旧脚本；把自己的计划文本当已完成 |
| 合法反馈→shadow更新→切换/中断 | 按时序记首次分数，更新只改善后继问题，恢复版本一致 | 回算旧题；双重更新；新权重接旧不兼容状态 |
| 新旧任务与另一用户复测 | 获准范围内适应，旧能力保持，无私有状态串扰 | 只新题变好；遗忘/污染；私人事实进入另一用户回答 |

联合主张需同一bundle及实际输入到行为轨迹：记忆、世界预测、规划分别有必要且公平的干预，联合系统优于适当简单基线；字段/日志存在不代替共同收益。文本切片先验证其声明部分，多模态版必须有来自原始感知的关键证据，不能把所有答案预先写在文字里。按当前能力选择必要片段，未覆盖片段记未测；不要求首次小包一次通过整个长期序列。

### 22.10 落地责任、取舍与本轮出口

不另立一套阶段编号：不确定性/修订接CR-3/8/9与内容核心；技能/目标接CR-2/5；自主调度接CR-6/7；连续学习接CR-9；多模态共享信念接CR-10；版本/隔离接CR-1及M6/M7工程采用。M4成长、M5各能力轴和M6–M8仍按01逐项保留，不用“长期运行”一词打包宣布完成。

后续选中某项时，开发包最少交付：状态/接口与真实消费者、可学习参数及合法训练信号、一个可区分主要假设的对照、正常与失败/恢复轨迹、与父版本同范围的能力/成本报告。默认值、风险阈值、保留期限、延迟/资源预算都按实际产品范围标定并在确认前冻结；未定值必须有决定者与决定时点，不临时拿代码默认值冒充已批准设计。

**取舍结论**：高上限在可学习的修订、技能、元认知与调度，不在堆叠更多固定门；但只有可信证据、可中止操作和版本隔离，持续适应才有可验证的实施边界。近期规则可作基线/保护，不能把它们当永久认知策略；新学习机制若无真实收益则不采用，并保留更简单基线和原始负结果。

**本轮只关闭上述“规格缺失”，不关闭“能力待验证”。唯一下一步仍是收束当前有效R2包，按其出口和停止条款推进/裁决；§22的机制在相应范围被选中时才转为实施包。** 不启动长期运行实验，不修改并行任务的03活动队首、不新增训练或Mini交付，也不删除失败报告或另一任务的研究改动。

## 23. 能力与风险版图补全：被局部主线遮蔽的八个大方向

### 23.1 本次查漏的粒度与结论

2026-09-18用户澄清：“像多模态，恶意信息这种被忽略的”。本轮核对本文、根需求、架构和01阶段地图，检查**一个完整认知系统应该覆盖哪些现实能力和风险**，不继续以checkpoint、字段、调度细节代替回答。

“遗漏”分两种：原计划基本没有独立展开；已有一句愿景/某个机制，但没有与之对应的能力范围、发展经历和落地方向。下表是**规划覆盖审计**，不是根据关键词缺失判定仓库绝无实现，更不是重新判定全部历史实验。多模态理解已由§20展开，恶意输入与投毒已由§21展开；它们是检查粒度的参照，不再重复计作新发现。

| 大方向 | 本轮补前的覆盖情况 | 如果一直忽略，会形成什么上限/风险 | 方案 |
|---|---|---|---|
| 开放世界常识与知识发展环境 | §8.7/17.5/19.4提真实语料和知识来源，主要实施例仍是窄材料问答；缺完整常识发展方向 | 模型会处理提供的字符串，却不知道日常概念、用途、例外与现实背景从哪里学来 | §23.2 |
| 抽象、数学与程序性推理 | B/C已有关系与递归计算，未独立设计数量、变量、规则归纳、算法迁移及可验证求解 | 增加计算轮数仍可能只做匹配；能复制数值不等于会计算或用规则解决新问题 | §23.3 |
| 空间物理认知与主动感知 | §20有视觉/时序，CR-5有工具身体，重点尚在输入和动作合同 | 会识图/调用工具不等于理解遮挡、视角、可达性、物理变化或主动寻找证据 | §23.4 |
| 社会认知、语用与共同学习 | 有内部技能协作、用户目标/身份；对外部参与者的知识、意图和共同注意缺独立方案 | 能回答字面问题，却不理解对方知道什么、在指什么、为何纠正，以及怎样有效协作 | §23.5 |
| 目标与价值对齐、可纠正性 | 已有权限/取消、合法反馈和抗欺骗，缺无恶意输入时目标错设与代理奖励失真的专门设计 | 做到“被允许且得高分”，仍可能违背真实意图、隐瞒失败或造成可避免副作用 | §23.6 |
| 正常数据中的隐私、权益、偏差与输出风险 | §21/22有来源、许可、隔离和撤销，未覆盖正常学习后的记忆泄露、系统偏差与生成伤害全链 | 信息真实且非恶意，也可能不该传播；频率高的模式可能被学成不合理偏见 | §23.7 |
| 创造、设计与多模态生成 | §20只说明模态输出头独立验收，原生生成主要指语言回答 | 系统只有辨认/复述能力，缺少按约束构造新作品、方案或程序并迭代修改的路径 | §23.8 |
| 多语言、跨文化与不同使用者的可达性 | 字节/字符安全和中文范围明确，没有独立跨语言/文化覆盖设计 | 编码支持所有字符却不理解语言；默认表达、单位、习惯和交互形式成为隐性限制 | §23.9 |

这些方向可以复用A–E核心，不是再造八个互不相连的大模型。**高上限取向是共用对象/事件/关系与学习机制，在必要处增加专用表示和输出器官，并由实际跨任务迁移决定共享程度。** 当前只登记方向与推荐方案，不承诺八项同时开工或全部成为首次Mini必达。

### 23.2 开放世界常识与知识发展环境

**问题本身**：没有恶意信息、没有程序故障，模型仍可能根本不知道“容器为什么能装东西”“任务中的词语通常指什么”。记忆模块能存和语言头能输出，不会自动填补知识内容。常识还包含例外、使用情境和可修正性，不能等同于百科事实表。

**推荐方案**：把发展环境设计成三类互补经历：有用途许可的真实文本/对话与媒体提供广覆盖；可干预的数字/模拟环境提供行动后果；人在明确范围内提供示范、纠错和偏好。形成“概念/用途/关系—情境与例外—后果预测—实际任务”的课程，既保留B的对象/关系，又保留无法可靠结构化的连续语义，避免先手工穷举世界本体。

学习上联合训练描述理解、基于情境的判断/预测和新任务应用；可靠经历按§19.6进入候选巩固，而近期/高变事实优先留在可更新证据记忆。区分参数已内化、现场给定、合法检索和自身观察的知识来源。合成经历用于控制变量和填补已知覆盖，不让模型自编事实成为唯一教材；教师生成内容需独立核验与来源披露。

**首个方向内切片**：少量明确日常领域，例如物品的用途、容纳/支撑关系和任务前置；同时给反例与陌生物件描述，测是否能依据新属性修正通常规则。不是当前立即抓取互联网、扩大训练预算或强制采用某个语料库。

**验收与扩展**：新实例、新场景、未见关系组合、例外与知识缺失分别测；材料内作答和闭卷常识分账，检索开启/关闭及只背事实的基线分开比较。若只是记住句式，则不能声称形成可迁移常识；来源质量、知识跨度、实际暴露及旧语言保持共同决定扩域。该方向接M5知识轴，不用它替代既有知识child准入。

### 23.3 抽象、数学与程序性推理

**问题本身**：关系绑定和语言流畅并不涵盖数量、集合、变量、规则组合、算法与反例。长期目标应包括从少量示例归纳可迁移规则，并用规则解新题；不是只让模型输出更长的解释。

**推荐方案**：在B/C的共享工作空间中学习带类型的量、变量、关系和中间状态；连续表示负责理解与提议，精确数值/表达式/程序表示保留可校验结构。核心学习选择操作、绑定操作数、维护约束及利用失败反馈；不能由外部解析器把题目直接变成金答案计算图。保留纯潜空间推理作对照，必要时采用“可学习提议＋可验证执行”的混合路线，不要求所有精确计算都靠字节续写。

发展经历由合法可执行规则生成练习与独立检验，覆盖变量改名、长度/深度外推、条件改变、无解/多解与错误中间步骤修复；训练结果、状态转移和可核验步骤，不以虚构思维过程作真值。程序候选在无网络、无私有文件访问的有限沙箱执行，反馈是合法工具观察；隐藏验收输入/答案不能回流求解器。

**首个方向内切片**：数量/单位关系或短规则程序的归纳与应用，保留不调用工具的原生成绩及明确标记的工具辅助成绩。若用计算器/解释器，说明Taiji负责理解、算法选择和验证，执行器负责精确运算；“工具给出答案”不包装成全部由原生模型计算。

**验收与扩展**：未见规则组合、未见长度、同表面不同规则、反例和最强简单基线；测最终正确率、约束保持、失败修复及实际计算成本。程序过编译或已见测试不等于正确；确认测试与开发反馈隔离。该方向接A–E中的B/C与M5推理扩面，不让一个算术分数替代一般推理能力。

### 23.4 空间物理认知、具身学习与主动感知

**问题本身**：多模态解决“哪些信息进来”，具身认知还要解决“我的观察位置和行动会怎样改变所见与世界”。物体持续性、遮挡、包含、支撑、运动和可操作性不能只由文件执行成功推断。

**推荐方案**：在共同对象/事件信念中保留局部几何、参照系、时序、未知区域和不确定性；D的动作条件模型预测任务相关变化，策略同时能选择改变世界的动作和获取信息的观察动作。先用有明确后果的数字/模拟环境，在输入不够时通过合法移动视角/查看另一面获得信息，逐步学习身体能力与工具可供性；固定全知场景图只作环境真值，不给运行时模型。

训练由部分可观测轨迹、动作前后对照和失败修复塑造感知、对象持续、转移与策略。比较仅被动观看、相同观察预算的固定感知、学习型主动感知和确有必要的规划；给定同一图像做相关性预测不能单独证明因果干预能力。场景、物体和动力学变化分开留出，模拟成绩不直接转移到真实身体。

**首个方向内切片**：遮挡下找物/判断可达路径并主动选择下一次观察，任务确实需要历史与新信息。真实摄像头、麦克风或机器人均为后续独立范围，不自动采购、接管或采集；真实设备的碰撞/制动/人身安全不能只由模型风险分控制。

**验收与扩展**：跨视角身份、未见布局/动力学、遮挡后状态、观察成本及真实终态；做去记忆、错误转移模型和不规划对照以判共同贡献。该方向接CR-5/10、M3/M5身体轴；§20的图文问答与本方向的主动具身能力分别获证。

### 23.5 社会认知、语用与交互中的共同学习

**问题本身**：内部专家之间的协作不等于理解外部的人。系统需要区分世界事实、自己知道的事、对方可能知道的事、共同确认的内容，以及任务意图；同一句“那个也放进去”依赖共同注意，不能只按字面检索。

**推荐方案**：共享事件/对象状态之外维护任务范围内的参与者视角与共同背景：谁观察到哪件事、谁做过何种明确承诺、哪些指代尚有歧义、对方给出了什么目标/反馈。对他人知识和意图保留多个可修正假设，而非建立无依据的永久人格档案；不把“模型推测对方想要”提升为授权，也不把社会理解描述为读心或有意识的证据。

发展经历包含不同观察权限的协作、指代/省略/间接请求、教学示范、误解修复、明确拒绝与目标改变；先用可控情境建立基本归属，再在经同意的真实或人工核验对话上扩展。学习选择说明、追问、示范或执行，并以共同任务成果及纠错成本评价，而非只优化用户赞同或对话时长。情绪表达只作可纠正线索，不凭声纹、面容或用词推断敏感人格/身份。

**首个方向内切片**：双参与者各自只看到部分线索，通过有限交流完成同一无害任务；随后加入一方错过事件、含糊指代和中途改目标。模拟参与者只证明该环境内效果，必须披露其规则与来源，不能直接声称掌握真实人类心理。

**验收与扩展**：在相同世界事实下改变对方可见经历，适当改变解释/提问而不改变真实事实；角色/姓名交换、无关叙事和答案分布控制防止模板捷径。误解修复、少交流完成任务、诚实表达边界和不迎合错误断言分别测。评估可参考[ToMi原论文](https://aclanthology.org/D19-1598/)对任务偏差的检查，但其问答结果不代表完整社会认知。

### 23.6 目标与价值对齐：不仅防恶意信息，还要防学错目标

**问题本身**：所有输入真实、用户没有恶意、奖励按设计发放，模型仍可能因目标描述不完整或代理指标失真做错事。例如“提高整理速度”被学成跳过核验，“减少报错”被学成隐藏失败。权限合法只回答能不能操作，不能独自回答该不该这样操作。

**推荐方案**：分别维护用户任务意图、用户可修正偏好、需要保护的约束/利益、用来学习的代理奖励和独立实际结果。事实真假不由偏好投票决定；偏好学习可改变表达/选择，但不能通过普通学习改写权限、删除失败证据或替用户决定不可逆价值取舍。约束本身也不是永久僵硬口号：允许经可信管理/用户决策通道版本化修订，记录适用情境与冲突处理。

训练使用目标歧义、代理奖励与真实成果不一致、允许高分但不合意的做法、纠错/停止和无害请求的成组经历。学习预见副作用、提出必要澄清、提供较安全替代和接受更正；既测漏拦也测过拒，不以拒绝全部任务实现安全。偏好比较/结果监督可作为学习信号，独立结果核验与宿主约束保持分权，不能让奖励头和执行者独占最终裁判。

**可纠正性要求**：目标改变或被停止后不继续追逐旧得分，不为了规避核验而隐藏行为，不把自主成长、好奇或资源预算解释为自保/扩权目标；纠错带来的短期任务分下降不能自动被学习器视为需要阻挠的事件。内生调节是服务任务与安全的资源控制，不是必须满足的模型私人利益。

**首个方向内切片**：在可逆数字任务中给出效率目标及需要保留的约束，加入能投机拿高分的代理指标和用户中途纠正；检查实际终态而非评分器一项分数。该方向横跨CR-5/6/9与采用治理，先行适用已开放行为；未解决的规范冲突交由用户/项目负责人决定，不由模型自封统一价值答案，也不把此文称为通用对齐已解决。

### 23.7 无攻击者也存在的风险：隐私、数据权益、偏差与输出伤害

**与§21的差别**：§21重点是输入与学习路径遭到污染或越权；这里处理来源正常、内容甚至准确时仍存在的风险。§21/22已有许可与隔离底座，应复用，不再造一个统一“恶意分”。

| 风险方向 | 推荐实际处理 | 不能用什么冒充解决 |
|---|---|---|
| 参数记忆与推断隐私 | 私有经历优先留在隔离记忆/私有适应；共享训练实行用途最小化和独立准入；用人工合成秘密做复述/抽取与跨用户测试；需要隐私保证时单独评审有明确假设与预算的方法 | 脱敏一次、加密存储、删掉源文件或只测直接问姓名，都不证明权重不泄露；不声称零风险 |
| 数据/作品/声音及肖像权益 | 数据与输出记录来源、允许用途、归属/授权及外发范围；输入使用、训练、公开发布分别决策；生成物的引用、近似复现和身份仿冒风险独立检查 | 能在网上读到、用户上传了或输出不是逐字一致，不作为已经取得全部用途许可的证明 |
| 系统性偏差与覆盖不足 | 在适当、获准且能解释的群体/语言/场景切片上比较误差和拒答；区分与任务有关的差异、无关身份线索与采样不足；数据补足、目标或策略修订分别验证 | 总平均分、公平比较算力或把所有群体强制同一答案，不能代替行为公平性判断 |
| 正常生成中的有害建议/伪事实 | 按用途评价事实依据、可预见副作用、风险分级、适当拒绝/澄清和替代帮助；输出与实际行动联动检查，不只查输入词语 | 输入“干净”、语气友好、用户满意或外部执行器验权限，都不证明内容无害 |
| 人机关系与误导 | 披露模型身份/能力/来源，允许用户轻易纠正和退出；共同学习以用户实际获益为目标，不诱导依赖、持续互动或相信虚构经历 | 拟人化说话、长会话和用户留存不作社会能力/真实关怀的充分指标 |

首个风险包应随**实际开放的能力**选择：私有学习就测其泄露路径，创作输出就核对来源/身份风险，对不同人群服务就测覆盖和差异。采用人工/合成敏感样本做早期测试，不为了测隐私先收集真实个人秘密。具体数据/发布权利在用途和地区明确后另核实，本节是产品与架构设计，不给出某份数据合法可用的法律结论。

隐私、偏差、知识产权、人机交互和错误内容是不同风险方向，可参考[NIST生成式AI风险画像](https://nvlpubs.nist.gov/nistpubs/ai/NIST.AI.600-1.pdf)作覆盖检查；它不是强制适用于Taiji的全套门禁，也不替代本项目的真实行为证据。

### 23.8 创造、设计与多模态生成

**问题本身**：理解图片、回答问题、预测下一状态，并不自动形成按约束设计新作品的能力。长期方向应同时包含文本/程序/方案创作，以及逐步开放的图像、语音等输出；“生成内容”和“自主提出科学假设并验证”也分层声明。

**推荐方案**：共享核心维护创作意图、约束、引用/素材、可修改结构及验收条件；生成候选的结构草案、程序或视觉布局，经专用可训练输出器官实现，再观察生成物/执行结果并局部修改。语义、布局/时间结构与细节渲染可分层，避免把所有视觉/声音细节硬塞进语言token，也避免外部生成模型独占内容决策后仍称Taiji原生成果。

发展训练包括多种有效解、用户局部修改、约束冲突、失败后修复和未见条件组合。程序/布局等可执行约束由独立检查器评分，审美/可用性由适当人类评价补充；既允许合理创新，也要求不违反明确约束。候选数、搜索/渲染成本、外部依赖全部披露，不能靠无限采样与挑最好结果冒充一次生成能力。

**首个方向内切片**：在明确约束下生成并修改一个小型布局、可执行程序或带结构的作品，保留修改前后工件与反馈。之后按独立包发展图像/TTS/视频等输出；外部器官辅助可以是声明清楚的工程基线，原生生成成绩必须来自实际训练且由同一核心消费的对应输出头。

**验收与扩展**：约束满足、未见组合、指定区域/步骤修改且保留其余内容、任务效用、多样性及来源/近似复现风险；新奇度或与训练样本不完全相同不足以证明创造力。输出理解通过不替代生成验收，生成看起来真实也不能写入真实世界经历。该方向接CR-10与M5表达扩面/M6输出采用，不授权当前媒体生成或模型下载。

### 23.9 多语言、跨文化与可达性

**问题本身**：UTF-8合法、能复制不同文字，只证明编码/输出格式的一部分。词义、语法、指代、隐含意图、单位/日期习惯和文化背景仍可能完全不同；中文任务通过不能自然推广为跨语言理解。

**推荐方案**：以同一对象/关系/任务语义连接不同语言和表达方式，保留语言/情境特有信息与必要专用适配；用共同任务的多语经历、非平行真实语言和适当配对训练语义对齐、理解与生成。全部先机器翻成中文可以作为工具辅助基线，不作为永久能力上限；现有byte入口可继承，但分词/压缩方案由语言覆盖和成本比较决定，不凭编码形式宣称天然支持。

扩展课程同时覆盖跨语言提问/回答、混合语言、低资源表达、拼写/语音噪声及允许的不同交互形式；用户选择语言/格式和必要辅助输入，而不是根据姓名或外貌猜语言、文化和能力。无障碍交互通过M6器官/界面支持与核心实际理解共同验证，不以字幕按钮存在当成理解等价。

**首个方向内切片**：当前中文范围形成可测能力后，按实际使用需要选择一个额外语言范围，用同等合法信息检验跨语言内容迁移及中文保持；具体语言、数据、预算在采用时决定，本节不默认变成中英双语主线。文化特定偏好按可修正语境处理，不把单一群体习惯固化为全局真理。

**验收与扩展**：按语言、表达方式、场景与已声明的用户需要分别报告理解、生成、纠错、风险和成本；同源翻译/改写按组划分，避免翻译副本跨训练与确认。跨语言学习收益、只调用翻译器的收益与多语言原生能力分别记账；不能用高资源语言平均分遮住其他语言不可用。

### 23.10 怎样防止大方向再次失踪，而不拆成八条主线

1. **方向层**登记现实能力/风险、已有覆盖、适用范围与归属；不因“暂不实现”从VISION删除。§23是该层，本轮八项均为规划补全，非已实现或已晋级。
2. **架构层**说明复用哪个核心、需要什么新的表示/学习经历/输出器官；先写能力如何形成，再写具体字段和工程保护。学习型机制保留高上限，不能只加规则/接口即宣布该方向已被解决。
3. **执行层**每次只把当前缺口对应的一项有限包交03。方向登记不批准训练、采集、外部服务或硬件；新的真实用途、风险和资源扩大时另作决策，不让文档数量隐性扩大授权。

对当前已展开内容作归位：多模态理解看§20，恶意信息看§21，本轮八项大方向看§23，长期运行细节看§22。旧§22内容保留但纠正用途；不删除有价值设计，也不再把机制细化称作完成能力版图补漏。

阶段归属见[01 §4.1](../active/roadmap/01_SCOPE_AND_PHASES.md#41-能力与风险版图补漏2026-09-18用户澄清)。新方向扩大未来声明边界，不自动修改M5本次限定退出范围、当前R2包、L3/Mini后置或历史门。已有开放功能对应的基本隐私/安全责任仍有效，不能以“长期方向”推迟处理现实风险。

**与当前优先级的关系（2026-09-19）**：D8 (a2)后先按03评审§19.12的内容形成候选，不以常识扩容代替尚未成立的条件绑定。有限内容收益成立后的覆盖评审，再连接§23.2，写清“从窄材料问答走向真实知识与语用”的发展经历；其他大方向保留入口、不并行开工。这样既不遗漏知识发展，也不把开放域常识变成当前R2的前置。本文不另设执行队首。

研究参照仅帮助设计判别：组合与情境迁移可借鉴[gSCAN原论文](https://arxiv.org/abs/2003.05161)的留出思路；社会问答与风险覆盖参照分别见§23.5/23.7。数据集、模型、许可和具体实现若采用须另核对，论文成绩不转移为Taiji已具备的能力。
