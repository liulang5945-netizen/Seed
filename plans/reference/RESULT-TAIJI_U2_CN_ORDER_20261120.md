# 结果卡：中文字序敏感性（`chinese_word_order_partial`；语序信息在编码层可恢复、经单位图仅 +0.078）

> 文档状态：[结果卡] — 2026-11-20（D-20261119-202）。上游 [中文接地卡](RESULT-TAIJI_U2_CHINESE_20261120.md)。**零 check/final、只读 fit。**

## 1. 协议

- 指令命名两个颜色并问**第二个提到**的颜色（`{c1}和{c2}取第二个`）；标签依赖**词序**，字符袋无法恢复；
- 编码两种：**bag**（字符袋投影，顺序无关）与 **seq**（逐字符 tick、经冻结 23.0b 单位图状态串联）；
- 训练 3 个模板、**fit 用留出模板「从{c1}{c2}取第二个」**；fit 种子与 train 不相交；
- 四臂：bag_units / seq_units（经单位图）、bag_raw / seq_raw（直接 MLP，编码层上界）；
- 门：`seq_units − bag_units ≥ 0.10`；3 seed、204.33 CPU（帽 1,500）。

## 3. 判读与披露（如实）

1. **语序信息可编码、但单位图+读出只部分利用**：raw 层 1.0 → 经图 0.472，差 0.53——与 23/25 系列「上限在表示/读出」一致；
2. **门未达（0.078 < 0.10）**：不能签「语序理解成立」，只能签「语序信息在输入层可恢复、经单位通路部分可用」；
3. **bag_raw 0.5 高于机会 0.25**：字符袋仍含颜色频率线索（两色各出现一次时无法区分、但检索分布偏置），已披露，不作为机制证据；
4. 封闭词表（14 字）、4 模板、4 类标签；**不签自然中文、语序理解、26/27 通过、final/C/D/J/模型成型**；旧保持 0.0 来自父冻结。
