# 预注册卡：SUB.1.01 主体循环集成冒烟（零训练）

> [预注册·零训练] — 2026-11-26（D-20261126-619）。把已冻结的四项设施（`SessionStore`／中文连续任务／证据可信度／不确定性表达）集成到一条主体循环；owner「合理即批、按推荐持续推进」授权。**集成冒烟：不训练、不产生能力声明，不读确认 seed/check/final。**

## 1. 集成内容

- `taiji/subject_loop.py`（`taiji-subject-loop-v1`）：
  1. `SessionStore` 跨会话持久化主体记录；
  2. `ChineseTaskEnv` 提供 3–5 回合中文连续指令；
  3. 动作由**脚本 oracle（明确标注为工程控制臂，非学得策略）**选择；
  4. 每步结果写入 `CredibilityLedger`（证据累积；每次会话从追加式经验日志**重建**）；
  5. 拉普拉斯平滑成功率 → `verbalize_confidence` 四级中文表达，并计算 ECE；
  6. 会话级 sha256 审计链；支持提交前崩溃注入与恢复；`check/final` 读取直接拒绝。
- 单测 `tests/test_subject_loop_20261126.py`：6/6。

## 2. 校准门（读前写定，5 会话）

| 门 | 要求 |
|---|---|
| 会话数 / 步数 | 5 会话；步数 ≥15 |
| 审计链 | 长度 5、可验证 |
| 崩溃注入 | 第 2 会话提交前崩溃，恢复后索引不变、续跑成功 |
| 封存拦截 | `check/final` 2 次均被拒 |
| 证据账本 | 跨会话重建，claim 后验 ≥0.5 |
| 不确定性 | ECE ∈[0,1]，表达均为四级之一 |
| 确定性 | 两个独立目录同序列 → 链与 digest 完全一致 |
