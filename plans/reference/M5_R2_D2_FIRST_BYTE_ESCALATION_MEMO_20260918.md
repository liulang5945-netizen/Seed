# M5 R2-D2 第二次 learnability 停止：首字节条件化根因与下一变量裁决备忘

2026-09-18。状态：**升级材料，等待用户裁决；不再自主修订图。**
依据：[H-A2 copy 修订合同](M5_R2_D2_COPY_MIXTURE_AMENDMENT_FROZEN_20260918.md) §6（「copy probe 再失败 ⇒ 第二次 learnability 失败，停止自主改图，升级人工复审」）。

## §2 根因（机制级，跨包收敛）

1. **所有失败答案都以「不」开头**：negation 答「不是X」与 combo_different 答「不同」首字节同为 0xe4；不以「不」开头的五个形状全部满分。这是**一个**故障，不是两个。
2. **首步查询在设计上与 prefix 无关**：v2 单通道合同令 renderer 从学习常量 `start_vector` 起步，故第一步寻址查询 q_0 对每个 episode 是同一个向量；首步只能靠「材料尾部颜色」这种跨题恒定模式，无法被「问的是是非题还是取色题」条件化。
3. **训练先验 119:55 强化该捷径**：119 个训练项首字节是颜色/未知/相同，55 个是「不」；首步复制颜色对多数题正确，CE 平衡点把 0xe4 压到 0.194。
4. **跨包同一根因**：H-FBW 记录 16/16 dev 全错在首字节；H3.8 修订引入 start_vector；本次给出直接机制——**首回答字节是整条链上内容条件化最弱的点**。copy 本身工作正常（材料事实、拒答、同色结论全部学会），失败不在绑定（排除 B 前提）也不在多事实算力（combo_same 满分）。

## §3 备选下一变量（取舍）

| 选项 | 内容 | 利 | 弊/风险 |
|---|---|---|---|
| **O1（推荐）问题条件化的回答起点** | graph v5：`r_0 = tanh(h_question·W_start + b_start)`，h_question 为**问题干结束时**（材料标记之前）的扫描状态；材料仍只能经证据读出进入。v2 的「材料旁路」禁令不被破坏（题干信息本就允许，无上下文基线保留题干） | 直接打根因（首步查询随问题类型变化）；因果干净（h_question 在材料之前，RNN 因果性保证不含材料）；copy/对照/门全部沿用；预算不变 | 单通道结构门要重新证明「材料变化在同题干下只经读出影响答案」；仍可能不够（若 h_question 本身不足以区分） |
| O2 形状均衡（数据/损失加权） | 重采样或对 0xe4 首字节加权，把 119:55 拉平 | 不动图 | D1 fixture 已冻结，加权=改证据分布，需仪器/合同修订；治标——首步查询 prefix 无关的设计缺陷仍在，泛化更可疑 |
| O3 转 B（对象绑定） | 上可学习对象槽 | 上限高 | 与证据冲突：copy 已证明定位/提取基本可用，绑定不是当前瓶颈 |
| O4 停止机制微调，转真实语料/规模 | 直接上更大课程 | 绕开合成残余 | 局部首字节缺陷未排除前扩规模，违反「未拟合微任务不扩数据」纪律，且成本高 |

## §4 推荐与预承诺（若裁决 O1）

1. 冻结 graph v5 修订（不扩参数级：W_start 64×64+b，约 4,160 参数；start_vector 保留为无问题信息的退化对照）；实现门新增：r_0 随题干变、随同题干材料不变；材料替换在同题干下经且仅经读出改变首步分布。
2. 重跑同一 copy probe（同 seed/预算/门：copy-supported M1≥0.90，含 negation；combo_different 列入观察）。
3. **O1 probe 再失败 ⇒ 不再有第三次自主图修订**：A 族在当前尺度的路线判据交回用户（规模/课程/B 全部重开评审），期间不动 dev 判据、不读 final。
4. O1 probe 通过才进入三 seed matched dev（G1–G6 原样）。

## §5 当前不得主张

H-A2 未过门：不能宣称内容能力成立。但也不能说「copy 无用」——五形状 train 满分与 0.089 loss 是真实的正向机制证据，失败精确定位在首字节条件化。所有训练仅限 D1 train split；dev 未用于训练决策、final 封存。
