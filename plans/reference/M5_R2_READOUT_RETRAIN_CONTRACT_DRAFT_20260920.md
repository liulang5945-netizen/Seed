## §1 为什么是这件事（前置事实，均已核实）

1. **P0-a′**：现行产品默认基座 `seed_beta.pt`（16M tick）的语言读出**从未独立训练过**——训练期修订
   `ac37c890` 的 `observe()` 只有 `motor.learn()` 一条写站，全文件无 `predictive_readout.learn()`；
   读出面是 v8 迁移时**从运动面权重重建的副本**（`load_legacy_motor_payload`）。
2. **P1/P2 否证了解释一**：解码参数不能补救——贪心成句率 0.2326 已是四臂最好，
   top-k/temperature 均 0.0 且显著更差（p=0.00195）。⇒ "换个解码设置就会说话"这条路已用数据关掉。
3. **D/E 脱离 0 但仍远未达线**（1/16、3/20），且表层形态**依 checkpoint 而定**（旧默认是模板回声）。
4. 历史负结果约束本件：内容绑定 v1–v6 全部判停，v6 结论是"**同架构放大已无依据**"；
   字节图族五条变体线已按预承诺关闭；字级粒度（D7）是唯一留有正向证据的表示层。
   ⇒ 本件**不是**"再放大一次"，而是"把一个从未被写入的面第一次写入"，这属于新的自变量。

## §2 主张与不主张

主张（若门通过才允许说）：在固定符号预算下，**把语言读出纳入训练**相对同等训练量的非读出路，
能否在**同一批未见题面**上带来可归因的改善。
不主张：不声称语言能力形成；不把成句率提升当回答能力；不以本件解除 R2 的 M5 排除状态。

## §3 设计（双臂 + 一个反事实，缺臂即作废配对）

| 臂 | 处理 | 它隔离什么 |
|---|---|---|
| **A 读出头** | 固定符号预算 N，仅开放 `predictive_readout` 学习，运动面冻结 | 自变量本身 |
| **B 多训一遍** | 同样 N 个符号，走原运动面路径，读出冻结 | "只是更多训练"这一替代解释（P3b 已证它是真混淆） |
| **C 出生即冻结对照** | N 个符号流过但两处都冻结 | 权重变化之外的漂移：episode 计数、动态状态、随机流 |

**重放纪律**：训练符号按**检查点血缘**计算，绝不重放该检查点已见过的数据——否则"改善"可以纯靠
记忆伪造（这条在 P3b 双臂里实测过代价）。未见评价集**先建先封**，训练前落 digest，训练后不得换题。

### §4.1 步骤 0 实测（2026-09-20 填入）

仪器：`scripts/training/calibrate_taiji_r2_readout_retrain.py`——只读、硬上限 200 tick、
报告已存在即拒跑、跑完硬核基座 sha256 未变。合同测试
`tests/taiji_native/test_readout_retrain_step0_contract.py`（14 项）。
报告：`reports/taiji_r2_readout_retrain_step0_calibration.json`（30 计时 tick + 5 预热，CPU）。

被测基座：`checkpoints/seed_beta.pt`，sha256
`ad2a06465e0ef78c75aff7302a6f7a2ae11825d2f19361d9d65926006f3bf793`，4,143,542 B，信封 tick 16,000,000。
语料 `data/p3b_all_fresh.jsonl`，跳过量 11,199,800（血缘推导，取自其清单），**窗口内重放 0 符号**。

| 臂 | 写入面（实测，非声明） | 每 tick 墙钟 | ticks/小时 |
|---|---|---|---|
| **A** 只训读出头 | 只动 `predictive_readout` | **0.0023630 s** | 1,523,513 |
| **B** 只训运动面 | 只动 `motor` | **0.0031833 s** | 1,130,889 |
| **C** 双冻结 | 两处都不动 | **0.0020120 s** | 1,789,273 |

- 写入面互斥性由报告里 `motor` / `predictive_readout` 的**载荷指纹前后差**当场判定，三臂
  `write_surface_ok` 全 true。守卫做了红跑：把 A 的预期写入面改错 ⇒ **rc=1 且不落报告**；
  `--skip-symbols 0`（切片落进已见前缀）⇒ 拒跑。⇒ 这两个守卫是能响的，不是装饰。
- 一次性启动成本（每臂各一次）：跳语料前缀 0.331 s + 载入信封 0.005 s + 建模型 0.151 s ≈ **0.49 s**。
- **峰值工作集 276.152 MB**（整进程峰值，含 A/B/C 三次装载与语料扫描；`measured`）。
- 如实登记的边界：`learn` 这一个开关同时管着感知面学习（`taiji/adapter.py` 的
  `perception.observe(..., learn=...)`），当前架构没有单独的感知冻结开关 ⇒ A/B 是"感知也学"、
  C 是"感知也不学"。A↔B 的对比不受影响；A↔C 的差里混着这一项，这正是 C 只当**漂移对照**的原因。

**由此提出的 N 上限（呈报后单独批准，本件不自行认定）**：**N ≤ 16,000,000 符号/臂**——
与基座自身的暴露量同量级，且远在未见窗口（52,280,150 符号）之内。预计墙钟：

| 臂 | 16M 符号预计墙钟 |
|---|---|
| A | 10.50 h |
| B | 14.15 h |
| C | 8.94 h |
| **合计** | **≈ 33.6 h**，可断点续跑（单臂 9–14 h） |

**另一条前置（本次新增，不是步骤 0 的产物）**：正式训练前必须**实测"能正确落盘 checkpoint 且能在
新进程里恢复"**——含 `--checkpoint-every` 节奏与恢复后的 `tick` 基线，写法沿用本仓既有的
保存/恢复证据格式。这条验证与三臂的写靶一律落在**隔离目录**；`checkpoints/*.pt` 全程只读，
跑前跑后 sha256 必须逐位相同。**该前置未过之前不启动任何正式臂。**
