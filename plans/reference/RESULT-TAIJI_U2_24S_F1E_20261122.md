## 4. 判读

1. **继承式出生使新生通路可用**：budding 后新生单元状态与 p24 源单元**逐位相同**（0.0），在 newborn-only 读出下 8 交互达 **1.000**；同协议随机出生（F1d）仅 0.2227 ⇒ 差异 +0.777，**继承是使能条件**（G4）。
2. **反馈因果成立**：无纠正 0.359、置换反馈 0.000–0.070 ⇒ 正确标签反馈是必要输入。
3. **旧能力与身份保持**：生长前后旧四体制均 0.992（逐体制相同）、旧 72 单元训练后逐位差 0.0、capsule 前向差 0.0、immature→mature 前向差 0.0（96/96 mature）。
4. **诚实边界（重要）**：单元可塑性贡献很小——把新生参数复位到继承值（保留训练头）只掉 **2.7pp**（1.000→0.973），而仅头臂 H 也达 0.992 ⇒ 本卡证明的是「**继承的表示 + 专用读出**承载新规则」，**不是**「新生单元在训练中自身学出新表示」；不得据此签「新生单元可塑性承载新功能」。随机出生复位掉 78.1pp 说明承载的是**继承参数产生的表示**，而非头单独就能完成。
5. **与 F1c/F1d 合并**：F1c（随机出生、宽读出）头级纠正快但新生单元不被因果使用；F1d（随机出生、newborn-only）失败；**F1e（继承出生、newborn-only）成功** ⇒ 结构生长的有效条件是「继承已学功能的新生表示」，与 objective「继承式出生/继承已学参数与有效功能」一致，但「新单元自主学新能力」仍未成立。

## 5. 过程披露（工程修正）

首跑（同判据同判据哈希）发现实现缺陷：`inherit_from_p24` 用同组重算 `edge_mask`，而模型 spec 为 `cross_group_edges=True`（全连接掩码），导致旧单元跨组边被删除、旧四体制降到 0.910。修正为按 spec 语义重建 `edge_mask`（全连接）后旧行为逐位恢复（0.992），**重跑一次**（101.20 CPU；首跑作废未入账）。修正后出生状态等值与旧状态不变性均为 0.0。
