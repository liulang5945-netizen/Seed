> 文档状态：[已裁定·方案 A·未启动训练]。裁定日期：**2026-11-03**。授权范围：**仅 N16.1**（0a/0b/0c/0d/1.1/1.2）；**不含 N15.2，不含步骤 12/13，不释放 14.7，不读 confirm**（confirm 继续封存，仅 1.2 在任务门通过后读取）。预算：owner 批"充足"，但仍守合理使用纪律与观察线（实际 CPU ≥20,000 秒或 wall ≥30,000 秒先回报，不静默跑穿）。

**立项依据（15.1 结案复核，2026-11-03）**：15.1.1 判 `native_byte_task_failed`，总体 0.5625/0.80、未见输出名字与新描述均 0.0；限定范围复核未发现仪器失效，三处断点为——① 解码门 γ≈0（强制 γ=0 完成率不变）；② 记录级选择 0/240（α 从未选中目标记录），训练 loss 2e-5 却由"软混合内容＋记忆模板"满足；③ 自前缀课程剂量落在 R1 已精确复制训练目标之后，因子按构造失效（自前缀与教师前缀 8/8 相同）。详见 [结案回执](../../reports/taiji_binding_copy_15_1_closeout_20261103.json)。

## 0. 与 15.1 证据对齐的修订点（裁定后补写，2026-11-03）

1. **选择头输入口径**：每例只喂 `goal` 文本与**每条记录的 description 片段**（不含 name、不含 action/expected）。`action`/`expected_hex`/评分结果一律不得进入前向；此点在 0a 以"键片段不含记录 name"自动检查冻结。
2. **选择标签来源**：只来自数据标注（`kind=="object"` 且 `description==object_description` 的唯一记录索引），不由模型或评分推断。
3. **选择锁定复制的可实现定义**：把 `read` 的**记录级 α** 替换为选择头的 one-hot（null 权重 0），**保留模型自己的字节级 betas**；因此实现上每步最多调用两次 read（先取未强制 betas，再一次以 `force` 注入 one-hot α）。这比"强制记录偏移复制"更不容易把答案位置泄漏给模型。
4. **γ 下限**：`γ_t = max(γ_model_t, 0.2)`，并把 γ 均值列为必报读数（0b/0c/1.1 三处都报）。
5. **课程触发**：自前缀按**该批教师强制完成率**触发（阈值 0.5，先冻结），第 1 次更新即可用；不再用固定 update 位置。
6. **oracle 口径修正**：强制复制必须落在**实体字节起点**（由模型 copy 后验定位），不得再用"记录偏移 0"（15.1 已暴露该口径错误）；oracle 只报上界与可达性，不设伪门。
7. **新增 0d 阶段**（原草案缺此页）：两 seed×两臂初态、step1、恢复端下一更新独立进程逐位一致；400 CPU/800 wall、≤24 工程 Adam、≤2GiB；不过则不开始 1.1。

## 1. 为什么不是"再调一版 15.1"

15.1.1 的断点已被三项独立读数定位，且都不是"训练不够久"：

| 断点 | 读数 | 含义 |
|---|---|---|
| 解码门 | 强制 γ=0 后完成率 **0.4167 → 0.4167（降 0.0）** | 学到的 γ 已≈0，字节级复制通路根本没在用；再加步数不会让它出现 |
| 选择 | 记录级 α 选对率 **0/240（四个 R1 配置全为 0）** | 目标条件化的记录选择从未形成 |
| 训练捷径 | 训练 loss 降到 2e-5，但 dev 总完成仅 0.5625、未见名字/新描述 **0.0** | 模型用"软混合内容 + 记忆模板"通过训练，而不是按描述选记录 |
| 课程 | 训练后贪心自前缀与教师前缀 **8/8 完全相同**，逐 update loss 与 P0 逐位一致 | 自前缀因子在 R1 上按构造失效，无法检验其假设 |
| 旧读取 | R0P1 塌陷：198 个 update 与 R0P0 不同、clip_max 1650.77、末 loss 0.465 | 同一课程剂量对旧读取不稳定 |

结论：问题在**架构的"选择—解码"接口**与**课程剂量位置**，不是容量、不是步数、不是随机种子。

## 2. 候选 A（主选）：显式选择 + 选择锁定复制 + 准确率触发课程

### 2.1 架构改动（相对 15.1 rev2）

1. **显式记录选择头（selection head）**：在写出第一个实体字节之前，用 goal description 的编码与每条记录的**关键描述片段**（而非全记录字节池化）算一次记录级打分，做一次 **hard 选择**（argmax；训练用 straight-through 或 Gumbel 采样）。输出一个离散记录索引。
2. **选择锁定复制（selection-locked copy）**：选定记录后，把 λ 从"由自生成前缀 m 递推"改为"由选择结果门控"：
   - 选中 → λ=1，直接按 `force`（正确记录 + 推定偏移）复制该记录的目标字节；
   - 未选中 → λ=0，走生成。
   这样 γ/λ 不再能靠"复制自己刚生成的字节"自锁，复制通路被迫真正指向被选中的记录。
3. **γ 下限与可观测**：对 γ 加下限约束（负熵正则或直接 clamp 到 ≥0.2），并把"γ 均值"提升为**必报读数**，防止再次出现"γ 塌到 0 而没人发现"。
4. 保留：14 父、原生字节、可塑整记录编码、H/F、mix/生成、恢复；旧 R0 路径原样保留作对照。

### 2.2 课程改动

- 自前缀**从第 1 次更新起按准确率触发**：当该 batch 的教师强制完成率 ≥ 阈值（例如 0.5）时，才把该例切到自前缀；不再用固定 update 位置（101/201）。
- 三个阶段、固定步数与 seed：
  1. **选择阶段**：只训选择头（记录级交叉熵），解码冻结；目标=正确记录索引。
  2. **复制阶段**：锁定所选记录，teacher-forced 复制目标字节；只训复制/表达相关组。
  3. **联合阶段**：选择 + 复制 + 生成一起，自前缀按准确率门触发；γ 下限生效。

## 5. 替代方案与取舍理由

- **B（次选，上限较低）**：保留 15.1 的连续后验读取，只加"α 的选择监督 + γ 下限"，不改解码接口。改动小、风险低，但训练捷径（用软混合内容记忆）仍然存在，预期上限低于 A。若 owner 要最小改动，选 B；若要先证伪"选择—解码接口"这一假设，选 A。
- **C（不选）**：只改课程（自前缀从第 1 步开始）。本次已证明 R1 的课程因子按构造失效与"训练捷径"同源，单改课程无法分离原因，故排除。

**推荐 A**：它同时修掉两个已测出的断点（γ≈0 的解码门、α=0 的选择），并把"离散选择"变成可单独判定的量，判据可证伪、上限更高。
