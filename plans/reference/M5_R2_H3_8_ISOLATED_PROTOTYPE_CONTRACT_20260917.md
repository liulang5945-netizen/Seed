# R2-H3.8 隔离原型实现合同（冻结版）

2026-09-17。状态：**已冻结**（本文提交即冻结）。依据：用户于 2026-09-17 明确答复「采用」——采用「联合序列信用 + 可训练 prefix 编码器」隔离原型作为下一研究包（[复审](M5_R2_H3_8_SEQUENCE_CREDIT_REVIEW_20260917.md) §3 唯一推荐；六维归因依据见[总账](M5_R2_H3_9_ATTRIBUTION_LEDGER_20260917.md)）。本合同把 H3.8 复审 §4-§6 的设计落为可执行条款；数值预算不在本文推测，按 §5 顺序在实现门通过后单独冻结。

## §1 计算图与所有权（逐条可测）

1. 链路：可见 prefix bytes → **Taiji-owned 可训练因果编码器** → 内容工作空间 W（48×4 槽维度可调，冻结于实现合同）→ **可训练循环 byte renderer** → 下一 byte logits。renderer 每步用自身隐状态对 W 做**内容寻址**读取；禁止按隐藏 reference 长度或固定中文字符 chunk 选槽。
2. W 在回答起点生成一次，单个回答内**参数冻结**（不因生成过程修改）；renderer 隐状态逐步推进。
3. 全部参数归 Taiji：禁外部模型代答、答案表、task/family/split 特征输入（含 hash-of-family 侧信道）。
4. 训练样本 = 当时可见 prefix + 右移 response 输入；预测 y[t] 只能读取 prefix 与 y[:t]；完整回答仅作损失标签，**不得**先编码为运行时 W。
5. 损失 = 真实下一 byte 交叉熵，含结束标记；v1 不加多重辅助损失（防调权救结果）。
6. 发展训练沿 renderer → W → prefix 编码器回传；计算图必须逐点标注 detach/mask/状态重置/截断位置；初版短序列全展开，超长截断另立合同。
7. 推理与训练用同一参数与前向公式；推理期无 optimizer、无长期参数更新。运行期持续适应属 VISION 后续，不得冒充已完成。

## §2 实现门（能力训练之前，五项全过；逐项留证）

1. **隔离与清单**：实现路径隔离、参数清单、native AST 合同适用范围成文；不静默解除 taiji/ 禁令；无隐藏第二认知栈。
2. **梯度数值差分**：合成输入下 prefix 编码器与 renderer 的每个声明参与训练的参数收到有限非零梯度；禁用连接的梯度归零。测试入套件。
3. **因果 mask**：修改未来标签不改变当前 logits；teacher-forced 与逐步前向同历史下逐步一致；中文/空上下文/结束标记/最大长度四类用例齐备。测试入套件。
4. **恢复**：零步原子保存 → 新进程加载 → 同输入 logits 一致 → 继续一步与不中断运行一致；保存参数、optimizer、RNG、数据顺序、课程游标、配置与代码内容摘要；缺失/不兼容拒绝，不静默随机初始化。测试入套件。
5. **接线合成检查**：缺权重拒绝、打乱 prefix 应改变输出、屏蔽 W 应移除其贡献——只证明接线，不证明能力；默认入口与既有 checkpoint 不受影响。

## §3 数据合同

1. 新语料（不复用旧 12/8/4 fixture 作证据；旧 fixture 仅工程回归）：冻结来源许可、去重、模板/实体/组合分离、独立 final；生成规则不暴露给模型。
2. 必含五类对抗形状：上下文事实替换、否定、未知信息、组合约束、同开头不同内容——防只学回答形式。
3. 两臂同数据/种子/更新数/byte 预算：**基线臂**（可训练循环编码器+renderer，无 W）与**工作空间臂**（加可学习 W）；匹配有效参数与推理成本，匹配不了分账披露，不得以「同 300k」掩盖训练差异。

## §4 训练合同冻结与顺序

1. 实现门全过 → 小规模 train-only 可学习性检查 → 正式 matched dev（种子数、精确参数/步数/墙钟/存储上限、checkpoint 周期、恢复与异常停止策略在 dev 前单独冻结成文；数值不从本合同推测）。
2. 已有训练授权沿用，但 dev 训练仅在实现门 + 数据合同 + 数值预算三事冻结后启动。
3. 停止规则：train 可拟合而 dev 不迁移 ⇒ 优先审数据与表示，不加 epoch；train 不可学 ⇒ 回计算图，不扩数据；任何臂失败保留失败状态。

## §5 晋级与停止门

1. 晋级 = 逐 seed 内容正确性提升且边界/保持不退化；不看 surprise、敏感性或非重复单指标。
2. **workspace lesion**（推理期撤销 W）与**关闭 workspace 训练信用的重训对照**分别命名、分别记账；先证真实收益，再议撤销收益。
3. 确切指标、阈值与统计规则在见到新 dev 数据**之前**冻结（独立预注册小节）。
4. 未过门不读 final、不进 L2/Mini；final 仅作冻结版本的一次独立验证。
5. `growth_admitted=false`、`can_promote=false` 贯穿，直至对应晋级门明示通过。

## §6 产物顺序

1. 隔离原型实现（新模块 + 装配脚本）+ §2 五门测试入套件。
2. 实现门报告落盘 + 独立提交。
3. 数据合同与小规模 train-only 可学习性检查 → 数值预算冻结成文。
4. matched dev 预注册（指标/阈值/统计）→ 执行 → 独立提交 + roadmap。
