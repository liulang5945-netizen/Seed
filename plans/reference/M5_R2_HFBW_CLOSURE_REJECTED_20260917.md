# M5 R2 候选 H-FBW 结项：**否决** —— 「首字节加权 CE」在有效预算下无效

日期：2026-09-17。状态：**已结项**。
依据：[读出诊断](M5_R2_READOUT_DIAGNOSIS_20260917.md)（16/16 dev 首字节错）的
对症形式 (b)（修正为 (b''')：内容形状首字节加权 CE）。
预算：**30 epochs × 25 episodes × 3 seeds**（有效预算档）。

## §2 两个独立的可信性证据

1. **control（fbw=1.0 ≡ λ=0）再次精确复现 `0.25 / 0.0625 / 0.0`** ——
   与 H-OBJ 实验、H-GEN 重验的对照臂**三次交叉一致** ⇒ 仪器与加载路径可信；
2. treatment 的 `train_acc` **有升有降**（919 升至 0.9277、917/918 降）⇒
   改动**确实生效**（不是没接上），只是**没有产生正收益**。

## §3 结论

1. **H-FBW 否决**：首字节加权（5×）在有效预算下不仅无优势，**反而使全部 3 seeds 的
   exact 归零** —— 对照臂里本可对的那几条（0.25/0.0625）也没了；
2. **「首字节全错」不是损失权重问题**：上权 5 倍都无法让它学会，
   说明模型**不是"不够重视"那个字节，而是从 prefix 状态里读不出该字节的内容**；
3. **三次"加损失"实验（H-OBJ 对比项、H-FBW 位置加权）在同一有效预算下全部失败**，
   而**同预算下不加这些损失的对照臂能产出非零 exact** ——
   ⇒ **"内容抽取 → 字节生成"的缺口不是损失设计能修复的，指向架构层**
   （即候选 **(c)：显式的"回答起点/内容读出"机制**）。

## §4 界限

- 只试了 `first_byte_weight=5.0` 单值（**冻结、未调参**）——
  **不能**断言"任何权重都无效"；
- 只试了"首字节"一个位置（诊断显示它是唯一系统性失败点，但未试其余位置）；
- 隔离原型结论**不外推**到 `chat()`；final 未读；无能力收益主张。
