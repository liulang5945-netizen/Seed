## 3. 判读（重要负结果＋诊断）

1. **R0/R1 联合训练依旧强**（0.98–1.000），胶囊逐位（0.0），旧中文 1.000。
2. **R2 即使联合训练也失败（0.16/0.25）**：R2 与 R0 共享 A 队列特征，但 A 特征**为 R0 特化**、只含 R0 所需信息；R2 需要 flag 的**相反约定**，A 特征中可线性利用的 flag 信息不足（与 P0-CU 奖励适应 0.55/0.65 的弱信号一致）。
3. ⇒ **队列特征专业化会限制「同队列再学互补规则」**；三规则共存需要**为 R2 单独分配队列**（再生长）或**联合训练时从一开始就让 R2 用独立队列**（先规划生长）。
4. 因此「N 个能力 = N 个专属队列＋专属读出」是当前最可靠的生长规则；共享队列的额外能力会相互挤占特征。
