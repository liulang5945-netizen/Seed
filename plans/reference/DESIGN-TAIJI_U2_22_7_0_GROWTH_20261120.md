## 2. 22.7.0-α 接口里程碑（**已通过**：D-20261119-34，适配器 v3＋r4 单位图 `adapter_ready`，fit 1.0×3、44.27 CPU、capsule 跨进程 3/3；早期 r1–r3 失败根因＝像素 x 轴误用）

- **任务**：first-A fit world 的 4 类位置词分类；观测→legal channels（复用 U2 多模态编码器或直读 raw_media 特征）；readout→4 类 logits。
- **通过判据**：随机初始化下 loss 有限且梯度非零；短训练（≤500 步）fit 面准确率显著高于 25% 机会水平；胶囊 save→独立进程 reload 后同输入 logits 逐位一致；`0 check/final`。
- **成本**：单位图单步（T=16、8 单位、fwd+bwd+Adam）实测 **`0.00234 CPU`**；500 步×3 seed ≈ `3.5 CPU`＋数据/适配器/评测 ≈ `50–100 CPU`；帽 `150 CPU`。

## 3. 七臂正式比较（α 通过后，另签合同）

| 臂 | 操作 | 预算/判据要点 |
|---|---|---|
| G0 | 信用覆盖条件出生（主候选） | 须真实提升残差信用、旧能力损伤 ≤0.02 |
| G1 | 随机内容盲门同预算出生 | 排除活梯度噪声 |
| G2 | 置换门同预算出生 | 排除门-残差未对齐 |
| G3 | GradMax 方向＋固定日程 | 排除方向/调度组合 |
| G4 | 仅重放无生长 | 排除复习解释 |
| G5 | 固定容量强优化 | 排除优化不足 |
| G6 | 最终容量预分配 | 排除「更多容量即收益」 |

- 判据（引自包 22 §2.7）：相对最强匹配对照净增益 `≥0.05`、world 95% 下界 `>0`、3 seed 同向；旧能力损伤 ≤0.02；恢复一致；真实退役须过旧能力与未结引用检查；删除新单元须移除 ≥50% 增益且绝对成功率下降 ≥0.02。
- 配平：同一 FLOPs 预算（解析计数）或同一时间预算，读前冻结；只按参数量配平不合格。
- 结构/状态/通信/功能分别报：单位数、有效边数、状态字节、可学习参数、独立信用方向、成熟单元数；**不得用瞬时特征增宽或存储槽扩容代签**。
