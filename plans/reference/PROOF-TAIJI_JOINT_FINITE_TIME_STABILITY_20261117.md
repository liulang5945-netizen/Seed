# M06/M43 联合有限时域稳定：反例与条件性扰动界

> 文档状态：[数学证明／反例] — 2026-11-17。范围仅为联合状态转移的有限时域扰动分析，不含训练、任务行为或长期运行验证。
> 核验：[代数脚本](../../scripts/training/verify_joint_finite_time_math_20261117.py)｜[报告](../../reports/taiji_joint_finite_time_math_20261117.json)。脚本只执行矩阵运算与闭式核对，`training_steps=0`、`behavior_validation=not_run`。

## 0. 结论

1. **无条件命题不成立**：每步分别有界、局部非扩张或谱半径小于1，均不能推出联合闭环收缩。
2. **条件性有限时域结论成立**：若联合转移在覆盖两条完整轨迹及其连接路径的域内满足一致 Lipschitz 条件（或由凸域上的有界雅可比推出），则任意有限时域内，初值扰动和输入扰动满足一个明确的乘积—求和不等式。
3. 对 `z/a/H/F` 核心，可以把结论分解为：**瞬态神经活动收缩＋持久记忆写增量有界**。不要求持久记忆本身收缩，也不把数值有界误写成语义稳定或学习能力。

## 1. 精确反例：逐步谱半径小于1，联合扰动仍增长

取

```text
A = [[1/2, 2], [0, 1/2]]
B = [[1/2, 0], [2, 1/2]]
```

因为均为三角矩阵，`ρ(A)=ρ(B)=1/2`。但

```text
BA = [[1/4, 1], [1, 17/4]]
eig(BA) = {9/4 - √5, 9/4 + √5}
ρ(BA) = 9/4 + √5 ≈ 4.4860679775 > 1
```

对属于最大特征值的扰动方向 `e`，交替两步满足 `‖(BA)e‖=ρ(BA)‖e‖`，因此 `(BA)^k` 使该扰动按 `(9/4+√5)^k` 增长。核验报告给出 k=1…4 的逐值一致结果。

将 `A/B` 视为两个合法时间步在零邻域的线性化块，并令持久记忆 `F` 只读、其他状态块取恒等映射，就得到联合线性化系统的同类反例。故：

> **单步谱性质、持久状态存在和局部非扩张，都不能替代联合乘积分析。**

## 2. 一般联合有限时域扰动定理

设联合状态 `X∈D`，输入 `u∈U`，`D` 为闭凸域，联合转移为

```text
X_{t+1} = Φ_t(X_t, u_t)
```

两条轨迹 `(X_t,u_t)` 与 `(X'_t,u'_t)` 的误差记为

```text
E_t = ||X_t - X'_t||
U_t = ||u_t - u'_t||
```

**直接采用逐点 Lipschitz 假设**：在覆盖两条完整轨迹的集合上，

```text
||Φ_t(X,u) - Φ_t(X',u')|| ≤ L_t||X-X'|| + M_t||u-u'||
```

若要从雅可比推出该假设，则须额外要求：`D×U` 为凸域，两条轨迹及其连接线段在整个时域均不离开声明域，且 `Φ_t` 在这些线段上可微并满足

```text
L_t ≥ sup ||∂Φ_t/∂X||
M_t ≥ sup ||∂Φ_t/∂u||
```

上确界取遍上述完整状态域和输入域。只有局部点态雅可比、但轨迹或连接路径可能离开该邻域时，不足以推出下述多步结论。

由逐点 Lipschitz 假设，

```text
E_{t+1} ≤ L_t E_t + M_t U_t
```

递归得到**联合有限时域乘积—求和界**：

```text
E_T ≤ (Π_{t=0}^{T-1} L_t) E_0
     + Σ_{k=0}^{T-1} (Π_{j=k+1}^{T-1} L_j) M_k U_k
```

若 `L_t≤L`、`M_t≤M`、`U_t≤U`，则

```text
E_T ≤ L^T E_0 + M U Σ_{k=0}^{T-1} L^k
```

即

```text
L ≠ 1: E_T ≤ L^T E_0 + M U (1-L^T)/(1-L)
L = 1: E_T ≤ E_0 + T M U
```

这给出任意有限 `T` 的显式扰动控制。若另有 `L<1`，瞬态扰动的长期上界为 `M U/(1-L)`；若 `L≥1`，仍可使用有限时域公式，但不能据此声称渐近稳定。

**证明范围**：该定理要求全轨迹上的逐点 Lipschitz 条件；凸域、连接路径不离开及一致有界雅可比只是**可推出该条件的一条充分路线**，二者不称为逻辑等价。定理不要求全系统收敛，也不要求所有状态分量收缩。

## 3. `z/a/H/F` 分块：瞬态与持久记忆分开

### 3.1 核心递推

考虑固定门下的核心：

```text
v = R x + W(g⊙z) - B a + R_F r(F,q)
z⁺ = C z + (I-C) tanh(v)
a⁺ = (I-E) a + E z⁺
H⁺ = (I-ℓ)H + ℓ tanh(W_H x + P(g⊙z⁺) + R_H r(F,q))
```

令 `Y=(z,a,H)`，使用分量最大误差 `E_Y=max(E_z,E_a,E_H)`。两条轨迹使用相同固定门；若门不同，其差异必须计入 `U` 及相应 `M`。

`L_r` 是在**覆盖两条完整轨迹及相应连接路径的记忆域上一致有效**的 Lipschitz 常数；若只知某个局部邻域内的常数，则必须另证整个时域内两条轨迹及连接路径均不离开该邻域。固定 `q` 时，记忆读出只改变输入 forcing，不改变下面的状态速率形式。

### 3.2 活动块速率

由 `|tanh'|≤1`，先采用矩阵范数形式：

```text
ρ_z = ||C|| + ||I-C||·(||W||·||g||_max + ||B||)
ρ_a = ||I-E|| + ||E||·ρ_z
ρ_H = 1-ℓ + ℓ||P||·||g||_max·ρ_z       (0≤ℓ≤1)
L = max(ρ_z, ρ_a, ρ_H)
```

各参数取当前声明配置值。若参数随时间变化，必须**逐时刻计算** `L_t=max(ρ_z,t,ρ_a,t,ρ_H,t)`，再取 `L=sup_t L_t`；或者对完整表达式在参数区间上求最大值。不得把各参数分别替换成上确界，因为 `ρ_a` 和 `ρ_H` 对 `η/ℓ` 并不总是单调递增。

当 `C=cI`、`E=ηI` 且 `0≤c,η,ℓ≤1` 时，上述矩阵形式退化为

```text
ρ_z = c + (1-c)(||W||·||g||_max + ||B||)
ρ_a = 1-η + ηρ_z
ρ_H = 1-ℓ + ℓ||P||·||g||_max·ρ_z
```

一般矩阵情形不得直接使用标量公式。若 `L<1`，则活动块在最大误差意义下收缩。该条件是**充分条件，不是必要条件**。

### 3.3 记忆 forcing

定义

```text
n_z = ||I-C||·||R_F||L_r
n_a = ||E||·n_z
n_H = ℓ(||P||·||g||_max·n_z + ||R_H||L_r)
N = max(n_z,n_a,n_H)
```

标量化 `C=cI`、`E=ηI` 时，`n_z=(1-c)||R_F||L_r`、`n_a=ηn_z`。若只有局部 `L_r`，则这些系数也只在该局部域内有效；写入扩大记忆域后必须重新确认其一致上界。

输入误差 `U` 的系数 `M` 同理，由 `R`、`W_H`、门及上述块递推求得。于是：

```text
E_Y,t+1 ≤ L E_Y,t + M U_t + N E_F,t
```

### 3.4 只读记忆

若 `F` 在 Recall 期间不变，则 `E_F,t=E_F,0`，并且

```text
E_Y,T ≤ L^T E_Y,0 + (M U + N E_F,0)(1-L^T)/(1-L)    (L<1)
```

持久记忆对应恒等块，使完整 `(Y,F)` 的联合雅可比至少具有特征值1。因此，**要求整个联合系统严格收缩在结构上就是错误目标**；正确目标是活动块扰动受控，同时持久记忆误差不被写入放大。

### 3.5 有界写入

令第 `k` 次写入对两条轨迹的增量差为

```text
D_k = ||(F'_{k+1}-F'_k) - (F_{k+1}-F_k)||
```

则

```text
E_F,T ≤ E_F,0 + Σ_{k=0}^{T-1} D_k
E_Y,T ≤ L^T E_Y,0 + Σ_{k=0}^{T-1} L^{T-1-k}(M U_k + N E_F,k)
```

若每次写入的增量预算为 `B_w`，两臂均有 `D_k≤2B_w`，则

```text
E_F,T ≤ E_F,0 + 2 T B_w
```

这仍然只是有限时域扰动界，不证明记忆内容正确、容量足够或巩固有效。

## 5. 已证明与未证明

**已证明**：

- 无条件“局部稳定⇒联合收缩”存在精确反例；
- 在覆盖两条完整轨迹及连接路径的一致 Lipschitz 条件下，联合转移具有显式有限时域扰动界；
- 对本文的 `z/a/H/F` 分块，`L<1` 时活动块收缩，持久记忆可单独按写增量控制；
- 不必也不应要求持久记忆严格收缩。

**未证明**：

- 当前所有 U2/Y 实际参数都满足 `L<1`；
- 全算法所有模块都已给出可组合的雅可比界；
- 长时域渐近稳定、唯一吸引子或正确记忆；
- 学习、中文表达、物理理解、旧能力保持或生长净收益。

## 6. 对 M06/M43 的收束

- **M06**：无条件全局收敛仍为假；本文补上“联合有限时域扰动界在明示雅可比条件下成立”。
