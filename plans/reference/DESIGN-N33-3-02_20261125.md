## 1. 任务与三臂对照（[continual_growth_task.py](../../taiji/continual_growth_task.py)）

- **两阶段任务无关课程**（共 16 维输入、6 类输出，零 `task_id`）：
  - **Phase 1（500 步）**：`y ∈ {0, 1, 2}`，由 `x[:, 0:8]` 区分；8 单元即可学透（检验「无压力不硬生」：`p1_growth_events == 0`）；
  - **跨阶段保存/恢复**：每臂在 Phase 1 结束后通过真实磁盘 `SessionStore` 保存与 reload 胶囊（检验逐位无损）；
  - **Phase 2（1,200 步，同比例回放 50% P2 + 50% P1）**：`y ∈ {3, 4, 5}`，由 3 对 6 位非线性 parity 模 3 构成，对 8 单元形成容量压力；每 100 步用内部 `GrowthPressureController` 检查验证错误率。
- **三臂设置**（同超参 `LR = 5e-3`、`BATCH = 128`、同批序列与回放比例）：
  1. `fixed_small`（`hidden = 8`，不生长）：证明存在真实容量压力；
  2. `growth_plastic`：初始 `8` 单元 → Phase 1 后经 `SessionStore` 交接并标 `mature` → Phase 2 平台压力触发中性出生 `grow_neutral_(24)` 扩至 `32` 单元（零扰动出生 `0.0`）→ 开选择性可塑掩码（成熟单元梯度置零，新生单元学习＋跨会话胶囊再保存）→ 末期做新生 24 单元休眠掉点与唤醒一致性验证；
  3. `prealloc_equal`（[MECHANISM_ACCEPTANCE](../active/MECHANISM_ACCEPTANCE.md) §4.5 标准替代）：初始即预分配 `32` 单元，同 Phase 1 → `SessionStore` → Phase 2 ＋ 同回放。
