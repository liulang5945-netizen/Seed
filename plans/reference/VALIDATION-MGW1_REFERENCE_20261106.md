源码回执的25个`unresolved_small_signal`保留原样。按公式进一步识别其中4个共享key bias为softmax平移规范零，proprio decoder query weight在坐标恒0的首profile不活跃。连同源码已登记的3项，最终解释为：**144 FD分辨＋7规范零＋1profile不活跃＋20真正小信号未分辨＝172**。

7项是goal_score.bias、actor末层bias、relation_geometry末层bias、Read_H/Read_O/relation/decoder共享key bias。它们从softmax公共平移可直接证明，不是见负结果后放宽阈值。正式优化器应去掉这些冗余参数；参考保留它们作零对照。剩余20项包括群间Q/K、F门等重要路径，本轮不能签有效学习信号，默认初始化和真实任务中须继续核验。不能以“梯度存在”代签。

## 4. 导数与初始化口径

最初FD重算了被stop-gradient冻结的policy/value belief输入，与Psi条件半梯度出现差异。本次先区分Theta真实目标及Psi固定belief目标，再按同一条件取FD，未靠放宽阈值消除差异。规划score不冒充真实环境梯度。

FD压力点使用参考自有fan-in缩放.3、bias=.01和非退化种子；它是合法参数点，不是默认初始化训练有效的证据。全形状前向也只签形状和有限值，不偷签初始化信用。分量FD的初始state、输入和固定Psi条件来自同一参考点，active切换/离散选择不套中心差分。

本次数值gap不使用未经证明的机器舍入上界，不把负gap夹0后称零误差。FP1的精确dual距离界与浮点估计分别登记，真实任务的误差预算还取决于传播敏感性、margin和校准。
