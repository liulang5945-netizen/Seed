## 2. 课程、样本格式和隔离

### 2.1 精确样本单位

`episode`是一段独立的多轮短对话，开始时使用全新的Taiji `CognitiveState`、Adapter状态和JointTaskState；episode内部输入按固定轮次推进并保留本episode产生的状态。一个family是固定语义组合及其全部改写，整个family只能属于一个split。组成原子词（常见物体、颜色、位置和通用答句）允许跨split复用；组合family ID、完整输入/监督目标对及完整脚本摘要不得跨split重复。这样测试的是未见组合，不会错误地要求“红色”之类常用词只能出现在一个split。

每个turn固定携带：`input_id`、原始UTF-8 `InputFrame`、`family_id`、`episode_id`、`turn_index`、parser span/act target（F0也有全O/ambiguous标签）、answer bytes target（UTF-8正文后固定追加V4停止串`b"<|end|>"`），以及两种target各自绑定的input SHA-256和target SHA-256。`JointT1AnswerTrainingTargetV1`只允许`partition=train`，并须同时匹配family、input ID和原始输入摘要；query/holdout答案与标签只交给训练结束后的独立只读scorer。推理、`predict`、`commit_to_joint_state`和生成API不接收任何训练target或Gold WorldObject。

### 2.2 Family构造和固定轮次

| Level | Train | Query（只读描述） | Holdout（主判定） | Family内课程 |
|---|---:|---:|---:|---|
| F0 | 320 episodes / 64 families | 128 / 32 | 128 / 32 | 每episode 5轮：问候、确认、简单请求、短回答、结束；一族5种等义短改写。parser目标为不写事实的ambiguous/全O。 |
| F1 | 320 episodes / 64 families | 128 / 32 | 128 / 32 | 每episode 8轮：事实陈述、当前值query、更正、更新后query、无关实体事实、回查原实体、明确否定、明确歧义；一族5种改写共享实体×属性×旧值/新值×干扰事实组合。 |

唯一数据实现放在`taiji/joint_t1_course.py`，课程seed=`17751027`；文件内固定中文词表、模板、F1家庭组合生成、family排序、target schema和source/target digest。每个level有128个唯一组合family，按该seed固定分为64 train、32 query、32 holdout；query/holdout各family四种改写。F1组合由固定日常词表的笛卡尔候选生成；对象/属性/值原子可复用，但完整组合family不得跨分区。否定与歧义各在每个F1 episode恰有1轮；holdout误写率分母因此固定为256轮（32 families×4 episodes×2），按family macro评分。F1仍只含一个目标对象、一项属性、普通取值，不使用专业问题。

Support split删除：它原来没有冻结用途，也不再占资源或成为调参入口。Query与Holdout均在训练进程外只读评分；Query仅描述，不能选阈值、checkpoint或超参，Holdout是主判定。builder在生成manifest时校验family唯一性、episode脚本摘要、完整input/target pair无跨split重复、span边界符合UTF-8、每个F1 episode确有否定/歧义轮次，然后写入语料/顺序/映射SHA。共享普通答案字符串不算泄漏。

## 3. 一次固定的训练臂和责任控制

Formal update package有5个更新模式×3个parser seeds，共15个arm。状态写入诊断在每个Correct终点派生一对冻结参数的write-enabled/write-disabled评估分支，不另计训练arm。

| Mode | Producer parser | V4 language parameters | CognitiveState write |
|---|---|---|---|
| Correct | 正确slot/act labels | 完整允许组 | 允许模型自产parse提交 |
| Parser-permuted | 只在F1把B/I_ENTITY与B/I_ATTRIBUTE标签作固定互换；act/span字节位置不变 | 正确answer targets不置换；完整允许组 | 允许模型自产parse提交 |
| No update | 冻结 | 冻结 | 不做学习期状态写入 |
| Readout only | 冻结 | 仅`language_candidate.output` | 冻结事实写入 |
| Responsible owner frozen | 冻结`input_semantic_producer`；语言分支保持完整更新 | 完整允许组 | 允许模型自产parse提交 |
| State-write diagnostic | 从同一个Correct终点checkpoint复制两支，全部参数冻结、相同holdout顺序和新episode状态；一支允许模型parse写CognitiveState，另一支只读不写 | 全冻结 | 成对比较write enabled/disabled |

每个update以4个相互独立episode构成batch。前640 updates由8轮F0全量epoch组成（每轮320 episodes/80 updates）；后1920 updates由12轮混合epoch组成（每轮160 updates、每批固定`F0,F1,F0,F1`），即每个F0 episode总曝光20次、每个F1 episode曝光12次。一个episode内turn次序固定；episode之间重置CognitiveState/Adapter/JointTaskState，禁止事实串入其他episode。所有15臂使用完全相同的episode exposure order；`build_joint_t1_update_order`将完整update→episode ID表固定并可SHA绑定，Parser-permuted标签变换是确定性的B/I_ENTITY↔B/I_ATTRIBUTE互换，不能现场抽签或按结果改动。No-update照同一顺序完成forward但不执行任何optimizer step和训练期状态写入。每臂零checkpoint、每256步、课程边界和终点保存。

Cache replay在新的episode输入到达时，必须把当前Adapter snapshot中的新观察/感知并入JointTaskState，同时保留之前由模型写入的WorldObject、WorldEvent和Workspace候选/绑定；如果任何已写事实或事件在下一轮消失，runner在本步loss/update前报错停止。该约束适用于逐turn cache状态与原始Adapter replay两种路径。

N177.5A实测确认重复Adapter输入前向过重，采用仅含train split的冻结TSK-v8 `InputTrace`/per-turn CognitiveState cache。缓存总字节590,512,321，按adapter checkpoint、课程/分割及每个episode/input/source SHA绑定；独立Fresh Adapter回放一个F0和一个F1（13 turns）后，InputTrace与CognitiveState逐字段一致。缓存前后同一F0 batch CPU成本80.156→25.188秒、mixed batch91.984→34.156秒；所有15臂共用该只读cache。每次更新仍由当前V4参数重建JointTaskState/V4语言状态，并重跑当前producer预测/事实提交与loss；禁止缓存上一参数revision的V4 `TaskState`、语义parse、WorldObject候选或producer结果。cache生成CPU未捕获，资源估算以未缓存完整前向的单位turn成本作cache建设上界并另加30%余量；新进程恢复会校验整个cache SHA。

`JointT1TrainerV1`已实现；五种模式的train-only backward profile验证了预定接收/冻结路径，未执行optimizer step。span/act loss只回`JointInputProducerV1`参数，answer loss回对应V4参数组；inference/predict/commit签名不接gold标签。实际参数更新收益仍只由N177.6固定训练/holdout决定。

## 4. Joint checkpoint和恢复

单个NativeCheckpoint必须包含：TSK kernel/perception组件、canonical CognitiveState、JointTaskState及source ledger、V4权重/Adam/RNG、producer权重/optimizer/RNG、联合update计数、training mode、family/split manifest SHA、seed、shuffle order SHA、冻结InputTrace cache SHA、下一episode cursor、六类credit policy和parse ledger。不得把producer、语言候选、Adapter和联合状态拆成互相独立的sidecars。训练输入cache作为独立的train-only数据制品保存；其逐项源身份、生成Adapter摘要和总SHA写入NativeCheckpoint，不包含V4中间态或模型决策结果。

每个arm在正式第一个更新前保存zero并由新进程恢复。第一批2步canary计入2560步：保存→新进程恢复→下一步输出与不中断克隆一致；随后沿恢复checkpoint继续。终点再次新进程恢复，并重现同一输入parse/answer。任一恢复差异、源绑定失配或optimizer参数组偏离立即停留证，保留partial；不清账重跑。

## 5. 固定验收、汇总和有限收官

逐臂分别报告parser span exact/F1、CognitiveState属性正确/更正、F0自由生成有效UTF-8与结束标记、F1原值/相关翻转/更正后查询/无关对象保持、否定/歧义不误写率、F0旧级保持和真实成本。每项先在episode内按轮评分，再在family内求均值，最后family等权宏平均；分别保留每seed与三seed结果。所有holdout episode用fresh CognitiveState，从该episode的第一轮开始，不读训练时CState。

- 主学习门：episode的`F1 state-query score`固定为`(更正后world state exact + 本episode三次query answer exact均值) / 2`，随后按family macro。对No-update和Parser-permuted分别在相同seed/holdout family上配对计算Correct差值；三seed差值中位数须均≥10个百分点，且至少2/3 seed为正、任何一个seed不得低于−5个百分点。否则结论为未观察到稳健学习增益。Parser-permuted只否定结构标签正确性，答案目标仍正确，因此其差值不能单独称为开放语义理解证据。
- 状态写入因果门只由Correct终点的write-enabled/write-disabled成对诊断判定；相同模型、query、初始状态和source order，逐family报告差异。Readout-only、owner-frozen比较参数责任，不替代该状态写入消融。
- 否定/歧义误写率=`导致该输入新建或改写WorldObject/WorldEvent的轮数 / 256`，按family macro统计；通过线≤5%。F0 retention在同seed、同Holdout family上对比零checkpoint与终点；三seed每支下降都须≤3个百分点。其他绝对门按三seed family-macro均值报告，并逐seed列出，不能用总平均遮盖单seed崩溃。
- 绝对任务线：F0有效UTF-8≥99%、结束标记≥95%、规范化简单答复exact≥85%；F1 entity/attribute/value各角色span exact与post-correction state exact各≥90%、更正后query answer exact≥90%、无关实体写入后原事实保持≥95%。各值按三seed family-macro均值裁决，另列逐seed读数。
- Query只作不参与选择的描述性评分；Holdout用于上述主判定。测试源码/labels只能在训练进程退出后交给独立scorer；scorer无权写回模型、CState、阈值或checkpoint。任何阈值未过仍到固定终点结案；不自动扩样、加轮、重抽seed或以另一个runner结果补洞。

能力范围上限：即使本包通过，也只支持“一对象/一属性的基础中文事实/更正切片”。不表示开放中文理解、T2跨经历记忆、T3自然目标理解、规划、外部行动、持续成长或自主性。
