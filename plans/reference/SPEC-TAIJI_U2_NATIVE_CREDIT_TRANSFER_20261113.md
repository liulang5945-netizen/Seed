# Native内容信用与受验收更新的迁移核验

> P3.8.2b实施规格，2026-11-13。工程帽130 CPU／260 wall草案，执行前固定源码、调用次数和保存点。当前Native权重尚未采用新学习规则。

## 1. 唯一父、数据和目标

研究父为P3.7问题Fusion预算内update-000758，其文件／参数摘要从[原始四臂结果](../../reports/taiji_u2_joint_learning_20261113.json)及[审计](../../reports/taiji_u2_joint_learning_closeout_20261113.json)绑定。保留25086参数／214张量／44字段、结构谱系和真实Adam。首问合格参照仅作为方法与可学性证据，其权重独立于Native。

工程数据选取train三个位置的三组完整四格，颜色配对(0,1)、(2,3)、(4,5)，共12条原episode；不读取dev作更新或验收。私有索引只供离线选组，模型输入保持原问题和公开包。全部监督标签由原答案字节派生。

先核对两问原目标的梯度职责。令g1=∇L_first、g2=∇(L_second_actual＋blocked)，逐参数验证g_joint=(g1＋g2)/2，记录None、方向和尺度。实际首答是当前父生成的事实；候选目标重算时固定该字节历史及其来源，保持条件信用范围。

更新算子迁移先使用首问目标，以对应已校准范围。h_b为原first-request话语初态的branch_context，ω_b为初始话语分支权重。新增训练头Linear(8,4)，36参数，初始化seed2026111311；类别按完整train答案hex排序，权重N/(K·count)。FP32／FP64都从同一父显式转换，旧moment时钟和值按目标精度检查。

\[
J_{content}=-w_y\log\sum_b\omega_b\operatorname{softmax}(W_ch_b+b_c)_y,\qquad
J_{first}=L_{first}+J_{content}.
\]

类别／权重均沿完整train答案分布，12例覆盖三位置、四类别的均衡条件组合。新增头只负责学习期误差，运行时仍用原字节头，source／所有权和去头等值必验。完整学习器参数registry含body的214张量及训练头2张量，总25122参数；推理部分25086参数。

## 2. 更新与历史一致性

采用[已校准参数更新](SPEC-TAIJI_U2_ACCEPTED_CREDIT_UPDATE_20261113.md)的同一方向规则、α集合及带容差目标验收。Native生效前须检查FP1切换、实际历史和离散选择边界，有限搜索可拒绝。完整两问／连续任务收益由后续真实生成裁决。

在独立learner影子中计算提案，当前运行主体保有最后接受的θ。拒绝时保留有限moment／学习器时钟，参数值与已发生行为事实保持原身份。接受后通过原参数迁移事务按新θ重编码合法原始历史，单写者提交模型／状态／moment。旧动作、旧输出、其行为概率和奖励记录继续使用原版本。

分别定义学习器提案时钟u和提交参数版本v。不同α的未提交子候选由提案ID、α和参数摘要区分。对外接受时参数版本才递增。接受参数变化、moment演进、资源消耗各自记账。

当前实时Runtime的参数／状态部分不能独自代表新增学习器的全部恢复状态。完整学习恢复包采用外层NativeLearnerCapsule，至少包含下表字段。

| 部分 | 必需内容 |
|---|---|
| native_runtime | 原typed运行时envelope，模型／44字段／事实历史／未结事项／RNG／资源 |
| learning_state | 最新body提案moment、内容头／其moment、标签来源／权重、u、v及参数祖先摘要 |
| sampling | 原始episode游标、实际首答前缀及其来源、数据／反馈权利、采样RNG |
| proposal | 空或明确祖先／候选摘要／已计算目标／搜索状态；当前实现仅在完整决策安全点持久保存 |
| identity | schema／factory、参数registry、模块来源、数据摘要及当前body摘要 |

外层包原子保存，完整恢复必须重建全部学习状态和下一提案。body-only导出承担推理恢复范围，学习继续入口使用完整包。冻结窗口、拒绝和提交边界的记录不得丢失moment或把候选行为登记为真实行为。

## 3. 执行与检查矩阵

工程机器合同先固定4次正常提案及2次故障提案，共最多6次真实Adam调用。故障位于提案后／提交前，实际调用及资源保留，原完整包的参数／moment／历史／RNG／下一损失应可恢复。正常提案可以有限拒绝，不要求每次强制参数移动。

| 检查 | 实现责任及验收 |
|---|---|
| 祖先／结构 | 旧214参数及真实moment逐值继承，头2张量新moment，Ψ范围保留 |
| 目标覆盖 | g1／g2／g_joint代数、内容反馈到共享表征，原字节头仅由字节目标负责；全部参数／None登记，并对照现行责任表显式记录新增梯度去向 |
| 提案／拒绝 | 参数数值与u／v分离、CPU RNG重放、零梯度／零位移／非有限／有限拒绝 |
| 提交 | 原始事实及状态重建、未结事项边界、源／父复核、原子提交 |
| 恢复 | 至少提交前／后各一次独立进程，body／头／所有moment、下一目标／全部梯度及下一提案一致 |
| 去头 | 完整body推理分布及实际生成保持等值，训练标签索引留在学习器 |

执行前先检查初始完整包可保存／恢复，首个非空moment再次校验。任何未覆盖项保持uncovered，能力或训练内标签分数不能代签完整接口。预算不足以承载必需范围时按not_admitted_for_budget结案并写出缺口。

## 4. 后继行为比较

工程通过后才以实价冻结P3.8.3。在同一Native父及相同公开输入上比较原字节目标／原更新与内容信用／验收更新这一整体配方，按真实CPU及样本暴露量分账。无足够消融时只签整个配方，不单独归因内容监督或搜索。

首问及实际两问分别报告，完整分母、RGB／问题必要性和描述性旧范围保持沿原合同。正式A的多实体／三seed／独立check仍需对应父和范围。自驱、递归发展、成熟生长及长期多模态目标在后继主线验收。

## 5. 文件落点与兼容职责

正式更新与学习器实现拟落在taiji/u2_credit_update.py及taiji/u2_credit_learner.py，工程runner落在scripts/training/verify_native_credit_transfer_22_5.py，回归落在tests/taiji_native/test_u2_credit_learner.py。原已冻结研究算子保持可重现身份，正式实现须逐提案核验参数／moment／RNG等值。
