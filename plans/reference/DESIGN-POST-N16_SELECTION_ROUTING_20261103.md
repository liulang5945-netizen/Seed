## 0. 是否需要修订算法

需要修订选择与表达接口。推荐一个完整候选，将有序内容表示、逐步记录/null选择、最终复制分布、同状态生成门和回答信用放进同一计算图。原生字节、已有整记录编码、H/F、后验连续复制、恢复及生长机制继续作为继承资产。此判断针对职责匹配和可优化性，任务收益仍由配对比较检验。

| 已确认的结构事实 | 本候选修改 | 可检验的结果 |
|---|---|---|
| 当前自前缀分支把生成字节同时传作loss标签，触发后回答目标变成自模仿 | 输入前缀与正确标签使用两个独立参数 | 错误自前缀下仍对原正确答案计算NLL，错误生成不能自签低任务损失 |
| 当前SelectionHead先平均独立字节嵌入，同字节计数的不同词序在精确算术下表示相同 | 共用已有有序整段编码与注意池化 | 字节计数相同的换序反例可产生不同内容表示，信用到达共享编码 |
| locked_generate在输出循环外选一次对象记录，select的argmax排除null | 每个输出步根据状态/已接受前缀选择记录或null | 对象、地点、模板三个阶段可在合法记录间切换，null可实际被选中 |

## 2. 本次修正的归因与接口

### 2.1 gamma的方向

当前代码的概率定义为

```text
P(b) = [gamma + (1-gamma)*q_null] * P_generate(b)
     + (1-gamma) * P_copy(b)
```

gamma是基础生成权重。gamma=0保留复制质量，实际生成质量还含q_null。原收束材料中“gamma≈0所以复制未使用”的解释方向相反。强制gamma=0后任务分数相同，只记录了该干预对完成率的影响。后继逐实体/模板阶段记录实际生成质量及目标字节的生成/复制后验。**16.1.1实测：A模型γ0.8212/0.7471、复制权重1−γ=0.1788/0.2529；B模型γ0.0616/0.0392但α=null，复制质量为0，生成经null支路仍主导。**

原N16规格的gamma_t为有效门，runner使用raw gamma均值作机制门。结案已登记两种字段的区别，17继续分别记录配置下限、实际生成/复制质量及输出后验。

### 2.2 选择指标的时间与对象

15.1正式evaluate_source_top1在previous=EOS时只作一次answer_step，再把最大字节位置所属记录与对象记录比较。该0/240属于首输出步的最大字节位置指标。它与记录alpha的argmax、实体输出阶段的Q/R质量各有不同定义。**16.1.1修正后：选择总体0.3833/0.3542；见已见66/108与46/108、未见名字10/60与31/60、未见组合18/36与15/36、新描述0/60与0/60。**

17的选择门对应目标阶段，分别统计对象起点与地点起点的选择准确率。过程探针可以用正确历史前缀，正式任务仍按模型自生成字节计完整分母。原N16门按其冻结定义结算。

### 2.3 原A的接口约束与后继假说

原locked_generate在循环外选择一次对象记录，整句沿用chosen_record。select使用整数argmax传递选择，回答NLL对独立选择头参数没有反向路径。原A还用未锁定probe的gamma覆盖锁定后的状态输出，并以clamp实施下限。下限以下的原gamma梯度被clamp截为0。

原锁定只替换起点分布alpha。R1最终Q仍为lambda*m+(1-lambda*sum(m))*S，m可保留另一条记录的质量。例如S=(1,0)、m=(0,1)、lambda=0.8时Q=(0.2,0.8)。最终复制来源需在Q接口上约束。

当前原A从零cursor出发且整句保持同一选择，支持集可持续留在该记录。上述反例针对逐步切换或带旧cursor恢复的扩展场景，最终Q锁定作为本候选允许跨记录选择时的配套条件登记。

这些代码事实支持修订选择、路由和生成门接口。固定300更新、两seed及单次干预对所有容量/剂量的覆盖仍有限。本轮保留已有编码、H/F、连续复制和表达资产。

### 2.4 自前缀与监督目标混用

当前16.1.1 runner的batch_objective在触发self_prefix时，用生成的own替换prefix，再将prefix传入locked_loss。后者定义labels=target_prefix+(EOS,)，因此答案标签也变成own。B臂同样把own传入score_example作为目标。原目标没有继续参与该分支的回答NLL，选择CE仍保留原选择标签。

这是源码可确认的目标定义问题。原N16的自由生成成绩依然可以按有效评分衡量，课程对比需按“准确率触发的自模仿”登记，不能据此声称已验证“错误自前缀下对正确答案纠偏”。17的三臂统一使用下文分离的输入/标签接口。原N16配方及历史源码按既有提交恢复。**16.1.1实测：A从未触发（批完成率上限0.375/0.25），B触发127/121次且loss从0.0026升到约1.1；A−B因此混淆，不作为干净机制检验。**

## 4. 逐输出步的可塑选择头

选择头共享主体已有的有序编码与pool。g为goal编码摘要，k_i为合法description键片段编码摘要，s_t为更新前H的QueryRead输出，e_prev为上一实际输入字节嵌入。

```text
x_ti = [g; k_i; s_t; e_prev; g* k_i]  # 576维
score_ti = w_out^T tanh(W_hidden x_ti + b_hidden)
k_null = learned_vector(128)
score_tnull = same_scorer([g;k_null;s_t;e_prev;g*k_null])
a_soft = softmax([score_t1 ... score_tN score_tnull])
a_hard = one_hot(argmax(a_soft))
```

每个输出步重算选择，候选含null。记录顺序通过同一共享打分函数处理，参数不含记录数组位置嵌入。数值并列在1e-12内时前向选null，单列并列率。模型可依据前缀和状态在对象记录、地点记录与null间切换。输入白名单不含当前字节索引、对象/地点阶段或正确角色。

新增头参数为37120个，替换原25602个独立选择头。共享编码资产仍计入继承可塑组。

| 参数 | 形状 | 数量 |
|---|---|---:|
| W_hidden / b_hidden | 64×576＋64 | 36928 |
| w_out | 64，无共享bias | 64 |
| k_null | 128 | 128 |
| **合计** | **独立选择头** | **37120** |

原底座3526481参数时，新容器总参数为3563601。正式图须从注册张量核对总数、共享与优化器所有权。训练中的共享编码保持任务图，缓存绑定参数revision，原文字段可独立缓存。

## 5. 锁定最终复制来源及同一状态生成门

每步先按原R1读取求Q_i,j与q_null。计算各记录内的条件位置分布

```text
mass_i = sum_j Q_i,j
eta_i,j = Q_i,j / mass_i
Q_locked_i,j = a_t(i) * eta_i,j
Q_locked_null = a_t(null)
```

合法记录的数值计算使用log概率，正质量归一需可分辨。记录本身没有合法位置时从候选集合排除。若合法记录的mass_i数值为0，eta_i改用该记录当前beta经原transport后的归一分布，这条新起点支路在数值饱和/跨记录切换时显式记账。该分布仍无正质量或出现非有限数则以instrument_invalid停止，禁止用均匀分布隐式填补。选null时复制质量为0，生成支路接收全部概率。selected记录之外的最终Q质量为0，保留选中记录内部的模型位置分配和连续状态影响。

用同一份Q_locked求content，推进H一次，再用该H/content计算generated与gamma_raw。生成下限使用

```text
gamma_effective = 0.2 + 0.8 * gamma_raw
P(b) = [gamma_effective + (1-gamma_effective)*Q_locked_null] * generated(b)
     + (1-gamma_effective) * copy_mass_from_Q_locked(b)
```

该映射满足已裁0.2下限，保留sigmoid内部的学习导数。原值低于0.2时clamp导数为0，新映射对gamma_logit的导数为0.8*gamma_raw*(1-gamma_raw)。统计raw/effective/logit、饱和率、实际生成/复制后验及参数更新量。effective均值≥0.2按配置检查登记。

复制后验、m、coverage均用最终同一P/Q/gamma更新。原probe可以提供位置概率，实际H/输出/后验由最终锁定状态统一决定。推理逐步选择和null路由均由模型输出。

## 6. 选择监督与回答信用

训练将已有对象/地点记录标签扩为逐字节路由标签。27字节规范答案中，对象byte3–14标对象记录，地点byte21–26标地点记录，模板及EOS标null。这些位置只在标注器/loss/评分器使用，模型前向由自身状态与已接受前缀决定路由。

L_selection为对象、地点、模板/null三个阶段各自平均CE后再取平均，避免实体字节长度决定角色权重。所有三臂统一采用以下阶段所有权。同一个Adam维护全部声明可塑参数，冻结组grad=None，阶段切换不清空已有矩和步数。

| 更新 | 损失与前缀 | 参数所有权 |
|---|---|---|
| 1–100 | L_selection，正确教师前缀 | 仅独立选择头37120参数更新，共享编码/读取/H/表达冻结 |
| 101–200 | L_answer，按训练批完成率触发自前缀 | 选择头冻结，继承可塑组更新；A的选择支路仍可将代理信用传到共享输入 |
| 201–300 | L_answer＋L_selection，权重均1，按同一规则触发前缀 | 独立选择头及继承可塑组更新，A/B/C的回答信用范围依§7 |

目标接口固定为routing_loss(input_prefix, target_bytes, route_labels)。target_bytes始终为原始正确27字节加EOS，共28个NLL项。input_prefix是教师字节或另一次无梯度自由生成的前27字节，过短时补EOS，超长时截到27，原始长度/早EOS另外落账。对第t项计算-log P(target_bytes[t] | input_prefix[:t])。状态的复制后验使用实际送入下一步的input_prefix[t]推进，目标标签只进入损失。固定长度的训练重放不因输入前缀中出现EOS而少算目标，在线自由生成仍遇EOS即停。两种模式只改变宿主循环和可见前缀，模型前向不接收正确标签或阶段位。

错误自前缀反例为输入含“乙”的生成序列、目标仍含“甲”。验收须逐项核对28个target ID未变、NLL等于原目标的概率和，且与自模仿目标的损失可分辨。改变目标必须改变损失而不改变同一前缀下的前向分布。该项在17.2图验之前单独测试。

联合回答信用采用原方案提及的straight-through估计，温度1

```text
a_train = a_hard + (a_soft - stop_gradient(a_soft))
```

训练前向为硬路由，反向采用softmax的代理导数。该估计的偏差属于算法假设，工程报告按代理信用登记。[Straight-through研究](https://arxiv.org/abs/1308.3432)。

工程分开验证条件CE的真实FD和ST规定的VJP。对固定状态，取实际锁定图的dL/da作为常量v，核对任务头梯度等于J_softmax^T v，再用v·softmax(scores)的连续标量目标作FD。硬argmax前向的FD可为0，按实际值保留。停止ST任务路径时，选择CE仍有梯度，回答NLL对独立选择头的梯度应为0。

课程保留已裁的训练批教师完成率0.5触发规则。每次更新记录触发值、实际自前缀例数、前缀与目标不同的例数/字节数、早EOS及完整目标分母。课程规则相同，实际曝光差异随候选轨迹记录。课程有效性按实际对照结果报告。

## 7. 三个配对对照及主要判据

| 臂 | 记录路由 | 回答对独立选择头的信用 |
|---|---|---|
| A_joint_lock | 逐步硬锁最终Q，训练ST | ST任务信用＋选择CE |

独立选择头精确37120参数，总容器提案3563601参数。共享编码引用同一张量对象，参数不能重复注册或被优化器添加两次。每阶段列出requires_grad、loss→组信用和实际delta，冻结组保持grad=None且Adam矩不重置。正常推理只能消费原始文本、合法状态/元数据和已批准的辅助键片段，监督标签由训练/评分侧保存。

正式训练checkpoint在完整更新边界原子保存参数、Adam/RNG、样本/阶段/课程游标和单调费用账。中途输出快照只序列化状态值；若要恢复尚未完成的训练计算图，必须从该样本起始状态与原文/RNG重放前缀并计费。17.4分别检验推理值续推和下一完整训练更新，禁止把Tensor值往返作为autograd图恢复。失败尝试及重放消耗原实际Adam/CPU上限，成本账不因回滚清零。

## 15. 17.5 开跑前的四项设计落地（2026-11-03）

### 15.1 指针温度退火

位置指针（记录内的目标位置）在训练期用温度 softmax，推理期取 argmax。温度按更新序号线性退火：

```text
T(u) = 1.0 - 0.95 * (u - 1) / 99      u <= 100
T(u) = 0.05                           u  > 100
```

- 训练期所有臂、所有阶段共用同一 `T(u)`；`u<=100` 覆盖选择阶段，复制/联合阶段保持 0.05。
- 推理期 `pointer_hard=True`、`T` 不参与；温度只影响训练软读，不改变推理的点复制定义。
- 退火只改变软读的锐度，不改变参数数、损失权重或更新数；三臂对照仍同剂量。

### 15.2 指针熵正则

对**被选中记录**的指针行加熵项，鼓励训练早期探索位置：

```text
H_u = -sum_j p_j log p_j,  p = softmax(row_logits_selected / T(u))
L   = L_stage - c(u) * H_u
c(u) = 0.01 * T(u)
```

- 只在该步路由到合法记录（对象/地点位置）时计入；null 步和无记录步不计。
- 系数随温度退火，u>100 后为 5e-4，属弱正则；报告分别列出每阶段实际熵与系数。
- 该项进入同一 loss 图，不增加参数、不增加更新数；三臂同式。

### 15.3 方差基线选择

选择路径的信用用 **pathwise/ST（直通）**，不引入 REINFORCE 基线：

- 指针位置走 pathwise（软读温度 softmax 直接反传）；记录路由在 A 臂走已冻的 ST 代理，在 B/C 臂止于选择输出。
- 不引入 REINFORCE 的理由：本图尚无REINFORCE与pathwise/ST的同预算方差比较；新增带学习基线的估计器会增加未定价、未预注册的信用路径，当前先验证已记录的路由ST与位置pathwise。
- 与 A 臂 ST 的共存关系：ST 只作用在记录路由分布 `a` 上，指针 pathwise 只作用在记录内位置分布上；两者串行复合，不是同一变量的双重估计。报告按“路由 ST + 位置 pathwise”登记。

## 17. 读数解读注意：`prefix_cursor` 与 `m`（2026-11-04）

以下两条是**本图的结构事实**，不是某次运行的偶然读数；解读检查点、复制探针和 18.1 中途回报时必须先套用，避免把“结构上的 0/极小值”误读成恢复缺陷或复制路径缺失。

1. **`prefix_cursor` 在本图恒为 0。** 选择路由图的 `_advanced_state` 只推进 `living`、`m`、`coverage`（以及门/记录选择），并不调用 `binding_copy.advance` 的游标递增；因此真实前向得到的 `prefix_cursor` 一直是 0。检查点里该字段存在但值为 0，属于正常状态面，不是“恢复时丢失”。只有独立走 `binding_copy.advance` 的路径才会移动该游标。
2. **`m` 按当前接受字节重建，而非累积。** `advance_copy` 用这一步被接受的字节重新计算 `m`（该字节的 transport 质量），不跨步求和。冷候选或该步字节未命中记录末位时，`m` 的绝对和可以为 1e-9～1e-33；个别格（如 28031-B）读到 0.925，也只是“该步字节命中”。因此 `m` 很小/为 0 **不能**当作检查点缺陷或复制能力缺失的证据；复制是否承重由任务门与 `new_name_copied` 判定，不看单步 `m`。

**验证出处：** 18.1 预检（`reports/taiji_preflight_18_1_20261104.json`）对六格做真实状态探针：`prefix_cursor` 真实值全为 0；`m`/`coverage` 在 5/6 格为 1e-9～1e-33 量级、28031-B 为 0.925，且保存/恢复逐位一致。

## 18. 课程触发死环登记（18.1，不改本轮）

**触发规则（冻结，未改）：** 每个更新对 batch 内 8 条样本做教师强制回放，`rate = completed / 8`；当 `rate >= 0.5` 时该更新把输入前缀换成模型自生成前缀（`self_prefix`）。阈值是**绝对整句完成率**，不是相对提升，也不是字节准确率。

**实测（step150 中途回执，六格）：** 课程触发次数全部为 **0**；`rate_mean = 0.000`。到 step150 为止共有 6 格 × 50 个 copy 更新 × 8 条 = **2,400 次教师强制回放，0 次完成**（selection 阶段不触发探针）。step300 的完整计数见 18.1 收尾报告。

**为什么是死环：** 整句完成率从 step0 起就是 0，而触发要求 ≥0.5，且完成率不会在没有任何自前缀训练的 copy 阶段自行跃迁；于是 `self_prefix` 永远关闭，复制路径只见过 gold 前缀，γ 也从未在“自己写错”的分布上得到纠正信号。这是**触发条件设计导致的死环**，不是计数写错，也不是数据偶然。

**两个处置选项（本轮一律不改，另起一包再改）：**

1. **相对改进触发**：把“本批完成率相对上一批（或最近 k 批均值）提升 ≥10%”作为触发条件。优点：0 → 1/8 的早期进步也能触发，打破 0 死环；风险：batch 只有 8 条，单条翻转就是 12.5%，噪声会频繁误触发，必须配平滑窗口与最小样本量，并冻结窗口/阈值。
2. **字节级准确率触发**：把触发指标从“整句完成率”换成“内容字节（物件 12 + 地点 6）逐字节命中率 ≥ 阈值”。优点：直接对齐复制机制真正要学的能力，早期就能给出非零信号；风险：需要在训练循环里新增逐字节统计，阈值必须在新包 prereg 里预先冻结，且与旧读数不可直接比较。

**本轮纪律：** 18.1 剂量、阈值、判据全部保持不变，避免与 17.5 的可比性被破坏；任何触发条件修改都要求新的冻结包（新 prereg、新定价、新台账），不得在 18.1 内热改。
