## 3. 预注册判据对账

SPEC 要求「4 题均 TF≥0.80 且自由前缀匹配≥0.80」才可称 128 byte 已见切片可学。

- 本包 **4/4 题 TF 均 <0.80**（最高 0.703），自由匹配 0–3.9%≪0.80 → **门槛未达**，不称已学、不称语言通过。
- 按 SPEC 预先写定的分支记录：**TF 与自由生成之间存在显著暴露/滚动缺口**；首步与滚动阶段是主要丢失位置，而不是完全无信号。
- 不降门、不加步数、不换种子/学习率来取得阳性；本包就此结束标定。

## 7. 唯一后继建议

**先做「暴露缩放探针」再决定 20,000 CPU 正式对照**：同一候选、seed169、同样 4 个 train episode 与 128 byte 切片，把 64 batch 提到 **256 batch**（4× 暴露），在 64/128/192/256 步记录 TF 与自由前缀匹配；单 seed、候选单臂，预计 ≤1,200 CPU/1,800 wall，**可在 CC-2 现有剩余额度内执行，不需新预算**。

- 若 TF≥0.95 而自由匹配仍 <0.20 → 证明瓶颈在暴露/滚动而非拟合，正式对照应先改训练曝光（如 scheduled sampling），而不是花 20,000 比较两条同样不会自由生成的链；
- 若自由匹配随暴露显著上升（≥0.60）→ 说明 4× 暴露即可起步，再申请 20,000 正式同资源对照才有意义；
- 也可由用户直接批准 20,000 正式对照，或先改架构（证据槽/decoder 宽度）再训练。

本包不自动选择其中任一路线；等待一个明确的预算/路线裁决。
