# SPEC-N1-11 · 逐位置证据隔离参考通路工程合同（2026-10-15）

依PLAN-N1-06§5和PLAN-N1-10 C3a先完成可审阅隔离参考原型。用户本轮要求按N主线持续推进；本件只在既有可逆参考诊断范围内实施，不据此把10路线正式采用当已批准，不替换默认Taiji、不训练能力、不恢复H3.8训练。此前目标回合是进展：08/09完整证据与提交已落库。

## 实现身份

新模块taiji/position_evidence_reference.py不从默认入口导入。字节词表0..255＋boundary256，embedding16、写入GRU32、问题GRU32、query/key16、value32、隔离参考字节GRU解码32。每个真实观察字节写入当时隐藏态与不可变session/source/byte-position，不从唯一末态造所有条目。回答每步softmax内容读取同会话条目、更新解码状态并输出257字节logits；不加copy、外部语义标签或模型。UTF8和边界复用taiji.utf8_state。

写入函数只收非空external观察；query、生成和跨会话来源拒收。标签仅进入显式teacher-forced损失接口，运行时生成只收问题、合法证据和自己的前缀。参考通路本身不证明外部事实已学会。会话与来源是可见性约束，位置不作为答案标签。

## 工程出口（不代替能力门）

1. 真实逐位置keys/values可被早期观察影响；同合法输入的末态重复对照仅用于未来比较，不先跑能力训练。
2. 回答末端CE对首个写入状态有有限非零梯度。切断所有写入状态到keys/values的信用，保持前向logits完全相同，首个写入状态梯度应不可达；不把只保留首步当零梯度。
3. 生成每步重新读取，合法UTF8/边界，拒绝空池/错误来源/跨会话。使用随机初始化，只测图和接口。
4. 先保存零更新checkpoint并在独立新进程weights-only恢复，核对参数、来源、RNG与logits；此门通过后，才允许一个优化器步作为恢复夹具，随即核对独立恢复后下一步参数逐位一致。父进程再执行一次续步、恢复工作进程执行同一次续步作等价比较（父2步、子1步）；这些固定恢复夹具不计训练收益，不复用固定16评测项。
5. 显式schema/config/模型/优化器/RNG/外部来源字节保留，拒覆写，不覆盖现有母档。临时checkpoint仅放.seed_test_tmp独立目录，报告进reports。

## 资源与结果纪律

一次工程审计独立最多60秒CPU（含独立恢复子进程）；1个Torch线程，零能力训练。正式前先小型合同测试；完整命令、代码身份、读取/首末梯度和有效截断、存档与恢复读数写入证据。失败保留报告，不将参考梯度补发原生no_grad基座通过；不设能力阈值、不打开C3b/C4。首版测试字节均为新工程夹具，与冻结评测隔离。
