# E1–E11计算图审查的数学裁定

> 状态 [数学裁定·设计输入]。日期2026-11-04。审查对象是[前沿对照意见](TAIJI_ALGORITHM_FRONTIER_MATH_REVIEW_20261104.md)的14条主张及[算法主稿](TAIJI_CORE_ALGORITHM_V1_DRAFT_20261031.md)中被引用的公式族，含[OP2](SPEC-COPY_OPERATOR_OP2_MATH_20261104.md)。本件不依靠实现状态、模型实验或历史分数作数学推断。原意见保留为历史输入，发生冲突时采用本件列明的证明前提。当前候选、预算和队首仍由[MASTER-PLAN](../MASTER-PLAN.md)维护。

## 1. 总裁定

多套寻址、门的共适应、有限精度带宽、容量治理和生长功能贡献值得研究。但当前14条意见不能整体升级为“已证明架构不可表达、训练剂量无效”。其中数条绝对断言被同一公式族的反例否定；数条是有效的局部条件或规格要求。参数增加史也不构成这些特定结构性原因的数学证明。

| 条目 | 裁定 | 保留的准确问题 |
|---|---|---|
| A1 三套寻址与跨步瓶颈 | 收窄；没有跨函数类归约 | 单微步F读取次数和显式路径成立；有限精度、条件数、步数与任务规模需声明，不能由泄漏系数推出必然丢信息 |
| A2 chi同号 | 收窄为参数化假说 | 同一个chi对两个编辑项共同调幅、信用可抵消；独立擦写门的梯度不必同号 |
| A3 三阶/秩≤2 | 撤回全域断言，保留近零有效秩界 | tanh可产生二阶混合导数和满秩有限相似度矩阵，输入有界不推出预激活近零 |
| A4 tau与折扣 | 不构成数学必要性缺陷 | 神经微步与效用折扣时间必须有明确映射，不必绑定tau和gamma |

| A7 原始信用与残差出生 | 保留功能新颖性问题，撤回无条件替换建议 | 先冻结父可塑集合和函数度量；完整父切空间投影可能抹去整个零入边出生的一阶信用 |

| B3 独立擦写 | 未强制残差校正成立 | 独立门可以条件化/关写且包含绑定回归子族，不能称无条件覆盖 |
| B4 闭环稳定性 | 证明范围缺口成立，强制条件错误 | 点态能量、两轨迹收缩、隐式可微和有限步稳定性需要分别定义 |

| C3 混合版本 | 要求唯一候选入口 | 发射层有精确代数映射，头参数化和状态递推仍必须分版 |

## 2. A1/A3/A5：能直接反驳的表达性断言

### 2.1 泄漏不是精确实数域的必然信息丢失

固定旧h、ell>0，若W_f可逆，则映射f→(1−ell)h+ell tanh(W_f f+c)是单射。对归一化N(h)=h/sqrt(1+||h||²/d)，其像在||y||²<d内，逆为h=y/sqrt(1−||y||²/d)。因此tanh、有界状态和小ell本身不足以证明不可恢复。

有限精度舍入、降维投影、重复读步数、逆的条件数可能限制任务能力。它们需要额外的精度/维数/资源前提。f→h→q仍是一个计算复合，不能因没有Transformer的同名残差流就说没有任何K-composition式能力。多套参数几何是否必须统一也未由此证明。

[Sanford等的单层下界](https://arxiv.org/html/2408.14332v1)约束其定义的单层Transformer（含头数、宽度、精度预算），不能未经归约套到可回读原文、可运行多微步的递归图。原意见引用的[2402.04333](https://arxiv.org/abs/2402.04333)实为LESS数据选择论文，不承担注意力深度下界。

### 2.2 加性tanh不等于加性分离函数

令单隐藏标量s(q,k)=tanh(q+k)，q_i=log(A_i)/2、k_j=log(B_j)/2，A=(1,2,3)、B=(1,2,4)。则

\[
S=\begin{pmatrix}0&1/3&3/5\\1/3&3/5&7/9\\1/2&5/7&11/13\end{pmatrix},\qquad
\det S=-94/61425\ne0.
\]

这已否定该函数族全域rank≤2。满秩本身也不保证按任务选对位置，不能反向以此宣称能力已成立。

冻结其余输入，将z与a视为独立变量时，一般展开点的混合导数为

\[
\partial_{za}^2s=\sum_c v_c\tanh''(u_c)W_{z,c}^{\top}W_{a,c}.
\]

在u_c不为0时通常非零，例如tanh''(log2)=−96/125。只有围绕所有预激活为0的原点，首个混合项才出现在三阶。常数特征/偏置/其他输入都可改变展开点。

可保留一个严格局部结论。还需预激活具有query-only与key-only分解u_ij,c=q_ic+k_jc，其余元数据固定，coverage等不额外携带query×position联合依赖。若所有|u_ij,c|≤epsilon_c，则利用|tanh u−u|≤|u|³/3，有

\[
S=S_{linear}+E,\quad rank(S_{linear})\le2,\quad
\sigma_3(S)\le\|E\|_2\le\sqrt{n_qn_k}\sum_c|v_c|\epsilon_c^3/3.
\]

最后一界由Frobenius界与奇异值扰动界得到。N/B只约束输入；没有W的范数界就不能推出预激活小。此处要诊断的是局部有效秩和条件敏感性。

加性tanh也能改变位置排序。取s(q,k)=tanh(q+k)−2tanh(q+k−2log2)，k取0/log2。当q=0时分数为(30/17,9/5)，选第二位；q=2log2时分数为(15/17,−3/13)，选第一位。常量可由合法常数特征提供。

### 2.3 目标侧投影已经构成条件寻址轴

\[
(Q_ih_i+Q_gg)^TK_jh_j=\cdots+g^TQ_g^TK_jh_j.
\]

标量Q_g=K=1、两个key为−1/+1，令g在−1/+1切换，排序立即翻转。不需要额外命名为W_Q'才在数学上具有此能力。

[Petrov原文§4/§6.1](https://arxiv.org/html/2310.19698v1)的单层prefix限制固定了内容侧投影/表示；其§6.1明确分析了下一层注意力变化。共同可学目标投影、多层反馈和原文重编码不能无前提等同于该限制对象。

## 3. A2/A4/B1：门、时间和数值条件

未裁剪时令E=(A_eD_alpha−I)F、U=k(w⊙v)^T，则partial_chi L=<grad L,E>+<grad L,U>，可以抵消。标量保留和写入系数为

\[
d=1-\chi+\chi\alpha/(1+\eta e^2),\quad u=\chi kvw,\quad
\frac{\partial(d,u)}{\partial(\alpha,w)}=
diag(\chi/(1+\eta e^2),\chi kv).
\]

内点chi kv≠0时此Jacobian满秩。共享chi约束一个坐标方向，并未把整个门族降成同号单方向。拆门可能改善训练条件，属于候选比较。

验证器的kv=1是归一化标量系数，只核对该Jacobian结构，不声称两个有限投影B的输出都能取1。一般非零kv的证明覆盖严格B内点；例如k=v=1/2时仍满秩。chi信用抵消也可在严格投影内点构造：取F=1/4、k=v=1/2、b=1/2、eta=3、alpha=19/32、w=1/2，则e=1/4、A_e alpha=1/2，遗忘−1/8与写入+1/8精确抵消。这些是独立门的局部控制命题，不能扩大为共享MLP所有参数都获得非零信用。

tau定义神经保持/松弛，gamma_RL定义未来效用偏好。二者可刻意独立；强绑gamma_RL=f(tau)会改变价值目标。神经微步不能未经单位映射直接代入gamma_RL的指数。随机时长还满足E[exp(−beta d)]一般不等于exp(−beta E[d])；取beta=log2、d等概率取1或3，前者5/16，后者1/4。

正时长本身也不保证资格迹有界。若d_j=1/j、增量恒1，最近j/2个增量的总衰减指数有统一上界，它们贡献随j线性增长。若另有d_j≥d_min>0、增量有界B，则可给出B/(1−(gamma_RL lambda)^d_min)的几何界。本件不对实际合同的时长作未核验断言。

A_e沿e的保留系数为1/(1+eta||e||²)。当前eta<16、||e||²<1给出>1/17，这是配置推出的严格局部不等式。它不是整个编辑的保留下界，例如eta=15、e²=1/4、alpha=1/1000时，衰减擦除合成保留仅4/19000<1/17。

移除eta上界保留固定方向的状态非扩张，但不保证零学习稳定性代价。标量A(e)=1/(1+eta e²)，取eta=t²、e=1/t，A恒为1/2，|partial_e A|=t/2趋于无穷。高维的条件数为1+eta||e||²。状态范数、输入导数和数值条件数不能互相替代。

## 4. B2/B3/B4：容量与稳定性究竟证明了什么

径向投影Pi(X)=cX对所有读出同比缩放，因此没有选择性；若X=S+N，S与N也同比缩放，瞬时范数SNR不由这一步单独改变。后续量化/噪声阈值可能受幅度影响，需要额外模型。两个32×32矩阵有2048个标量条目，每头rank≤32，块对角联合rank≤64；其他拼接按实际算子另算，不把参数个数当秩或事实存储条数。

独立擦写没有强制使用当前预测残差，这个归纳偏置差异成立。但独立门可关闭写入、条件化，并包含绑定近端回归子族。故不能推出冲突键必被无条件覆盖。对冲突新值是否应覆盖，还取决于真实来源和有效版本。

固定门下F范数非扩张不推出闭环收缩。取f(F)=[1−chi+chi sigmoid(4F−4)]F，chi=1/2。虽然所有F均有|f(F)|≤|F|，在F=1处却有f'(1)=5/4。它是一个状态依赖门的精确反例。

隐式可微也不要求rho(J)<1，只需解处I−J可逆；J=2时逆为−1但Neumann级数发散。固定J的rho<1可保证相应Neumann级数收敛；逐步各自rho<1仍不保证变输入乘积稳定。例如

\[
A=\begin{pmatrix}1/2&2\\0&1/2\end{pmatrix},\quad
B=\begin{pmatrix}1/2&0\\2&1/2\end{pmatrix}
\]

各自谱半径1/2，BA却有大于1的特征值。全域共同收缩需要更强的共同度量/一致范数界。

合法禁写要求F_next=F，因此完整(H,F)图的Jacobian含单位块，必有特征值1。不能同时把永久保留状态与全主体严格收缩作为无条件要求。应分别声明有界性、固定输入局部吸引、有限时域扰动增益和反向传播条件。

## 5. A6/C3：位置不可辨识与复制表达性不同

C_b=sum_j Q_j 1[b_j=b]在重复字节时非单射，单token目标不能唯一辨识隐位置。这不推出序列函数无法表达。固定记录/首址/长度，令OP2的a=1、gamma_copy=0、lambda=1、首步fresh为首位delta。归纳得每一步Q是当前位置delta，接受后posterior仍为该位置delta，再shift到后继。任意重复字节串都可在这段受控复制中输出。

这是理想hard/边界控制子族，不主张有限logit参数化能精确达到delta和0/1。这个构造不证明神经控制可学、EOS能自主选择或soft有限精度的无界长度性能。[C-RASP相关原文§3/附录A](https://arxiv.org/html/2505.21785v3)讨论特定形式类与长度泛化。未建立本递归图到该类的归约，不能迁移其不可能性结论。

原意见E11表还有一项实质误读：a_i≥lambda_i M_i不是OP2合法域条件，只是“指定记录边缘+原样继承续读+非负重启”同时成立的条件。OP2已采用缩放后的a_i lambda_i m_i，对任意合法a均归一化。

发射层可以精确对应。若q0<1，令

\[
g_{mix}=\gamma+(1-\gamma)q_0,\quad w_{ij}=Q_{ij}/(1-q_0),
\]

则OP2的P恰等于§7.2的归一复制混合形式。q0=1时P=G。该映射不意味着头的参数化、读内容、posterior、coverage或cursor转移相同；候选仍需唯一方程入口。

## 6. A7/C1/C2：信用不等于功能增量

父群已有a(x)=W_eff x+P tanh(Rx)。零入边出生在R_new=0处的一阶变化为

\[
delta a_{birth}=B\,delta R_{new}x.
\]

固定端点、同一合法分支且相关真实导数存在时，若本次允许自由更新W_slow，父图取delta W_slow=B delta R_new即在所有输入/微步产生同一预激活变化。后续链式传播也相同，所以

\[
col(J_{birth})\subseteq col(J_{parent}).
\]

这是“非零启动信用不证明新增一阶函数方向”的更强限定。同时，把完整父切空间投影出去会抹掉这种出生的全部一阶信用。父W冻结、仅允许低秩适配、受保持可行域限制时必须重新定义可实现集合，不能直接套线性正交投影。硬路由tie或ST代理不冒充上述真实Jacobian。成熟后的非线性贡献与瞬时切空间分开评估。

初始出边梯度0也不要求特殊重置。f=b tanh(r)、b=1、r=0、目标1，平方损失给partial_r L=−1、partial_b L=0。普通SGD取eta=log2后r=log2，下一次partial_b L=−6/25≠0。入边已能解除出边零信用。[GradMax](https://arxiv.org/html/2201.05125v3)与[TINY](https://arxiv.org/html/2405.19816v2)讨论的目标、父更新集合和度量应分别对应，不把二者的判据直接合并。

字节CE与活动option级RL可合法分工。若声明字节也用序列收益，才必须补其采样、score-function、加权和离策略约定。默认可以明确byte_policy_credit=false，不把“可选”误作已启用的信用路径。

软惩罚系数是目标权重，硬约束的对偶乘子是优化解的一部分，不要求二者相等。例如min_x .5(x−2)^2+.5x²，约束x≤1.5，解x=1、约束松弛、对偶0，软惩罚梯度仍为1，KKT完全成立。功能准入负责一阶代理未覆盖的真实损伤；三者需要责任/单位表，不能由共存推出矛盾。

## 7. 对统一在线目标的真正补充

取Fbar=D_alpha F_t，beta≥0，目标

\[
J(F)=\tfrac12\|F-Fbar\|_F^2+\tfrac\beta2\|F^Tk-v\|^2
\]

严格凸，唯一解为F_star=Fbar+beta/(1+beta||k||²) k(v−Fbar^T k)^T。这是已有误差校正候选的清晰定义，不自动统一E1/E4/E6的寻址几何，不自动解决全图Jacobian或径向容量投影。

尤其Pi(F_star)一般不是min_{||F||≤C}J(F)的解。取k=(1/2,0)、beta=1、v=5/8、Fbar=(0,1/4)，有H=diag(5/4,1)、线性项b=(5/16,1/4)、F_star=(1/4,1/4)。设C²=2/25，径向投影为(1/5,1/5)。该点的两个坐标要求不同KKT乘子5/16与1/4，因此不可能是该约束目标的解；父Fbar自身仍在球内。

若要精确解带球约束的统一目标，定义b=Fbar+beta kv^T。按Lagrangian J+(mu/2)(||F||_F²−C²)的约定，应解

\[
(I+\beta kk^T+\mu I)F=b,\quad\mu\ge0,\quad
\mu(\|F\|_F^2-C^2)=0.
\]

C>0且超球时可用单调的一维mu方程求有限根，并利用rank-one结构；C=0时直接F=0，b非零通常对应mu趋向无穷而无有限根。这是新的计算成本，不能预先称同费用。chi松弛、硬许可跳过、状态依赖alpha/beta/k也需明确是否仍在同一目标内，不能只给未约束闭式解便代签整条更新。

因此保留统一在线误差校正目标为候选，不据本次审查将其升为唯一v1.3默认，不宣称它消除全部14项问题。
