# 多模态与物理世界：共同认知图的前置设计

> 状态 [设计原则与待冻结接口]，2026-11-05。响应owner“新算法是否考虑多模态、怎样理解物理世界”。现有主稿只预留图像/音频编码器及动作条件后继预测，CF1/执行20仍是中文反馈规则任务。本件不宣称多模态已实现或已理解物理世界，不调整执行20的工程、价格、预算及实际队首。

## 1. 当前考虑到哪里

[算法主稿§5.1](TAIJI_CORE_ALGORITHM_V1_DRAFT_20261031.md)允许图像/音频后继编码器接入事件；§8定义动作条件的后继表示、奖励与终态预测。[VISION§20](VISION_FUTURE_TECHNOLOGY.md)要求专用器官共享对象/事件/关系，根需求CR-5/CR-10要求身体因果闭环与跨模态组合。它们给出了方向，尚未冻结视觉/音频的张量、时空对齐、对象身份、物理状态转移和学习信用完整算法。

执行20即使通过，也只说明有限中文符号下的反馈适应；“软/硬、空心/实心”在该任务中只是属性名字，不能代签模型已从感知与行动学到这些物理属性。把相机画面先转成文本后做问答，也不自动证明共同多模态认知。

原生字节是当前文本器官的边界编码。图像、音频、深度/触觉和控制信号可保留自己的连续/离散编码，不必先转成中文或当作UTF-8字符。共同主体拥有表征、来源、记忆、预测与选择；外部器官或成熟组件不得暗中提供任务答案。

## 2. 不同感官怎样进入同一个世界

| 层 | 后继候选必须明确的责任 | 不可借接口存在宣称的能力 |
|---|---|---|
| 专用感知 | 每模态编码器产生带空间/时间的局部特征序列，保留原始帧/片段引用与编码revision | 图像/音频接入不是识别、理解或因果学习已经成立 |
| 时空证据 | modality、source、获取/有效时间、坐标系/相机标定、覆盖范围、missing/unknown及同步误差 | 未看到不等于不存在，零值不冒充缺失；神经微步与真实秒分开 |
| 共同状态 | 支持同一对象跨帧/视角持续、对象间关系、事件/动作和目标查询；多模态共同更新H/F及证据绑定 | 不要求所有模态共享同一套投影权重，也不以末端logit加权代替共同认知 |
| 证据回读 | 依query选择原始片段/区域与历史事件，处理变长信息及容量成本 | 不把整段视频压成一个均值向量后声称保留全部关系 |
| 后果预测 | 条件于当前信念、动作及真实dt，预测任务相关后继分布、终态/成本与不确定性 | 低隐藏态预测误差、好看的视频或常量表征不代签物理正确 |
| 身体/工具输出 | 从共同状态产生动作/控制提案，执行器提供真实回执和新观测 | 想象结果不能写成真实Outcome；语言动作描述不等于动作已执行 |

对象/关系可以由分布式表示或可学习槽实现，具体选择需比较；不预先把宿主分割、实体真值/物理参数直接给入模型。真实可用的传感/位姿/标定数据可作为合法观测，模拟器隐藏状态仅评分或作明确上界。原始媒体/状态的字节、带宽、缓存及恢复成本分别记账。

## 3. 怎样操作性地定义物理理解

本项目把它分成可验证责任，不以会讲物理名词或逐像素重建质量作唯一依据。

1. **持续存在与部分可见性**：遮挡后仍可维持对象假设；证据不足时保留多种可能，重新看到后修正身份和状态。
2. **空间与视角**：区分物体移动和观察者移动，关系能随坐标变换一致，不把背景/外观当对象身份。
3. **动作与动力学**：同一状态下不同动作应有不同后果；观测变化后能修正运动响应、接触/支持等预测。
4. **规划与检验**：利用后果预测选择有成本的行动，行动后再观察；比较无世界模型、打乱动作对应和真实回执对照。
5. **不确定性与纠正**：对不可辨识属性不强行给确定值；预测偏差通过独立真实结果归因到感知/绑定/动力学/控制，并在后继任务中检验修正。

可以从视频和他人动作观察中学习，并不要求先造机器人。若声称模型会预测自己的行动后果，需在可控制环境或有明确动作记录的独立任务中验证。模拟环境的成功仍限定其物理规则、观测与执行范围，不能自动外推现实机器人。

例如两个外观相同、运动响应不同的物体，单张图可能无法辨识差异。主体应保留不确定性，通过一次合法推动与后续帧更新预测，再预测下一次推动的后果。质量与摩擦若仍不可分别辨识，可先学任务相关响应，不必假装恢复全部真实物理参数。这样的属性才与“看、推、发生什么”建立了可检验联系。

## 4. 核心算法还缺的具体定义

后继正式算法必须补齐：各模态特征形状/帧率、证据寻址与跨模态绑定、持久世界信念的更新、动作条件预测分布及目标、观察误差与任务信用、行动/再观察、状态保存和模态扩容。通用的“encoder→共同状态→world model”框图不算这些定义已交付。

共同状态是基于有限观测的信念，不直接等于环境真值。需要区分实际观测、历史推断、想象后继与已执行回执；暂时不见的对象不能被静默删除，冲突证据要有来源/有效时间。物理dt、微步调度和效用折扣各自定义，不能混单位或因都含时间就强绑。

训练可以结合跨模态对应、时序/潜在后继、动作结果与真实任务损失，但权重与责任需逐项声明。损失不必来自唯一全局能量；它们需要形成实际信用路径。反馈若宣称能改进感知或动力学，必须给出到该模块的更新和干预证据，不能重演“器官能输出、任务信用到不了它”的问题。冻结感知基座可作比较方案，冻结组不能宣称被反馈重塑。

当前F内容区分与输出杠杆的工程问题不会因换成视觉输入自然消失。后继还需检验对象/时间条件读取是否真正影响回答和动作，不能用模态接口数量签能力。必要的空间/时间/关系信息不能先被不可逆合并，再指望后端纯内部自纠。

## 5. 第一个物理切片的设计入口

一个合适的后继切片是受限二维视觉交互：原始画面、可见动作/真实时间，主体预测推动后的对象变化并在重新观察后纠正，遮挡只在身份仍可辨或允许不确定的条件下测试。这里先定义问题，不物化数据、代码、预算或正式训练合同。

| 验证面 | 必须防住的替代解释 |
|---|---|
| 新外观/背景，同动力学 | 只认颜色或背景，未学状态变化 |
| 同外观，变化的动力学，给合法试探反馈 | 只复用视觉标签，不会依据后果改预测 |
| 可控遮挡、视角和传感缺失 | 将看不见当不存在，或把未知真值泄漏给模型 |
| 同初态的不同动作/无动作对照 | 只预测时间相关性，未消费动作 |
| 视觉/其他感官冲突或错时配对 | 末端平均掩盖错误绑定，未形成共同证据 |
| 干预感知、记忆、动力学与策略 | 独立模块可用但共同任务不承重 |
| 恢复、纠正、旧中文能力及真实费用 | 多模态扩容后状态丢失、旧能力退化或算力未记账 |

可先只做视觉＋动作/本体感受的最小完整闭环，不必一次加入所有模态。音频等扩域要证明新增信息确有任务价值。每一切片都需合理无记忆/无世界模型基线、同信息预算，以及显式的状态真值上界；上界不进主体运行链。

## 6. 与当前推进的关系

改正“所有多模态工作都等S22.7后才考虑”的表述：共同接口、对象/时空语义与动作结果信用现在进入设计约束；实际媒体训练或身体闭环另按父能力、价格与数据合同条件准入，不必机械等待全部S22结束，也不成为当前执行20的追加门。

执行20的工程、价格和原报告保持各自身份，实际状态以MASTER-PLAN为准。新的多模态字段不追改旧报告或直接加入现行候选；未来迁移时再冻结接口版本。学习/纠正闭环成立后，可在S21责任下选择一个物理切片，先验证对象/后果/任务贡献，再扩大传感和结构规模。

研究参照仅用于明确问题：[DreamerV3](https://www.nature.com/articles/s41586-025-08744-2)学习感知表征与候选动作的后果/奖励并用于控制；[V-JEPA 2](https://arxiv.org/abs/2506.09985)区分视频表征预训练和动作条件世界模型后训练。这些工作不替本项目提供能力证据，也不将其大规模资源或现成架构直接指定为默认。
