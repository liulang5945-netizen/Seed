# 预注册卡：N32.5.01 轻量 Q3 GRU 可学性检查（方向 X：去 MLP 门＋等价编码缓存）

> [预注册·探索] — 2026-11-25（D-20261125-534；owner 2026-11-25 裁定「方向选 X」，在 `N32.4` 于 `2,063.52 CPU` 触帽结线后新开研究线 `N32.5`）。不沿用 `flat-MLP ≥0.90` 工程门（已在 `N32.4.04` 证伪）；不比较 `S vs RT`；不读确认集 / `check` / `final`。

## 1. 问题

在 `taiji-23-composition-v2` 数据合同、QF 顺序（问句在前，场景在后）、训练统计标准化与换名增广 `×3` 下，骨干 `G3 GRU u96 + final-tick read_gate` 能否在 `6,000` 步（`153.6 万` 次呈现）内把 `Q3`（两跳组合）学到 `≥0.85`？

## 2. 工程前置（替代已证伪的 `flat-MLP ≥0.90` 门）

1. **既有可学性证据**：[N32.4.03](RESULT-N32-4-03_20261125.md)（`0.8988`，6 个实体类 `77.9%–87.1%`）已证明 `Q3` 编码与标签通道信息充分、无结构性损坏；
2. **快速等价编码强校验**：`encode_q3_fast` 预先缓存字符嵌入、`scene_order` 坐标与问句张量并预分配张量以消去重复 `~120 CPU` 编码开销，且每次运行**必须强制断言**与 `N32.4.01–04` 完全一致的原始张量 `sha256` 摘要（fail-closed）：
   - `train (288,000 × 20 × 48, float16 + labels)`: `df7b1ad98a6c7c908ebdb9ddba7e4e407c839edaba01371fccf2bb1a27a034e9`
   - `val (12,000 × 20 × 48, float16 + labels)`: `7f3f3c580ae1f8577b1046c304513d99fa4ab150e7fb0965f1ac315c665d7928`
3. **单元测试**：[test_n32_5_01_fast_encode_20261125.py](../../tests/test_n32_5_01_fast_encode_20261125.py) 验证切片上 `encode_q3_fast` 与参考 `ce.encode()[:20].to(torch.float16)` 逐位一致（`torch.equal`）。

## 3. 臂与超参（冻结）

| 臂 | 结构 | 步数 × batch | 优化器与裁剪 | 门 |
|---|---|---|---|---|
| **G3 GRU u96** | `GRU(48→96)`，QF 顺序 `[3..19, 0, 1, 2]` → 末步 `read_gate`（bias `1.0`）→ `96→64→ReLU→10` | `6,000 × 256`（`1,536,000` 次） | Adam `lr=3e-3` 余弦退火至 `10%`、`wd=0.0`、grad clip `1.0` | `val Q3 ≥ 0.85`（探索 seed `20261120, 20261121, 20261122`） |

每 `2,000` 步评估一次 val；输入标准化 `mu/sd` 在原始 `train_x` 上以 `float64` 统计后按 QF 顺序重排缓存（数值等价）。

## 4. 预算与冒烟分流门（硬帽 `CAP_CPU = 250.0` 含冒烟）

- 冒烟（`SMOKE_STEPS = 100`，精确分离计测 `encode_cpu`、`train_loop_cpu` 与 `eval_cpu`）外推单 seed 与 3 seed 总耗（含 `1.10×` 安全裕量）：
  - **`all_3seeds`**：`smoke_cpu + projected_3seeds <= 250.0` → 跑 `20261120`，过 `0.85` 后补跑 `20261121 / 20261122`；
  - **`screen_only`**：否则若 `smoke_cpu + projected_1seed <= 250.0` → 仅跑筛选 seed `20261120`（严守 `≤250 CPU`，不超帽硬跑 3 seed）；
  - **`budget_insufficient`**：否则不训练，直接停在 `smoke`。

## 5. 出口（读前写定）

| 出口 | 条件 | 后续 |
|---|---|---|
| `learnable` | `all_3seeds` 下 3 seed 均 `≥0.85` | `Q2 + Q3` 单任务可学性前置齐备，可申请正式 `R1` 比较 |
| `learnable_unstable` | `all_3seeds` 筛选过 `0.85` 但补跑 seed 有 `<0.85` | 记「Q3 在 GRU u96 下可学但不稳定」，待决定容量/步数 |
| `screen_passed_needs_rep_budget` | `screen_only` 下 `20261120 ≥ 0.85` | 筛过！以极小追加预算（`~170 CPU`）单开补跑 `20261121/22` 复现卡 |
| `q3_not_learnable` | `20261120 < 0.85` | **`Q3` 在当前 `u96 GRU+read_gate`（6k 步）不可学**，明确暴露瓶颈，不再盲烧预处理/MLP 预算 |
| `engineering_failure` | digest 校验失败 / NaN / 超时截断 | 修复后复验；不得伪造读数 |

## 6. 范围与纪律

- 探索 seed `20261120–22`，零 `check` / 零 `final` / 零 `confirm`；
- 范围标签：`data=synthetic; vocab=closed; diagnostic=learnability_q3_gru; no_shared_gain_claim`；
- 不签 `N32` 正式准入 / `R1` / `24-S` / `25-S` / `29` / `final` / `C` / `D` / `J`。
