# U2有状态神经单位、连接与生命周期修订

> 文档状态：[合同] — 2026-11-13设计修订。代码审查基线`efa7bda72`；本文定义后继候选，不追认当前运行图已具备全部机制。调度归[MAINLINE](../MAINLINE.md)，主方程归[U2](SPEC-TAIJI-CLOSED_LOOP_U2_20261110.md)。

## 1. 路径裁定与证据边界

采用**有持续状态的计算神经单位、可塑连接和可恢复生命周期**作为原生核心的结构方向，继承现有任务信用、原始证据、恢复与发展结果反馈。生长应能改变主体实际计算结构；只增加瞬时特征宽度不能完成这项长期要求。这里选的是与根目标更一致、可逐步验证的路径，尚无数据证明它比当前U2有更好的任务表现。

| 代码/结果事实 | 对设计的约束 |
|---|---|
| `u2_subject.py::native`保存群体H，用Q/K/V进行群间通信；H坐标本身可视为循环神经状态 | 当前单元并非互不联系，也并非完全没有神经状态 |
| R/P单元每次由`tanh(Rx)`重算；`u2_group_structure.py::GroupResidual`同样没有逐单元活动状态 | 当前主要出生对象与持续状态对象不同，必须统一单元身份、状态、参数、连接与信用 |
| `birth_units`真实扩张R/P，保存unit_ids、门谱系并迁移moment；逐群宽度已有实现 | 继承这些资产，不把已有成长说成纯配置占位；尚未完成完整生命周期 |
| P3.7 Native各臂恒答未知；P3.8独立参照的内容信用及受验收更新取得179/180 | 信用与优化仍是前置；参照成功不证明Native已学会，也不证明神经单位能自动改善它 |
| 既有保持失败及稀疏连接限制均在册 | 出生、重连、退役都须量出任务贡献、旧能力损伤与全部费用 |

三个选择中：继续只扩R/P，继承容易但留下生命周期缺口；直接改为详细脉冲/生物仿真，增加时间编码及训练难度且目前无对应任务证据；本修订选择连续值有状态单位图，以可微任务信用为首版学习基准，再独立比较局部近似学习。生物启发落实为状态、可塑性、连接和生命周期职责，不把“相似外观”当作能力依据。

## 2. 统一单位和状态身份

首版一个单位是**一个标量循环状态及其适应状态**，可按群向量化运行。它不是一个独立语言模型。每个世界假设分支保存各自`z_i,a_i`；参数及结构在分支间共享，想象分支不得覆盖实际分支。

| 类别 | 必需字段/责任 |
|---|---|
| 单位身份 | 永久unit_id、group_id、parent_ids、birth_version、生命周期状态；ID不得复用 |
| 神经状态 | 活动z、适应量a、最后内部tick、状态来源版本；跨事件/会话保存 |
| 单位参数 | 输入行r、输出列p、保留系数c、适应率η、适应强度b、既有内容门谱系 |
| 有向连接 | edge_id、source/target unit_id、权重w、创建/退役版本、optimizer归属 |
| 学习状态 | 实际任务梯度、birth-fit诊断、moment、有限窗资格迹及截断来源 |
| 生命周期账 | proposed→immature→mature→dormant→retired；拒绝/回滚、因果贡献、稀有能力及成本记录 |

单元规模N、有效边数E、状态字节、可学习参数、独立信用方向、成熟单元数分别报告。预分配但禁用的槽位不算新生；替换不等于净增长。首次迁移将原R/P unit_id逐一映射到该registry，原H及器官职责保留。

## 3. 唯一递推与兼容嵌入

沿用U2的群输入`x_g∈R^(8d)`、合法内容门`g_i(x)∈[0,1]`和群预激活。一个`native`调用是一个内部tick；先同步读取全部旧z/a，再计算全部新z，最后更新a和H。首版禁止顺序原地更新导致单位排列改变动力学。

\[
v_i^k=r_i^T x_{g(i)}^k+\sum_{j:(j,i)\in E}w_{ij}g_j(x^k)z_j^k-b_i a_i^k,
\]
\[
z_i^{k+1}=c_i z_i^k+(1-c_i)\tanh(v_i^k),\qquad
a_i^{k+1}=(1-\eta_i)a_i^k+\eta_i z_i^{k+1},
\]
\[
A_g^k=W_gx_g^k+\sum_{i\in g}p_i g_i(x^k)z_i^{k+1},\qquad
H_g^{k+1}=(1-\ell_g)H_g^k+\ell_g\tanh(A_g^k).
\]

`w_ij`是有向边j→i，允许有符号作用；不强制兴奋/抑制细胞类型。首版c直接约束在`[0,1−1e−4]`，η在`[1e−4,1]`，b在`[0,2]`，旧父迁移用c=b=0、η=0.1、E为空。参数提案经投影后按**实际位移**重新验收，不能沿用未投影方向的下降证明。边权有限、投影/限额及非有限出口在工程合同冻结。

此时`z_i^+=tanh(r_i^T x)`，逐步恢复原R/P映射；旧参数、门、消息支持和归一化尺寸不变，可对完整原图做兼容检查。c=0必须是可表示端点，不能用有限sigmoid logit冒充精确零。c学习打开后才形成该单元的跨tick记忆，端点采用可行方向导数检查。

若初始z/a/H逐坐标在[−1,1]且系数满足上述范围，三个更新均为有界量的凸组合，归纳得任意有限tick仍在该区间。该结论只签**状态有界**；任意循环边权仍可能造成振荡、饱和、梯度放大和多吸引子，未证明收缩或全局收敛。

物理时间、内部tick、学习器提案u、参数版本v四类时钟分列；一次观测的多轮内部处理不能重复推进环境时间。首版保持原native调用次数，多tick研究必须另冻结CPU/截断窗。等待保存状态与唤醒条件；自主工作由已有目标/活动策略选择，不能以不停空转代签自驱收益。

## 4. “共振”的可检验含义

采用**任务条件下的循环相互作用与协同贡献**：合法输入驱动单位，连接传递状态，后续活动反过来改变相关单位及决策/表达。相同频率、激活相关性或多算几轮只作诊断。

至少比较完整图、阻断跨单位消息、置换源单位、保留参数但去掉历史状态四种干预；控制实际计算与信息范围。记录相互影响JVP、任务效应和恢复，协同量可用`U_AB−U_A−U_B+U_0`，明确其任务/尺度及置信区间。结构上有环不代表协同收益；相关性高也可能是共模坍缩。多tick失稳时具名停止，不能借助全局强收缩先验强行消除一切长程记忆。

## 5. 有状态出生的启动信用

采用已有的零入边/非零出边中性出生：新单位r=0、z=a=0、b=0；所有触及新单位的循环边初值为0，p非零，c取预注册值。新单位不改变旧softmax分母、归一化维度或消息支持。参数不更新时新z恒0，旧轨迹、输出及旧参数梯度保持原函数；新状态的零初始化不清空旧状态。

令δ_g,k为真实任务损失对A_g,k的总导数，允许它包含后继循环影响；在本次可微窗起点对新状态的导数为零。出生点定义

\[
e_i^{k+1}=c_i e_i^k+(1-c_i)x_{g(i)}^k,\quad e_i^0=0,
\]
\[
C_i=\sum_k g_i(x^k)\delta_{g(i),k}(e_i^{k+1})^T,
\qquad \nabla_{r_i}L=C_i^Tp_i.
\]

证明：出生点tanh′(0)=1，所有新循环边及b为0，故对r求导得到e的递推；将输出列p和内容门代入链式法则得上式。`c=0`才退回原`Σgδxᵀ`。不同c/门对应不同C，不能共用一个原始输入矩阵冒称同一秩预算。超过本窗的梯度按截断合同处理，有限窗公式不签全寿命精确梯度。

同一C下，独立启动方向数≤rank(C)，**非零梯度单元数不受该秩直接约束**；复制同一有效方向可以产生多个非零但相关的梯度。已有v1.2勘误继续有效。p取C的有效左奇异方向，并沿用噪声、绝对信用、birth-check及门对齐检查。首版c候选仅`{0,0.5,0.9}`，在fit内选择并计入搜索次数，check不得反向选c。

出生首刻∇p、∇c、∇b可为零，r必须获得与解析式一致、超出数值噪声的信用；r发生合法更新后才检查下游参数的启动。成熟单位的完整循环梯度以有限窗BPTT为基准。上述e是**出生点导数**，不能直接替代成熟循环网络的完整梯度；局部资格迹近似属于后续受控比较。

## 6. 连接重塑、增殖、衰退与回收

**连接新增/重连**：缺失边没有现成参数梯度。仅在影子候选注册预算内的零权重边，测真实任务信用，再经成熟与保持验证；禁止暗算N²边却只记稀疏运行成本。删除旧边和增加新边是两个需分别保持的操作，合称“重连”不能免验删除损伤。新边插入不重归一旧连接。

**继承式增殖**：对原单位集合建立映射π，新单位j映射到原单位π(j)，原单位u的复制数为m_u。复制z/a/r/c/η/b及门，按

\[
w'_{ij}=w_{\pi(i),\pi(j)}/m_{\pi(j)},\qquad
p'_j=p_{\pi(j)}/m_{\pi(j)}
\]

构造全部关联边，包括自环映射出的复制间边。复制仍归原群，使用同一x及门，其他单位/群的归一化支持不变。同步递推下，同一原单位的各复制状态相同，输入和输出按复制数求和还原原函数；据归纳每步保持。仅复制输入、随意分配循环边不能获得该结论。完全对称复制不立即增加独立功能，后续fit内分化和因果删除收益才能签成熟。该代数不保证Adam轨迹等价，moment分配须独立签署，不能机械复制后二次放大更新。

**衰退/休眠**：低使用率只产生候选，先保存可恢复父并以可逆门在影子中降低作用；通过包括稀有旧能力的干预保持检查后才休眠。门未精确为零不等于功能消失。

**凋零/回收**：所有输出及循环影响均隔离、无未结信用或外部引用且保持通过后，才删除张量/边并更新registry与optimizer。零输出但仍有循环出边的单位不能删除。退休ID永久留谱系，释放的存储给新ID。

**合并**：只对已验证完全等价的复制单位采用上述增殖的逆操作；一般单位必须经蒸馏/迁移和误差预算验收，没有通用函数中性合并定理。

上述操作由主体发展策略提出，宿主只执行权限、资源和事务约束。出生/重连/回收的真实收益、损伤、成本回到发展结果模型，继承U2的预测→操作→回执→再选择闭环。首版冻结结构策略以隔离算子，后续再学习策略，不把外部脚本日程称为模型自主增殖。

## 7. 防止固定接口再次成为永久上限

首个兼容候选仍经原d维H与器官接口读取单位，这只用于隔离改变及继承已有父。N增长不保证通信/表达带宽增长。后继25.2必须检查单位内容的直接查询、可变群宽及通信宽度，量出瓶颈贡献。

新单位接入attention时，不能直接扩旧softmax分母并声称中性。可先用独立支持集读取新单位，以零输出投影在旧读出后增加残差；输出投影先获信用，查询/键随后获信用。新路径占比、原路径依赖和成熟效果都须验证；若统一路由重建，则签显式迁移误差及保持。没有证据前不抹去固定H带宽的限制。

多模态内容由原RGB/audio/proprio/byte器官进入共同状态图，单位不预贴实体、颜色或答案标签。新单位的状态和边不能代替空间/时间、行动条件预测、对象持续性及证据读取。自驱也须来自任务/发展回执，而非另加“生命值”奖励即可成立。

## 8. 恢复与验证合同

新schema加入逐分支z/a、单位/边registry、稀疏索引顺序、状态/参数版本、moment、生命周期阶段、未结事务与RNG。旧bundle使用显式迁移；旧字段缺失不能静默当零恢复。初始及首个非空moment的完整保存/恢复通过后才可训练。结构变更在安全边界影子执行，提交与回滚按同一父签署。

| 层 | 交付与判定 | 不得代签 |
|---|---|---|
| 本轮局部数学 | [核验脚本](../../scripts/training/verify_u2_neural_unit_math.py)：双精度/单精度兼容、有界、中性出生、历史信用、复制及反例；[报告](../../reports/taiji_u2_neural_unit_math_20261113.json) | 完整U2、optimizer、恢复或能力 |
| 正式参考图 | 方程→参数/状态→源码→检查覆盖；兼容父逐参数输出/梯度、每个声明可学习参数实际更新 | 总范数非零代替负责单位信用 |
| 学习与恢复 | 单位/边ID驱动映射、完整learner包、独立进程下一损失/梯度/提案、两代出生/休眠恢复 | 只保存模型权重代替连续主体 |
| 行为与成长 | 无状态/无边/固定最终容量/重放/随机出生控制；新任务、仍有效旧能力、成熟删除、全部成本 | 低损失或增大张量代替新能力 |

局部数学使用固定合成数据和0次optimizer更新；有界/中性证明的适用条件与数值反例同存。成熟损益沿原22.7数值门，未满足父资格前只签工程证据。实施卡在执行包22，本文不另开并行训练队列。

本轮核验41项通过（FP32 19、FP64 22），runner CPU0.859375。第一轮使用与自动微分相同的1e−12容差检查有限差分，出现1.40e−12偏差；原因是差分本身的截断误差。现按`|tanh(u)−u|≤|u|³/3`沿c递推求出每坐标截断界，另列工程舍入容差。该修订不改变任何冻结行为门，也不把有限样例通过提升为全图证明。

## 9. 先验工作与可主张范围

- [GradMax](https://arxiv.org/abs/2201.05125)：提供保函数加宽及梯度导向出生依据；不证明新单位必能成熟，也不自动覆盖循环持续状态。
- [Net2Net](https://arxiv.org/abs/1511.05641)：保函数知识迁移的先例；本稿循环复制需要第6节完整边映射，不能只借名称。
- [RigL](https://proceedings.mlr.press/v119/evci20a.html)：任务导向稀疏拓扑更新的实证先例，研究设置保持参数预算，不能据此声称无限规模成长。
- [Continual Backpropagation](https://www.nature.com/articles/s41586-024-07711-7)：在其持续监督/RL设置中，选择性重初始化有助保持可塑性；不能把低频等同可安全删除，也不等于净增规模。
- [e-prop](https://www.nature.com/articles/s41467-020-17236-y)：局部资格迹结合学习信号的先例；任务信用仍需来源和近似误差检查。
- [Growing Neural Cellular Automata](https://distill.pub/2020/growing-ca/)：可学习局部状态交互产生生长/修复图案；不构成语言、认知或可变参数图已成立的证据。

本修订主张的是待验证的统一设计及有条件推导；不主张首创神经出生、动态稀疏、保函数复制或生物大脑等价。采用依据是根目标与现有工程/负证据，不是新颖性名称。
