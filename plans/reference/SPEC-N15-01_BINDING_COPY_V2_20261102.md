## 3. 唯一读取候选：原文对齐、内容转移与连续复制

### 3.1 目标原文与来源原文对齐

保持14的共享整记录字节表示`g_p,u_ij∈R^128`及已观察事件边界。新寻址维k=32；`s_t`为更新前H的原QueryRead输出，`e_prev∈R^64`为上一输入字节嵌入。先定位目标当前相关部分，再在记录中定位锚点：

```text
q_w = Q_w [s_t; e_prev]                       # 32
q_s = Q_s [s_t; e_prev]                       # 32
w_p = softmax_p(q_w · E_goal(g_p) / sqrt(32))
M_pij = E_goal(g_p) · E_source(u_ij) / sqrt(32)
l_ij = logsumexp_p(log(w_p) + M_pij)
       + q_s · E_source(u_ij) / sqrt(32)
       + v_meta · metadata_i
alpha = softmax_i([logsumexp_j(l_ij)-log(L_i); q_s·null_key/sqrt(32)])
anchor_ij = alpha_i * softmax_j(l_ij)
```

目标为空时用同一投影的固定零goal-null；无合法记录时alpha_null=1。这个logsumexp匹配保留逐位置的目标/记录相互作用，不能在实现中提前平均目标再声称实现了同一算子。长度归一是明确结构先验；不保证它一定优于池化。

### 3.2 从匹配锚点转移到内容起点

模型自己选择同记录内的内容起点，不由宿主查“是”、跳固定偏移或给gold span：

```text
T_t(i,k | i,j) = softmax_(k in record_i)(
    Q_transport[q_w;u_ij] · K_transport(u_ik)/sqrt(32)
    + v_relative · PE16(k-j))
S_t(i,k) = sum_j anchor_ij * T_t(i,k | i,j)
S_t(null) = alpha_null
```

PE16沿用正弦位置特征的16维有符号相对位置定义，不含实体长度/模板分隔符。T只允许在同一真实观察记录内转移，所有合法位置均参与；无需定义“对象槽/地点槽”。传输是完整概率核，不在宿主代码argmax后截取实体。这里允许关系上下文先验，但不声称已学会一般关系理解。

每步复杂度含目标/来源对齐`O(goal_bytes×source_bytes×k)`和记录内转移`O(sum_i L_i²×k)`；价格与RAM须按真实28步/批次8测，不能借14的旧单价批准新训练。

### 3.3 复制连续性及后验状态

新增随输出携带的`m_t(i,j)`是“下一步继续复制的位置”的**次概率分布**，质量h_t≤1，按(source_id,version,byte_offset)登记，初始全0。模型输出continuation门lambda_t=sigmoid(Linear([s_t;sum_p w_p g_p;e_prev]))：

```text
Q_t = lambda_t * m_t + (1-lambda_t*h_t) * S_t
c_t = sum_(i,j) Q_t(i,j) * V_position(u_ij) + Q_t(null)*null_value
```

将c_t送入14的同一递归H更新，使用原generate/mix产生p_gen、gamma，仍从同一Q输出原始字节：

```text
P_t(b) = [gamma_t+(1-gamma_t)*Q_t(null)] * p_gen_t(b)
       + (1-gamma_t) * sum_(raw_ij=b) Q_t(i,j)
R_t(i,j | accepted_byte) =
       (1-gamma_t)*Q_t(i,j)*1[raw_ij=accepted_byte] / P_t(accepted_byte)
m_(t+1) = shift_within_same_record(R_t, +1 byte)
coverage_(t+1) = coverage_t + R_t
```

末字节移出记录的质量消失，不跨到下一条来源；空来源、EOS或真实生成后复制后验为0时m也归0。Q总质量为1；R质量≤1，shift不会增加质量。null回生成分支，EOS只由生成分支产生。稳定实现采用log概率计算后验，禁止以随意clamp掩盖零概率条件/NaN；不可能观察的工程强制分布单列退出。

观察完整目标的输入步沿14的事件块协议，只推进H，不作为输出接受事件，不更新复制后验；开始应答时m/输出coverage为0。序列内参数revision固定，批次Adam更新后不跨revision复用已编码图或cursor；更新前的source/H/F迁移规则不能被省略。

复制时机与起点都由模型决定，`+1 byte`仅表达原文相邻字节关系，不写死中文3字节、实体12字节、“是”或名字清单。m由实际接受的上一字节更新；当前待预测标签不进入本步查询。训练教师前缀时accepted_byte为前一目标字节，自前缀/评价为前一模型字节，接口和状态递推相同。

14的coverage累计的是软读取质量，即使gamma=1仍累计；本候选改成**已输出复制的后验质量**。这是声明的算法语义修改，不把旧实现按原定义统计coverage判成违约。新接口的连续性/覆盖/对齐以整个读取包比较；没有额外消融时不逐项认领学习收益。

## 6. 正确的评分和过程观测

主评分仍为自由生成completed_action_exact：strict UTF-8、单条规范动作原始字节完全相同且EOS终止；最多64字节/65次预测，提前EOS/解析失败/截断均留在分母。tuple/bytes先用唯一规范化函数转bytes，评分不得从展示文本推断“正确”。oracle/恒定输出/列举/错误名字/截断、字节类型互换都先验。

拟新增`taiji/binding_copy.py`实现新算子/状态，沿`record_relation_core.py`的显式variant注册，旧R0与历史回执保留可复现身份；一个`scripts/training/verify_taiji_binding_copy_15_1.py`分data/graph/price/preflight/compare/confirm/closeout阶段，测试在tests/taiji_native；manifest在plans/manifests、回执在reports、payload在output/taiji_core_binding_copy_15_1。本轮不创建这些运行件或虚构可执行CLI。

连续复制采用已有[CopyNet](https://aclanthology.org/P16-1154/)的研究启发，本文的后验/cursor公式仍须本图核验，不主张首创。自前缀参考[Scheduled Sampling](https://proceedings.neurips.cc/paper_files/paper/2015/hash/e995f98d56967d946471af29d7bf99f1-Abstract.html)，同时承认其目标存在[理论上的一致性批评](https://arxiv.org/abs/1511.05101)；故将其作为独立因子，不从训练/开发NLL差直接推出它必然有效。

主张范围是：根据已观察到的未见输出名失败，检验原文对齐和连续复制状态能否改善有界中文任务，并以配对设计识别训练课程效应。能力、连续学习、主动性、生长和新颖性不互相代签。
