## 2. 两条路线的同层比较

这里A/B是架构路线标识，与包22任务A/B及其父资格无关。

| 比较项 | 路线A：兼容嵌入 | 路线B：单位原生核心 |
|---|---|---|
| 主计算图 | 保留U2群H和器官边界，把R/P特征升级为z/a单位并接边，再通过P投到H | 单位图Γ承担主要持续神经计算；内容/目标进入单位，查询直接读取单位/群体，读取参与决策与字节表达 |
| 原H地位 | 仍为原器官主要共同入口，z与H构成两层持续状态 | 可迁移为普通单位群或短期scratch；不预设所有信息必须经固定H中介 |
| 可继承资产 | 现有参数、完整学习包、器官接口、已核验恢复与控制容易对应 | 复用合法数据、感知/表达器官、记忆/证据协议、信用更新及恢复基础设施；核心参数/状态需明确映射或重建 |
| 目标匹配 | 可较早验证状态/连接/出生的增量贡献；存在长期停留在外围增强的风险 | 生长、连通、读取与主体状态在同一核心设计，结构上限更直接；尚无性能优势证据 |
| 主要代价 | H+z重复状态、固定中介、接口叠加及迁移费用，是否构成实际瓶颈需测 | 新完整图、直接查询、稳定性、学习和恢复需重新覆盖；不因形式统一而自动更易训练 |
| 归因价值 | 与原U2的兼容对照可隔离“持续单位是否有用” | 可检验“旧计算图组织是否限制单位作用”，避免只在旧接口内反复试验 |
| 禁止推论 | 兼容容易不意味着能力上限更高；固定维度本身不证明任务不可表达 | 生物名称、可变单位数或更多参数不证明智能；彻底重构不等于废弃工程证据 |

共同要求：持续状态、可塑边、负责模块信用、来源与权限、完整恢复、真实资源成本及旧有效能力保持。两路线均可使用连续值动力学、可微学习和当前原生字节器官。脉冲实现另属参数化选择，不是本次路线B的前提。

## 3. 本次设计裁定

**长期目标采用单位图主导原生认知计算；工程推进采用可裁决的渐进重构。** 路线A承担兼容迁移与控制，路线B作为明确的目标架构候选提前进入P3.9。A若确有收益可作为阶段父，但不能凭阶段能力自动证明完整单位核心目标已完成。最终选定的图须由任务贡献、持续学习、成长和成本共同决定；本记录尚未批准把生产默认图切换到B。

选择依据是用户长期要求与当前架构缺口，不是旧代码投入量，也不是已经取得的A/B优胜结果。既有Native尚无正式任务A父，缺少“必须保住当前Native成熟能力”的实证理由；恢复/学习/数据和失败归因资产仍然有用。P3.8先给出可解释的信用更新结果，它不会成为B必须永远保持U2形状的约束。

### 3.1 复用、替换与退役边界

| 资产 | 处理方式 |
|---|---|
| 数据分区、信息/反馈权利、原始证据与失败记录 | 两路线共用原合同，封存面不打开，不改写历史结果 |
| checkpoint、身份/谱系、事务与学习器时钟 | 复用机制与经验，新增图必须重签schema/下一更新恢复 |
| 内容反馈、实际任务信用、参数提案验收 | 作为共同学习配方候选；逐图核验，有限参照成功不自动转移 |
| 感知、物理状态、F/E记忆与字节表达 | 按职责复用；允许更换读取/消费接口，旧模块不享有永久保留资格 |
| 固定H主干、R/P投影、群间与器官接线 | A保留作比较；B按单位图重组，必要时替换，不以兼容性否决 |
| 旧核心权重/状态 | 有经验证映射才签继承；无映射可作为新研究候选初始化，明确新身份，不能伪称同一主体连续成长 |
| 原实现和草稿 | 已签证据对应源码保留可恢复身份；仅当消费者迁走且不再担任控制/唯一证据后，按目录规则退役清理 |

每个B候选需冻结`Γ=(unit_registry,edge_registry,z,a,Θ_unit)`、合法输入编码、直接查询、活动选择/表达消费及任务信用的覆盖矩阵。Γ是持续神经计算主载体；证据、F、对象/世界状态仍可作为具名存储和世界模型状态，不要求把所有数据强塞进同一种神经状态。原H若保留，须明确作用及可切断边界，不能在接口深处仍强制所有B读出经过它。

## 4. 公平比较与路线转换

P3.9.1同时定稿A的兼容图和B的最小直接单位图，B以明确源码factory建立独立身份；不以A已有公式和41项检查代签B。B的输入/读出、形状、初始化/迁移、时钟、完整参数信用和恢复规格冻结后，才进入P3.9.2。

P3.9.3的主要比较是A与B，旧R/P作为历史/现行控制；状态关闭、边关闭及单位直读切断为必要机制干预。首次窗口只比较核心组织，结构发展策略保持同一冻结日程。大规模自驱成长留在22.6/22.7/25/26。新读取不是外部语义解析器，不准增加答案信息或独占反馈权利。

公平性分别回答两问：①可映射同父时的迁移增益；②核心组织不同、不能逐值映射时的同信息/同资源学习效果。后者固定公共器官来源、各核心初始化及其种子策略，所有初始化、预训练、迁移和蒸馏费用计入，不能把重初始化B与已训练A的差异独立归因核心。两种比较混杂未清时只作配方级结论。

在读取比较结果前冻结父/来源、train/fit/check权利、随机种子、实际CPU及样本暴露、最小有意义任务效应Δ、保持容差和最多候选数。工程价不足以同时覆盖两图则`comparison_not_admitted`，预算不足不记为B失败。沿每个范围最多两个具名架构版本，不无限追加局部头或小探针。

| 观察/证据 | 决策 |
|---|---|
| A具有可核验学习收益，B未通过工程或任务门 | A可作为阶段父；B按明确失败/未准入结案，单位核心长期目标未完成 |
| B通过直接单位因果贡献、实际学习、恢复与价格门；未见收益相对A≥预注册Δ、配对置信下界>0；有旧能力时保持也通过 | 将B作为该范围的新主候选，A退为兼容基线；继承或新身份分别登记 |
| A的固定接口存在适用范围内的明确不可表示见证，而B正式图消除该障碍 | 停止A同接口上的重复扩宽；进入B受控核验，尚不自动签B能力 |
| 冻结范围内A持续失败，且排除共同信息/信用/优化/恢复问题后，B同资源取得合格收益 | 强制结束A增补路线，切换B；所排除因素只在实际检验范围内成立 |
| A/B均失败，或收益/成本差异不可判 | 关闭本窗，回到共同编码、任务目标或学习机制归因；不宣布单位思想被否定，不靠扩大规模继续消耗 |
| 两图差异低于预注册效应或成本无法配平 | 记范围内未证优劣，按资格保留阶段父；重新评审结构目标覆盖，不用实现便利冒充性能证明 |

单纯“单位里可解码而H里难解码”的探针不够决定切换，还需合法任务干预及实际读出效果。固定维度并不自动形成任务不可能性。若重构涉及已证明旧能力，数值状态迁移与行为保持两项都须验收。

## 5. 长期目标及全路线影响

根目标保留自然中文、跨会话学习/纠错、旧能力保持、自驱、递归发展和多模态物理理解；明确神经单位及其群体为持续认知与成长的基础。具体z/a、c、tanh、U2、RNN或Transformer不写成长期公理。详细目标见[根需求§2.1](../active/TAIJI_CORE_REQUIREMENTS.md#21-统一目标与验收)。

[长期路线](PLAN-TAIJI-N_LONG_HORIZON_20261111.md)本次逐包同步22–28：22在P3.9检验核心组织；23将直接单位作用带入组合任务；24覆盖跨会话单位/边状态与语义迁移；25扩大连接/群体/读取宽度及回收；26学习发展操作及真实后果；27验证跨模态/身体的共同单位作用；28联合检查持续生命周期。包号与已冻结门保留，25不再是首次提出直接单位读取的地点。

P3.8.2b仍为唯一当前动作，结束本轮信用迁移/比较/收束后进入上述P3.9。P3.8所有具名出口都进入收束；不要求它先取得完整A能力才允许单位图工程。P3.9的新范围及价格需重新冻结，本次0训练、0优化器、0新项目任务数据读取。
