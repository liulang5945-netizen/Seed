# 预注册卡：N32.3.01 R1 可学性预检（单任务，零比较实验）

> [预注册·探索/预检] — 2026-11-25（D-20261125-515，owner 授权「先做一次可学性预检」）。**回应 N32.2 结线卡 §5 的第 1 条**：在比较 S vs RT 之前，先确认任务族里单任务可学到门（0.85）。**本卡不比较两臂、不改任何成绩单、不读确认 seed。**

## 1. 问题

合同 v2（`taiji-23-composition-v2`）的任务，用最小的单任务学习器（单列 GRU＋read_gate）能否在**单任务**上达到门 0.85？需要多少步数/容量？Q3 的 60%「未知」类不平衡是否需要均衡采样？

## 2. 设计（冻结）

| 项 | 值 |
|---|---|
| 数据 | 合同 v2：Q2 训练 24,000 行、Q3 训练 72,000 行；验证各取前 1,024 行（与 N32.2.03 相同协议） |
| 学习器 | `taiji-gru-rt-v1` 单列（`RTSubject` 只建当前题型一列，u=48 或 96），forward 收任务名 |
| 配置 | Q2：u48×{1,200 / 3,000 / 6,000 步}；Q3：u48×{3,000 / 6,000 步}×{普通 CE / 类均衡 CE}，u96×3,000（普通 CE） |
| 训练 | B=48，Adam lr 3e-3 余弦→10%，梯度裁剪 1.0；单初始化 seed 20261120（探索 seed，非确认 seed） |
| 评测 | 验证集准确率；Q3 另报混淆矩阵的「未知」占比（诊断） |
| 预算 | **≤600 CPU**；先冒烟（40 步）外推，超预算即停 |

> **修订（D-20261125-516，冒烟后、正式读数前）**：原 7 个配置冒烟外推 **638 CPU > 600**，按预算收缩为 **5 个配置**：Q2 {1,200 / 3,000 / 6,000 步，u48}、Q3 {3,000 步 u48 普通 CE、3,000 步 u48 类均衡 CE}。去掉 Q3 6,000 步（两种）与 u96（诊断价值低、成本高）。**本修订在正式读数之前，不依据任何读数**；预计外推 ≈410 CPU。

## 3. 出口（读前写定）

| 出口 | 条件 | 后续 |
|---|---|---|
| `precheck_pass` | **Q2 有任一配置 ≥0.85**（单任务可学性成立） | 允许另写 S vs RT 正式卡（沿用该配置的步数/容量），仍须 owner 授权预算 |
| `precheck_fail` | Q2 所有配置 <0.85 | 记「R1 前置不成立：单任务 Q2 不可学」，不得比较两臂；建议重检编码/任务设计 |
| `precheck_partial` | Q2 过门但 Q3 所有配置 <0.85 | 记录 Q3 需要的额外手段（更长训练/均衡采样/更大容量）作为下一卡预注册输入 |
| `engineering_failure` | 缺配置、NaN、超预算 | 修复后重跑本卡 |

## 4. 声明范围

- 本卡**只测单任务可学性**，不构成 R1 的正面或反面证据，不进入交付签署；
- Q3 的均衡采样命中只作诊断，不能替代 S vs RT 比较。

零 check/final；不签 24-S/25-S/29/final/C/D/J。
