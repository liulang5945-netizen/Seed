## 1. 编号规则

| 对象 | 格式 | 例 | 说明 |
|---|---|---|---|
| 阶段 | `N<阶段>` | N31 | 每个阶段有一份成绩单和一个时间盒。N30 及以前全部为历史，不再新增 |
| 研究线 | `N<阶段>.<线>` | N31.2 | 在 N31 中一条线对应一份机制卷宗。`.0` 留给阶段级工作 |
| 探索卡 | `N<阶段>.<线>.<01–89>` | N31.2.03 | 两位数顺序递增，不跳号，不带字母后缀。修 bug 或改设置都要开新卡号 |
| 确认运行 | `N<阶段>.<线>.<90–99>` | N31.1.90 | 只有确认运行能改变成绩单格或机制级别 |
| 开线卡 | `N<阶段>.<线>.00` | N31.1.00 | 写明问题、代理指标、预算、熔断条件 |
| 成绩单格 | `N<阶段> 格<两位>` | N31 格03 | 在阶段内编号 |
| 机制级别 | `级0–级4` | 级3 | 取代草案 v1 中的 M0–M4（与旧资产 M0–M8 撞名） |
| 决策 | `D-<日期>-<序号>` | D-20261124-452 | 不变。决策台账记录决定，不记录工作 |

**文件命名**（统一用短横线）：

| 类型 | 格式 |
|---|---|
| 结果卡 | `plans/reference/RESULT-N31-2-03_<日期>.md` |
| 设计 / 预注册 | `plans/reference/DESIGN-N31-2-03_<日期>.md` |
| 判据清单 | `plans/manifests/n31_2_03_criteria_<日期>.json` |
| 脚本 | `scripts/training/n31_2_03_<主题>.py` |
| 报告 | `reports/n31_2_03_seed<seed>.json` |
| 卷宗 | `plans/reference/DOSSIER-N31-<线>-<机制>.md`；登记表 `DOSSIER-N31-0-REGISTRY.md` |
| 成绩单 | N31 写在阶段规则 §5；N32 起为 `plans/active/SCORECARD-N<阶段>.md` |
| 判词 | `n31_2_03_signal_positive` / `n31_1_90_pass` 等 |
