## 1. 现行规则的三处缺陷（逐条给出处，不是风格问题）

| 缺陷 | 现行文本 | 实测后果 |
|---|---|---|
| **口径错** | 对**原始** `pressure` 取 p90（PLAN-N3-01 §1 的冻结规则，判读器 `count_taiji_n3_pressure_thresholds.py` 的 `distributions["pressure"]`） | 闸比的是 `pressure_ema`（`adaptive_residual_growth.py:388-395`、:437-444）⇒ ㊵-499 的"越阈却不触发"（DEBT-G53） |
| **格宽大于信号** | `GRID = 0.05` 向上取整 | 两链 p90 间距只有 0.007085–0.009236 ⇒ circuit 链被送到 0.70，而其可触发上界是 0.685877 ⇒ **候选落在全场不可能达到的位置**（circuit 两档六道合取真步数 0） |
| **动态范围是"另一步"而不是验收** | 旧 §4.5"先测"是流程要求，不在判据里 | 冻出一个"够不到的阈"在旧规则下**仍然算冻成功**；PLAN-N3-04 的 J-N3b-阈 因此要靠事后否证支才拦下来 |

## 2. 升版后的规则（逐字冻死；四步按顺序执行，任何一步不满足即整件不判）

1. **口径**：τ 的母量＝**`pressure_ema`**（v2 面每行的 `decision_pressure` 键，即产品 `:475` 装进决策的那个值）。
   **不许**再用原始 `pressure`。旧面（v1）没有这一列，只允许按 PLAN-N3-07 §2 那条恒等式**重放**得到，
   且必须同时通过 A-1（逐行 `should_propose` 全等）与 A-2（逐行 `pressure_digest` 全等）两条锚点——本件跑的是 v2 面，不需要这条豁免。
2. **warmup 处置**：取分布前**先剔除**每支面最前面 `K = 17` 条观测（推导：`ema_rate=0.25` 从 0 起步，
   恒定信号要 `n ≥ log(0.01)/log(0.75) ≈ 16.0078` 步才进渐近值 1% 内 ⇒ 上取整 17；**推导值，非实测**），
   并在件内自述 `warmup_dropped`（剔了几条）与 `warmup_share`（占原观测数比例）。
   剔除**不是**为了让 τ 变小，是为了不把"平滑还没爬上来"混进分布低分位。
3. **分位与格宽**：τ ＝ `ceil(p90(剔除 warmup 后的 pressure_ema) / 0.01) * 0.01`
   ——**格宽从 0.05 改为 0.01**，理由写死在本件 §1 第三行（0.01 < 两链间距 0.007–0.009 的 2 倍 ⇒ 链间差异不再被取整吞掉；
   而 0.001 会细到超出这套观测本身的精度，故不取）。分位数仍取 **p90**（旧规则意图：不给 max，给连续段留空间）。
4. **动态范围改为硬验收（本件的核心改动）**：按 ③ 算出的 τ 必须**在同一支面上**满足
   `六道合取为真的最长连续段 ≥ required_pressure_steps`（面内自述值，默认 3）；
   不满足 ⇒ **该 τ 判"不可冻"并出版为负结果**，同时报出"要可解，τ 必须 ≤ 本面五道同真窗口内合成量上界"那个数
   （重放仪已经算过它：`tau_fire_ceiling_within_five_gate_windows`）。
   ⇒ 新规则下"冻出一个够不到的阈"这件事**结构上不可能再被报成成功**。

## 4. 判据（先冻；两条，互斥分支各自有名字）

* **J-N3e-规则**（主判据，逐面各判一次，五面全报不许只报绿的）：
  按 §2 四步走完 ⇒ 该面出版 `tau_candidate_v2` 并判 `freezable`；第 ④ 步不满足 ⇒ 判 `not_freezable_at_this_grid`
  并出版那条"必须 ≤ X"的上界。**两链的候选值若不同，本件只报差、不解释成因**（解释需要单变量臂，那是另一件）。
* **J-N3e-跨链分辨力**（新规则自身的有效性检验，能为假）：
  若 beta 与 circuit 两支同 gate 档的 `tau_candidate_v2` **相同**，判"0.01 格宽仍不足以分辨这两条链"⇒
  本件的升格主张被否证，须回到 0.001 格或改用别的统计量（先登记再讨论，不许当场换尺）。
  若不同，判"格宽升版后链间差异可分辨"——**这只说明尺子有分辨力，不说明 τ 定对了**；τ 定对与否由 §2 第④步说话。
