# 开线卡：N32.2 研究线 R1——任务无关共享表征的实际收益（预注册）

> [开线卡·预注册] — 2026-11-25（D-20261125-506）。依据核心需求 §2.1 v4（R1）、路线 C 的 B 段（owner 授权，D-20261125-506）、[阶段规则](../active/STAGE_GATES_AND_STOPPING.md) §3。**研究线：结论只有「成立 / 未成立（当前规模）」，不进入交付签署。** 本卡零训练，0 check/final。

## 1. 问题

在输入格式完全相同的一组任务上，一个**不给任务名**的共享模型，能否靠共享表征得到**实际收益**：学两跳关系（Q3）时，比各任务各用一列、互不共享的外控模型（RT）学得更快、更好？

与 N31.1 的区别：N31.1 的三个任务输入格式不同，看输入就能分出任务（0.996–1.000），共享也没有可迁移的内容。本线的三类题都是关于同一个三物体世界的中文问句，Q3（两跳）由 Q2（一跳）组合而成，共享表征有东西可以迁移。

## 2. 任务族与数据（已冻结的 23.1 合同 `taiji-23-composition-v1`）

| 项 | 内容 |
|---|---|
| 任务 | Q1「X 现在在哪里？」（位置）、Q2「X 的 d 边是谁？」（一跳关系）、Q3「X d1 边物体的 d2 边是谁？」（两跳关系） |
| 输入 | 编码 `taiji-23-composition-ticks-v1`（`taiji/composition_encoding.py`）：3 个场景 tick（名称、坐标、颜色字嵌入；顺序按世界 seed 打乱）＋每字一个问句 tick；三类题**格式完全相同**；≤24 tick |
| 输出 | 10 类答案（左边/中间/右边/未知＋6 个名称）；共享模型用一个 10 类头 |
| 训练数据 | 新生成的世界（seed 23,100,000 起，12,000 个，见 N32.2.01），与冻结分区的世界不相交；题目按合同的 train 风格（模板组 0，方向只有左/右） |
| 验证（设门） | **冻结的 train 分区**（512 个世界 × Q1/Q2/Q3），本线只用于评测、不训练（披露） |
| fit（只报告） | 冻结的 fit 分区（留出方向前/后、留出顺序、其他措辞、Q4）；训练从未见过前/后，**不设门** |
| check / final | 继续封存，编码器拒绝读取 |

## 3. 臂与协议（N32.2.02 起适用；单变量后续卡只能改一项）

| 臂 | 结构 |
|---|---|
| **S（主臂，任务无关共享）** | 单个 GRUCell(48→96)＋末步输入 read_gate＋读出 96→64→10；**前向只收 ticks** |
| **RT（对照，外控不共享）** | `taiji-gru-rt-v1`，每类题一列（u48），前向收任务名；参数约为 S 的 1.1 倍（两者参数量都写入回执） |

- 课程：Q1 → Q2 → Q3 顺序，每阶段 1,200 步；B=48；Adam lr 3e-3，每阶段余弦衰减到 10%；梯度裁剪 1.0。S 对旧题型用固定回放（每个旧题型每步 16 条，取自训练池）；RT 各列互不相交，不需要回放。
- Q3 阶段在第 150 / 300 / 600 / 1,200 步评测两臂的 Q3 验证准确率。
- 诊断（不设门）：①迁移探针：S 学完 Q1+Q2 后冻结循环核，只训读出 300 步学 Q3；②RT 各列终值；③fit 分区读数。

## 4. 指标与门（每个 seed）

| 门 | 定义 | 达标条件 |
|---|---|---|
| G1 分布内能力 | S 末态在验证集上每类题的准确率 | ≥ gate_k，**gate_k = max(0.85, 最强规则基线_k ＋0.15)**；规则基线（多数类、照抄问句实体、只走一跳等）由 N32.2.01 在训练前算出 |
| G2 共享收益 | Q3 四个检查点上 (S − RT) 的平均值 | ≥ +0.05 |
| G3 保持 | S 的 Q1、Q2 在 Q3 阶段后的 BWT | 都 ≥ −0.05 |

- **与开线提议的差别（披露）**：去掉了「共享块休眠后 ≥2 个任务各掉 ≥0.10」：主臂是全共享模型，这条恒成立，没有信息量；去掉了「不低于 C2 −0.02」：S 本身就是标准共享基线。门槛改为「0.85 与规则基线＋0.15 取大」，避免题目可以靠捷径答对。
- **天花板**：若 RT 在 Q3 第 150 步已 ≥0.95，G2 不可分辨，该卡记 `inconclusive`。
- 代理指标：最弱 seed 的 min(G1 余量, G2 余量)。
