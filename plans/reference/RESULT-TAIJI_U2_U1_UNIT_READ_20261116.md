## 3 归因（探针，11.27 CPU，非冻结门）

**不是剂量**：单 seed 剂量响应 384→768→1536→3000（8×）：train 0.375→0.375→0.406→**0.5**、fit 0.3125→0.344→0.1875→**0.219**。**连训练集都拟合不了**（train 远低于 0.9），8× 剂量后 fit 反而塌、预测类别从 {右/未知} 塌缩到 {左:31/未知:1}——**类别塌缩，不是学会绑定**。

**RGB 信用饥饿**：起点梯度信用 rgb 编码器 **0.0025** vs question 0.0435 vs query 0.073 vs units_p 0.065——RGB 输入编码器比 query 弱 **~30×**。读出机制把信用传给 query/单位参数，却几乎不传回 RGB 内容输入；RGB 置零 agreement≈1.0 实证读出基本不用 RGB。

**架构假设（定位）**：读出 `readout.mean(dim=0)` 在 T=16 列上均值，**把"查询颜色在哪一列"的空间绑定平均掉**——query 绑定到空间平均后的单位态，不保留列位置信号。这与 C 线 C.1（位置注意力近均匀把记录平均成常量）同族，但发生在单位核心 B 的直读聚合上。**编码本身信息忠实**（96/96 oracle 一致），缺口在读出聚合＋RGB 信用路，不在输入。
