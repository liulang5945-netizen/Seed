# 结果卡：P0-AB 继承初始化后的中文翻转（`p0ab_flip_not_learnable`；继承读句权重后翻转仍不可学）

## 1. 设置

在 P0-AA 基础上，训练前把 **cn 块（0:24）的读句权重继承给新生单元（72:96）**（r/w/write_in/write_state/c/eta/b/write_bias、group_index→cn 组、edge_mask 重建），然后直接训练 8 类**翻转** 800 次（无检测课程）。

## 3. 判定

G0 旧中文 ✅；G1 压力 ✅；**G3 翻转 ≥0.75 ❌ 0.523**；G4/G5 ❌；G6 保持 ✅ ⇒ **`p0ab_flip_not_learnable`**。

## 4. 判读

1. **继承读句权重没有让翻转可学**（0.523 ≈ 50% 基线）：新生状态即使能读句，翻转仍只学到「预测正常答案」，**flag 条件没有被用上**。
2. **可能原因**：继承的 `write_bias`（cn 块初始 −2.0）使写门长期关闭，适配器（零初始化、作用于写门）的梯度信号弱；继承的递归动态也可能压制 flag 通路。
3. **旧中文 1.000 无损**（继承只改新生行，未伤旧块）。
4. 与 P0-Y 对比：无继承时**检测**可学（1.000），有继承时**翻转**仍不可学 ⇒ flag 通路与句子通路需要**分别学习/协调**。

## 5. 下一轮方向

1. **继承＋检测预热＋翻转课程**：先学检测（打开适配器），再学翻转；
2. **把适配器从写门改为直接加性输入**（或提高适配器 lr/单独优化器），避免被写门偏置压制；
3. 任务拆解：先固定 `pick_first` 模板（配对另一色 = c2），再泛化。
