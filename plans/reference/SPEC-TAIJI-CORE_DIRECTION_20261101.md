# 09.6.4：出生方向规则候选合同（不授予正式训练）

> 文档状态：[合同] — owner 已于 2026-11-01 裁定「立项，瞄准份额门」。本合同只冻结一个针对出生**方向规则**的可证伪假设与其判据；**不批准 09.7 正式训练或有界能力比较**。前置读数见[09.6.3](SPEC-TAIJI-CORE_FIXTURES_20261101.md#5-执行读数2026-11-01)与 09.6.3b 报告。

日期：2026-11-01。对象为 R023 出生管线与 R021 参考图。`taiji/living_core.py` 字节保持不变。

## 1. 假设与它瞄准的门

09.6.3b 表明方向规则是瓶颈之一：把出生方向换成神谕（holdout 梯度奇异向量）后，新生单元份额从 **2.1e-5** 升到 **2.915e-4**，过了份额门；但绝对贡献只有 5.888e-6，仍差绝对门 17 倍。owner 选定**份额门**（`newborn_share ≥ 1e-4` 且 `retention_drift ≤ 0.030`）作为本合同的判据，绝对门不在本合同范围内且不得被本合同的结果声称满足。

**假设 H1（可证伪、不泄漏 holdout）**：若出生方向不是"整段 fit 生涯的信用 SVD"，而是**在 fit 生涯内部多个留出子窗口上做共识选择**（每个子窗口单独算梯度、归一化后求共识方向），则新生单元份额会从 2.1e-5 升到 ≥1e-4。

为什么这是合理的一步：神谕用的是"对评估集有用的方向"；在不能看评估集的前提下，最接近的合法代理是"对训练生涯内部多个不相交子窗口都有效的方向"。若 H1 成立，说明方向规则缺的是**泛化选择**而不是信息本身；若 H1 不成立，则"份额可达"这条上界与任何不泄漏的规则之间仍有鸿沟，生长线在该参考图上应就此收束。

## 2. 方向规则

- 把 `LONG`（fit 生涯）按步切成 K 个不相交子窗口（K ∈ {2, 4}），每个子窗口等长。
- 对每个子窗口 b，在**父模型**上算该子窗口的 NLL 对其 P 的梯度 `g_b`，归一化为 `ĝ_b = g_b / ||g_b||`。
- 共识方向取 `M = Σ_b ĝ_b ĝ_bᵀ` 的主特征向量（按群计算；每群取 `units_per_group` 个方向时取前几个特征向量）。
- **禁止读取**：`HOLDOUT`、任何 evaluation 生涯、任何 gold。规则只接收 fit 子窗口。

## 3. 判据

必须是预注册的四条，缺一不可：

1. **主判据**：至少一个声明格满足 `newborn_share ≥ 1e-4` 且 `retention_drift ≤ 0.030`，记 `hypothesis_h1_supported`。
2. **基线必须同轮复现**：fit SVD 规则在同一轮、同一父、同一 8 步下必须复现约 2.1e-5 的份额（容差 ±20%），否则说明本轮测面与 09.6.3 不同源，主判据不得判读。
3. **负对照不能过门**：随机方向（同数量、同范数）在同一轮不得达到 1e-4。若随机方向也过门，则该指标无判别力，主判据作废（`metric_not_discriminating`）。
4. **不泄漏守卫**：规则构造函数只接收 fit 子窗口就位；源码级检查 + 运行时断言，若任何一格读到了 HOLDOUT 则整轮作废（`leak_detected`）。

## 4. 网格、预算与出口

- 网格：`K ∈ {2, 4}` × `steps ∈ {8}`、`lr = 1e-5`、`units_per_group = 2`，共 2 格；另加基线格与随机格各 1，共 4 次训练。
- 预算：≤1800 CPU 秒 / 3600 墙钟秒；超限 `budget_stop`。
- 出口：`hypothesis_h1_supported`／`hypothesis_h1_refuted`／`metric_not_discriminating`／`leak_detected`／`baseline_face_mismatch`／`budget_stop`／`engineering_failure`。
- 交付：本合同、`taiji/birth_direction.py`（共识方向规则，纯函数、只吃 fit 子窗口）、`tests/taiji_native/test_birth_direction.py`、`scripts/training/verify_taiji_birth_direction.py`、`reports/taiji_core_birth_direction_20261101.json`、MAINLINE/03 同步。
- **通过只表示份额门在声明网格上被一个不泄漏的规则达到**；不表示绝对收益成立、不表示任务能力、不表示 09.7 准入。绝对门（≥1e-4 NLL）在本合同之外，任何引用本合同的结果都不得声称它。
