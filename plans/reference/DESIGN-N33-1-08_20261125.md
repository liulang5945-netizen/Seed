- 只为 rollout 采样传入显式局部生成器：`sample_gen = torch.Generator().manual_seed(seed_from("N33.1.08", train_seed, "sample"))` → `torch.multinomial(dist, 1, generator=sample_gen)`（同时在 GAE 中用 `float(values[t].detach())` 消去张量标量转换警告，数值语义不变）。
- **全部超参与网络保持不变**：`ActorCritic(train_seed)`（`7→64→Tanh→6/1`）、`EPISODES = 6000`、`ROLLOUT_EPISODES = 8`、`PPO_EPOCHS = 3`、`CLIP = 0.2`、`GAMMA = 0.95`、`LAM = 0.95`、`LR = 3e-3`、`VALUE_COEF = 0.5`、`ENTROPY = 0.05 → 0.005`、训练 seed `1001/1002/1003`、评测 seed `5000–5039`。
- **G2 尺子保持 N33.1.07 冻结固定探针集**：env seed `7000–7199`，每域 `K=150`（pool `rest=969, verify=358, work=2247`），阈值 `0.50` 不变。

## 2. 两遍逐位复现门槛（前置强制）

对每个训练 seed 独立跑两遍 `train_policy_det`（Pass 1 与 Pass 2）：
- `weights_exact`：所有参数张量满足 `torch.equal(p1, p2)`；
- `metrics_exact`：Pass 1 与 Pass 2 的 `return_normal`、`return_zeroed_state`、`fixed_shares` 完全相等；
- 只有两遍逐位一致（`repro_exact = True`），才采信门读数；否则直接判 **`repro_failure`**。
