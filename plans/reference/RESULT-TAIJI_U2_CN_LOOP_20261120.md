## 1. 协议

- 场景 3 物体＋连续 3 条中文指令；动作 = 把**最后一条**指令应用到场景（槽位×方向，12 类）；
- 两次尝试：attempt0 看场景+指令；attempt1 额外看**上一次动作**与**带噪成功/失败反馈**（模拟器 70% 正确）；
- 两臂：no_feedback（反馈与上次动作屏蔽）、with_feedback；位置注意力读出；replay 上界须 ≥0.80；
- 3 seed、209.78 CPU（帽 1,500）。

## 3. 判读与披露（如实）

1. **动作接地本身弱**：单位+读出仅 0.33–0.38（12 类），远低于 raw 上界 0.818——与 D-203 同向（动作类任务受表示/读出限制）；
2. **反馈未被利用**（甚至轻微负向）：本卡设计中训练时「上一次动作」是**随机采样**的，不是模型真实行为，反馈信息与真实纠正动作关联弱；**这是设计缺陷，不得据此判「反馈机制无效」**；
3. **闭环语义未真正实现**：真正的闭环需要在训练/评估中让模型**自己行动**、由模拟器打分、再据结果更新；
4. 不签闭环、指令动作、自然中文、26/27、final/C/D/J/模型成型；零 check。

## 4. 后继

- **修复版**：闭式训练（模型自身动作 → 模拟器反馈 → 下一次尝试），或按 D-196 的证据「以最新信号裁决」直接把反馈作为 tick 输入序列；
- 在动作接地本身未达可用（0.33）前，闭环增益难以归因；建议先解决动作接地（读出/表示），再重开闭环；
- 累计本卡 ≈210 CPU；零 check/final。
