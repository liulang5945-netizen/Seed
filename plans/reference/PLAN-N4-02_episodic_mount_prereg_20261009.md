# PLAN-N4-02 · 情节写入挂载与真值材料现生（预注册：判据先冻、实施另批、不开跑）

日期：2026-10-09 · 线别：N4 读取形态补全 · 母件：[PLAN-N4-01](PLAN-N4-01_addressing_measurement_prereg_20261008.md)
批准：owner 第十次弹窗裁"**批：做挂载＋跑**"（台账 08 ㊵-568 之后；本件把"做挂载"的设计冻结成可评审文本）

## 0. 来源：堵点的精确定位

㊵-568 现读证实：连 owner 批过的巩固跑（n2c1）写出的新档里也只有 episodic 的**配置**（`memory_episode_dim`/
`episodic_learning_rate` 等超参），**没有任何 episodic 状态键** ⇒ N2 链的 `sleep_pass` 在这条挂载上
不产情节写入。而 N4 的真值记录（`memory_id + cue`）只能在"挂上 `EpisodicMemoryStore` 并写入"的跑里现生——
产品侧挂载点**已经存在**（`taiji/model.py:7113` `attach_episodic_memory(store)`），缺的是：
谁在跑里写、写什么当 `cue`、写完怎么持久化。本件把这三件事冻住。

## 1. 挂载与写入策略（冻）

| 项 | 冻结内容 |
| --- | --- |
| 挂载点 | 训练器在装载后调用产品现成的 `Taiji.attach_episodic_memory(store)`（`taiji/model.py:7113`），**不新增挂载 API** |
| 存储容量 | `capacity=1024`（与 N4 面仪器的默认一致，超出按产品语义淘汰最旧条目——淘汰行为本身是读数的一部分，照实出版） |
| 写入时机 | **每篇文档边界**写一条（训练流以边界符分篇；篇边界计数器现数） |
| 写入内容 | `memory_id = f"doc-{n:06d}"`（n＝本跑内篇序，从 0 现数）；`cue = 该篇**前 32 字节**的 float 向量 ÷ 255`（可由语料字节复算、与模型内部状态无关——首版刻意选**模型无关**的 cue，把"模型内部表示当 cue"留给后继格，避免一次引入两个变量） |
| 持久化 | 每次落 checkpoint 时把 `store.checkpoint()` 一并写入同一信封的新键 `episodic_memory`；`from_checkpoint` 往返校验由契约测钉 |
| 训练器旗标 | `--episodic-mount`（默认关 ⇒ 逐位不变；给值即挂载并按上表写入） |

## 2. 真值材料现生（冻）

写入器在跑完（或每 checkpoint 间隔）出版两枚 JSONL：`materials`（`memory_id + cue`，即全部已写条目）
与 `queries`（从已写条目**分层抽样** 100 条的 cue，`expected_memory_id` 与写入对齐）。
两枚件就是 N4 面仪器 `measure_taiji_n4_addressing_surface.py` 的直接输入——**真值不再由我合成，
而是本跑自己写出来的记忆**。

## 3. 判据（冻；沿用 PLAN-N4-01 的尺，不新增）

* 母量＝`wrong_top1_rate`（四态不塌缩由 N4-01 的仪器守卫保证）；
* `ruler_usable` 必须为 `true`（零干扰夹具那条镜子：若写入的 cue 之间无区分度，尺不可用，整件不判）；
* 报告必须带 `mount_layer="training"`／`product_default_mounted` 自述（N4-01 §5 G-N4-3 的口径）；
* 缺任一项 ⇒ `ran_not_measured`，不许把"没测"读成"测了"。

## 4. 守卫（冻）

* G-N4d-1 **默认关逐位不变**：不给 `--episodic-mount` 时，训练器输出与行为逐位同（信封键集不含
  `episodic_memory`）；给值时信封**多出**该键且 store 往返一致；
* G-N2c-4 同族的分离机检在此**不适用**（本件不比较巩固材料；只保证真值来自本跑写入）；
* G-N4d-2 **写入计数＝篇边界计数**（两者独立计数，不一致 ⇒ rc=2）；
* G-N4d-3 **cue 可复算**：任一记录的 cue 必须能由"该篇前 32 字节 ÷ 255"逐位复算（防写入器漂移）；
* G-N4d-4 **负对照**：把写入器改为"每 10 篇写一条"必须让 G-N4d-2 红（守卫能为假）。

## 5. 实施与跑的批次

* **实施**（产品/训练器代码＋契约测）：可自办，判据如上先冻；
* **跑面**：真值材料现生后，N4 面（100 查询 ≈0.8 s，㊵-560/561）**另批**——虽然成本极低，
  "批准跑面"与"批准实施"分开记账，避免把两者混成一次授权。
