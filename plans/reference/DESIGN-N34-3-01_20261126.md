# 预注册卡：N34.3.01 生长决策学得化（探索，≤300 CPU）

> [预注册·探索] — 2026-11-26（D-20261126-646；owner 长期授权「合理即批」下探索卡）。依据 v4 条款「按需新增/分化/整合/休眠/唤醒/回收……**选择与调整须由主体内部学得的策略产生**；脚本常数、手工规则或外控调度只能作为对照或工程原型，不计入达成」。现状：N33.3/N34.2 的生长由 `GrowthPressureController`（工程规则）触发——**生长决策本身尚未学得**。本卡验证「生长决策可由主体内策略学得」。

## 1. 设置

- 环境：`taiji-continual-growth-v1` 两阶段任务（P1 3 类、P2 3 对 parity mod 3）；网络 `PlasticGrowthNet(16, 8, 6)`；
- 每局：P1 训练 250 步 → P2 热训 150 步 → **一次生长决策** → 施加动作后再训 250 步；
- 动作（主体策略输出）：`no_grow` / `grow8` / `grow16` / `grow24`（中性新增单元）；
- **奖励 = 最终综合准确率 − 0.001×新增单元数**（真实收益−成本）；
- 策略：MLP(4→32→32→4)，观测 `[验证误差, P1 准确率, 已增容比, 1−验证误差]`；REINFORCE＋滑动基线与显式采样生成器；
- 训练：每 seed 50 局；评测：20 个留出任务 seed；
- 对照：`no_grow`、`grow8/16/24` 固定、**脚本压力规则**（val_err>0.15→grow8）；
- 探索 seed 6501–6503。
