# 请求条件证据读取的有界学习准备

> 22.5.P3.4，2026-11-12。P3.3按工程回执通过。当前唯一队首P3.4.1，先完成参数配平控制与新父checkpoint预检，随后统一实价并冻结学习合同。

## 1. 待验证命题

在相同旧参数、公开单场景输入和原生字节表达下，直接request→公开感知token读取能否改善实体位置问答的输入条件化，并超过同参数增量控制。现有证据支持优先测试该路径，有限剂量、感知和表达优化仍可能导致失败。

主范围沿P1/P2的六个已见颜色实体、左/中/右/未知四类中文回答与257字节自由输出。训练1–2对象、开发未见3对象，保持全部应答分母。允许标签来自公开图像的训练监督，模型forward接收公开观测/请求/动作/坐标/结果。物理私有状态和答案表不进入forward。

## 2. 四臂与父

| 臂 | 旧参数父与增量 | 作用 |
|---|---|---|
| Native-old | P2 Native-conditional末参数，22,742参数 | 原读取路径控制 |
| Native-query | 与old相同194张量，新增584参数读取器，23,326参数 | 直接任务条件证据读取 |
| Native-capacity | 同一旧参数父，新增584个实际参与前向的参数 | 排除单纯增加参数与查询残差映射的解释 |
| Transformer | P2同一冻结Transformer研究父，22,373参数 | 合理通用基线，登记其全部先前学习成本 |

Native-capacity拟用16→23→8 MLP及一个可学习残差尺度，共391+192+1=584参数，输入当前request和H读取，经原生表达输出。与新读取器采用相同初始残差量级。所有声明参数须有完整回答梯度，空参数补数不接受。实现后将此定义冻结为具名候选类型与bundle身份。

Native三臂共同旧权重必须逐位相同，新参数固定生成种子，Adam统一重置。原始P2学习与本轮学习的成本/谱系分开记录。该比较检验从当前研究父继续发展的收益，从头训练结论需独立实验。

## 4. 合同待实价冻结的细节

拟保持train64与单种初始化的开发范围，fit另用未对模型读取的新recipe段32例，price8。最终序号/摘要在执行清单中固定。此前已读fit全部继续属于开发集。封存check/final当前读取0。数据生成失败和配对不可用均具名结案。

首比较采用相同逐字NLL与自由生成，保留EOS和64字节上限。整体主行为拟沿开发门fit≥0.50，query相对old及capacity各增益≥0.15，同时报告配对bootstrap与全部单例。候选似然重评分仅作归因，不能替代自由回答。正式A父仍须0.80、3seed及独立check。

拟从当前未分配16950 CPU中提出最多3600 CPU/7200 wall的开发票据，具体每臂训练额、更新数上限及评估余量按实价冻结。该数目前是上限草案，尚无可执行剂量。先验证较充分的输入学习剂量，P1/P2的约32训练CPU不直接复用。失败不得通过修改已读门、扩大数据或更换头后继续签同一实验。

必须记录原RGB/坐标切断、request置换、关闭新读取、时间/来源扰动的效应。来源id仅作审计，不能作为实体语义输入。四事件/128token边界固定，本轮单事件范围不签previous、跨会话或长期任务。若只提高输入敏感性但自由回答未过门，按conditional_credit_only结案。若所有Native臂相近，则新增读取机制的独立收益未证；若Transformer也失败，保留任务/优化混杂并全局收束。
