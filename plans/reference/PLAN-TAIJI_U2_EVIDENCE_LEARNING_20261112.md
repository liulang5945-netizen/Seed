# 请求条件证据读取的有界学习准备

> 22.5.P3.4，2026-11-12。5381更新全部完成并结案，原始出口resource_parity_unavailable，Native配平子比较未支持新增读取收益。P3.5.1可识别任务已交付，当前队首P3.6.4正交学习实价与准入。

## 1. 待验证命题

在相同旧参数、公开单场景输入和原生字节表达下，直接request→公开感知token读取能否改善实体位置问答的输入条件化，并超过同参数增量控制。现有证据支持优先测试该路径，有限剂量、感知和表达优化仍可能导致失败。

主范围沿P1/P2的六个已见颜色实体、左/中/右/未知四类中文回答与257字节自由输出。训练1–2对象、开发未见3对象，保持全部应答分母。允许标签来自公开图像的训练监督，模型forward接收公开观测/请求/动作/坐标/结果。物理私有状态和答案表不进入forward。

## 2. 四臂与父

| 臂 | 旧参数父与增量 | 作用 |
|---|---|---|
| Native-old | P2 Native-conditional末参数，22,742参数 | 原读取路径控制 |
| Native-query | 与old相同194张量，新增584参数读取器，23,326参数 | 直接任务条件证据读取 |
| Native-capacity | 同一旧参数父，新增584个实际参与前向的参数 | 排除单纯增加参数与查询残差映射的解释 |
| Transformer | P2同一冻结Transformer研究父，22,373参数 | 合理通用基线，登记其全部先前学习成本 |

Native-capacity已实现16→23→8 MLP及一个可学习残差尺度，共391+192+1=584参数，输入当前request和H读取，经原生表达输出。残差乘数0.2·sigmoid(a)，a初值0，初始乘数与query同为0.1。随机激活幅值仍有差异。5个声明参数张量已获得完整回答梯度，正常候选类型与bundle身份已冻结。

Native三臂共同旧权重必须逐位相同，新参数固定生成种子，Adam统一重置。原始P2学习与本轮学习的成本/谱系分开记录。该比较检验从当前研究父继续发展的收益，从头训练结论需独立实验。

## 4. 合同待实价冻结的细节

已按P3.4.2固定train64、单种初始化及price8，fit选取recipe192–223的32例，模型评测尚未读取。此前已读fit继续属于开发集。具体摘要见价格/数据清单。封存check/final读取0。数据生成失败和配对不可用均具名结案。

首比较采用相同逐字NLL与自由生成，保留EOS和64字节上限。开发门已在价格合同固定为query fit≥0.50，相对old及capacity各增益≥0.15，同时报告配对bootstrap与全部单例；bootstrap为报告项。候选似然重评分仅作归因，不能替代自由回答。正式A父仍须0.80、3seed及独立check。

拟从当前未分配16950 CPU中提出最多3600 CPU/7200 wall的开发票据，具体每臂训练额、更新数上限及评估余量按实价冻结。该数目前是上限草案，尚无可执行剂量。先验证较充分的输入学习剂量，P1/P2的约32训练CPU不直接复用。失败不得通过修改已读门、扩大数据或更换头后继续签同一实验。

必须记录原RGB/坐标切断、request置换、关闭新读取、时间/来源扰动的效应。来源id仅作审计，不能作为实体语义输入。四事件/128token边界固定，本轮单事件范围不签previous、跨会话或长期任务。若只提高输入敏感性但自由回答未过门，按conditional_credit_only结案。若所有Native臂相近，则新增读取机制的独立收益未证；若Transformer也失败，保留任务/优化混杂并全局收束。

## 6. P3.4.2实价及P3.4.3实施合同

[实价回执](VALIDATION-TAIJI_U2_EVIDENCE_PRICE_20261112.md)已交付，CPU67.1875、0step。Native-old/query/capacity/Transformer每更新1.0117/1.0547/1.0547/0.1328 CPU秒，建议510/490/490/3891更新，各约516 CPU秒，合计5381步。新fit32已确定且未送模型。另预留180后，当前未分配16590 CPU。

运行器准入按以下顺序完成。

1. 对照价格清单核验全部源、四份initial字节摘要、完整数据摘要和batch顺序。再次确认Adam空状态、参数及revision一致。episode输入保持公开字段，运行器无目标值读取旁路。
2. 固定执行合同，原生三臂及Transformer均用同一逐字NLL、Adam配方和batch2，按建议步数执行。运行器帽拟3240 CPU/6480 wall，与前两卡预留180+180组成阶段3600 CPU/7200 wall。单臂实际训练CPU及评估/checkpoint开销分开报告。
3. 核对实际可用磁盘和5381份逐步checkpoint的估算占用，预留终点报告和最后一次读回空间。以原始父和规范数据为恢复根，单写者锁、逐步claim及accepted账本共同约束写入。
4. 每次更新前固定update/cursor，执行真实Adam后保存全部参数/moment/RNG/游标并读回。首个真实更新逐项核对非空Adam，后续保存采用同一正常入口。checkpoint或账本异常停止，不能在未知提交状态上继续写同一路径。
5. 基线和末态fit均保持32完整分母及自由输出。初始结果读取后源、步数、门值与数据冻结。逐例错误、无EOS、无效UTF-8、预算停止及工程错误按预定规则记录，不能删掉失败样本。
6. 结束核对实际训练CPU配平、完整成本、继承/参数更新、query必要干预及配平控制。若资源失配则比较资格具名限定；行为过开发门仍不自动签正式A父。无增益则按预定范围结案并全局收束。

本节是运行器实施规格。价格清单状态为priced_pending_runner_admission，实际训练剂量须由含运行器源码身份的执行清单最终冻结。

## 9. 完整结案与方向修订

[全局结案](CLOSEOUT-TAIJI_U2_EVIDENCE_LEARNING_20261112.md)记录四臂fit0/8/8/9正确，5381次真实更新全部保存/读回，原始失败与v2恢复均保留。实际训练CPU526.91/522.09/546.03/597.56，四臂配平12.63%超10%门，三Native内部4.38%符合容差；query与capacity逐例同为恒左边，完整输入干预不改变其输出。本轮独立机制收益未证。

事后Native训练内仍0/2/2正确（各8例），四答案重评分均0.25；Transformer训练内7/8，但完整未见fit9/32。train64仅覆盖24个实体问题×答案组合中的21个，fit另混有5个支持未见组合。由此转入[P3.5重审](PLAN-TAIJI_U2_LEARNABILITY_REVIEW_20261112.md)，先分离任务可识别性、Native训练内拟合与组合迁移，审查原生图计算摊销和真实优化器定价。当前没有追加本轮训练或新的学习剂量。
