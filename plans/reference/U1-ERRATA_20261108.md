## 1. E1：定理 5.1（FP1 全域化）的 β→∞ 子句

### 1.1 原文

U1 §5 先把算子定义为**带球约束**的近端问题

`F⁺ = argmin_{‖X‖_F ≤ C_F} ½‖X − F₀‖_F² + ½ Σ_j β_j ‖Xᵀk_j − v_j‖_F²`

随后定理 5.1 断言两句：①旧 `edit_fast` 在 `e=k`、`w=η/(1+η‖k‖²)` 时与**单对无约束** FP1 解逐项相等；②**β→∞ 时读出响应沿 k 精确收敛 v**。

### 1.2 为什么②为假（证明边界）

记 `K=[k_1…k_m] ∈ R^{d×m}`、`V=[v_1…v_m] ∈ R^{r×m}`，关联方程即 `XᵀK = V`；最小范数精确解 `X_min = (K⁺)ᵀVᵀ`，其范数

`ρ ≜ ‖V K⁺‖_F`（单对且 ‖k‖=1 时 ρ = ‖v‖）。

对**任意**可行 `‖X‖_F ≤ C_F`，令 `A = X − X_min`，取 K 的紧奇异分解 `K = UΣWᵀ`（U 正交列、Σ 只含非零奇异值），则

`XᵀK − V = AᵀK = AᵀU Σ Wᵀ` ⇒ `‖XᵀK − V‖_F ≥ σ₊(K)·‖AᵀU‖_F`

而 `‖AᵀU‖_F ≥ ‖X_minᵀU‖_F − ‖XᵀU‖_F ≥ ρ − C_F`，故

**`‖XᵀK − V‖_F ≥ σ₊(K)·max(0, ρ − C_F)`，与 β 无关。**

单对特例：误差下界 `‖v‖ − C_F‖k‖`，读出被压缩为 `(C_F‖k‖/‖v‖)·v`。β 再大也消不掉——因为约束不是正则项，增大 β 只会让无约束解更远地飞出球外，可行集内的最优仍被球面截住。

独立数值证据（复核 R1，float64）：`C_F=4, ‖k‖=1, ‖v‖=5` 时，β=1e6 下无约束误差 5.0e-6、带约束误差 **1.0**；绿对照 `‖v‖=2<C_F` 时约束不激活，误差 2.0e-6 → 0。

### 1.3 勘误后陈述（替换 U1 §5 定理 5.1）

> **定理 5.1a（有限 β 等价，前提必须同时满足）**
> 当 `e=k`、`w=η/(1+η‖k‖²)`、`α=1`、`χ=1`、`F₀=F_t`、且球约束未激活时，旧 `edit_fast` 的单对更新与 FP1 的**无约束**单对解逐项相等（数值 500 例最大差 1.87e-14）。**六个前提缺一不可**；一般情形下二者是**两个不同算子**，不构成恒等。
>
> **定理 5.1b（极限，带容量条件）**
> 对约束 FP1 族（β 自由），β→∞ 时：
> - 若 `ρ ≤ C_F`（约束未激活）：读出沿 K 精确收敛 V，收敛率 `β/(1+β)`；
> - 若 `ρ > C_F`（约束激活）：读出误差有正下界 `σ₊(K)(ρ − C_F)`，且随 β 单调逼近该下界而不趋 0。
>
> **登记（口径边界）**：`edit_fast` 的 `η_e = 16σ(·) < 16`，故 β 在真实参数化下**有上界**，β→∞ 不可达；5.1b 只是对「β 自由的 FP1 族」的陈述，**不能读作对 `edit_fast` 的陈述**（与 11-04 审查 B1 的 1/17 同源）。

### 1.4 新增可计算证书（本勘误的实质增量）

对每个域 `(K, V, C_F)` 定义两个**互不替代**的量：

- 容量缺口 `δ_cap ≜ max(0, ρ − C_F)`：系统**相容**（`ker K ⊆ ker V`）但球太小 ⇒ 加容量（球半径/秩/键维）**可以**把下界压到 0；
- 结构残差 `δ_comp ≜ ‖V(I − K⁺K)‖_F`：目标本身不相容 ⇒ 任何可行 X 的残差 ≥ `δ_comp`（取 X=0 即达），**加容量不能降它**。

判定式：`δ_comp > 0` ⇒ 结构性不可分，生长无效；`δ_comp = 0 且 δ_cap > 0` ⇒ 容量不足，生长有效。这正是生长触发的判据基础（见 [生长设计](SPEC-TAIJI-GROWTH_DESIGN_20261108.md) §2），也是 owner 所问「扩容能不能救」的代数回答：**只有当 δ_comp=0 时才可能救**。

## 2. E2：命题 4.1（归一性）的 null 前提

### 2.1 原文与破裂点

U1 §4 同时给出

`P_b(y) = γ'_b G_b(y) + (1−γ_b) C_b(y)`，`γ'_b = γ_b + (1−γ_b) q^b_null`，并断言 `Σ_p w^b_p = 1 − q^b_null`；

而 `w^b = λ_b m_b + (1−λ_b m_b^{mass})·anchor_b`，其中 `anchor_b = α_b·β_b`、`α_b = softmax([…; null_b])`（**含 null**）、`β_{b,·}` 为记录内位置 softmax。

由 `Σ_p anchor_p = Σ_i α_{b,i} Σ_p β_{b,i,p} = 1 − α_{b,null}` 得

`Σ_p w^b_p = λ_b m_b^{mass} + (1−λ_b m_b^{mass})(1−α_{b,null}) = 1 − α_{b,null}(1 − λ_b m_b^{mass})`。

于是 `Σ_y P_b(y) = 1 + (1−γ_b)[ q^b_null − α_{b,null}(1 − λ_b m_b^{mass}) ]`。

**归一成立 ⟺ `q_null = α_null(1 − λ m_mass)`。** U1 未给此绑定，且把 `q_null` 与 §3 的 `null_b` 当两个量使用。

数值证据（复核 R2）：`α_null=0.1334, λ=0.5, m_mass=0.3` ⇒ `Σw=0.8866`；独立取 `q_null=0.15, γ=0.3` ⇒ `Σ_yP_b(y)=1.0256`；绑定为 `0.1134` 后偏差精确为 0。

### 2.2 勘误（选择绑定，不改 w）

在 U1 §3 增加一条定义，并在 §4 声明同一性：

> **定义 3.x（null 唯一）** `null_b` 与 `q^b_null` 是**同一个** null 质量，且
> `q^b_null ≜ α_{b,null}·(1 − λ_b m_b^{mass})`。
> **推论**：`Σ_p w^b_p = 1 − q^b_null` 恒成立（不再是前提）。

代入即得 `Σ_y P_b(y) = γ'_b + (1−γ_b)(1−q_null) = γ_b + (1−γ_b) = 1`，命题 4.1 由「待验前提」变为**代数恒等式**。

**对 OP2 的口径修正**：OP2 §5 是两级质量 `Q_{ij}=a_iη_{ij}`、`q_0=a_0`。绑定后 U1 与 OP2 逐项对应 `q_0 = α_null(1−λ m_mass)`；但「OP2 定理族**原样**覆盖统一表达」的措辞须撤回——U1 把两级压成单层 `w`，只在 null 绑定下等价。

**对预审的要求**：复核 U1 在 [verify_taiji_unified_u1_math.py](../../scripts/training/verify_taiji_unified_u1_math.py) 第 64–68 行**硬编码**了满足断言的 `w`，属于恒真检查。勘误生效后，预审必须**从 §3/§4 的构造式生成 w**（α、β、λ、m_mass 全走公式），否则不得再作为归一性证据。
