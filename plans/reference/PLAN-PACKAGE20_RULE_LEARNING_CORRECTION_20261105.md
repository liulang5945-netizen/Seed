## 3. 精确任务范围

### 3.1 世界与规则

每个world有4个二值属性，共16种组合。原始中文属性名/值例如“表面细/粗、材质软/硬、哑光/亮面、空心/实心”；这些只规定首包任务范围，不进入宿主语义解析器。规则为

\[
y=b\oplus\bigoplus_{i\in S}x_i,\qquad b\in\{0,1\},\quad1\le|S|\le2.
\]

共20条规则。输出动作是两个原生UTF-8字节串“应送左箱。”/“应送右箱。”；格式可共用字节协议，选择哪个标签必须由模型决定。规则ID、bit向量、真值表及符号求解器仅在生成/评分侧，不给运行模型。不得新增按属性词/字符位置硬解析后算XOR的回答路径。

五个anchor为0000和四个基向量，反馈标签唯一确定规则：b=y(0000)，1[i∈S]=y(e_i) XOR b。其余11组合是未提供标签的查询。v2从其余19规则中抽取，任意规则变更至少改变11查询中的4项，须单列changed_query。

### 3.2 三会话与全部应答轮

| 会话 | 因果顺序 | 应答轮 |
|---|---|---:|
| session1 | 5个未标注anchor先预测并保存receipt；5反馈作为一个原子批次释放后写入；回答预先选定的5个non-anchor；保存完整状态 | 10 |
| session2 | 独立进程恢复；从session1已答5题中重答2题；通知v2生效，先对5个anchor盲答，再原子释放5反馈；答11个current-v2及session1尚未问过的6个previous-v1；保存 | 24 |
| session3 | 再恢复；用新实体名/同范围中文表述重复11个current-v2及6个previous-v1，测恢复、复发与保持 | 17 |
| 合计 | 所有51轮均保留原始字节及评分，解析失败/无合法答案/不答计错 | 51 |

新world-version-query首答共22轮：v1的5＋v2的11＋previous-v1的6。5/6查询划分、重复的2题、anchor释放顺序都在看到标签与模型结果前固定。每个版本独立打乱anchor顺序与句内字段顺序；名字、world标识、seed、来源序号不得编码规则。被模型答过不等于已获得合法反馈，未释放的query标签不回灌E/H/F。

会话内E/H/F持续，版本更正不清空历史；新world是同一候选初态的独立受控生涯分支，不能带入上一world规则。v2的当前答案变更不是遗忘违规；previous-v1查询才检验仍合法的旧版本知识。

该任务只验证已知20规则族、同中文任务范围内的新world/实体/反馈对应及未标注组合迁移。全部规则和16组合在外层训练中可出现，不声称未见规则族、全局未见属性空间或一般中文推理。

### 3.3 信息上界与强捷径

不能只与0.5随机猜测比较。仅保留查询和5个anchor标签多重集、丢掉绑定关系，Bayes基线在20规则×11查询上仍可达140/220＝7/11。最近邻、原Task1匹配器和标签/位置/名字捷径同样必须先审计。

51轮包含10个反馈前盲答。理想主体对v1盲答的期望上界1/2；已知v1、v2均匀取其余19规则时，v2盲答上界10/19。因此全轮信息Bayes期望参考为

\[
U_{all}=(41+5/2+50/19)/51=1753/1938\approx0.904541.
\]

它不是单次样本硬上限，也不能被0.95整句门替代。初答错误仍进入51轮分母；22轮新查询、changed_query、恢复重复轮分别报告，不用后续纠正覆盖早先错误。若将拒答另奖或改变动作空间，必须重算任务目标和该参考，不能悄改评分。

## 5. 单一候选图CF1

CF1是反馈绑定快记忆候选，承接M-GRAPH-1，不再为每种题形增加一套独立概率核。复用原生字节encoder、共同H/F图、E回读、query/expression头与来源协议。Task1匹配/复制/停止资产作为旧能力保留，不允许调用符号规则解释器来回答Task2。

| 对象 | 责任与更新 |
|---|---|
| E | 原文、来源、版本、预测receipt、已释放反馈；未知query真值不存入 |
| H | 所有臂按同一合法事件协议推进；每个回答的临时字节游标可重置，主体H不按题重建 |
| F | 首包唯一被检验的在线可塑权重；仅合法反馈批次可写，普通query/自生成答案不能冒充核验事实写入 |
| Ψ/Θ | 会话内冻结；外层训练塑形编码、读、写和表达，具体可塑清单及所有消费者在20.1冻结 |
| receipt | prediction_id、输入源版本、当时查询表示、模型版本、原始输出、释放/应用状态；重复反馈不得重复写 |

反馈写入将此前查询的合法表示u_pred作为key视图，将已释放反馈u_fb作为value/编辑视图。沿用原有有界擦除/写入公式，但明确两个视图及其投影/门的责任，不再把“当前事件”与“被纠正预测”无条件混成同一个u。硬许可、chi整体编辑/禁写冻结语义继续适用，配对、输入维数和参数增量由正式图枚举。

u_fb在F支路仅含已释放的核验答案字节、反馈类型及当前语义版本等声明字段；prediction/source ID用于journal合法性，不作为value的神经特征。不得在value或门中重复塞入足以重建原query绑定的完整描述/实体名。正常E/H仍接收完整合法反馈，因此置换控制只干预F的指定绑定边，不宣称破坏了所有信息路径；20.1必须列清每条视图的字段与真实消费者。

外层query loss必须能经F读取与合法反馈写入到达负责的key/value编码和读写门；同一训练窗内不能用序列化或全面detach切断这条链。跨会话持久化只存值和revision，不保存autograd图。会话内Θ固定，避免每次反馈改变坐标后重建全部历史；外层更新后下一个world从规范初态重建，不能把旧F直接挂到新编码revision。

外层训练至少将“同一反馈批次→首个反馈后query”保留在同一可微窗，逻辑session边界不冒充跨进程可微恢复。真实跨进程session2/3在冻结外层参数的评估与20.2恢复检查中执行；本包不声称跨进程精确BPTT。F-only、权限关闭、无反馈F=0、共享参数的其他信用及结构零类分开检查，不用总梯度norm代替逐负责组及实际状态/输出变化。

teacher-forced标签仅用于训练评分分支，不能成为后续H/F的未授权事件。持续回答轨迹用模型实际输出推进；从同一support状态分支计loss时必须恢复父分支，不把gold字节提交到真实事件流。先预测、后释放、再应用反馈三步分别落账。

新任务损失以22轮反馈后新查询的决策字节NLL为主，全输出字节NLL另报；同配方同归一用于A/B。盲答的不可辨噪声与恢复重复题不冒充新增监督。语义标签判错不等于编造来源：Task2答案标为基于合法证据的推断，L2检查原文/反馈身份与未来信息隔离，不能沿用Task1“每个标签字节必须在该原记录抄出”的判据。

新参数按父图实际输入/输出尺度初始化，20.2先确认负责链的有效可辨识性；不能以极小随机块、一个非零梯度或一次head更新签架构通过。L1的UTF-8/EOS协议共用确定性资产，语义标签选择仍由本候选字节概率决定，模板格式正确不计为学习收益。

五个anchor只含少量信息，H/E可能已足够。A/B都成功时，允许结案为反馈条件适应成立、F额外贡献未证；禁止改题或重定阈值直到F胜出。一个算法可解有限规则族不等于宿主替模型求解；只要运行侧真实由共同神经路径承担，学习机制的比较就有意义。

参数、原文信息、持续状态字节和CPU不是同一容量指标，分别配平/记账。若不能给出真实同容量B，不以padding凑数；保留预算匹配结果，但“同容量F净收益”判不可判。符号枚举器的100%只作公开任务上界和有成本的算法参照，不进入运行链，也不把其可解性误判为任何有限学习任务都没有残余。

## 7. 误差预算与裁决提案

以下为设计提案，不是已冻结训练门。20.3在见正式dev结果前一次性冻结，之后不得为过门改数。分母、世界单位、首答/重复、source/semantic version要逐项对应。

| 维度 | 提案与判读 |
|---|---|
| L1 | 合法字节/EOS、身份、来源/反馈顺序、保存恢复、幂等与预算账按工程合同硬守；不能靠平均正确率抵消 |
| 全轮得分 | 51轮全部计入；初答/盲答不删。报告对信息Bayes期望参考及最佳低成本基线的归一差距，不单用0.80/0.95绝对线 |
| 反馈后适应 | v1首答5、全部current-v2的11及previous-v1首答6三个轴各自相对最佳已声明低成本基线b（不含特权符号枚举）：U=(acc−b)/(1−b)提案≥0.50，配对world-bootstrap增益下界>0；22轮pooled只作汇总，不能互相补偿。仅主轴b=1时停止该无残余任务，诊断子集b=1不作此推断 |
| 纠正 | 最多5条合法反馈后，全部11个current-v2独立过适应门；changed/unchanged仅分层诊断。无条件翻转v1在changed上可100%但不代表纠正，previous-v1保持须独立过门 |
| 恢复/复发 | 20.2用同一字节输入/版本/RNG检查恢复前后分布与状态一致；session3新实体/表述只判语义保持和复发，不要求其分布逐位等于不同输入的旧题，也不当新首答 |
| 保持 | 复用账本两层保持原则，Task1子/父比值bootstrap下界≥0.85及硬不变量；Task2-v1的合法历史查询另测已学能力保持，不能只靠结构Task1 |
| F净贡献 | A_F−独立B_EH点差提案≥0.05且95%配对区间下界>0；cutF与反馈置换的因果读数另外成立，才签F额外贡献 |
| 费用 | CPU/wall、外层Adam、F写次数、读/重编码、峰值RAM、快照/恢复及子进程成本实记；不可得记missing，不补0 |

每个预定seed分别报值和区间；pooled不能掩盖方向相反。dev可做world-bootstrap，confirm只按冻结统计一次判定。初答错误与后续纠正都留存；若反馈不足导致不可辨，按定义报告，不归因模型失败。所有满足五anchor信息门的查询仍失败才进入算法候选归因。
