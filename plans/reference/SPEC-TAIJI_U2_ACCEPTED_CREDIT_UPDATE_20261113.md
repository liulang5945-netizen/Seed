# 训练目标验收的参数更新校准

> P3.8.2a，2026-11-13。原P3.8.2工程240 CPU中的90分配给通用更新算子校准，剩余150用于Native责任核验。当前研究父与Native能力资格保持原身份。

## 1. 依据与唯一变更

P3.8.1b同初始化／2000步内容监督对照取得首问train66.11%／dev63.33%，未过原门。保存点的联合训练目标在1900步为0.17506、1950步为1.39074、2000步为0.93753。原末点与固定剂量结论保留，未选择较早保存点签署能力。

本卡保持65169参数body、260参数训练头、初始化、原始RGB／问题、全批180例、byte＋类别平衡内容目标及Adam超参数相同。只改变参数提案的验收规则。两个原卡结果作为冻结对照，dev用于末点评分，更新验收只用train。

## 2. 算子及适用域

固定θ与同批原始经历，g=∇J(θ)。一次Adam提案产生θ_A及新的moment／时钟，d=θ_A−θ。若gᵀd<0，保留该方向；否则在g非零时令

\[
d'=-\|d\|_2\,g/\|g\|_2.
\]

于是gᵀd'=−‖d‖₂‖g‖₂≤0，尺度沿原提案。内积与范数使用float64归约，实际参数按原精度更新。零梯度具名返回，不发优化器提案。

按α∈{1,1/2,1/4,1/8,1/16,1/32,1/64,1/128}依次检验

\[
J(\theta+\alpha d')\le J(\theta)+10^{-4}\alpha g^Td'+10^{-6}.
\]

原方向已下降时上式中的d'即d。实数下，若J连续可微且gᵀd'<0，Taylor式的余项o(α)保证存在足够小的正α满足无容差的充分下降式。有限8次搜索及float32数值容差按实际结果判定，不签全局收敛或完整耦合收缩。

接受则提交该参数值；有限搜索全拒绝时参数恢复，有限Adam moment／时钟继续推进，为下一提案保留学习状态。异常时参数、moment及RNG回到异常前状态，实际Adam调用次数保留。未使用参数的None及其时钟保持原值。

候选检查使用同一CPU RNG起点，并在结束后恢复一次真实前向的RNG后态，搜索不重复消耗随机经历。当前CNN-GRU目标是固定teacher历史、无dropout的平滑目标。Native应用须先冻结实际历史及离散选择，条件目标验收和真实自由运行分别裁决。

## 3. 计数、保存与推理

分别记录梯度批次／提案尝试、真实Adam调用、接受参数更新、搜索次数、回退方向和α。学习器时钟与参数版本分别登记，原checkpoint的180×update在本卡表示优化梯度样本呈现量。完整保存body、训练头、两个optimizer组、RNG、接受计数及更新源码身份，前后独立恢复比对全部23参数梯度／概率／greedy输出。

body-only导出及移除头后的全分母生成仍沿原factory，运行时只有原257字节生成器。训练头分类及目标下降只作诊断，主判据仍train≥0.95／dev≥0.80／每问题dev≥0.80。

## 4. 预算与有限出口

固定90 CPU／180 wall，训练≤60 CPU、最多2000次梯度尝试，接受最后预算内完整状态，超限一次隔离并回滚。所有搜索／方向计算／真实Adam均计入训练CPU。与原固定2000步对照报告梯度样本数和实际费用，不推定严格CPU配平。

达标为first_round_calibrated_stable_credit，完整未达标为stable_credit_not_calibrated，源／恢复／非有限为engineering_failure，超帽为budget_stop。本卡只运行一次。后续Native接口需核验参数版本／学习器时钟、影子提交与完整历史，当前并未签署Native更新算子生效。

原剩余900 CPU中预留90后810，Native工程余150／runner草案600／审计草案60仍在原1110研究额度内。原两个负结果和所有开放开发集读数保留其身份。
