# 备忘：22.5.1 子体跨会话积累探针（`cross_session_no_learning`，天花板限制）

> 文档状态：[证据备忘/负面] — 2026-11-20。机器回执：[`taiji_u2_22_5_1_cross_session_20261120.json`](../../reports/taiji_u2_22_5_1_cross_session_20261120.json)（`58.16 CPU`、预注册帽 `220`、`0 check/final`）。预注册出口：`budget_stop`／`engineering_failure`／`cross_session_retention_breach`／`cross_session_no_learning`／`cross_session_accumulation_pass`。

## 1. 预注册协议

- **session 1**＝已保存联合门子体（器官已用 `train[:64]` 训练 256 步）。
- **session 2**＝**同一子体**继续训练 256 步、`train[64:128]`（不相交批次）、**新优化器**（模拟会话边界），学习率/权重与联合门协议一致。
- 评测面：S1＝`train[:64]` 前 24 个非未知 B 项；S2＝`train[64:128]` 前 24 个。每面在 session2 前后各评一次。
- 判据：S1 保持下降单侧 95% 上界 `≤0.02`；S2 习得增益 `>0` 且 95% 下界 `>0`；继承参数逐位不变。

## 2. 读数（三 seed 一致）

| 项 | 读数 |
|---|---|
| S1 面 B（session2 前 → 后） | `24/24 → 24/24` |
| S2 面 B（session2 前 → 后） | `24/24 → 24/24` |

| 继承参数 | 逐位不变 |
| `organ_mix` | `1.2024 → 2.31～2.35`（session2 确实更新了器官） |

**判词：`cross_session_no_learning`**（习得无增益，触发预注册负出口）。

## 3. 判读（为什么是「天花板」而非「不会积累」）

1. **S2 面在 session2 之前已 24/24**：联合门训练只用 `train[:64]`，但器官是**匹配滤波式路由**——对新 world 的 B 项直接泛化，因此继续训练没有可提升空间；增益恒 0 是**天花板效应**，不能写成「跨会话学不会新东西」。
2. **保持与身份成立**：session2 在不相交批次上继续训练后，S1/S2 表现均 `24/24`，继承参数逐位不变，`organ_mix` 上升说明训练确实发生——「跨会话继续训练不破坏既有表现/不污染继承权」在 fit/train 面成立。
3. **机制含义**：当前 Task B 的「学习」主要是**路由技能**（把匹配到的记录导向输出），不是内容记忆的增量写入；所以 24/24 在训练早期就饱和。这与联合门「反馈学习净益 1.0」的机制解释一致，也说明要检验**新内容积累**需要更硬的任务面（新实体/新谓词/4 体世界或 22.6 的 C 任务），而非继续加同分布训练步。

## 4. 边界与后继

- 零 check/final；不改既有判词；22.6 仍锁定。
- 后继建议：① 若要在 22.5.1 面补「新内容积累」，需预注册**新任务面**（held-out 谓词/实体或 4 体世界），并接受 ceiling 风险；② 更自然的位置是 22.6 C 任务（限时取证/求真），其数据本就不与训练同分布；③ 本卡作为「跨会话保持不退化」的边界证据引用，不签「跨会话积累新知识」。
