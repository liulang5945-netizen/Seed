## 样本 2（history=1）

历史用户1：编写一个python for循环
历史助手1：当然，我可以帮你解决这个问题。Python 中的 for 循环用于对一个序列 (即一个列表、一个元组、一个字典、一个集合或一个字符串) 进行迭代。它不像其它编程语言中的 for 关键字，而更像其它面向对象的编程语言中的迭代器方法。

for循环的语法是：

```python
for val in sequence:
    print(x)
```

这里，`val`在每次迭代中访问`sequence`的每一项，并打印出该次访问的内容。循环一直持续到我们到达序列中的最后一个项目。

例如，如果你想打印一个列表中的每个元素，你可以使用这样的for循环：

```python
fruits = ["apple", "banana", "cherry"]
for x in fruits:
    print(x)
```

这将输出：

```python
apple
banana
cherry
```

你也可以使用`range()`函数来生成一个数字序列，并对它们进行循环。比如说：

```python
for x in range(5):
    print(x)
```

这将输出：

```
0
1
2
3
4
```

你还可以使用`break`和`continue`语句来改变循环的行为。`break`语句在循环完成所有项目之前停止循环，而`continue`语句则跳过循环的当前迭代。比如说：

```python
for x in range(10):
    if x == 5:
        break # 当x为5时终止循环
    print(x)
```

这将输出：

```
0
1
2
3
4
```

```python
for x in range(10):
    if x % 2 == 0:
        continue # 跳过双数
    print(x)
```

这将输出：

```
1
3
5
7
9
```
