# 判定纪律（2026-11-18 立，因当日反复自我推翻）

> 用途：约束"什么时候可以说结论"。本文件由 2026-11-18 的事故倒推而来，每条都对应当日一个具体反转。

## 1 三级判定

| 级 | 允许的说法 | 前提 |
|---|---|---|
| **读数** | "本次运行得到 X" | 一次运行，须标种子数、样本数、预算 |
| **推断** | "在 A 对照下 X 大于 Y，方向为 Z" | **至少一个对照臂**，且机制可命名 |
| **结论** | "X 成立／不成立" | 预注册判据 + **≥2 个独立见证**（不同种子或不同路径）+ 红向演练能失败 |

**禁止**：拿"读数"当"结论"。单次运行不得使用「成立／越过／证明／不可能」。

## 3 四条硬规则

1. **先穷尽零更新路径**：任何"必须训练才能改善"的结论之前，先证明"不训练做不到"。E5 三轮的代价就是没做这一步。
2. **归因必须带对照**：说"瓶颈在 X"时，必须同时给出"去掉 X"的对照臂读数，否则只能写"读数分布"。
3. **换道前先做等价性/函数类分析**：能证明两个改法等价时，不要花预算去跑。
4. **反转必须落账**：每次推翻自己，在当日台账写一行「原判 → 新判 → 依据」，不得静默改写历史卡。
