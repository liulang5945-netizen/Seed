## 加固 C：`.gitignore` 按约定覆盖打包运行目录

**根因同类性**：`.gitignore` 里 `output/` 是**逐个实例名**列举（`output/taiji_m5_k_p3_0_*` 等一长串），
`p6-1d-packaged-data` 不在列表 ⇒ 被跟踪。**与"带斜杠锚定"是同一类疏忽：写死实例名而非命名约定。**

**改法**（`.gitignore` L215–220，两条互补）：
```
output/*-packaged-data/     # 按命名约定覆盖整族
output/p6-*/                # 兜住当前实例
```
**不能整体 ignore `output/`**：那里有 23 个**有意入库**的版本化验收证据
（`manual-r5-*/README.md`、`output/playwright/*.png`）。

① 按约定覆盖（同时探 `p6-1d-packaged-data` 与**假想的** `anything-packaged-data`）；
② **反向钉住**（通配不得吞掉有意入库的产物 —— 只查一侧会接受"为了不泄漏而把验收证据一起 ignore"的坏中间态）。
