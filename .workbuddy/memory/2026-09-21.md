- 落档：`plans/reference/FRONTEND_TS_VS_HARNESS_ADOPTION_DECISION_BRIEF_20260921.md`（状态：待所有者裁定，未裁定前不产生代码改动）。
- 待批准后唯一下一步：前端 TS 地基（`typescript` + `vue-tsc` + `openapi-typescript`；`tsconfig.json` 开 `allowJs`、`checkJs:false`；由 api OpenAPI 快照生成 `src/api/schema.d.ts`；`nativeApi.js` → `nativeApi.ts`；CI 加 `vue-tsc --noEmit` 仅限新增/改动文件）。零 `.vue` 改动、零回归、可逆。
- 可借用思想（借架构不借代码）：append-only session log + trajectory；Code Mode / PTC 收敛 workbench 端点；**dsh 的 Minimal 裸 harness 形态 = R2 所需裸环境对照臂**。

## 卸载"缺陷"反转 + 圆角图标（同日续）
