## 装后体验八条修复（owner 试装 Seed.exe 后逐条反馈；会话 commit 8b51fd0e / 703fc4c5 / 9212c868 / 6e129598）

- **① 与官方 DeepSeek Harness 不能同开**（实测根因，对照本机官方 0.2.0-rc.2 安装版）：fork 原样继承上游两处独占资源——desktop-host 固定 `--port 19387`（官方 asar 里 findstr 同命中）＋共享 `~/.dsh`（profiles/desktop、dsh-runtimes 载荷会互相覆盖）。修法：Web host 改 `--port 0`（OS 分配、ready URL 回报）＋默认家目录 `.dsh`→`.seed`（home-paths 一处；`$DSH_HOME` 覆盖不变；agent-instructions 的 `~/.dsh/AGENTS.md` 硬编码改由 home-paths 常量组合）。

- **③④⑤⑥**：zh 词条改英文；LifePanel 全部换真实主题 token（原来用的 `fill-accent`/`text-tertiary` 等在本仓主题里根本不存在）；FishLogo 改双色层（`--dsw-specific-brand-mark-struct/foliage`，深色主题结构层提亮）；删 hero 旋转（SMIL＋CSS 两处）。
